把已授权的研究内容接入自己的工具。

API 只读开放报告与已生成的内容。先由管理员开通权限，再在“我的账号 → 开发者 API”生成自己的密钥。这里的内容读取与 AI 研究次数分别管理。

1. 创建密钥并开始读取

  1. 联系管理员开通 API，确认内容范围、可用操作及有效期。
  2. 登录账号，展开“开发者 API”，输入用途名称并生成密钥。完整密钥只显示一次，请当场保存。
  3. 在服务端环境变量中保存密钥，通过 Authorization: Bearer 请求头发送。不要把密钥放进 URL、公开代码或网页前端。

API 基础地址：https://kcdesk.com/api/content/v1。以下示例假设已在环境变量 KCD_API_KEY 中配置你的密钥。

curl --fail-with-body \
  -H "Authorization: Bearer $KCD_API_KEY" \
  'https://kcdesk.com/api/content/v1/reports?limit=25'

返回 {"ok":true,"items":[...],"next_cursor":null}。如有 next_cursor，原样放进下一次请求的 cursor 参数并进行 URL 编码；不要自行构造游标。空列表表示本次筛选中没有可返回的报告。

2. 读取报告与关联内容

GET 路径（相对基础地址）用途与参数
/reports报告列表。可选 date=YYYY-MM-DD（报告发布日期）、limit（默认 25，最大 100）、cursor。
/reports/{id}单份报告的元数据。报告 ID 从列表获取，不使用 R2 路径或文件名。
/reports/{id}/download原报告 PDF，直接返回文件字节；需要 reports:download 权限。
/reports/{id}/artifacts可用关联内容列表。可选 kind、language、limit 和 cursor。
/reports/{id}/artifacts/{artifactId}下载列表中指定的关联内容，返回原有 MIME 类型与文件字节；需要 artifacts:read 权限。

有哪些内容可用？

kind 可为 text（文本，可能为摘要或节选）、image（图片）、chart（图表）、metadata（结构数据）、translation（翻译）、article（文章）或 pdf。语言使用列表中的 language，例如 zh、en；und 表示未指定语言。

关联内容描述包含 id、report_id、kind、language、mime_type、size，可附文件名与校验值。文本范围由 text_scope 说明，partial_excerpt 表示节选，不应当作全文；可附 page_number 标明页码。部分索引图表的 size 尚未知时为 null。仅返回实际可用的产物，不保证每份报告都有图片、图表、全文或每种语言的翻译。此接口不会现场生成缺失内容。

# 将 REPORT_ID 替换为报告列表返回的 id
curl --fail-with-body -H "Authorization: Bearer $KCD_API_KEY" \
  'https://kcdesk.com/api/content/v1/reports/REPORT_ID/artifacts?kind=chart&limit=25'

# 将 REPORT_ID 与 ARTIFACT_ID 替换为对应列表返回的 id
curl --fail-with-body -H "Authorization: Bearer $KCD_API_KEY" \
  'https://kcdesk.com/api/content/v1/reports/REPORT_ID/artifacts/ARTIFACT_ID' \
  --output research-artifact.bin

3. 权限、有效期与额度

管理员可选择“沿用网站现有下载权限”，或单独授权一组报告（也可授权全部报告）。API 授权不会修改网站会员状态与网页下载入口。可用操作分别为 reports:read、reports:download、artifacts:read；用户生成的密钥继承当前授权范围。

选择沿用网站权限时，报告 PDF 和关联文件下载也共用网站原有的试用下载额度，按报告去重计次；同一报告的多个关联文件不会重复消耗一次性的报告下载名额。

API 权限有明确到期时间。新密钥默认在 90 天后或 API 授权到期时失效，以更早者为准；每个用户最多保留 5 个有效密钥。撤销单个密钥只影响该密钥；管理员撤销 API 权限会同时撤销旧密钥，重新开通后需重新生成。

默认每分钟 30 次请求、每日 1000 次请求、每日 1 GiB 文件字节，实际以管理员配置为准。同一账号的多个密钥共享额度；每日额度在 UTC 00:00（北京时间 08:00）重置，分钟限额按整分钟窗口计数。完成身份验证后的内容请求都会计入请求数，包括内容不存在的请求。文件传输开始前会预留字节额度，中途中断也可能计入额度。AI 研究额外次数由管理员另行添加，不通过此 API 兑换积分或付款。

4. 错误与重试

错误响应为 {"ok":false,"error":"错误码"}。请先检查 HTTP 状态和错误码，再处理响应正文。

错误码处理方式
key_invalid / key_expired / authentication_required检查请求头与密钥有效期；必要时在账号内生成新密钥。
api_permission_denied / scope_denied / report_denied确认 API 已开通，并包含该操作和报告。
rate_limited降低并发与频率，等待后重试；如返回 Retry-After，请遵循该值。
daily_request_limit / daily_byte_limit当日额度已用尽，等下一个每日额度窗口或联系管理员调整。
membership_required / download_limit_reached网站会员或试用下载权限不可用，请联系管理员核对或续期。
invalid_request / content_not_found使用列表返回的 ID、游标与语言；确认内容仍可用。
service_unavailable稍后以渐增间隔重试，保留已完成下载。

密钥遗失后无法查看原文，可撤销并生成新密钥。密钥管理入口仍在原有账号面板，日常网页报告下载方式不变。
