# EveryCRSReport 按需信息源

KC桌面的「国际智库」纳入美国国会研究处（Congressional Research Service，CRS）报告。未输入关键词时，展示国际智库列表，并优先呈现最新 CRS 报告；输入关键词后，查询该来源的报告元数据。

## 机构与发布渠道

- **研究机构**：[美国国会研究处（CRS）](https://www.loc.gov/crsinfo/)，隶属美国国会图书馆，为国会提供研究与分析。
- **本次接入的网站**：[EveryCRSReport.com](https://www.everycrsreport.com/)，公开汇集、转载 CRS 报告的独立网站，并非美国国会官方网站；运营主体见[网站介绍](https://www.everycrsreport.com/about.html)。
- **来源标识**：机构显示 CRS；内部来源元数据保留 EveryCRSReport 对应报告页。上游元数据中的 Congress.gov 链接可用于追溯官方出处，不应把转载站标成报告作者。

接口依据为网站的 [Bulk Download and Developer Documentation](https://www.everycrsreport.com/download.html) 及首页、搜索页公开使用的 RSS 和搜索配置。

## 按用户操作读取

| 用户操作 | 上游来源 | 获取内容 |
| --- | --- | --- |
| 打开默认「国际智库」列表 | `https://www.everycrsreport.com/rss.xml` | 最新报告的标题、报告页链接、发布日期 |
| 输入搜索关键词 | 官网搜索页使用的公开 Algolia 索引 | 当前查询的一页报告标题、日期、编号及结果数量 |
| 查看报告详情 | `https://www.everycrsreport.com/reports/{reportNumber}.json` | 最新版本标题、日期、格式和原文地址 |
| 点击下载并通过现有下载权限校验 | 最新版本元数据中的 PDF `filename` | 本次需要的 PDF |

首页通过 `rel="alternate"` 声明 RSS 地址。RSS 当前仅提供标题、链接和日期，不含 PDF 内容；必须按发布日期降序排列，不能假设 RSS 原始顺序就是最新在前。相同报告编号去重后再分页或截取。

搜索采用官网公开的只读 Algolia 配置，配置来源为 `search.html` 的 `instantsearch({ appId, apiKey, indexName })`；首页的 `algoliasearch(...)` / `initIndex(...)` 也公开同一配置。此文档不保存实际配置值。CRS 每页最多读取 30 条命中及需要的字段，与原有国际智库搜索各自分页，合并结果最多 60 条；默认 RSS 列表每页最多 30 条。不扫描完整报告索引。上游为英文内容，英文关键词可以直接查询；不能假设上游会把中文关键词自动翻译，页面提供英文关键词或报告编号提示。常见 CRS 报告编号（R、RL、RS、IF、IN、LSB、TE 前缀）直接解析对应元数据，避免全文模糊查询命中其他编号；历史合成编号可从标题搜索结果进入详情。

报告 JSON 的 `versions` 按时间逆序，`versions[0]` 是当前版本。现代记录的 `date` 可以是 `YYYY-MM-DD`，旧记录也可能包含时间；统一输出日期后再比较，并保留 2000 年以前的日期。上游摘要可以为空，本次列表不依赖摘要。PDF 格式项的 `filename` 相对 `https://www.everycrsreport.com/`，`sha1` 标识该版本的文件内容；不要自行猜测带版本的 PDF 文件名。报告 JSON 的编号必须与请求一致，报告页和 PDF 地址只接受预期的来源域名及路径。

## 缓存与下载边界

发现与详情流程的缓存限于 RSS 列表、搜索配置、查询结果、单报告元数据及文件版本标识。元数据与查询结果正常使用 15 分钟缓存；上游暂时不可用时，可以读取 7 天内的旧元数据。相同元数据请求合并，缓存层读取或写入失败不妨碍尝试上游。每个上游元数据请求有 8 秒超时和 512 KiB 响应体上限。用户请求触发获取，后台定时任务不批量采集该来源。

以下操作均不请求或预先保存 CRS PDF：默认列表、关键词搜索、详情元数据读取、定时预热。EveryCRSReport 来源从既有国际智库 PDF `warm` 路径排除，也不经热门归档任务顺带预存。PDF 仅在用户实际请求下载且通过现有权限判断后，从元数据声明的来源地址获取；真实下载沿用既有 PDF 结果缓存与热门归档流程。PDF 缓存键包含稳定报告编号和版本标识，报告更新后不会误用旧版本缓存。

上游超时或返回异常时，可以返回此前可用的元数据缓存或其他国际智库结果，并标明当前来源暂不可用；部分来源失败的结果不覆盖上次完整查询缓存，失败也不被写成长期有效的空结果。默认列表失败不会触发全量 CSV 扫描或 PDF 预热。详情接口将不存在的报告返回为 404，暂时无法读取元数据返回为 503，避免把上游故障误报为永久缺失。

- RSS 返回 HTTP 200，约 8.36 KB、25 条报告，最新日期为 2026-09-04；原始条目由旧到新排列。服务器支持 `ETag`，条件请求返回 304。
- 官网公开 Algolia 索引包含 23,466 篇报告，最新的 `R49338` 可以按标题查询；按报告对象 ID 查询 `crs:IF13121` 可以得到正确的最新记录。中文原词「中国」直接查询没有结果。
- `reports.csv` 的响应体约 6.72 MB，不用于默认展示或每次关键词搜索。
- `reports/IF13121.json` 约 3.36 KB；最新版本同时声明 EveryCRSReport 镜像文件名和 Congress.gov 原始地址。
- 该记录声明的镜像 PDF 经 HEAD 检查返回 HTTP 200、`application/pdf`；探测过程未下载 PDF 内容。

上线验证应覆盖：空搜索显示 CRS、关键词命中与报告编号直达、详情日期和标题一致、未登录/无权限下载遵循现有规则、授权下载得到对应版本，以及列表/详情/定时预热均未请求或写入 PDF。
