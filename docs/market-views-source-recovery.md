# Market Views source recovery

The public catalogue was verified on 2026-10-04 with `market-view:260930` as its newest entry. Daily report runs after that date failed before dispatching Market Views. Saved diagnostics show late Dropbox batches, terminal MinerU extraction failures, and expired TLS certificates when downloading completed results from `cdn-mineru.openxlab.org.cn`. Four MinerU token slots were loaded. The user's 2026-10-04 token-page screenshot shows four valid tokens and one older token expired on October 2; it does not establish which credentials the failed runs used. The specific cause of the 18 terminal provider failures remains unverified. The CDN certificate failure is a recorded result-download failure, not evidence that the current API or all tokens are unavailable.

The durable MinerU client previously selected one configured credential per shard without falling through to another credential on explicit authentication rejection. It now permits the next credential only after HTTP 401 or the provider's explicit invalid/expired-token codes, without any acceptance acknowledgement. [MinerU's API documentation](https://mineru.net/apiManage/docs) identifies `A0202` as an invalid token and `A0211` as an expired token. It records each rejection before proceeding and retains the exact original batch and byte bindings. Accepted tasks, polling failures, timeouts, conflicting acknowledgements and other ambiguous submission outcomes never authorize another submission. Switching credentials cannot repair a shared result download certificate.

Market Views now has an independent recovery branch after a failed report-notes job. It reuses the selected original PDF artifact, verifies every filename and SHA-256 against the original selection manifest, and extracts native text plus original exhibit pages. It uploads a complete source receipt to a separate private R2 prefix and dispatches the exact bank issue date. The report-notes job retains its failure, and WeChat/translation retain their existing completion gates. Native temporary sources are deleted only after Market Views succeeds; failed or cancelled PDF consumers retain their inputs.

The consumer verifies transferred markdown, status, original page coverage and figure hashes before synthesis or the existing-PDF skip. Auxiliary sources use the latest usable date on or before the bank issue; a future auxiliary date cannot rename or suppress the new bank issue.

Native recovery performs no OCR or MinerU submission. Every page must have at least 40 readable text characters and each report at least 600. Scanned, textless, encrypted, damaged, incomplete or mismatched originals reject the whole batch. Numbered exhibit captions select original full-page images; uncaptioned visuals are not inferred or redrawn.

For missed dates, dispatch **Recover Market Views from original PDFs** (`market-views-native-recovery.yml`) with `date_folder` and the exact `expected_articles`. Supply `source_run_id` to reuse an original Daily report artifact; leave it empty to download that exact Dropbox batch and bind a fresh manifest without classifying or submitting it to MinerU. The recovery waits for PDF archive/public commit success before cleaning its source prefix.
