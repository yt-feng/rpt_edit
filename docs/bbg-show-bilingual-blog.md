# BBG Show 双语脚本归档

中文 Blog 的 `BBG Show 中英对照` 模块展示已发布视频片段的双语脚本。集合入口为 `/blog/bbg-show.html`，详情使用稳定的 `bbg-YYYYMMDD-<identity>.html` 地址；按日期倒序分页，保留节目来源、讲述人和每段时间。这里的内容是已发布片段字幕，不是整期节目全文。

## 数据与更新

`scripts/sync_bbg_show_blog.py` 从 BBG Show 仓库已提交的 `rendered-clips/**/highlight_plan.json` 读取双语字幕，包括 Git 历史中已移除的目录。仅写入 `portal_suite/data/bbg_show_archive/` 的公开文章字段，不复制媒体、私有全文归档、提示词或本地文件路径。

每篇文章以类别、公开节目链接和片段起止时间生成稳定身份；同一片段再发布或翻译修订更新原文章，不新增重复地址。英文保留原字幕，中文优先使用已发布的 `zh_filtered`，其次使用 `zh`；两种语言都存在才可导入。渲染时只进行 HTML 转义，不替换原文标点或编辑标签。

`BBG Show bilingual blog archive` 工作流每日两次同步最近 8 天，也可手工指定 1–63 天。默认遇到不完整双语数据失败并给出计数，源读取失败始终终止；同步只增加或更新记录，不因源目录清理而删除既有文章。提交后由站点常规刷新发布。文章归档目录参与发布语义比较，因此已有文章修订也会触发实际内容更新。

## 建站契约

`build_portal_suite_site.py --bbg-archive-root` 默认读取上述目录。普通研究文章和双语脚本分别分页，中文 Blog 首页显示最新脚本卡片与全量入口；详情页返回双语集合，同时提供研究和注册入口。集合、详情均有独立 canonical 与结构化数据，正文保留中英文语言标记。

BBG 集合及详情是中文站的双语内容，不进入其他语言的翻译库存、页面副本、sitemap 或 hreflang。其他语言的 Blog 保留返回中文双语集合的入口，不再次翻译英文字幕。

验证包含导入完整性、稳定身份、Git 历史恢复、读取失败、非法时间与来源拒绝、HTML 转义、分页链接、文章结构化数据及多语言排除。首次回填和定期同步的实际篇数以脚本成功返回的汇总为准。
