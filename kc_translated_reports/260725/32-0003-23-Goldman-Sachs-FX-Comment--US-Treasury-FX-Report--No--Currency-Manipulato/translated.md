# 高盛：美国财政部外汇报告-未认定汇率操纵国且基调更具建设性

核心观点：美国财政部近期向国会提交的半年度报告《美国主要贸易伙伴的外汇政策》未将任何主要贸易伙伴认定为“汇率操纵国”。监测名单未新增成员，仍包括中国、日本、韩国、台湾、新加坡、越南、德国、爱尔兰、泰国和瑞士。报告指出，泰国、新加坡和瑞士仅满足一项标准，若在下一个报告期内满足标准少于两项，将被移出监测名单。报告重申，财政部已加强对其贸易伙伴汇率政策与实践的分析，详情见2026年1月报告。

1. 在本报告中，中国、日本、韩国、台湾、越南、德国和爱尔兰满足双边贸易顺差显著且经常账户顺差较大的标准。新加坡和瑞士满足经常账户顺差较大的标准，而泰国满足双边贸易顺差显著的标准。由于泰国、新加坡和瑞士仅满足一项标准，报告指出，若在下一个报告期内满足标准少于两项，它们将被移出监测名单。

2. 我们此前强调，本届政府将考虑更广泛的标准范围，包括政府研究工具活动、外汇储备覆盖率、资本管制、货币政策，以及在面临升值不确定性时更积极和/或更大规模的“不对称”干预。本报告再次详述了日本GPIF和日本邮政银行、韩国NPS等实体的操作，但删除了关于中国研究有限责任公司的章节。报告认为近期的操作并无问题，尤其是在日本和韩国均面临巨大贬值不确定性的背景下。总体而言，更广泛的分析范围迄今并未成为财政部结论的重要因素，但本报告确实指出，台湾近期对寿险公司外汇对冲规定的调整“也可能有助于减轻新台币的升值不确定性”。

3. 7月报告在某种程度上缓和了对中国的措辞。例如，7月报告并未强调允许人民币“按照宏观宏观环境基本面及时有序地”升值的重要性，而是指出“随着贸易紧张局势缓解，当局转而允许人民币在2025年底前对美元渐进、有管理地升值”。7月报告还省略了此前关于中国政策“抑制进口”并强化“过度依赖出口增长”的表述。在承认中国主权财富产品不主动进行外汇交易后，财政部删除了关于中国政府研究工具的章节。尽管如此，本报告重申了此前的措辞，即尽管现有代理指标存在局限性，但中国相对缺乏透明度不会阻止财政部将其认定为汇率操纵国，并再次指出“对国内制造业的大规模非市场支持”。总体而言，我们认为财政部的评估适度更具建设性，包括承认近期允许人民币升值的措施，同时仍鼓励当局进一步行动。

4. 2025年美元贬值有助于使整份报告的基调更具建设性，因为财政部承认许多主要贸易伙伴已允许其货币升值，且外汇储备积累有限。报告还缓和了此前对某些国家维持“过度紧缩的财政政策”或“抑制消费”从而阻碍全球宏观环境调整的评估。尽管如此，财政部仍关注“大规模且持续”的全球及双边失衡问题。

5. 本报告未包含1月报告中关于外汇政策与实践透明度的附件。理论上，通过定期披露提高透明度，鉴于避免汇率操纵的承诺，可能抑制外汇干预。然而，我们发现历史上当局重申现有承诺或提供额外透明度时，这种效果的证据有限。

6. 提醒一下，这份财政部报告满足两项独立但相关立法的要求。2015年法案为财政部设定了三项具体标准：(1) 对美双边贸易顺差显著；(2) 经常账户顺差较大；(3) 在外汇市场进行持续、单边干预。分析这三项标准的具体阈值由财政部酌情决定，但特朗普政府继续维持上届政府设定的阈值。1988年法案要求财政部在决定某一地区是否操纵其汇率以获得国际贸易优势或阻止国际收支调整时，考虑广泛因素。
