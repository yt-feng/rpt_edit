# 摩根大通：Akeso-HARMONi总生存期特别更新
## Akeso：公司情况更新

HARMONi 总生存期特别更新：积极但不太可能从根本上改变格局

7月22日，Summit 发布了其全球 III 期 HARMONi 试验（依沃西单抗+化疗 vs 化疗用于二线及以上 EGFR 突变非鳞状 NSCLC）的特别总生存期（OS）更新分析；该试验支撑其 FDA BLA（PDUFA 日期为2026年11月14日）。随着更长的西方人群随访和2026年6月的数据截止，西方患者的 OS HR 现为0.76，与这项全球研究中的 ITT（意向治疗）人群一致，并与中国 III 期试验 HARMONi-A 的中国人群一致。我们认为这有助于提振情绪，而非从根本上改变格局。更新的 OS HR 看起来不错，但由于这是原始统计计划之外的特别分析，我们无法声称其具有或不具有统计学显著性；没有正式的 p 值，只有一个显示有利趋势的名义 p 值。安全性良好，无新信号。我们维持对 Akeso 的公司观点。

- **对 HARMONi 本身的影响**——对 BLA 有增量支持，但非决定性。预先指定的主要 OS 分析未达到统计学显著性（HR 0.79，p=0.057），而 PFS 明确达到（HR 0.52，p<0.00001）。7月22日的分析将西方患者的 OS HR 收紧至0.76，并显示西方/亚洲数据趋同，这在一定程度上帮助解决了早前的两个担忧：1）OS 获益偏向亚洲；2）亚洲和西方患者的 OS 获益可能不一致。然而，鉴于该分析是特别分析，这并非 OS 获益的决定性证据。我们认为，此次 OS 分析加上2025年9月的分析将有助于 BLA 审评，而非增加决定性的统计权重。

- **我们对 HARMONi 中 OS HR 随随访时间延长而降低的趋势持积极看法**，这可能表明依沃西单抗的 OS 获益类似于 PD-1 单抗，随着随访时间延长而持续改善。具体而言，在 ITT 人群中，OS HR 在2025年4月/2025年9月/2026年6月的分析中分别为0.79/0.78/0.76。同样，在西方患者人群中，OS HR 在2025年4月/2025年9月/2026年6月的分析中分别为0.98/0.84/0.76。

- **对 HARMONi-3 的启示**（这是读者最关心的 III 期试验）为适度积极，影响有限。HARMONi-3 是一项全球性一线 NSCLC 研究；鳞状队列的最终 PFS 数据将于2026年下半年读出，同时有中期 OS 数据，非鳞状队列的 PFS 数据将于2027年上半年读出。HARMONi 中一致的西方 vs 亚洲 OS 表现令人欣慰，因为 HARMONi-3 的成功依赖于在以西方人群为主的群体中复制强劲的中国数据（HARMONi-6 OS HR=0.66）。此前，我们估计最终 PFS 将达到，但 HARMONi-3 的中期 OS HR 需要大约0.72才能具有统计学显著性，我们认为这是一个高门槛。但我们认为 HARMONi-3 的最终 OS 将达到。

- **下一步关注点**——HARMONi-3 鳞状队列的最终 PFS 和中期 OS（2026年下半年）是下一个关键催化剂。这是下一个二元事件，比7月22日的 OS 更新更重要，因为早前的中期 PFS 分析未达到终点，使得中期 OS 成为近期判断 OS 疗效在以西方人群为主的一线 NSCLC 人群中是否成立的信号。此外，日程上还有：2026年11月14日针对二线 EGFR 突变 NSCLC 适应症的 PDUFA 决定，以及 HARMONi-3 非鳞状队列的 PFS 数据（2027年上半年）。

# 研究论点、估值与不确定性

Akeso

## 研究论点：公司情况更新

Akeso 是中国一家处于商业化阶段的生物科技公司，也是双特异性抗体领域的领导者。尽管 Akeso 在2024年报价表现稳健，但我们继续看到其报价在2025年有上涨空间，驱动因素包括：(1) AK104（PD-1/CTLA-4）：适应症扩展至中国多个大市场，我们预计这将在中国产生约70亿元人民币的峰值销售额。(2) AK112（PD-1/VEGF）：成功纳入国家医保目录，应能释放强劲的销售动能，仅在中国 NSCLC 领域峰值销售额就超过80亿元人民币，并且其在 PD-(L)1/VEGF 领域的领先地位以及相对于 Keytruda 极具竞争力的疗效数据，应能支持中国以外地区超过60亿美元的峰值销售额。
