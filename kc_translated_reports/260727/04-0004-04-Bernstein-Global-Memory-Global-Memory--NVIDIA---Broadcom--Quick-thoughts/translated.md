# 伯恩斯坦：全球内存-英伟达与博通合作规模超5000亿美元

在韩国政府于旧金山举办的AI峰会上，三星、SK海力士、英伟达与博通宣布了在内存、代工及AI数据中心领域的合作伙伴关系（来自三星、SK海力士、英伟达的新闻稿）。

SK海力士与英伟达签署了意向书，并提供了7月7日已宣布内容的细节（链接 & 链接），包括该合作伙伴关系在内存领域超过5000亿美元的规模，以及计划于2027年为SK Telecom上线的一座2GW Vera Rubin DSX AI工厂。我们注意到，该内存合作包括长期技术开发以及下一代AI内存（HBM4及后续产品？）的稳定供应，以使SK海力士能够“扩大增长基础”。我们还注意到，据报道（链接 & 链接），SK集团未来五年还将与其他全球科技公司合作，提供价值2500亿美元的内存供应。

三星与博通签署了一份谅解备忘录，涉及未来五年至2030年价值2000亿美元的内存（包括HBM）及代工服务。代工服务将专注于2纳米及以下制程，用于无线宽带通信解决方案等产品（但AI ASIC呢？），以及用于“AI与网络”芯片的2.3D（图表1，图表2）（Cube-E与-R，类似于台积电CoWoS-L与-R）和2.5D（Cube-S，类似于台积电CoWoS-S）先进封装技术。

我们认为这凸显了内存在AI中的重要性。我们认为宣布的金额更多是针对内存，并表明英伟达和博通需要确保内存供应。尽管我们无法精确量化这些公告的影响，但为帮助读者理解其背景，我们注意到市场共识预期2027年和2028年整体内存年收入均约为1.3万亿美元（图表3）。

对台积电的影响应可忽略不计。我们注意到，该公告未明确博通是否会在三星生产AI ASIC的晶圆或先进封装。无论如何，由于等待台积电产能的需求积压，我们认为即便有任何份额流失给三星或英特尔，也不会影响台积电可预见的盈利。

我们仍看好内存，并认为近期的回调是良好的入场点。我们发现内存在AI中比逻辑半导体更重要，因此对需求持积极态度。然而，我们担心中国在NAND领域的长期威胁，因此给予铠侠“弱于大盘”评级。由于中国最终将难以在没有EUV的情况下在DRAM市场竞争，该威胁在DRAM领域要低得多。因此，我们给予三星、SK海力士和美光“强于大盘”评级。

这些交易可能有助于缓解英伟达和博通的供应担忧，因为两家公司都指引了未来强劲的AI增长（英伟达在2025-2027年期间约为1万亿美元，暗示明年接近5000亿美元；博通明年超过1000亿美元）。我们对两家公司均给予“强于大盘”评级。
