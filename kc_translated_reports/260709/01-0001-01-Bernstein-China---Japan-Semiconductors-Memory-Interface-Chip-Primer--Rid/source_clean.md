Memory interface chips are a direct and amplified beneficiary of the server CPU Renaissance driven by Agentic AI. As the industry shifts from GPU-centric training toward inference-heavy agentic AI deployments—where the CPU reclaims its role as orchestrator of multistep, sequential tasks—server CPU volumes are poised to grow structurally faster than expected (our CPU report), and the role of memory interface chip becomes increasingly important when the DRAM capacity and bandwidth per CPU grows. We project the global memory interface chips TAM to reach USD 20Bn by 2030 (3x of our previous projection) at 65% CAGR (vs 32%), driven by three reinforcing tailwinds: rising server CPU volume, increasing DRAM package count per CPU, and higher interface chip content per package through the MRDIMM upgrade.

MRDIMM penetration is an important driver, as interface chip value per MRDIMM module is roughly 10× that of RDIMM. Each MRDIMM adopts a "1 MRCD+10 MDB" architecture, versus just one RCD in standard DDR5 RDIMM. We project MRDIMM penetration to reach 25% (vs 20% previously) of global server DDR DIMM shipments by 2030, driven by the bandwidth improvement MRDIMM delivers. The adoption hurdle is manageable: MRDIMM premium is only about 10% of the current 128GB RDIMM price, and this gap narrows further as rising DRAM die prices reduce the premium.

The competitive landscape for core memory interface chips is a textbook oligopoly that drives high margin. Montage, Renesas, and Rambus (RMBS, not covered) collectively control 90%+ of global share, protected by rigorous JEDEC qualification cycles and deep co-development ties with DRAM IDMs and CPU platforms. The chip is crucial for the package performance but takes only LSD% of the package price, customers have very low incentive to shift to new vendors and are willing to offer high margin to secure the quality. The three vendors compete neck-and-neck on the RDIMM roadmap, while Renesas and Montage hold early-mover advantages in MRDIMM. The complementary supporting chips segment is more fragmented, where Renesas leads thanks to its analog heritage.

We favor all three leading suppliers, as market has not fully priced in upside from CPU acceleration and MRDIMM adoption. We raise Montage TP to CNY400/ HKD520 for A-/H-Share, supported by CPU-driven demand across both its memory interface and PCIe businesses, as well as share gains from CXMT expansion. Renesas's memory interface is at a scale similar to Montage's despite contributing only 6% of it revenue, yet its market cap is only 25% above Montage's; it appears significantly undervalued, and management's guidance for 20-30% growth CAGR for this business is too low. Rambus benefits across both interface chip products and memory controller IP royalties; its smaller revenue base and market cap give it the largest potential upside elasticity.

## MEMORY INTERFACE CHIP: CORE BENEFICIARY IN THE AGENTIC AI ERA


The AI industry is entering a new phase. As workloads shift from training to inference and agentic applications, compute intensity is migrating back toward the server CPU. In training, GPUs handle massive parallel computing workloads while CPUs sit largely idle. As AI moves from reasoning to action, the workload becomes multistep, sequential, and time-sensitive, precisely the domain where CPUs excel. The CPU becomes the essential orchestrator: it schedules thousands of small computational tasks to the GPU every second, manages the model's working memory (KV cache), executes real-time safety checks, and coordinates API calls to external tools. In these workloads, CPU-side processing can account for 50–90% of total task completion time. The CPU-to-GPU ratio shifts dramatically, reaching approximately 1:1-2 in agentic architectures. AMD recently doubled its projection for the global (x86) server CPU TAM to USD 120 billion by 2030 compared to the projection in last quarter's earnings, reflecting rapidly rising expectations for CPU demand. Every additional server CPU shipped requires multiple DDR memory modules, each populated with memory interface chipsets.

Agentic AI workloads demand substantially more memory bandwidth and capacity than prior generations, for KV cache storage, context windows, and working memory that grows with task complexity. The industry is responding by increasing the number of DDR channels per CPU (migrating from 8 to 12 and eventually 16 channels) and by fully populating DIMM slots in AI servers to maximize accelerator utilization. More DRAM modules per server means proportionally more memory interface chips per server — a structural multiplier that compounds on top of the CPU volume growth.

Bandwidth starvation of agentic AI are accelerating the transition from DDR5 RDIMM to DDR5 MRDIMM, which increases the memory interface chip value per module by roughly 10×. As data rates push beyond 8800 MT/s — driven by the same AI workloads demanding higher memory bandwidth — conventional RDIMM architectures hit fundamental signal integrity limits. MRDIMM resolves this through active signal retiming, requiring one MRCD plus ten MDB chips per module versus a single RCD for RDIMM. This is not an incremental improvement; it is a step-change in silicon content per server that transforms the economics of the entire memory interface chip market.

These three forces are multiplicative, not additive. The TAM is the product of CPU volumes, DRAM modules per CPU, and chipset value per module, nearly all of which are rising simultaneously. This structural alignment explains why we project the global DDR module chipset TAM to reach USD 20Bn by 2030 (\~65% CAGR), dramatically outpacing the \~24% growth in server CPU shipments, making the sector almost 3x more elastic on top of the CPU vol growth. Note that the TAM is both sensitive to the CPU volume and MRDIMM penetration, as we highlighted in Exhibit 5, so if the CPU market didn't grow as fast as expected and MRDIMM penetration was lower than projected, there is downside risk to our projections.

## PRODUCT PRIMER: MEMORY MODULE AND MEMORY INTERFACE CHIPS

DDR module chipsets are a family of specialized ICs mounted on server DIMM modules. They divide into two tiers — high-value memory interface chips (RCD, DB, MRCD, MDB) and complementary supporting chips (SPD, TS, PMIC) — with silicon content per module increasing dramatically across DDR generations and DIMM formats. Memory interface chips are the core high-value silicon, and Complementary supporting chips have grown in relevance since the DDR5 generation.

[[KC_IMAGE_012]]

Not all DRAM packages require memory interface chips. In PCs and low-end servers, where memory capacity and bandwidth requirements are modest, the CPU's integrated memory controller can communicate directly with DRAM chips without intermediary buffering. However, in high-end servers, particularly AI servers that demand maximum memory bandwidth and capacity, the CPU cannot talk to too many DRAMs simultaneously without signal degradation. This is where DDR module chipsets become essential.

## CORE INTERFACE CHIPS

Core interface chips are the most technically sophisticated and commercially valuable components in the DDR module chipset. They sit physically between the CPU memory controller and the DRAM dies on the module, buffering and conditioning signals to enable higher memory capacity and bandwidth than would otherwise be possible. A useful analogy: if the CPU is the "CEO" of a company, the RCD/MRCD is the "manager" that directs instructions, and the DB/MDB is the "delivery person" that physically moves data to and from the DRAM workforce.

RCD (Registered Clock Driver): The RCD is the bridge between the memory controller and the DRAM chips on the module. It provides command, address, and clock signals to achieve synchronous data transfer. RCDs are employed on RDIMM and LRDIMM server modules to enable higher capacity and better reliability than PC modules (UDIMM and SODIMM). One RCD is mounted per RDIMM module. The main functional blocks on a typical RCD chip include a logic microcontroller (usually ARM-based) for managing I/O ports, an I2C/I3C interface for inter-chip communication, and a clocking block for handling reference signals.

MRCD (Multiplexed Rank RCD): The MRCD is the next-generation registering clock driver designed specifically for DDR5 MRDIMM modules. Unlike conventional RCDs that passively buffer signals, the MRCD actively reshapes and re-clocks signals, maintaining signal integrity at the higher data rates that MRDIMM targets (8800–12800 MT/s). One MRCD is mounted per MRDIMM module.

RCDs/ MRCDs are the most complex and advanced ICs among the DIMM chipset. They were first introduced with DDR3 and have gained relevance with each subsequent generation. The leading vendors typically manufacture their RCDs using TSMC's CMOS processes, with DDR4 RCDs on 40nm platforms and DDR5 first-generation RCDs starting at 28nm. Future generations will migrate toward even more aggressive nodes (down to 10nm class) to support higher data rates.

DB (Data Buffer): Data buffers store copies of data blocks being transferred between the CPU and the DRAM dies. Positioned spatially closer to the DRAM chips than RCDs, they reduce I/O trace lengths, leading to less pronounced signal reflection and lower data load on the module's data bus. Consequently, modules with data buffers (LRDIMMs) can support higher memory capacities than RDIMMs. Data buffers were first implemented on DDR4 LRDIMMs, with 9 per module. Since JEDEC defines a specific number of DBs per module, they are sold in bundles to memory module vendors.

MDB (Multiplexed Rank Data Buffer): The MDB is the next-generation data buffer for DDR5 MRDIMM. Like the MRCD, it actively manages data signals through multiplexing, enabling concurrent access to two memory arrays on the module, effectively doubling per-module bandwidth versus conventional RDIMM. 10 MDBs are mounted per MRDIMM module, representing a dramatic increase in silicon content compared to DDR5 RDIMM, where no data buffers are required at 6400 MT/s.

## COMPLEMENTARY CHIPS

The DDR5 specification introduced several new on-module components that were absent in DDR4, expanding the total chipset content per module and creating additional revenue opportunities for chipset suppliers.

SPD Hub (Serial Presence Detect): The SPD Hub stores module configuration information — including size, speed, voltage, and timing parameters — that is read by the system BIOS during boot. It contains an embedded temperature sensor and manages the standalone temperature sensors mounted on the DIMM. A 1KB EEPROM device is also included to store DIMM topology configuration and DRAM information. One SPD Hub is present on every server DDR module across all formats and generations.

TS (Temperature Sensor): DDR5 temperature sensors must achieve approximately $0.25^{\circ}$ C accuracy to trigger effective thermal management actions, including lowering IC speed or increasing cooling fan activity. Two standalone temperature sensors are mounted on each DDR5 server module (RDIMM and MRDIMM), compared to zero standardized sensors on DDR4 RDIMM modules. The sensors are managed by the SPD Hub through the I3C serial bus.

PMIC (Power Management IC): The transition to DDR5 moved power regulation from the motherboard to the DIMM module itself. DDR5 PMICs include step-down switching regulators and low-dropout regulators to manage voltage conversion and distribution. ## PC DDR MODULE FORMATS AND CKD

While this report mainly focuses on server memory interface chips, the parallel developments in PC and laptop DDR modules represent an incremental — though structurally smaller — TAM opportunity.

PC and laptop memory uses two primary formats: SODIMM (laptops) and UDIMM (desktops). Unlike server RDIMMs and MRDIMMs, these modules do not employ RCD or data buffer chips, while the CPU memory controller communicates directly with DRAM without intermediary buffering. As a result, DDR4-generation PC modules contained essentially no on-module chipsets.

DDR5 changes this picture. Beyond the SPD Hub and PMIC now standard across all DDR5 formats, JEDEC has defined a new chip specifically for PC memory: the CKD (Clock Driver). The CKD buffers and re-drives clock signals on DDR5 UDIMM and SODIMM modules, enabling stable operation at 6400 MT/s and above, speeds at which the unbuffered architecture would otherwise suffer from signal degradation. One CKD is required per module. Montage was the first vendor to deliver a CKD chip for sampling in September 2022. The CKD is distinct from the server-side RCD/MRCD. CKD buffers only clock signals, carries a lower ASP, and is not paired with data buffers. It therefore represents a complementary product category that expands the TAM into PC memory for the first time, albeit at a fraction of the server opportunity. One headwind to monitor is the rapid adoption of LPDDR in laptops, which is soldered directly without DIMM modules and will limit SODIMM-based CKD volume over time.

Beyond DDR, the CPU Renaissance is also structurally favorable for CXL-based memory expansion. AI agents require massive persistent memory for KV cache and context windows, and CPUs provisioned with large, disaggregated RAM pools via CXL memory pooling offer a more efficient architecture for accommodating the growing data volumes generated by long task chains — compared to HBM bound directly to GPUs. ## RISING DIMM MODULES PER CPU

The second growth driver is the increasing number of DDR modules per CPU, which is a function of two sub-drivers: the migration to higher channel-count CPU architectures and the rising occupancy rate of DIMM slots.

Channel count migration: The number of DDR channels per CPU is migrating upward in response to AI workloads that are extremely bandwidth-hungry. The share of server CPUs with 12-channel DDR configurations will grow from 24% in 2025 to 45% in 2030, while 16-channel CPUs will rise from near zero to 30% over the same period. This transition has the potential to roughly double the memory interface content required per CPU.

The drivers behind this migration are clear. AI workloads demand massive memory bandwidth, since additional channels reduce contention and latency during parallel computing. CPU core counts are scaling faster than per-DIMM bandwidth, meaning that adding channels is necessary to sustain bandwidth per core and avoid memory starvation. Higher channel counts also enable more DIMM slots and greater total memory capacity per socket, supporting virtualization density, LLM inference, and large memory-resident workloads.

Competition between Intel and AMD to raise the bar on DDR channel count ensures that neither vendor can afford to fall behind on memory specifications, creating a secular ratchet effect. Intel's Sapphire Rapids and Emerald Rapids (2023–2024) operated on 8-channel DDR5 architectures. The step-change comes with Clearwater Forest (1H 2026), Intel's next-generation E-core platform, which doubles the channel count to 12-channel DDR5 with up to 288 cores. Looking further ahead, Diamond Rapids, Intel's next P-core platform (expected in mid-2027), is designed with 16-channel DDR5 support. On the AMD side, the channel count migration began earlier. AMD's Genoa (EPYC 9004, 2022) debuted with 12-channel DDR5. The upcoming Venice (EPYC 9006, 2026), built on Zen 6 architecture with TSMC 2nm and up to 256 cores, is expected to support up to 16 channels of DDR5 on the new SP7 socket.

Occupancy rate increase: AI servers fully populate DDR slots with approximately 70-80% occupancy to optimize accelerator utilization. The logic is straightforward: insufficient DDR capacity directly caps xPU utilization, and with accelerators representing the majority of the system BOM cost, maximizing xPU utilization far outweighs the incremental cost of populating every memory slot. Larger DDR capacity with manageable bandwidth trade-offs (losing 5–15%) is acceptable in AI's parallel compute profile, and symmetric DDR configurations are critical for scale-up AI systems.

By contrast, general-purpose servers leave roughly half of memory slots empty (\~50% occupancy) to optimize fleet-level TCO and preserve headroom for future upgrades. DRAM accounts for approximately 50% of GP server CAPEX and is energy-intensive, making overprovisioning costly. GP servers expand via scale-out, with half-populated slots preserving flexibility to upgrade memory and add servers as needed.

As AI servers grow from approximately 14% of global server shipments in 2024 to an estimated 30% by 2030, the blended average occupancy rate of DIMM slots across the global server fleet rises from approximately 54% to 56% — a meaningful uplift in total DIMM demand per CPU shipped.

## HIGHER MEMORY INTERFACE CHIPS VALUE PER MODULE FROM MRDIMM MIGRATION

The migration from DDR4 to DDR5, and subsequently from DDR5 RDIMM to DDR5 MRDIMM, is a powerful driver of dollar content per package expansion for memory interface chips. DDR5 modules require additional chip types beyond the RCD and SPD that were only interface chips in DDR4 RDIMM; specifically, PMIC and TS are now integrated, lifting the total interface chip count per RDIMM module. More importantly, the transition to MRDIMM represents a step-change in silicon content: each MRDIMM module adopts a "1+10" architecture consisting of one MRCD chip and ten MDB chips, compared to one RCD and zero data buffers for a DDR5 RDIMM at 6400MT/s. This translates to a dramatic increase in memory interface silicon content per module, directly boosting Montage's dollar content per DIMM sold. We estimated that the memory interface chip total value could increased from about 7 USD in RDIMM to more than 70 USD in MRDIMM (with all interface chip combined).

As a result, MRDIMM penetration is the single most sensitive variable in the TAM model. TrendForce estimates MRDIMM just accounts for 3% of global server DDR DIMM shipment units in 2026; and we project the rate will rise to 25% by 2030E.

## CONFIGURATION COMPARISON ACROSS DDR GENERATIONS AND DIMM FORMATS

The chip count and composition per module varies significantly across DDR generations and DIMM formats, with each upgrade cycle introducing additional silicon content.

## Why do we believe the MRDIMM adoption will accelerate?

\- First, data rates above 8800 MT/s exceed RDIMM's practical signal integrity limits. Without active retiming, RDIMM faces crosstalk and signal loss at high data rates — a fundamental physical constraint that cannot be solved through incremental improvements to passive architectures. MRDIMM's MRCD and MDB actively reshape and re-clock signals on the module, maintaining integrity at 8800–12800 MT/s.

\- Second, CPU platform support is broadening. Intel committed to MRDIMM support from its first-generation DDR5 MRDIMM-compatible platform, and AMD has followed by supporting MRDIMM from its second generation. It signals to the entire downstream ecosystem that the format will see sustained investment and qualification.

\- Third, the memory supercycle helps close the cost gap. As DRAM die prices rise, the interface chipset becomes a proportionally smaller component of total module cost, compressing the percentage cost gap between RDIMM and MRDIMM, which incentivizes CSPs to shift from RDIMM to MRDIMM faster.

## Why will MRDIMM not repeat LRDIMM's failure?

The most common bear-case objection: DDR4 LRDIMM also carried high interface chip content yet never exceeded 1% of server DDR shipments. Why should MRDIMM be different? We see structural differences:

\- LRDIMM solved the wrong problem. LRDIMM offered higher capacity without improving bandwidth, as the data buffers added latency while per-module bandwidth stayed flat. In the DDR4 era, capacity was not the binding constraint. MRDIMM addresses both dimensions: its multiplexed architecture doubles per-module bandwidth while also supporting higher capacity, directly tackling the bandwidth bottleneck that AI workloads create.

\- RDIMM was "good enough" in DDR4; it is not in DDR5. RDIMM handled DDR4 data rates (up to 3200 MT/s) without signal integrity issues, giving customers no reason to migrate. At DDR5 speeds of 8800 MT/s and above, RDIMM can no longer maintain clean signals. The migration to MRDIMM is pulled by physics, not pushed by marketing.

\- Platform commitment versus orphan status. Neither Intel nor AMD published a Plan of Record for DDR5 LRDIMM, effectively killing the format. MRDIMM has explicit support from both vendors.

\- AI servers create a customer base that did not exist. DDR4-era servers were predominantly general-purpose machines with moderate memory needs. AI servers fully populate DIMM slots and push every specification to the limit; hence, they are the natural high-volume customer base for a format that delivers maximum bandwidth.

\- The memory supercycle narrows the cost gap.

## COMPETITIVE DYNAMICS AND INDUSTRY MOAT

The core memory interface chip market is a textbook oligopoly with \~92% share held by three players. High barriers to entry protect incumbents, including JEDEC certification, multi-party validation, and advanced node fabrication. The complementary chip market is more fragmented, with many conventional analog or sensor suppliers.

## CORE MEMORY INTERFACE CHIPS MARKET: A CONSOLIDATED OLIGOPOLY

The core memory interface chip market exhibits a degree of concentration that is unusual even by semiconductor industry standards. Three players — Montage Technology (\~37% market share), Renesas (\~36%), and Rambus (\~20%) — collectively controlled approximately 92% of global market share by revenue as of 2024. The only other meaningful participant is One Semiconductor, a Korean company that has emerged as a small player offering RCD and CKD products, manufacturing on Samsung Foundry's process platform. One Semiconductor was founded by the former Head of DRAM Development at Samsung Electronics and the former Chief Technology Officer of Samsung Electro-Mechanics. Despite its close ties to Samsung, the company has struggled to meaningfully scale its market share, underscoring the exceptionally high technological and ecosystem barriers in this sector.

These structural barriers have progressively eliminated competitors across successive DDR generations, resulting in the current level of industry concentration. Compliance with JEDEC standards demands deep expertise in high-speed serial interface design, analog/mixed-signal engineering, and memory controller protocols. In addition, the multi-party qualification and validation process—spanning foundries (primarily TSMC), CPU vendors (Intel, AMD), JEDEC committee participation, DRAM manufacturers (Samsung, SK Hynix, Micron, CXMT), module vendors (e.g., Kingston), and OEMs/CSPs—typically requires 18–24 months from initial silicon to volume production approval. During this period, any design flaw or interoperability failure can fully disqualify a supplier.

RCD and MRCD are the most technically complex components among the DIMM chipset family, fabricated at leading-edge CMOS nodes. DDR4 RCDs were manufactured on 40nm platforms, while DDR5 first-generation RCDs started at 28nm. Future RCD and MRCD generations for DDR5 will offer faster data rates and could employ even more aggressive technology nodes (down to 10nm below class), raising the technological bar for any potential new entrant.

## COMPLEMENTARY SUPPORTING CHIPS: A MORE FRAGMENTED MARKET

In contrast to the oligopolistic structure of the memory interface chip market, the complementary supporting chip market (PMIC, SPD Hub, TS) is considerably more fragmented, with dozens of analog and discrete IC vendors participating. The technical barriers are relatively lower: these components do not require the same level of high-speed digital design expertise as RCDs, and they are fabricated on mature process nodes rather than leading-edge CMOS.

Renesas is the market leader in complementary chips with the largest market share of DDR5 PMIC/SPD/TS, leveraging the deep analog product expertise it acquired through its 2019 acquisition of Integrated Device Technology (IDT) for \$6.7 billion. IDT had been the market leader in DIMM chipsets prior to the acquisition, and Renesas used the deal to reinforce its position in advanced communications and automotive mixed-signal products.

Montage achieved portfolio completeness at DDR5 launch in October 2021, but partly through manufacturing partners: Giantec Semiconductor (Shanghai) for SPD Hub and Global Mixed-mode Technology (Taiwan) for PMIC. This preserved R&D focus on core RCD/DB competency. More recently, Montage appears to be building in-house PMIC and SPD design capability, with its US office now recruiting analog engineers for these products.

Rambus initially lacked complementary chips, a noted disadvantage; but it closed the gap through sequential in-house development: SPD Hub and TS in July 2022, server PMICs in April 2024, and the PMIC5030 for MRDIMM in October 2024.

Other notable participants in the complementary chip space include Samsung, Monolithic Power Systems, Richtek, Texas Instruments, NXP, and Analog Devices. The lower barriers and higher number of participants mean that pricing power in complementary chips is significantly weaker than in memory interface chips.

## EVALUATION OF THREE CORE MEMORY INTERFACE CHIP PLAYERS

Montage, Renesas, and Rambus collectively controlled over 90% of global core memory interface chips market share in 2024. Barriers to entry are formidable: chips must pass 18–24 month qualification cycles with DRAM vendors, CPU platform providers, and CSPs, while incumbents shape the JEDEC specifications that new entrants must meet. Suppliers who fall behind a DDR generation have historically been eliminated. We evaluate the three players across product portfolio breadth, DDR5 RDIMM roadmap, and MRDIMM positioning.

## Product portfolio breadth: all three now offer complete DDR5 chipsets, but through different paths

DDR5's expanded module architecture introduced PMIC, SPD Hub, and Temperature Sensor alongside the traditional RCD and DB, making a complete chipset offering a competitive imperative for module manufacturers seeking one-stop sourcing.

Renesas entered DDR5 with the broadest in-house portfolio from the outset, inheriting deep analog and power management expertise through its 2019 acquisition of IDT (USD 6.7Bn), which had launched the industry's first DDR5 PMIC in 2017 and held the largest PMIC share among the three incumbents.

Montage achieved portfolio completeness through manufacturing partnership at the beginning, but is gradually building up in-house design capabilities for complementary supporting chips.

Rambus initially lacked complementary chips, but has closed the gap through sequential in-house development since 2022. With this build-out complete, Rambus now offers a fully in-house chipset for both RDIMM and MRDIMM.

In short, portfolio breadth is no longer a differentiator. The remaining distinction lies in the development model: Renesas leads on in-house analog heritage, Rambus has caught up through organic investment, and Montage bridges the gap through a hybrid

of partner-sourced and increasingly in-house capabilities.

## DDR5 RDIMM roadmap: Renesas leads, Montage and Rambus in close pursuit

Renesas is slightly ahead, having reached mass production of DDR5 Gen 5 (8800 MT/s) and begun sampling Gen 6 (9600 MT/s) in November 2025.

Montage achieved mass production of Gen 4 (7200 MT/s) in October 2025 and is sampling Gen 5 (8000 MT/s), with Gen 6 still in R&D.

Rambus reached mass production of Gen 5 (8000 MT/s) in October 2024 but has not disclosed a Gen 6 timeline.

In practice, the commercial impact of Renesas's speed-grade lead is moderated by server platform qualification cycles, which tend to compress vendor timing within each platform launch window.

## DDR5 MRDIMM chipsets: Montage and Renesas co-pioneered Gen 1; Rambus pivots directly to Gen 2

MRDIMM carries the highest-growth potential given the step-change in silicon content per module, making competitive positioning here disproportionately important for long-term share dynamics.

Both Montage and Renesas introduced Gen 1 MRDIMM chipsets (8800 MT/s) in 2022 on comparable timelines, establishing them as co-equal early movers. Their chipsets enabled the initial MRDIMM modules that shipped with Intel Granite Rapids in H2 2024. Rambus made a deliberate decision to skip Gen 1 entirely and direct resources toward Gen 2, after JEDEC formally unveiled the product standard.

For MRDIMM Gen 2 (12800 MT/s), the competitive landscape is more evenly contested. All three incumbents are now actively competing for Gen 2 design-ins, and ultimate share will depend on qualification outcomes, volume ramp execution, and pricing dynamics through 2026–2027.

## THE MOAT OF THE INDUSTRY

The memory interface chip market possesses deep structural moats, built on reinforcing pillars.

Standards definition through JEDEC participation: The three incumbent suppliers are all active members of JEDEC, the industry body responsible for defining DDR standards. Notably, Montage and Renesas sit on the JEDEC board of directors, granting them early visibility into upcoming specifications and the ability to influence standard setting. This creates a “roadmap definition” dynamic in which incumbents help shape the technical requirements that new entrants must ultimately meet—effectively defining the competitive landscape on their own terms.

Multi-party validation ecosystem and strong network effects: Bringing a new memory interface chip to market requires rigorous interoperability validation across a complex ecosystem, including foundries (primarily TSMC for advanced nodes), CPU vendors (Intel, AMD), JEDEC committees, DRAM manufacturers (Samsung, SK hynix, Micron, CXMT), module vendors (e.g., Kingston), and end customers such as OEMs and cloud service providers. This qualification process typically spans 18–24 months and must be repeated for each new product generation. For new entrants, this implies a minimum of 3–4 years from initial R&D investment to first meaningful revenue, assuming no qualification setbacks. The deeply interconnected and established ecosystem reinforces both network effects and high switching costs, creating strong structural protection for incumbent players.

Industry consolidation across technology generations. Historical industry dynamics point to increasing consolidation over successive DDR generations. The number of viable suppliers has declined rather than expanded: Intel exited after DDR2 due to insufficient returns, and Texas Instruments followed after DDR3. The remaining players have each invested billions of dollars over multiple DDR cycles in IP, engineering capabilities, and foundry partnerships. For potential new entrants, the combination of deep technical expertise requirements, lengthy qualification cycles, and the risk of missing critical generational transitions, which has historically proven fatal, results in prohibitively high barriers to entry.

## FUTURE TECHNOLOGY ROADMAP

## DDR6 AND ITS IMPLICATIONS FOR MEMORY INTERFACE CHIPS

JEDEC completed the initial DDR6 specification draft at the end of 2024, with final ratification expected within 2026. Compared with DDR5, DDR6 introduces two fundamental architectural changes. First, the peak data rate roughly doubles for the basic format: DDR6's JEDEC spec defines a base rate of 8,800 MT/s scaling up to 17,600 MT/s, versus DDR5 RDIMM's range of 4,800–8,400 MT/s. Second, DDR6 replaces DDR5's dual 32-bit sub-channel architecture with a quad 24-bit sub-channel design. By splitting data transfer across four narrower channels, each bit line is shorter and experiences less capacitance and crosstalk, enabling the data rate doubling without proportional increases in power consumption. DDR6 is also expected to adopt the CAMM2 connector standard, replacing decades-old DIMM and SO-DIMM form factors, which could change the physical design and BOM for memory modules, including the role of on-module interface chips.

All three major DRAM manufacturers — Samsung, SK hynix, and Micron — have kicked off DDR6 development, completed prototype chip designs, and are now working with memory controllers and CPU platform players on interface testing. However, commercialization timelines remain uncertain and diverge significantly across the industry: SK hynix's public roadmap, disclosed at its AI Summit in November 2025, positions DDR6 in the 2029–2031 timeframe, reflecting its strategic priority of extending DDR5 through MRDIMM and HBM4/5 for AI workloads. Next-generation CPU platforms from Intel and AMD are reportedly undergoing DDR6 interface validation, though neither has disclosed a clear product roadmap with confirmed DDR6 support. On the memory interface chip side, none of the three major vendors has yet disclosed concrete DDR6 interface chip products. Montage claims it is conducting DDR6-related R&D programs. Historically, interface chip development lags the DRAM standard by one to two years, as vendors require a stable specification before committing silicon design resources.

Critically, DDR6's base data rate of 8,800 MT/s is equivalent to the effective throughput of DDR5 MRDIMM Gen 1, while DDR5 MRDIMM Gen 3 is expected to match DDR6's high-end spec at 17,600 MT/s. It means the full DDR6 data rate range is already achievable within the DDR5 generation through advanced interface chip architectures; hence, this substantial overlap weakens the near-term urgency for server OEMs and CSPs to migrate to DDR6. This dynamic reinforces our projection that DDR5 MRDIMM penetration will continue to rise through the decade, before DDR6 becomes a compelling alternative. Looking further ahead, the outlook for DDR6 is structurally positive for the memory interface chip industry. For DDR6 to offer a meaningful bandwidth advantage over DDR5 MRDIMM, it will need to push data rates well beyond the current 17,600 MT/s ceiling of its basic specification, achieving that will require a new generation of advanced memory interface chips for active retiming, signal conditioning, and multiplexed-rank architectures analogous to what MRDIMM brought to DDR5. In other words, DDR6 in its basic module format does not offer a compelling upgrade path over DDR5 MRDIMM; only with higher interface chip content can DDR6 unlock data rates that justify the generational transition. This ensures that each successive push for higher memory bandwidth demands greater interface chip intelligence and dollar content per module, a secular trend that is positive for Montage, Renesas, and Rambus regardless of which DDR generation dominates.

## CXL: THE NEXT FRONTIER FOR MEMORY INTERFACE

As server CPU core counts have scaled aggressively over the past decade, memory bandwidth and capacity per core have not kept pace — a gap widely referred to as the "memory wall." Compounding this, a significant portion of installed DRAM in datacenter servers sits idle because the CPU cores associated with that memory are already fully allocated, a phenomenon known as memory stranding. Compute Express Link (CXL) has emerged as the industry's leading open interconnect standard to address these inefficiencies. Built on the PCIe 5.0 physical layer, CXL enables cache-coherent memory expansion and pooling, allowing disaggregated memory resources to be decoupled from host processors and dynamically shared across multiple compute nodes.

CXL serves two primary use cases: memory expansion and memory pooling. Memory expansion allows a CPU to access additional DRAM beyond its native DDR channel limits through CXL-attached memory modules, meaningfully increasing both effective capacity and bandwidth per socket. Memory pooling goes a step further by enabling shared DRAM pools, connected via CXL switches, that can be accessed by multiple CPUs or accelerators on demand. Given that typical server memory utilization hovers around 50%, pooling has the potential to substantially improve resource efficiency and lower total cost of ownership for cloud operators. Early estimates suggest first-generation CXL deployments could reduce DRAM procurement requirements by roughly 10%, with savings potentially exceeding 35% as more advanced pooling capabilities under CXL 3.0

mature.

The CXL ecosystem has gained broad industry support, but mass adoption remains in early stages. The CXL Consortium now counts over 180 members spanning CPU vendors, memory manufacturers, cloud providers, and chip companies. On the platform side, both Intel and AMD have integrated CXL support into their server CPU roadmaps starting from Sapphire Rapids and Genoa, respectively. Major DRAM manufacturers including Samsung, SK Hynix, and Micron have developed CXL-compatible memory expansion modules. Certain hyperscalers have also begun piloting CXL-based architectures for next-generation server designs. The standard has evolved rapidly — from CXL 1.0 in 2019 to CXL 3.0 in 2022 — with each generation adding more sophisticated capabilities such as multi-level switching, peer-to-peer communication, and rack-scale disaggregation. CXL 3.0, built on the PCIe 6.0 physical layer, doubles transfer rates to 64 GT/s and introduces the fabric-level capabilities needed for full memory composability.

However, meaningful barriers remain before CXL can scale to broad deployment. CXL introduces an additional latency penalty of roughly 67–87 nanoseconds compared to locally attached DRAM, which confines its practical applicability to infrequently accessed memory tiers rather than latency-sensitive hot data. In AI-centric workloads, CXL also faces a fundamental bandwidth disadvantage against purpose-built accelerator interconnects such as NVLink, which delivers substantially higher bandwidth per area. This positions CXL's strongest opportunity squarely in CPU-centric general-purpose server environments rather than GPU-centric AI training clusters. Furthermore, the cost-benefit case for CXL at datacenter scale has yet to be validated in production, and product roadmap visibility for CXL 3.0-based solutions remains limited.

## SOCAMM2 - NVIDIA BESPOKE DRAM FORMAT FOR ITS CPU PLATFORMS

In our latest SOCAMM2 report, we argue that NVIDIA's adoption of SOCAMM2 in its next-generation Vera CPU represents a platform-specific architectural optimization rather than a disruptive industry-wide memory standard. SOCAMM2 replaces the soldered LPDDR5X memory used in Grace processors with a modular LPDDR5X-based design, improving serviceability, upgrade flexibility, and multi-vendor sourcing while retaining the power-efficiency advantages of LPDDR. However, the benefits of SOCAMM2 are closely tied to NVIDIA's vertically integrated, rack-level AI system architecture, and we therefore expect its adoption to remain largely confined to NVIDIA platforms over the foreseeable future.

From a technology perspective, SOCAMM2 delivers compelling advantages in power efficiency, form factor, and bandwidth-per-watt, making it well suited for GPU-centric AI servers where system power budgets are increasingly constrained. However, DDR5 MRDIMM continues to maintain a clear advantage in both memory bandwidth and capacity, while benefiting from a mature ecosystem and broad industry support. Given the substantial switching costs associated with redesigning memory controllers, platform architectures, qualification processes, and software ecosystems, we believe mainstream x86 platforms and most non-NVIDIA ARM server platforms will continue to adopt DDR5 RDIMM and MRDIMM solutions rather than migrate to SOCAMM2.
