# 伯恩斯坦：裂解价差创纪录，原油现货与成品油价格背离达20美元

石油在很大程度上是无用的。作为一种产品，其原始状态几乎没有实际用途。然而，石油并非毫无价值。它有一个价格，目前低于 70 美元/桶（较年初可能上涨约 20%）。当石油被提炼成有用的产品时，它驱动着全球宏观环境。全球交通的两大用途是消费者购买的汽油和柴油。这些价格较年初上涨了超过 50%。

我们从未见过今天的石油“投入”价格与成品油“产出”价格之间存在如此巨大的脱节（图表 1）。我们使用裂解价差来描述这种差异。传统上基于 Nymex 合约的 3-2-1 裂解价差——即 2 桶汽油和 1 桶柴油的收入减去原油（WTI）投入成本后的标准化每桶差额。

我们显示平均裂解价差是“可预测的”（图表 2）。几十年来，典型的裂解价差是油价的 20%。在过去十多年里，典型的裂解价差是油价的 33%。

鉴于这种可预测性，我们可以仅使用汽油和柴油价格反推出油价。该模型拟合良好（图表 3）。

**价格表现，1 年**

我们放大显示 2020 年后的时期（图表 4）。俄乌战争扰乱了交通和供应链，增加了裂解价差（从而提高了炼油商的盈利能力），因此模型的误差项（失拟）上升了。今天的结果（图表 5）处于创纪录的脱节状态——现货价格交易在 70 美元/桶以下，而裂解价差隐含的价格则高出 20+ 美元/桶，达到 90+ 美元/桶。

虽然供应链中断可以解释当前脱节的部分原因，但更重要的扭曲是政府战略储备的释放扰乱了商业库存（图表 6），再加上特朗普政府可能具备通过口头和公开表态压低价格的能力。

一些启示。(1) 我们仍然对 Brent 75 美元/桶（WTI 72 美元/桶）的中周期油价感到舒适。(2) 90 美元/桶的隐含油价不应足以摧毁需求，因此可以持续。(3) 海峡刚刚重新开放，可能不会保持开放，因此不确定性偏向上行。(4) 炼油商（以及拥有炼油业务的一体化公司）将从石油与裂解价差隐含油价之间的脱节中产生显著的超额回报。(5) 在供应冲击（例如俄乌战争）之后，裂解价差（炼油利润率）可能在高位持续多年。(6) 政府通过实际（即释放 SPR）或口头（即沟通）手段压低原油价格的能力不一定是永久性的。(7) 政府最终重建战略库存的愿望可能会在 60 多美元/桶（接近我们目前的位置）附近产生一个 SPR 看跌期权。重建的规模可能达到每年数十万桶（占预期需求增长的很大比例），并可能持续多年。

当然，美元的价值随时间变化。我们可以应用 CPI 平减指数将数据从名义值转换为实际值，或者考虑比率。

我们在下面显示比率。如果我们任意选择 2012 年初作为一个“分界点”，我们发现之前的平均裂解价差为 20%，之后的平均为 33%。为什么是 2012 年？大约在那个时候，供应担忧开始因页岩油增长而缓解。大约在阿拉伯之春时期。大约在油价持续 100 美元/桶的时期。这也标志着裂解价差底部的结束。无论如何，具体选择点的移动不会改变这样一个事实：在过去十年左右的时间里，裂解价差大约是油价的三分之一。

如果裂解价差定义为

$$
\text { 裂解价差 } = (2 \times \text { 汽油 } + 1 \times \text { 柴油 } - 3 \times \text { 石油 }) / 3
$$

那么我们可以（裂解价差 / 石油）= 三分之一，我们可以很容易地得出

$$
\mathrm{石油} = (2 \times \text { 汽油 } + 1 \times \text { 柴油 }) / 4
$$

我们可以将该公式与实际油价进行对比。注意，在 2012 年之前拟合度较差（低估价格），但之后相当准确。
