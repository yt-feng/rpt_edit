# 本周主题：美光业绩对亚洲存储芯片制造商的影响
## 美光业绩/指引的五点启示

美光及其他大型存储芯片制造商越来越多地使用LTA来固定ASP；其芯片生产也将更加高端化（HBM、SOCAMM、LPDDR5）。这或将为存储芯片制造商开辟新的增长机遇，且无需经历激烈的价格竞争。我们注意到，例如南亚科技的DRAM销售（主要为旧款/传统DRAM）仍主要基于月度/季度协商的ASP（对LTA的敞口极低）。
