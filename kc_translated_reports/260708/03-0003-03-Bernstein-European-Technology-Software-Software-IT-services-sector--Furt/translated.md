# 伯恩斯坦：贝恩研究佐证，AI改写代码快但利润未增，软件定价权面临挑战
# 软件/IT服务行业：进一步复苏，狂热减弱

周二收盘后，我们参加了法国软件和IT服务公司行业协会（Numeum）的半年度会议。该组织介绍了其于4月/5月对其成员进行的一项调查结果，涵盖413家公司和CIO，其中43%为IT服务提供商，29%为软件供应商，28%为CIO。与往常一样，它聘请了一家行业研究公司——此次为Xerfi——来开展调查，并预测其追踪的各细分市场截至2026年的增长情况。

**仍在复苏，但程度不及最初预期。** 首先，我们注意到，本次调查进行时，中东冲突正处于风口浪尖，法国GDP增长预测已开始被下调（3月底至4月底下降10个基点）。调查还反映出小型企业（包括软件供应商和IT服务提供商）士气非常低落。对于小型IT服务公司而言，挑战包括客户整合和缩小首选供应商名单的趋势、向近岸和离岸交付模式的转变，以及研究新技术的需求。对于小型软件供应商而言，困难集中在研究能力以及避免受到与AI驱动工具相关的运营成本上升的冲击。基于这些原因（宏观环境以及小企业调查回复的权重），与六个月前相比，我们并不对调查中出现的丝毫乐观迹象感到过分担忧。这一次，主要的下修涉及软件板块（从+8.4%降至+6.2%），而IT服务公司的增长预计将保持在低个位数。Numeum预计所有板块下半年的增长将高于上半年。详见图表1和图表2。

**‘SaaSpocalypse’并非现实，而是一种不祥预感。** 尽管软件供应商并未看到其现有业务被新进入者颠覆——未观察到客户流失率上升，也未出现大量‘软件工厂’涌现以取代成熟软件——但受访者认为，由于AI带来的技术剧变，决策者做出选择所需的时间更长。他们对未来的担忧也超出了我们的预期。对于仍处于AI应用早期阶段的软件供应商而言，前路似乎漫长——无论是将新功能货币化，还是升级技术栈以匹配AI原生公司的能力。有一个统计数据尤其令我们印象深刻：22%的CIO认为，代理型AI可以取代或减少某些软件支出。这里的‘某些’一词至关重要，因为它可能指的是对核心业务运营不太重要的应用。这与咨询公司贝恩的一项研究相呼应，该研究强调了其在并购流程背景下，能够识别出那些可以在十天内使用AI重写80%的应用。

**将IT服务收回内部无疑是一种选择，但并非因为AI。** 在调查中，成员们强调了将IT服务活动内部化的可能性。这一选择一直存在，但在快速、深刻创新的时期，随着公司试图内化与这些新技术相关的知识，它往往更受关注。换句话说，推动这种内部化举措的并非AI，而是创新和技术颠覆的步伐。

**AI：带来额外业务，但无利润提升。** 无论是对于软件供应商还是IT服务提供商，观察到的和预计的生产力提升都是显著的，但两个群体都未预期盈利能力会有显著改善——原因多种多样，主要是将收益让渡给客户以及需要承担额外成本。

**能效/绿色IT：不再是优先事项。** 不幸的是，面对技术颠覆以及需要升级信息系统以保持竞争力的需求，能效和绿色IT在2026年仅被22%的受访CIO列为优先事项——远落后于网络安全、合规、优化不可避免的成本以及生成式AI。

Bernstein品牌根据未来12个月相对于基准指数的相对表现预测对公司进行评级：对于在美国和加拿大交易所上市的公司，基准为标普500指数；对于在欧洲交易所和亚太地区以外的新兴市场交易所上市的公司，基准为彭博欧洲发达市场大中盘价格回报指数欧元（EDME）；对于在日本交易所上市的公司，基准为彭博日本大中盘价格回报指数美元（JPL）；对于在亚洲（除日本）交易所上市的公司，基准为彭博亚洲（除日本）大中盘价格回报指数（ASIAX）——除非另有说明。

- **跑赢大盘**：公司将跑赢市场指数超过15个百分点
- **与大盘持平**：公司表现将与市场指数一致，偏差在+/-15个百分点以内
- **跑输大盘**：公司将跑输市场指数超过15个百分点

**暂停覆盖**：Bernstein品牌对某公司的覆盖已暂停。，不再有效，因此不应再被依赖。
