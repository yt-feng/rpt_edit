# 高盛：万辰与鸣鸣很忙门店扩张超预期，同店销售韧性凸显

我们的价值零售商覆盖标的（鸣鸣很忙/万辰）报价已从近期低点反弹29%/18%，但仍较5月中旬的前期高点低约15%。我们认为1H26盈利存在上行空间，驱动因素为门店扩张速度快于预期（根据GS估算，1H26两者均净增约4,500+家门店，见图表2中的追踪数据），同时我们预计1H26单店平均GMV大体保持韧性（得益于春节季节性因素，尽管2Q存在天气影响）且同店销售增长健康。我们目前预计鸣鸣很忙1H26销售额/调整后净利润分别增长54%/98%，万辰2Q26销售额/扣除激励前净利润分别增长41%/102%。我们重申，市场总规模仍然广阔，渗透率和品类扩张空间巨大（我们认为，行业门店总数长期有望达到约10万家，而GS估算2026年末约为6.8万家）。

1) 两大领先企业门店网络扩张速度快于预期：门店开业数同比加速，万辰净增门店数超过2025年全年（约4,700家），根据我们的追踪数据，鸣鸣很忙也达到4,500家以上，而1H25两者净增门店数分别为1,500家/2,500家，月度开业速度加快（5月/6月月度净增门店数加快至1,000家以上），为即将到来的暑假旺季做准备。门店开业主要来自深耕优势市场（领先企业的差异化）、探索低线/渗透不足地区的空白市场以及从区域性小企业手中夺取市场份额，例如万辰强调，1H26门店开业地点仍与竞争对手存在差异化，70%的开业门店集中在优势市场（长三角/山河四省）。我们注意到，两家行业领先企业在门店开业补贴方面保持理性和自律，仅对特殊位置/区域批准专项补贴。展望未来，我们预计两家企业将继续优先考虑健康的单店GMV表现，但仍会寻找足够的空间以维持2H26的门店开业步伐。

我们对行业门店长期增长空间仍然广阔的判断不变：我们预计行业门店网络到2026年末将扩张至6.8万家，到2028E达到约8万家，2025-28E年复合增长率为+15%，我们重申长期可触达空间超过10万家门店。同时，我们预计领先企业鸣鸣很忙/万辰将利用网络规模/门店管理专业知识的优势，从区域性小企业手中夺取份额（我们的追踪数据显示，2026年至今小型连锁门店扩张非常有限），到2026年将合计市场份额提升至80%（2024-25年为70%以上）。

## 2) 1H26/2Q26同店销售增长趋势因具体增长举措/好于担忧的客流稀释而保持韧性：我们预计两家公司1H26平均单店GMV仍为正增长，支撑因素包括：i) 1-2月春节交易强劲，管理层表示单店GMV增长为中高个位数百分比；ii) 现有门店同店销售增长持续提升；iii) 在更理性的竞争环境下选址质量提高；以及iv) 基数较低，鸣鸣很忙/万辰1H25单店GMV分别下降中个位数百分比/十个百分点左右。尽管如此，两家企业均指出天气/客流流动性对单店GMV产生不利影响，尤其是在6月/2Q后期。

■ 进入2H，我们预计平均单店GMV增长将较1H26环比节奏变化，原因是基数较高（鸣鸣很忙/万辰在3Q25/4Q25恢复单店GMV正增长），同时我们预计两家公司将继续优先考虑门店健康和加盟商利润率，并通过品类扩张/产品组合升级来支撑单店GMV（例如，两者均成功增加了冷链和冷藏/冷冻品类，万辰该品类约占总GMV的3%）。

3) 门店单位宏观环境模型保持健康（门店开业加速的关键支撑），同时利润率扩张空间不变：我们强调，在自律定价下，门店层面的加盟商毛利率保持稳定或有所改善，同时研究回收期仍具吸引力（例如约2年）。在加盟商层面，我们继续预计采购规模和物流优化将进一步支撑毛利率扩张，同时允许加盟商通过分享更高效行业价值链带来的收益来保持有吸引力的回报（餐饮品牌向价值零售商渠道提供有吸引力的定价，以享受可扩展性/高渠道增长/运营费用节省）。我们现在预测鸣鸣很忙/万辰2026E调整后净利润率/扣除激励前净利润率分别为4.6%/5.7%，同比上升0.5个百分点/1.0个百分点，而1H26利润率可能因春节旺季和2H25新店爬坡而享有更多经营杠杆。

盈利预测调整：由于门店扩张加快和经营杠杆，我们上调鸣鸣很忙/万辰2026-28E销售额2~10%/最高9%，上调净利润6~13%/2~11%。我们更新公司观点鸣鸣很忙/万辰，考虑到不确定性回报具有吸引力，该股目前交易于2026E市盈率17倍/14倍，而2026-28E净利润年复合增长率为25%/21%。
