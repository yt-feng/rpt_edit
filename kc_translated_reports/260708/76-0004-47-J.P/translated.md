# 摩根大通：新能源汽车销量韧性，燃油车零售下滑明显
# 出口与特别地方政府债券发行（小幅）提速

在6月制造业PMI基本稳定之后，市场目光聚焦于未来两周即将公布的硬性活动数据，以评估近期动能并判断宏观环境进入三季度的态势。我们更新了另类数据追踪（相较于上次更新），主要结论如下。

- 出口：港口追踪显示，6月离港集装箱（+8.5%）和散货（+10.1%）载重吨位在未经季调的环比口径下均加速。同比增速可能进一步回升。总体来看，6月离港货物载重吨位（不含油轮）同比增长17.2%（5月为7.7%），表明在近期价格上涨的同时，货运量增长也在提速。6月油轮抵达量依然仍在调整，同比下降超过30%，与5月类似。

- CCFI至美东、美西航线较两周前分别上涨14.3%、20.6%；CCFI至波斯湾/红海航线进一步上涨8.6%。

- 随着能源价格开始正常化，6月下半月中国国内及国际航班取消率显著回落。

- 生产：6月原油加工量调整可能加深（5月同比为-9.1%），但石油沥青装置开工率在6月下半月开始回升。6月汽车工业增加值降幅可能扩大（5月同比为-3.2%），而钢铁工业增加值调整可能收窄（5月同比为-2.8%）。6月下半月焦炉装置趋于稳定。

财政：6月政府债券发行量达11380亿元，与5月的11400亿元发行量基本持平。特别地方政府债券发行强劲反弹，显示出应对性的加速，但资金拨付至项目的进展仍存在不确定性。据国家发改委称，全年2000亿元的设备更新资金已全部下达。如果近期疲软态势持续，我们预计三季度财政部署将加快。

• 货币：6月央行通过7天期质押式逆回购净投放5830亿元，通过MLF净投放2000亿元，同时通过买断式逆回购回笼3000亿元。

- 央行还在6月底启动了隔夜逆回购操作，这与潘行长在陆家嘴论坛上的宣布一致。但该操作的利率并未披露，表明近期焦点仍在7天期逆回购。如果增长疲软持续并超过通胀不确定性，下半年降息的可能性可能增加。

- 汽车销售仍影响零售额。6月乘用车零售额同比下降21%，部分原因是单车置换补贴和购置税减免减少，以及燃油成本上升。新能源汽车销量降幅较小，为7%。

- 住房：6月二手房销售继续改善，而新房销售降幅扩大。

- 通胀：随着美伊和平协议下能源状况趋于平静，6月下旬汽油、柴油和液化石油气价格继续回落。石化产品价格大幅下跌至接近冲突前水平，尽管硫酸价格持续上涨。农产品价格同比下跌0.5%，而猪肉批发价格降幅仍处于高位。

## 2. 贸易：公司情况更新

尽管美伊签署了为期60天的谅解备忘录，中国主要航线的出口集装箱运价进一步上涨。按目的地划分，CCFI至美东、美西航线较两周前分别上涨14.3%、20.6%；CCFI至波斯湾/红海航线进一步上涨13.6%。波罗的海干散货运价指数在4月以来连续数周上涨后进一步小幅回落。6月发往美国的航运量同比增长6.9%，环比（未经季调）增长15.8%（5月为同比增长25.9%，环比增长1.5%）。

- 集装箱船通常运输消费品以及部分机械设备与电子产品。6月离港集装箱船载重吨位同比增长4.6%，环比（未经季调）增长8.5%。抵达集装箱船载重吨位同比下降0.4%，环比（未经季调）增长6.7%。
- 散货船在其货舱中运输谷物、煤炭、铁矿石、钢材等未包装的散装货物。6月离港散货船载重吨位同比增长20.9%（环比未经季调增长10.1%），而抵达散货船载重吨位同比增长23.3%（环比未经季调增长8.0%）。
- 6月油轮抵达量依然仍在调整，同比下降超过30%，与5月类似。

随着能源价格开始正常化，6月下半月中国国内及国际航班取消率显著回落。

5月中国从美国进口的大豆减少，此前4月曾出现增长。白宫声明称，中国将在2026年至2028年间每年购买至少170亿美元的美国农产品。

## 3. 销售与生产

- 汽车销售：据乘联会数据，6月乘用车零售销量同比下降21%，部分原因在于单车置换补贴和购置税减免减少，以及燃油成本上升。新能源汽车销量降幅较小，为7%。这表明汽车销售在6月可能仍对整体零售销售构成影响。
- 石油沥青装置开工率在6月下旬回升，但仍远低于中东冲突前水平。螺纹钢开工率6月保持稳定，而半钢胎和全钢胎开工率小幅下降。焦化厂开工率在自5月中旬以来小幅下降后，于6月下旬企稳。

## 4. 政策：政府债券发行与流动性操作

6月政府债券发行量达11380亿元，与5月的11400亿元基本持平。专项地方债发行强劲反弹，表明应对性加速，但资金投向项目的不确定性依然存在。如果近期疲软态势持续，我们预计三季度财政支出将加快。

- 国债发行量从5月的7080亿元几乎减半至6月的3180亿元。年初至今发行量达到年度发行目标的40.2%，落后于去年50.8%的进度。进一步细分来看，特别国债发行在6月保持稳健，为2040亿元（5月为2490亿元），随后7月至今发行800亿元。据国家发改委称，全年2000亿元的设备更新资金已全部下达。
- 专项地方债发行量从5月的1610亿元强劲升至6月的5720亿元，超过去年6月水平，表明在利用3月全国人大批准的剩余财政资源方面出现了应对性加速。这使得年初至今发行量达到年度目标的47.0%，现已赶上往年进度。
- 一般地方债发行量小幅上升至410亿元；再融资地方债达到2070亿元。
- 6月，央行通过7天期质押式逆回购净投放5826亿元，通过MLF净投放2000亿元，同时通过买断式逆回购回笼3000亿元。央行还在6月底启动了隔夜逆回购操作，6月29日操作3000亿元，6月30日操作6000亿元。这与潘行长在陆家嘴论坛上的宣布一致。但该操作的利率未披露，表明央行近期重点关注7天期逆回购。
- 4月活动数据出人意料地疲软以及二季度GDP的节奏变化不确定性，使得降息仍有可能。美联储更鹰派的立场可能使背景复杂化，但由于人民币汇率具有韧性，中国的决策应仍以国内为导向。如果增长阻力加剧并超过通胀不确定性，下半年降息的可能性可能会增加。与往常一样，10个基点的变动更可能是一种政策信号，而非有意义的宽松推动。

## 5. 房地产

6月二手房销售继续改善，但速度节奏变化，而新房销售降幅扩大。

- 30个大中城市新房销售降幅从5月的-1.4%扩大至6月的-7.3%，此前4月曾短暂增长2.8%。大中城市二手房销售在6月实现12.3%的稳健增长（5月为18.0%）。
- 中原经理指数和中原二手房报价指数在6月均小幅下降。
- 6月中下旬土地出让金低于去年同期水平，继续影响政府性产品收入。溢价率从近期高点回落，随后小幅回升，可能受到个别拍卖案例的影响。

## 6. 通胀：公司情况更新

- 随着美伊和平协议下能源形势趋稳，汽油、柴油和液化石油气价格在6月下旬继续回落，而液化天然气价格在6月中旬上涨后也有所下跌。煤炭价格在近期峰值附近相对较高，部分原因是夏季季节性需求。
- 6月下旬，多数石化产品价格大幅下跌，尽管硫酸价格持续上涨。聚乙烯、橡胶、石油苯价格已降至接近冲突前水平。涤纶短纤和甲醇价格也有所回落，但仍高于冲突前水平。
- 6月农产品价格同比下降0.5%（5月为-0.9%），对整体CPI的影响进一步收窄。大米、小麦和玉米价格基本稳定。
- 6月猪肉批发价格价格变化率仍处于高位，为-28.3%（5月为-28.5%），行业产能过剩问题持续。
