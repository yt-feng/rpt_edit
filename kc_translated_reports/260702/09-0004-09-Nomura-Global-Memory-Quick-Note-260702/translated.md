# 我们对影响存储股价的两个问题的看法 快评

韩国存储公司及其关联公司已与政府共同宣布大规模中长期投资计划（合计金额4.8千万亿韩元，其中3.7千万亿韩元为直接与存储相关的投资），但未明确具体时间表。这似乎加剧了投资者对供应过剩的担忧。目前，全球存储行业因AI行业前所未有的强劲需求，正经历非常严重的短缺局面，这导致智能手机、PC等产品生产中断和价格上涨，进而使这些产品的需求下降。此外，部分消费者甚至对存储行业提起了反垄断诉讼。

我们认为，考虑到近年来存储公司全力扩大产能，所谓全球存储公司通过供应控制进行价格串通的指控似乎缺乏依据。存储公司别无选择，只能优先生产高利润的HBM，这减缓了商品存储的产量增长。自2025年下半年以来，商品存储需求的强劲增长导致了严重的商品供应短缺。因此，存储公司正以远超以往计划的力度积极扩产，但这仍不足以满足强劲需求。

其结果是，存储公司已建立的产业集群可能比预期更快耗尽产能（土地、电力、水资源），同时这些公司还必须为中长期（2035年后）新集群的建设做准备。考虑到存储行业在韩国的重要性，政府迅速准备和支持似乎是合理的。韩国政府似乎提出了远离首都圈、且易于获取电力和水资源的地区，以追求国家均衡发展。我们认为，作为回报，企业预计将享受各种政策支持和税收优惠。这与美国、日本、中国等国家吸引先进产业的基本政府支持政策类似。

与一些误解相反，我们认为韩国公司没有理由应政府要求进行不必要的投资，这高度取决于市场状况。九年前启动的巨型项目——龙仁半导体集群，其首个洁净室要到2027年2月才能完工，我们认为小规模芯片生产要到2027年底才有可能实现，这意味着从投资到生产实际上需要超过10年时间。该投资计划可能会加速，但我们认为其影响至少要在5-10年后才会显现。

存储公司此前曾因经济低迷期投资不足或需求意外强劲而经历供应短缺。另一方面，尽管需求空前，它们也曾通过创纪录的投资造成供应过剩。这种动态一直是周期波动的关键原因，且没有政府胁迫导致投资的先例。因此，虽然始终存在企业过度投资的风险，但通过长期协议等新方法对冲此风险的努力，以及AI带来的强劲存储需求增长所支撑的结构性稳定增长可能性，是当前形势与过去不同的因素。此外，具有讽刺意味的是，与利润挂钩的员工奖金可能成为管理供应过剩和利润下降风险的另一种机制，这也与过去不同。尽管投资者对供应过剩的担忧可以理解，但我们认为这种担忧被过度夸大了。

（2）Meta决定将过剩算力出售给外部客户
其次，Meta（META US，未评级）宣布将向外部出售过剩算力，这也引发了对存储需求的担忧。类似地，亚马逊（AMZN US，未评级）进入云业务也是出于将过剩容量变现的需求——数据中心本质上必须匹配峰值算力的容量，因此在非高峰时段和季节，很大一部分计算容量处于闲置状态。此外，对于其他有算力需求的公司而言，此类云业务一直是高效的算力来源，且云业务至今已成为高增长、高盈利的业务。

与专注于纯云业务的AWS或新型云公司不同，在那些数据中心同时用于内部和外部目的的云服务提供商中，Meta是唯一未涉足云业务的公司。Meta基于社交网络和广告的主要商业模式，其算力利用率在不同时段和季节也存在显著波动，随着规模经济逐步建立，像xAI（未上市）那样将过剩算力对外出售，是非常自然的结果，也是一个有潜力提升Meta投资回报率的决策。虽然Meta仍有不对外出售算力的选择，但这对其业务而言将是一种“奢侈”，并且随着容量增长会变成资源浪费。此外，这可能成为Anthropic（未上市）和OpenAI（未上市）的重要算力来源，这两家公司没有自己的数据中心，但急需算力来提供企业AI服务。我们不认为Meta的决策是塑造（即减少）AI相关硬件需求或拐点的因素。相反，它有可能通过稳定降低因供应短缺而呈上升趋势的每token价格，并创造新的AI需求，从而强化杰文斯悖论。
