# 摩根士丹利：金山办公WAIC2026新品发布
## 核心观点：公司情况更新

WPS 365正从AI办公协作工具转型为一站式办公平台，切入企业管理领域。

我们认为，金山办公的全套办公+协作套件、现有云文档基础以及在办公场景中的垂直专注，是其关键竞争因素。

借助AI，工具、智能体与企业级管理软件之间的界限正变得愈发模糊。

在世界人工智能大会上，金山办公发布了两款产品

- 灵犀Pro：面向个人的高级办公智能体，支持WPS Office和Microsoft Office插件。具备面向项目的上下文管理、高质量任务交付以及专业办公软件操作能力。

- WPS Comate（WPS 365升级版）：企业级AI工作空间，内置专家/技能/应用库，并包含以下模块：(1) Token审计（WPS AI Hub）、(2) 文档管理（WPS AI Docs）、(3) 数据管理（WPS Data Hub）、(4) 软件系统集成（WPS API Hub）、(5) 安全（WPS Trust）。
