# 伯恩斯坦：周末科技简报，算力资本市场对冲万亿美元AI资本支出

## 算力的资金化

现货算力市场包括即时获取可用GPU容量的交易，算力资源按当前市场价格出租，用于近期工作负载和交付。算力衍生品与其他大宗商品衍生品一样，允许参与者通过GPU容量的远期头寸锁定GPU租赁价格。买方可以锁定其训练和推理工作负载的成本，卖方可以在产能建成之前进行远期销售，贷款方可以对其已承诺用于GPU建设的资本进行对冲。过去几个月，芝加哥商品交易所集团和洲际交易所均宣布计划推出受监管的GPU算力期货，有待美国商品期货交易委员会审查。值得注意的特点不仅仅是期货合约本身，而是围绕它们形成的更广泛的市场结构。算力正在逐层获得每个交易型大宗商品市场都具备的相同架构（图表1）

- **交易所**：交易所提供集中化的场所来匹配算力期货合约的多头和空头头寸，为一系列衍生品合约（涵盖不同期限、GPU型号等）建立透明的订单簿。离岸交易所因其宽松的监管结构，在提供GPU算力价格衍生品合约方面起步较早，然而Kalshi、ICE和CME（均未覆盖）等境内平台现在正在追赶。Kalshi已提供基于GPU价格的事件合约，而ICE和CME已宣布计划在2026年底推出受监管的GPU算力期货，有待CFTC审查。

- **指数**：市场倾向于围绕少数公认的参考价格进行结算，因为每个人都希望根据同一基准进行交易。当前的算力市场分散在不同的私人和公共参与者之间，缺乏透明的现货或远期定价曲线。Silicon Data（与CME合作）、Ornn（与ICE、Kalshi合作）和Compute Desk（与Architect合作）等平台正试图汇总GPU价格数据，针对不同变体进行标准化，并构建GPU定价的基准。

- **流动性与参与度**：我们看到针对各类市场参与者——超大规模云服务商（算力买方）、新型云服务商（算力卖方）、贷款方和套利者——的产品不断推出。现有产品的初始流动性仍处于萌芽阶段，且以投机性资金流为主。然而，随着算力市场的监管结构逐步演变，参与者认识到算力市场的产品-市场契合度，流动性应会随之而来。

我们认为与算力最接近的类比是电力。电力曾因无法储存、因地点和质量而异而被认为不可交易——直到标准化枢纽和参考价格将远期采购转变为市场。算力正遵循同样的路径，因为它具有相同的物理特性——GPU小时无法储存，容量因地点、芯片代际和租户而异。因此，远期曲线反映的是预期的稀缺性而非储存成本，而对冲是承担价格不确定性的唯一方式。

各平台现在正试图解决算力标准化（基准和每GPU小时方法）的问题，为远期合约开发现金结算和实物交割通道，并在基础算力上构建结构化资金产品。我们的观点是，基准和分销是算力市场增长的关键因素——这与任何大宗商品市场并无不同。

## 算力的大宗商品检验——最接近的资产类别类比

与算力最接近的类比是现有的大宗商品市场，尤其是电力。

- **可互换性与可衡量的供应——不完美但可行**：可互换性意味着某个物品的单个单位是完全可互换的。来自俄亥俄州的H100小时（例如）与来自德克萨斯州的并不相同，原因在于不同的网络、服务水平协议要求和部署环境。算力市场大致遵循两种可互换性方法：（i）推出涵盖芯片型号、服务器接口、期限等标准化条款的合约；（ii）允许各方根据标准期货价格使用基差（价格调整）直接协商算力容量的等级、时间和地点。

- **可储存性——算力不可储存**：未使用的GPU小时永远消失，无法仓储、运输或持有库存以应对未来需求。这使得算力类似于电力，远期市场反映的是预期的稀缺性而非库存动态。

- **价格波动性——高，因此对冲需求真实存在**：波动性是任何衍生品市场增长的前提条件。GPU芯片短缺和硬件代际更替（例如，从H100到B200）导致算力市场价格波动。一方面是新云服务商/云运营商，许多拥有大量正在折旧的GPU。另一方面，我们有AI实验室和企业，其宏观环境状况取决于未来的算力成本，因此市场中同时存在天然买方和天然卖方。

算力市场的市场结构仍在演变中，新产品公告和战略合作伙伴关系不断涌现。市场仍在试图解决三个关键问题——（i）算力标准化：标准化算力的现货和远期定价曲线，并构建普遍接受的指数；（ii）产品-市场契合度：构建各种资金产品，如期货、永续合约、事件预测合约，并确定适合不同参与者的产品；（iii）结算：为合约的现金结算和实物结算构建基础设施。行业参与者正在尝试多种方法来构建一个整合定价、产品和结算的市场结构。我们在接下来的章节中概述几种方法。

## 算力标准化——构建基准

每个大宗商品市场都从回答一个问题开始：一个单位到底是什么？石油几十年前通过标准化解决了这个问题——特定的等级、数量和交割规格。算力正开始解决同样的问题，但指数提供商的任务类似于电力市场运营商——将一个高度异质的产品，为其构建一个可交易的参考价格。问题在于，原始算力价格在整个市场中不具有可比性，因为同样的H100根据是从新云服务商、超大规模云服务商层级还是公开列表租赁，其定价可能不同（图表7）。这种价差反映了技术因素（网络）或非技术因素（SLA、支持、增值、交易对手质量）的实质性差异。

解决方案来自构建一个基准，该基准从各种来源获取分散的、不可比较的价格，并产生一个市场可以据此交易的数字。该过程可以设想为三个步骤

步骤 1 - 数据收集与标准化：指数提供商需要定义“单位”，例如 NVIDIA H100 SXM 80GB（包括服务器、内存、带宽等）。进一步的规格包括层级（新云/超大规模云）、租赁类型（按需/承诺期限）以及针对地区和配置的标准化步骤。为确保指数变动源于市场而非抽样误差，所有观测值/交易均需标准化为“参考单位”。Silicon Data（图表 2）收集了广泛的数据集——涵盖 50 个地区/国家、超大规模云、新云和市场中 50-100 个平台的每日 15 万条已验证定价记录（链接）。这些数据经过捕获和标准化处理，涉及定价结构（租赁类型/期限）、提供商和地点以及细粒度硬件规格，然后将异构物理单元的价格标准化为统一配置，以确保仅聚合可比较的价格信号。Ornn 则基于“协商交易价格”运作，即数据中心与算力买家之间的交易定价，追踪各 GPU 型号的租赁价格，并对硬件配置、提供商和部署环境进行价格标准化。

步骤 2 - 基准/指数：标准化后的数据成为参考指数。Silicon Data 指数在每个工作日采集价格，运用统计技术过滤掉过时或非代表性数据，并经过验证程序以确保指数完整性。对基准的需求甚至促使 CME、ICE 等传统资金交易所与 Silicon Data 和 Ornn 合作。CME/Silicon Data 和 ICE/Ornn 的合作聚焦于算力市场的资金化，预计最大需求将来自寻求对冲 AI 支出的读者，而非 GPU 的实物交割。CME 和 ICE 正利用其既有地位和现有生态系统来促进交易活动。

一家专注于 AI 算力的新交易所 Architect（私营）拥有多项合作：(i) 与 Ornn 合作推出算力永续合约，其基准基于现货市场的实时 GPU 数据，该产品已上线。AX 是 Architect 在海外（百慕大监管）设立的交易所，提供传统资产和算力的永续期货；(ii) 与 ComputeDesk（The Compute Index Inc. 旗下品牌）合作推出 ComputeConnect 和 EFP（实物换期货）网络，该网络通过 Compute Desk 的 Compute Clear 平台，将 AI 交易所上的算力期货与实际 GPU 容量交割联系起来。

步骤 3 - 远期曲线：由于算力无法储存（类比电力），不存在将远期价格锚定现货价格的持有成本，曲线必须从市场观测中推导得出。远期曲线目前由 Silicon Data 和 Kalshi 发布（图表 6）。曲线的形态基于对未来稀缺性的预期，而非库存的函数。关于曲线的两个主要概念是

\- 期货升水曲线：向上倾斜，远期价格高于现货价格，意味着市场预期稀缺性将持续或加剧。

\- 期货贴水曲线：向下倾斜，远期价格低于现货价格，意味着市场预期供应浪潮即将到来，硬件折旧将产生影响，因此买家预期未来支付更少。

## 产品 - 期货、永续合约、事件合约

一个分层的算力资金工具市场正在形成，不同的工具针对不同的用例。ICE、CME、Architect 和 Kalshi 等参与者正在开发一系列基于算力价格的衍生品（图表 3），包括指数结算期货、实物交割期货、永续期货和算力事件合约。这些产品仍处于早期采用阶段，因为公司仍在建设所需的分销和结算基础设施。

ICE、CME、Architect 的美国创新交易所（指数结算期货）CME（使用 Silicon Data）、ICE（使用 Ornn）和 Architect（使用 Compute Desk）已宣布计划于 2026 年底推出基于 GPU 租赁费率的期货合约，尚待监管审查。指数结算期货是基于 GPU 租赁价格指数的标准化合约，类似于其他大宗商品的期货。算力买方锁定训练和推理成本，卖方预售计划建设的容量，贷款方可以对冲 GPU 抵押品的价值。这些合约以每 GPU 小时美元报价，并根据基准指数以现金结算。合约以美元对照参考指数结算，硬件不发生易手，与现金结算的公司衍生品完全相同。

Kalshi 和 Polymarket（事件合约）Kalshi（受 CFTC 监管）和 Polymarket 等预测市场平台提供基于 GPU 租赁价格的事件合约。例如，Kalshi 上列出的一个典型算力事件合约可能是“到 2026 年底 NVIDIA B200 价格高于 7 美元？”——指定 GPU 型号、价格和期限。如果结算日价格高于 7 美元，合约支付 1 美元，否则支付 0 美元。此外，如果合约交易价格为 0.4 美元，则意味着 B200 租赁费率到年底超过 7 美元的隐含概率为 40%。因此，预测市场上的算力合约也有助于构建未来 GPU 价格的概率分布。Kalshi 现在正在聚合多个活跃合约的数据，以推导不同 GPU 模型的远期定价曲线。

## Architect 的 ComputeConnect（实物换期货）

Architect 已宣布推出 ComputeConnect，这是一个将现金结算的算力期货转化为实际交付的 GPU 容量的交易所。实物换期货产品允许通过实物结算系统将期货头寸转换为实际的 GPU 容量。ComputeConnect 与一个新云和容量提供商网络合作，通过双边协商实现实物结算（实际的 GPU 容量）。参与者可以通过协商实物交割的等级、时间和地点，将期货头寸转换为算力交付。其他算力市场衍生品，如指数结算期货、事件合约和永续合约，大多为现金结算，仅为参与者提供宏观环境敞口，没有机制来实际满足其交割需求。

Architect的AX永续算力期货交易所：Architect的AX交易所已在离岸市场上市永续型算力期货。永续期货是无到期日的合约，通过资金费率机制追踪现货指数，这一结构源自加密货币市场。永续合约是为算力量身打造的早期衍生品之一，因其（通过离岸结构）上线更快，且投机资金能引导流动性。当永续合约交易价格高于追踪指数时，多头定期向空头支付费用，从而压低价格（反之亦然）。持续的正资金费率意味着市场看涨现货价格。对于按需出售算力且无需承担单一未来日期不确定性的Neocloud，或购买按需算力的企业而言，永续合约可作为良好的对冲工具。

## 结算基础设施——现金交割与实物交割

衍生品市场存在两种结算机制——现金交割与实物交割。在算力市场中，目前所有已公布的期货合约、永续合约和事件合约均以现金结算，对标基准指数。

现金交割的优势：现金结算产品更易于清算、保证金管理和规模化，使其成为构建新资产类别市场的理想选择。合约根据合约价格与基准指数水平之间的差额以现金结算，无需实物交割基础设施。这为更广泛的参与者（包括贷款人、做市商和套利者）打开了市场大门，这些参与者可能无法满足实物交割要求。

现金结算期货的成功取决于底层基准。算力仍通过私下协商交易进行，这使得构建具有代表性的算力价格指数变得困难。然而，随着现货交易定价透明度提升及算力市场获得更广泛采用，算力市场基准正在持续改善。

为算力量身定制的实物交割：实物交割将期货市场锚定于底层资产——若期货在到期时交易价格高于现货价格，卖方可以交付算力而非现金结算。这消除了合约到期时期货与现货之间的价差。此外，需要芯片的参与者可能更偏好实物交割的衍生品。Architect与ComputeDesk推出了Compute Connect，这是首个用于GPU算力实物交割的算力交易所。例如，一个持有H100期货多头头寸（价格为每GPU小时2.3美元）的AI实验室，可以通过ComputeConnect将其头寸转换为实际算力。该AI实验室在ComputeDesk的算力卖方网络中请求交割。双方根据期货价格（并根据芯片配置、地点及其他规格进行调整）协商实际的GPU算力交付协议。

## 算力市场追踪指标

算力市场需追踪的关键指标——现货算力价格曲线、远期算力价格曲线和代币成本曲线。这些市场指标仍处于早期开发阶段，基于算力定价方面有限的异构数据构建。

- Silicon Data与Ornn——Neocloud GPU租赁指数（图表4-图表5）：Silicon Data与Ornn发布按GPU型号（如A100、H100和B200）划分的每小时GPU价格指数。Silicon Data收集广泛的数据集——涵盖50个地区/国家、覆盖超大规模云服务商、Neocloud和市场的50-100个平台，每日经核实的定价记录达15万条。Ornn的定价模型基于数据中心与算力买家之间按GPU型号协商的交易价格。数据聚合后，Silicon与Ornn根据硬件配置、提供商和部署环境对其数据进行标准化，并发布每日指数价格。

- Kalshi——远期曲线（图表6）：Kalshi近期推出了基于其预测市场价格的GPU算力远期曲线。Kalshi利用其实时预测市场合约，汇聚关于算力定价的分散观点，这些观点反映了市场对不同期限的预期。

- 按租户划分的GPU现货定价（图表7）：Silicon Data持续追踪不同地区和提供商类型的H100定价。利用其内部价格历史数据，他们发布了H100租赁价格随时间推移对不同参与方（超大规模云服务商、Neocloud和市场）的变化情况。

- Silicon Data LLM代币支出指数（图表8）：一个每日统计基准，衡量活跃交易的大语言模型市场的支出。该指数以每100万代币价格序列形式报告，因此指数水平是每百万代币的美元价值，而非标准化为100的指数。
