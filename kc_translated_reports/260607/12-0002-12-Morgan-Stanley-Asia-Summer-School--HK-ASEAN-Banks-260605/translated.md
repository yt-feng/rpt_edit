# 东盟银行业不断演变的行业格局  

# 印度尼西亚  

- 在1998年亚洲金融危机后重建，印度尼西亚银行的贷款以8%的年复合增长率增长（2014-2025年）。这得益于该国私人债务占GDP比率低于50%，为区域内最低，以及近期强劲的经济增长。  
- 行业的贷存比从2002年的44%攀升至2019年5月的96%，因存款增长落后于贷款增长。过去两年，贷款增长放缓及流动性上升导致贷存比在2022年12月降至80%，但目前已回升至约90%。  
- 该行业由四大银行主导，同时存在大量中小型银行的长尾，可能导致进一步整合。  

# 泰国  

- 一个因高负债经济体（家庭债务占GDP约87%）和人口老龄化而面临结构性问题的成长中市场。  
- 自2014年以来，贷款增长显著放缓至2-5%。资产质量自2012年以来一直是个问题，当时银行面临消费者/汽车信贷质量问题，随后在2014年出现中小企业信贷问题，近期则是新冠疫情带来的信贷质量问题。经过数年的贷款组合整合，问题在于信贷质量现在是否已建立在更稳固的基础上。  
- 回报率因费用降低和信贷成本上升而承压。银行正寻求在传统能力之外发展高利润率业务，例如数字无抵押贷款、财富管理。  
- 银行体系相对集中，进一步整合的空间有限。  

# 菲律宾  

- 银行业主要服务企业客户；这是历史低资产回报率的驱动因素之一。贷款增长在2019-2021年显著放缓，随后在2023年恢复至8%，2024年恢复至12%，2025年恢复至10%。  
- 金融包容性是央行的议程，且正大力推动无现金交易，但银行在数字化转型方面滞后。  
- 成本收入比是区域内最高的之一，受投资和菲律宾群岛地理特征驱动。自全球金融危机以来，资产质量一直不是问题，且银行很好地管理了新冠疫情的信用风险，得益于较低的系统杠杆率。  
- 历史上，资本比率往往处于较低端，每个信贷周期中常见资本筹集，但过去几年的低贷款增长改变了这一动态。  

# 不断演变的行业格局  

# 新加坡  

- 一个成熟经济体，贷款增长相对较低，为3-5%。利率一直是回报率的最大驱动因素之一。市场相对集中。  
- 大多数银行拥有区域业务，星展银行和华侨银行聚焦大中华区，大华银行则更侧重于东盟。  
- 新加坡银行建立了可观的收费业务，尤其是财富管理。近年来，更加关注资本回报。这些银行被视为数字化的全球领导者，尤其是星展银行。新加坡在数字资产领域处于领先地位。  

# 马来西亚  

- 一个相对成熟的市场，贷款增长已放缓至5-6%，抵押贷款是贷款增长的最大驱动因素之一。马来西亚的资产质量相对稳定。  
- 部分银行拥有东盟区域业务。联昌国际银行在印度尼西亚有重大敞口，马来亚银行在新加坡有重大敞口。  
- 随着股东派息增加，重新关注管理回报。过去曾有关于银行整合的讨论，尽管该行业已相对集中。  
- 由于马来西亚拥有大量穆斯林人口，该国实行双银行体系，即传统银行和伊斯兰银行。

# 香港银行有哪些？  

# HSBC控股（5.HK）  

- 一家总部位于伦敦的银行，在香港拥有主导市场份额（集团收入的33%），在英国有大量业务（集团收入的20%）。集团其余业务分布在亚洲其他地区、欧洲、中东和美洲。  
- 以存款为导向的业务，拥有强大的活期及储蓄账户比率，尤其是在香港。HSBC对利率敏感。  
- 关键差异化因素是其全球网络，重点利用该网络支持贸易和资本流动，并发展其财富业务。  
- 净资产收益率正在改善，集团目标是在2026年至2028年期间每年实现17%或更高的有形净资产收益率。  
- 我们预计随着HSBC寻求业务转型，IT投资将增加。  

# 渣打集团（2888.HK）  

- 一家总部位于伦敦、专注于新兴市场的银行，60%的收入来自亚洲，6%来自阿联酋，14%来自英国和美国。在54个市场拥有8.1万名员工。  
- 该行在全球金融危机中幸存，但在2015-2017年受到信贷问题的打击。转型和变革现已完成。管理层专注于在四个关键领域取得领先地位：新兴市场批发银行、大众零售、富裕客户业务（财富）和可持续发展。  
- 有形净资产收益率正在改善（2025年为11.9%），股价的关键驱动因素将是到2028年预期有形净资产收益率能在多大程度上提升至超过15%的目标。  

# 中银香港（2388.HK）  

- 由中国银行持股65.65%。  
- 专注于香港的业务，在香港拥有15%/20%的存/贷款市场份额，活期及储蓄账户比率为53.4%。历史上，其贷款和存款增长领先于市场。  
- 人民币清算行，在与内地相关的IPO中拥有主导市场份额。  
- 内地业务低于其他本地香港银行（占总贷款的5%）。2016/17年，收购了中国银行的大部分东盟业务。  
- 以低成本收入比（约24%）、低信贷成本（低于50个基点）和高资本比率运营。股息支付率约50%。

代币化——亚洲各经济体的发展与采用阶段差异显著

资料来源：MS

# 香港——受关键全球趋势与中国监管影响的混合市场

- 作为区域金融中心，香港在数字资产领域走在前列至关重要。香港的数字资产发展已酝酿至少五年，2021年启动了“Evergreen”项目及“金融科技2025”战略。
- 现实世界资产与代币化可能为香港资本市场带来机遇。然而，对中国相关资产的代币化禁令可能拖慢发展进程。
- 稳定币的使用仍以加密货币为中心，其渗透至关键金融支付生态系统，取决于将香港发行人的稳定币与加密货币交易相连接的进展。
- 积极的一面是，我们认为稳定币监管的发展将有助于部分香港及中国内地的金融机构在全球加密货币交易市场获取市场份额。我们看好富途证券成为香港市场稳定币发展的主要受益者。

#  Ensemble项目

专注于批发型央行数字货币基础设施，以支持代币化货币的银行间结算。香港金管局提供基础轨道，银行负责商业化。

# 香港金管局稳定币条例

于2026年4月向HSBC银行（计划于2026年下半年发行港元稳定币）及一个由渣打银行牵头的财团（Anchorpoint Financial）授予首批稳定币牌照。

# 新加坡——数字资产是其“枢纽中的枢纽”战略的重要组成部分

- 新加坡可能代表了亚洲最先进的代币化生态系统，其特点是多方参与的网络、监管清晰度以及从试点向商业化的过渡。
- 新加坡金管局热衷于培育数字货币的发展，但并非加密货币的投机。Dunbar项目涉及创建央行数字货币并将其用于结算国际支付。

# Guardian项目

一项由政策制定者——包括英国金融行为监管局、日本金融厅及国际货币基金组织等国际机构——协会与合作组织（如SWIFT及ISDA）以及金融行业共同发起的合作倡议，旨在通过资产代币化提升流动性和市场效率。

# Partior

提供一个分类账，使银行乃至企业能够进行安全、实时、全天候的交易。

# Contour Network Hub

一个数字财资与贸易平台中心，能够实现信用证及银行保函等财资与贸易融资流程的数字化。

# Dunbar项目

涉及创建央行数字货币并将其用于结算国际支付。

MAS 已允许包括新交所在内的受监管交易所设立加密货币期货。星展银行也设有数字资产交易所，并为高净值客户提供数字资产托管服务。

# 新兴东盟——采用步伐较慢

# 马来西亚

- 马来西亚国家银行于2025年6月推出数字资产创新中心，并于2025年10月发布讨论文件《马来西亚金融业资产代币化》。
- 三项举措——由渣打银行和亚洲航空牵头的林吉特稳定币用于B2B结算；以及联昌国际银行和马来亚银行分别推出的两项独立代币化存款计划。

# 泰国

- 泰国银行在过去数年间通过多项举措，在批发、零售和跨境领域推进代币化。其批发型央行数字货币之旅始于2018年的Inthanon项目，该项目邀请当地参与银行探索分布式账本技术在提升泰国金融基础设施方面的可行性。
- 作为mBridge项目的创始成员，该项目展示了一个平台，通过消除代理银行网络，使用多币种央行数字货币相比现有系统能提升跨境交易效率。

# 印度尼西亚

- 印度尼西亚银行于2022年通过其央行数字货币计划Garuda项目推进代币化，旨在探索数字印尼盾的架构。印尼央行发布了白皮书，阐述了数字印尼盾的高层设计。
- 2024年12月，印度尼西亚银行完成了Garuda项目的概念验证。

# 菲律宾

- 菲律宾中央银行于2024年完成了其批发型央行数字货币计划Agila项目的概念验证。该项目涉及多家金融机构，并测试了大额支付技术。
- 菲律宾央行目标在2029年前发行其批发型央行数字货币。在代币化国债试点之后，菲律宾央行也在探索使用央行数字货币结算政府证券。
- 菲律宾央行暂无发行零售型央行数字货币的即时计划。
