# 10年期日本国债能反弹多少？

尽管中东不确定性仍然很高，但日本央行落后于曲线的风险已有所缓解。由于10年期日本国债板块仍带有约30-40个基点的通胀风险溢价，我们认为，随着市场从通胀超调担忧转向增长下行风险，做多中段的风险回报仍然具有吸引力。我们还讨论了寿险公司在2025财年末的披露情况。

# 关键要点

10年期日本国债板块已开始企稳，因为盈亏平衡通胀率停止创出新高，通胀超调担忧有所缓解。
- 日本央行沟通仍偏鹰派，但市场已对未来12个月近三次加息进行定价，前端重新定价的空间有限。
- 如果中东紧张局势持续，通过供应链中断和金融条件收紧削弱增长，中段的通胀风险溢价应会压缩。
- 大型寿险公司在2026财年减少了10年期以上日本国债持仓，因进行从低息债到高息债的换券操作。我们认为净久期需求有限，且没有明显的资金回流迹象。
- 互换和互换期权名义本金下降，因ESR驱动的资产负债管理调整到期；支付方对冲可能被选择性重建以管理退保风险，而非增加整体久期。

# 日本央行落后于曲线的风险有所缓解。

中东局势仍然高度不确定，停火协议的可见度仍然有限。尽管如此，通胀超调的担忧已开始有所缓解。

在Polymarket上，认为霍尔木兹海峡将很快恢复正常运行的看法近期再次消退。即便如此，盈亏平衡通胀率并未创出新高（见图表1）。

在日元利率市场，10年期板块似乎终于找到了更稳固的支撑。这很可能反映了通胀风险溢价的下降，因为通胀超调的担忧已有所缓解。

6月2日的10年期日本国债拍卖出现了大量未识别需求（《日本经济新闻》，6月4日，仅日文版）。

这实际上证实了来自似乎获得直接配售的投资者的强劲需求。

另一方面，短期利率预期开始重新定价走高（见图表2）。在6月3日对木曜会的演讲中，日本央行行长植田和男强调，原油价格上涨将拖累增长，但在当前条件下，他更警惕价格的上行风险。

特别是，行长表示，鉴于企业盈利稳健，以及春季工资谈判后工资上涨和政府减轻能源成本负担的措施支撑了私人消费，经济下行风险有限。

相比之下，日本央行似乎认为价格的上行风险更大。它指出通胀预期呈上升趋势，以及近期企业商品价格指数（CGPI）的上升。

植田行长还强调，实际利率仍为负值，金融条件仍然宽松。他还指出，近期长期收益率的上升源于对日本央行落后于曲线风险的担忧。

在此背景下，他认为，确保市场相信通过适当的货币政策操作能够恰当控制通胀至关重要。鉴于对价格上行风险的明确强调，我们的经济学家维持对6月加息的预测。

总体而言，日本国债曲线本周呈蝶式平坦化（见图表3）。这反映了受日本央行鹰派转向推动，前端为中心的加息预期上升，以及中长期板块通胀风险溢价的下降。

# 我们的观点不同

然而，我们的经济学家认为，第二轮通胀效应不太可能显现（参见《再次迈向3%以上：CPI展望表更新（5月东京CPI初值后）》）。他们还预计，到第二季度将出现增长下行风险。

至少，近期消费相关数据并未显示强劲的通胀势头。正如《通胀风险溢价的下行重估》中所讨论的，剔除特殊因素后，4月消费者价格并不强劲。

4月是许多公司调整价格的时间点。即便如此，涨价压力也不如上一财年强劲。

从《日本经济新闻》CPINow的5月追踪数据来看，接近消费者感知通胀的超市价格持续减速。零售POS销售额实际同比也仍为负值（见图表4）。

这发生在中东不确定性开始浮现之际。在这些结果公布后，我们的经济学家下调了对1-3月实际国内生产总值（GDP）的预测（参见《受资本支出拖累，一季度GDP将被下修：1-3月企业统计》）。

对于4-6月，我们的经济学家预计，如果中东动荡持续，名义GDP在AI相关特殊需求之外也可能显示出停滞迹象。贸易条件恶化将是其中一个传导渠道。

日本央行担忧未来价格的上行风险，包括CGPI上升所暗示的风险。然而，实际数据也显示，增长下行风险正开始显现，即使部分疲软被资本投资需求所部分掩盖。

如果中东局势持续紧张，供应链中断逐渐变得更加明显，市场应开始更多关注增长放缓的风险。在这种情况下，已充分定价于收益率曲线中段的通胀风险溢价应会下降。

# 10年期收益率还能反弹多远？

在《关于我们更新后的日本国债收益率预测的细节》中，我们介绍了一个公允价值模型，该模型利用短期日本央行加息定价和10年期美国国债收益率来解释隔夜指数互换利率。

如该报告所述，10年期日本国债收益率已开始出现一些支撑。即便如此，与公允价值的差距仍然很大（见图表6）。

这一差距在很大程度上可由高企的通胀预期来解释。换言之，收益率曲线中段仍可被解读为包含约30-40个基点的通胀风险溢价。

如上所述，如果市场开始更多关注由中东冲击长期化引发的增长担忧，而非通胀担忧，那么随着该风险溢价的消失，收益率应有进一步下跌30个基点的空间。

市场已几乎完全定价了这种可能性（见图表9）。此外，5月底进行的QUICK月度债券调查显示，基于调查的预期仍以终端利率约为1.5%的主流观点为主。

目前，除能源成分外，中东冲击尚未导致通胀明显加速。在这种情况下，市场似乎难以在未来一年内定价超过三次加息（包括6月加息）。

然而，如上所述，如果供应链停滞和金融状况收紧导致投资者更多关注中东冲击长期化对增长的负面影响，那么加息定价本身的短期路径也可能被下调。

鉴于市场已经定价了较大的通胀风险溢价，我们继续认为做多收益率曲线中段具有吸引力的风险回报比。

# 日本寿险公司在2026财年的投资活动

在2026年3月期，主要寿险公司继续减持并轮出低票息的超长期日本国债。因此，一般账户中的日本国债持有量以及按剩余期限计算的平均久期均有所下降。

主要寿险公司为满足ESR合规要求而进行的ALM久期调整已取得显著进展。鉴于负债久期的缩短和大规模退保风险，寿险公司作为超长期日本国债结构性买家的角色较过去有所减弱。

在衍生品方面，接收方/接收对冲似乎接近完成，而我们相信，作为应对与利率上升相关的动态退保风险和大规模退保风险的保护措施，重建支付方/支付对冲仍有空间。

外国债券余额小幅增加，但这应打些折扣，因为包含了外汇影响。几乎没有迹象显示大规模资金回流日本国债，而通过海外并购、另类投资和离岸再保险获得的间接海外资产敞口的重要性正在上升。

# 日本国债需求符合我们的观点

在2026财年业绩中，日本寿险公司一般账户的日本国债持有量为90.8万亿日元，较2025年9月期减少约4.6万亿日元。从剩余期限看，10年期以上的日本国债持有量减少了类似幅度。平均久期的下降幅度也有所扩大，截至2026年3月，平均久期降至12.1年。

10年期以上持有量的减少主要集中在主要寿险公司。正如《日本寿险公司和家庭的主要变化对固定收益市场意味着什么》所述，主要寿险公司正从低票息债券轮换至高票息债券，同时其相对充裕的股票未实现收益使其有能力抵消因出售债券以避免减值损失而产生的已实现亏损。

与此同时，一些中型寿险公司的日本国债持有量略有增加，但由于主要保险公司的减持规模较大，对总体总量的影响有限。一些实现收益能力有限的中型寿险公司难以像主要公司那样大规模出售低票息债券并实现亏损（另请参阅我们的报告《寿险公司会计准则变更的潜在市场影响》）。

同时，在利率上升的环境下，它们有动力逐步增加收益率较高的债券，从而降低投资组合的平均购入成本并提高账面收益率。仍存在ALM久期错配的寿险公司也可能保留对超长期债券的需求。

正如我们在报告《这是似曾相识吗？》中指出的，我们预计日本寿险公司对超长期国债的投资立场将保持不变。

利率上升提升了超长期国债的投资吸引力，但至少在主要寿险公司中，其操作核心是从低息债券轮换至高息债券，而非简单增加持仓余额。

因此，国债的总交易量应会保持庞大，但我们预计净新增久期需求以及国债持仓增加的压力仍将有限。

如果日元利率大幅上升，经济偿付能力比率（ESR）下的大规模退保风险可能会恶化模型偿付能力，从而削弱增加久期的动力，或增加出售超长期国债的可能性（即负伽马特性）。尽管我们并未假设利率会如此急剧上升，但仅从风险回报角度看，寿险公司的国债需求也可能保持低迷。

从结构性需求角度看，同样重要的是，由于投保人老龄化以及新保单产品组合的变化，负债久期本身已较过去缩短（详见我们的报告）。在低利率时期，寿险公司为进行资产负债管理（ALM）久期匹配并遵守ESR规定，增加了对超长期国债、收取固定利率互换以及收取者互换期权的使用。

然而，如下文所述，主要寿险公司的这一调整已取得显著进展。因此，即使利率水平上升，我们预计过去那种结构性的、对价格不敏感的超长期国债购买行为也不会重现。

# 衍生品需求未来可能呈现分化

日本寿险公司收取固定利率互换与收取者互换期权的简单名义本金总额，从2025年9月期间的5.97万亿日元降至2026年3月的4.62万亿日元。

对于日本寿险公司而言，这些收取方头寸为其使用衍生品进行基于经济价值的偿付能力监管下的ALM久期匹配提供了动力。

*   收取固定利率互换使寿险公司能够灵活地创造久期，而无需像购买现货债券那样大幅调整资产负债表。此外，在满足套期会计要求时，还能减少估值损益的会计波动。
*   收取者互换期权使寿险公司能够构建非线性对冲，在利率下降时增加资产端久期，同时在正常时期支付期权费。

尽管如此，并非所有寿险公司都是衍生品的活跃使用者；这些头寸似乎主要集中在少数几家主要寿险公司。

在主要寿险公司中，为满足监管要求而进行的久期匹配已基本完成，从这个意义上说，增加收取固定利率互换或收取者互换期权的需求可能已较过去下降。

# 外国债券：余额小幅增长；前景依然谨慎

其他证券中的外国债券余额较2025年9月期间小幅增长。按地区划分，拉丁美洲略有下降，而北美和欧洲小幅上升。北美仍占较高份额，占总量的57%。

乍看之下，这有些令人意外，因为国际收支（BoP）净流量数据持续显示卖出趋势。然而，财务报表余额可能不仅反映了简单的交易流量，还包含了日元贬值的影响。

外汇对冲比率持续下降。尽管对冲资产余额在三个半年期以来首次增加，但以外币计价的资产（似乎主要是股票）的增幅更大。

即使外汇对冲成本有所下降，活跃于外国债券投资的寿险公司仍根据汇率和利率水平采取战术性立场。随着全球利率呈上升趋势，结果表明这并非一个他们积极增加敞口的阶段。

2026财年的投资计划也表明，寿险公司对已对冲和未对冲的外国债券仍持谨慎态度。根据我们对利率和汇率的预测，即便是战术性投资，规模也可能有限。

尽管日本国债收益率大幅上升，我们仍不预期会出现大规模资金回流日本国债。自1月以来，超长期日本国债收益率急剧上升，重新引发了日本寿险公司资金回流的讨论，但目前尚无迹象表明这种情况正在发生。

日本寿险公司的增量久期需求已经下降，考虑到负债久期缩短以及ESR框架下的大规模退保风险，一些主要寿险公司甚至可能有动机缩短资产久期，以纠正过度对冲。

寿险公司的资金更可能流向收入来源的多元化，例如海外并购和另类投资，而非回流至超长期日本国债（正如我们在报告《日本寿险公司和家庭重大变化对固定收益市场意味着什么》中所讨论的）。

从资本效率和资产负债管理的角度来看，间接海外投资渠道也变得越来越重要，包括通过离岸再保险转移保险风险，以及再保险公司投资于私募信贷等高收益海外资产。
