# 大中华区科技硬件

# 核心观点

# 智邦科技 (2345.TW, OW, PT NT$3,350)

• 网络交换机将成为2026年主要营收驱动力，AI加速器营收将于2026年下半年回升。
• 光学解决方案营收将于2027年显现，因公司已与潜在客户接洽，但更显著的贡献可能要到2028年才能实现。
• 目标价NT$3,350，基于33倍2027年预期市盈率，当前估值为26倍2027年预期市盈率。

# 嘉泽 (3665.TW, OW, PT NT$3,665)

• 毛利率波动可能是暂时的，应会随着未来几个季度新产品的爬坡而正常化。
• 铜数据互连产品将因客户采用率提升及规格升级而持续增长，而电源互连产品则应受益于今年服务器出货量的增长以及Rubin世代更高的单机价值。
• 光学产品将在2027年获得更多动能，得益于收购XFS后增强的能力和客户关系。
• 目标价NT$3,665，基于30倍2027年预期市盈率，当前估值为19倍2027年预期市盈率。

# 致茂电子 (2360.TW, OW, PT NT$2,800)

• 电源测试业务将受益于服务器机柜功率密度提升及主要客户的产能扩张。
• 半导体与光电业务拥有多重驱动力，包括：1) 新的GPU SLT周期及更广泛的采用；2) 先进封装的计量工具；3) 收发器与CPO的光电测试；4) FT分选机和老化炉的潜在营收。
• 目标价NT$2,800，基于50倍2027年预期市盈率，当前估值为46倍2027年预期市盈率。

# 核心观点

# 川湖 (2059.TW, OW, PT NT$6,650)

- 凭借全面的专利组合、稳健的执行力和强大的客户关系，公司在GPU和ASIC服务器市场均占据主导地位，是AI资本支出周期的良好代表。
• 不同机架上的更多设备正采用导轨套件以便于维护和维修，这对川湖而言是积极利好。
• 目标价NT$6,650，基于34倍2027年预期市盈率，当前估值为28倍2027年预期市盈率。

# 亚德客 (1590.TW, OW, PT NT$2,000) 和上银 (2049.TW, OW, PT NT$400)

- 处于广泛上行周期的早期阶段，与自上而下（JMTBA、美国/中国/欧洲制造业PMI）和自下而上（行业参与者的月度销售和季度盈利）的数据点一致。
• 科技行业持续提振需求，包括半导体、零部件和组装，而中国的电池订单也表现稳健。
- 在整体行业复苏的基础上，亚德客应受益于市场份额增长和直线导轨的增量贡献，而上银则应看到由产能利用率提升和提价支撑的利润率扩张。
- 亚德客目标价NT$2,000，基于30倍2027年预期市盈率，当前估值为21倍2027年预期市盈率。
- 上银目标价NT$400，基于37倍2027年预期市盈率，当前估值为34倍2027年预期市盈率。
