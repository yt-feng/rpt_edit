# 旧款存储：短期趋势分化

近期存储周期讨论 + CSP自由现金流担忧 + 中国存储仓位观点偏谨慎导致旧款存储公司估值下调，但我们看到DDR4价格涨幅更为强劲，且传统闪存定价能力在3季度达到前所未有的水平。我们认为1.0倍2028年预期每股账面价值提供了良好的节奏变化支撑。

主流存储格局转变：根据Trendforce（图表1），3季度26年传统DRAM混合均价预计环比上涨13-18%。具体来看，PC DDR5价格预计环比上涨15-20%，服务器DDR5价格环比上涨13-18%，移动LPDDR5(X)价格环比上涨8-13%，NAND价格环比上涨10-15%。此外，对于4季度26年，Trendforce估计传统DRAM价格环比上涨3-8%，NAND价格环比上涨0-5%。这些预估增长率似乎低于部分读者此前的预期。

然而，近期我们看到传统存储定价走强：与我们之前的报告（链接）类似，我们认为DDR4在3季度可能持续月度涨价。与一个月前的定价预期相比，我们认为CSP愿意为DDR4提供更高定价，甚至可能尝试与供应商签署1-2年的长期协议（仅限数量）。因此，我们认为月度价格在3季度可能上涨20%以上，意味着季度环比涨幅至少为30%。我们仍预计3季度SLC/MLC NAND价格环比上涨50-60%，NOR Flash价格环比上涨30-40%。

相关市场仓位抛售可能趋于稳定：兆易创新发布公告（链接），称公司利基存储产品未来可能面临大幅价格下跌。我们认为这一警示是潜在的长期趋势，而非短期可能性，因为我们仍看到DDR4、SLC/MLC NAND和NOR Flash存在结构性供应缺口，支撑价格持续强劲上涨。

节奏变化支撑在哪里？兆易创新（603986.SS）：作为设计公司，市盈率底部难以衡量，但截至6月29日，该股已从840元高点回调45.6%，提供了一定估值支撑。旺宏/南亚科/华邦电分别交易于1.5倍/1.2倍/1.2倍2028年预期每股账面价值；历史来看，1.0倍是大中华区IDM公司较强的节奏变化支撑位。
