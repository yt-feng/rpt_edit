# 澳大利亚消费 | 亚太地区
# 更剧烈的住房下行带来盈利风险
# 核心要点

住房现已成为需求逆风，预计房价下跌5–10%，成交量下降20–30%。
■ 房价下跌拖累消费者信心和品类支出，而成交量下降则减少了装修和搬家相关需求。
五金建材受直接影响最大，其中MTS比WES对行业和装修疲软更为敏感。
- 大件消费电子产品和住房相关品类（包括家电、地板和户外用品）面临需求走弱。

**五金建材受住房重置影响最大：** WES（Bunnings）和MTS（IHG）对房价下跌、成交量下降和建筑活动疲软具有最直接的敞口。在五金建材领域，我们认为商业/行业客户比DIY更脆弱，原因在于其对建筑活动的敏感性，以及随着房价和成交量走弱，其支出意愿降低。

**大件可选消费需求将走软：** JBH和HVN受到的影响来自房价下跌导致的消费者信心减弱，以及成交量下降减少了搬家相关购买（涵盖消费电子、白色家电和家具/户外品类）。在JBH内部，TGG的敞口更大，而HVN更广泛的住房相关品类敞口则增加了其对住房活动疲软的敏感性。

**评级与预测：** 我们下调了五金建材和大件品类2027财年同店销售增长及利润率假设，并下调了WES、MTS、JBH和HVN的每股收益和目标价。鉴于住房前景走软加剧了本已疲弱的消费前景，我们继续偏好必需消费品（超配 COL / SIG / BGA）而非可选消费品（低配 JBH、SUL、AX1）。

# MS住房观点：对消费意味着什么

住房已从顺风转变为国内需求风险：我们以宏观团队在《澳大利亚宏观+洞察》（《住房游戏规则已变》，2026年5月20日）中详述的预期住房重置为框架，审视对住房敏感性最明显的可选消费股：WES、MTS、JBH和HVN。

**房价下跌削弱了可选消费的财富背景：** 我们预计房价将下跌5–10%，原因是投资者需求减弱，而市场本身已因澳联储加息失去动力。这将抑制支出意愿，其中五金建材、电子产品、家电和家具属于最敏感的品类。

# 成交量下降是住房相关支出的更直接传导渠道：

历史上，5–10%的房价下跌会导致成交量下降20–30%。交易减少意味着装修活动减少、行业需求减弱，以及大型家居用品购买减少。这直接传导至五金建材、建筑产品和零售。

**建筑活动疲软进一步增加了压力：** 政策变化有利于新增供应，但利率上升、成本高企和预售疲软可能在短期内拖累审批和活动，从而加剧五金建材/行业量的逆风。

**宏观背景加剧了品类层面的拖累：** 我们预计国内需求增长将在2027财年放缓至远低于趋势水平，住房和消费是主要的调整渠道。利率上升、财政政策支持减弱以及必要支出成本高企正在挤压可支配收入，影响更广泛的可选消费。

**当前消费盈利假设可能尚未充分反映这一点：** 我们覆盖范围内的共识预测仍暗示需求环境具有韧性。住房主导的国内放缓将使这些假设面临压力，尤其是那些同时暴露于成交量和财富效应渠道的股票。

**WES和MTS受影响最直接，但JBH和HVN也受到冲击：** 成交量放缓、审批疲软和装修需求减弱均对WES（Bunnings）和MTS（IHG）构成利空。对于JBH和HVN，传导渠道是通过住房相关支出（电子产品、家电和家具）走弱，并叠加消费者情绪疲软。

# WES / MTS——五金建材：受住房重置影响最大

在我们覆盖的消费股中，WES和MTS分别通过Bunnings和IHG对住房活动具有最直接的敞口，这两项业务均与住宅建筑、装修活动和行业客户密切相关。

五金建材、建筑产品和DIY品类的需求通常与住宅审批、装修和住房成交量相关，这使得建筑活动的近期前景变得重要。

虽然维修和保养支出通常更具韧性，但大型装修项目和行业活动往往会随着住房成交量、审批和消费者信心放缓而走弱。

我们下调了五金建材相关股票（WES / MTS）的同店销售增长预测，并认为2027财年共识预期面临的风险正在上升。

**WES：** 对于WES，约60%的集团利润来自Bunnings。在Bunnings内部，约40%的销售额与行业客户相关，约60%与DIY相关。历史上，在住房市场疲软时期，DIY比行业客户更具韧性。在最近两次住宅市场疲软期（2019财年和2023财年），Bunnings的同店销售增长较之前年份大幅放缓。2019财年，同店销售增长放缓至3.9%（而此前三年平均约为8%）。同样，2023财年同店销售增长放缓至1.8%（而此前三年平均约为10%）。

MTS：对于MTS，约33%的集团利润来自硬件部门。在硬件部门内部，约60%的销售额与贸易相关，而约40%的销售额与DIY相关，这使得其相比Bunnings更容易受到成交量和建筑活动放缓的影响。对于MTS的硬件部门（IHG），同店销售额增速从FY18的+7.4%放缓至FY19的+3.0%。同样，在FY23，MTS贸易同店销售额增速从FY22的+12.7%放缓至+3.8%。

# WES：评级为EW；目标价78.70澳元/股

盈利预测调整：鉴于我们对房价和住房相关活动（即成交量、批准量）的预期，我们将FY27e Bunnings同店销售额增速从4.0%下调至2.0%。我们还下调了Bunnings FY27e的EBIT利润率（现预计同比持平），以反映疲软的收入增长势头，这使得我们对Bunnings FY27e的EBIT预测比VA一致预期低约2.5%。Bunnings的下调被我们对WESCEF EBIT预测的上调（FY27e EBIT上调+15%）所抵消，后者受到化肥和氨价格上涨（年初至今上涨+10-20%）的推动。

EW观点：我们维持对WES的EW评级。住房的周期性疲软可能会拖累Bunnings的盈利增长；然而，我们预计集团的其他关键业务（K-MART / WESCEF）将继续表现强劲。WESCEF应受益于化肥和氨价格上涨，而K-MART在消费环境疲软的情况下仍是消费降级的受益者。估值仍高于周期中值，为FY27e市盈率30倍。

估值：我们将目标价从79.30澳元/股小幅下调至78.70澳元/股。我们的目标价源自等权重估值方法。基于市场倍数的SOTP目标价现为66.50澳元/股（此前为68.80澳元/股），应用的目标倍数降低（从FY27e市盈率25倍降至24倍），反映了市场倍数的下降。我们的DCF估值现为90.90澳元/股（此前为89.90澳元/股），核心假设不变。

# MTS：评级为EW；目标价3.20澳元/股

盈利预测调整：鉴于近期发布的指引，FY26的风险已降低。我们预计FY27对硬件部门而言将更具挑战性，利润率重建路径的不确定性给部门盈利带来下行风险。我们下调了FY27-28e硬件部门的销售增长和利润率假设，分别将集团每股收益下调1.9%和4.5%。

EW观点：负面的住房情绪以及较低的预期房价和成交量，推迟了住房相关建筑活动的周期复苏，从而拖累硬件部门盈利。我们预计食品与酒类业务将面临竞争压力。我们重申EW评级，因为这些风险已反映在当前估值中。MTS目前的12个月远期市盈率为12倍，低于周期中值估值1个标准差。

估值：我们将目标价下调至3.20澳元/股（此前为3.40澳元/股），源自等权重估值方法。基于市盈率的估值为3.10澳元/股（此前为3.40澳元/股），我们将应用的目标倍数从13倍下调至12倍，略低于周期中值-1个标准差，反映了更为疲软的住房前景。基于DCF的目标价为3.40澳元/股（此前为3.50澳元/股），核心假设不变。

# JBH / HVN - 大件可选消费品：住房周期对需求构成逆风

JBH和HVN受到住房的下游消费和财富效应渠道的影响。两者都受益于与搬家、装修和可选消费支出增加相关的家电和电子产品需求——我们认为所有这些都面临压力。

同样，HVN还涉足家具和床上用品品类，这些与家庭组建和住房成交量相关。

更广泛地说，房价疲软和成交量下降可能会拖累消费者信心和家庭财富感知，从历史上看，这已转化为可选零售品类需求的疲软。

我们下调了对大件/住房相关可选零售商的同店销售额增速预测，并认为FY27e一致预期面临的风险正在增加。

JBH：在最近两次住宅市场疲软期（FY19和FY23），The Good Guys的同店销售额增速疲软（分别为+0.9%和+0.8%）。JBH澳大利亚在FY19显示出类似的减速趋势（+2.8%，而此前3年平均增速约为7%），但在FY23相对具有韧性（+4.8%，受疫情后电子产品需求高涨推动）。

HVN：对住房相关品类（包括白色家电、地板和户外家具）的敞口较大，使其同时受到直接成交量渠道和财富效应的影响。对于HVN，在上次住房低迷期间观察到与JBH类似的趋势。在FY19，国内同店销售额增速放缓至-0.9%（而此前3年平均增速约为4%）。同样，在FY23，同店销售额增速放缓至-5.1%（而此前3年平均增速约为7%）。

# HVN：评级为中性；目标价每股4.70澳元
