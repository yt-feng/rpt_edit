# 美国汽车、汽车零部件与汽车科技  
# 800V：从电动汽车到直流电（及电池储能系统）

寻找拥有非汽车业务机会的汽车公司。投资者持续寻求人工智能数据中心和电池储能系统的投资敞口。汽车公司可能提供独特的投资途径，且估值低于其他工业类人工智能标的。虽然其他工业公司目前拥有更大的敞口以及可观的订单/积压，但汽车公司具备相关能力与新兴机遇，尤其是在800V领域。这些机遇几乎是100%的增量。正如我们在五月初所写，汽车公司拥有深厚的专业化技能（许多技能可应用于其他领域），实行精益制造，并管理着复杂的供应链。这些技能可转化为能源发电/存储、机器人和太空领域的机遇。Modine为汽车向工业的"转型梦想"树立了标杆。

重现2018年的盛况？来自汽车和非汽车投资者对人工智能敞口的新增群体兴趣，自2018年（自动驾驶/电动汽车热潮顶峰附近）以来从未如此之高。不同之处可能在于，电动汽车需求依赖于消费者接受度、法规以及更为遥远的技术，而人工智能数据中心/电池储能系统则基于真实需求和经济回报。虽然BWA和F一直是汽车领域可能性的典型代表，且仍受关注，但下一个最常见的问题是：谁会是下一个？在本报告中，我们深入审视了每家公司的产品组合及其对800V人工智能数据中心和电池储能系统的适用性。我们认为，BWA、APTV和ST处于最佳位置。BWA已宣布其TurboCell产品、电池储能系统以及双向微电网逆变器。但我们也看到了其他逆变器/转换器的潜力。此外，尽管可能较为困难且可能需要投资，但它们也具备固态变压器所需的能力。APTV在高压连接器和母排方面拥有专长，这可能使市场对其8-10%的非汽车年增长目标更有信心。虽然APH和TEL也应受益于更高功率的连接器含量，但它们已拥有部分人工智能电源含量（而我们相信这对APTV而言几乎完全是增量），且APH/TEL可能在铜数据连接器方面失去含量（APTV无相关业务）。随着人工智能数据中心从风冷转向液冷，ST可以获得更多的传感器含量，但ST也拥有可用于800V电动汽车的接触器，这些接触器可用于新的800V应用。

800V带来了有趣的机遇。回顾一下，纯电动汽车的技术路径是转向800V（从大多为400V），因此供应商投资于技术，特别是电力电子领域。供应商已管理着复杂的供应链，并知道如何以高公差进行大规模制造。这一点变得重要，因为下一代人工智能数据中心正在切换至800V，从而改变了电气基础设施。随着GPU集群密度增加，出于物理、热管理、效率、成本和占地面积的原因，转向800V成为必要。这为在逆变器/转换器、高压电源连接器和母排等领域具备能力的汽车供应商打开了机遇之门。此外，电池储能系统也存在800V机遇。

能力 + 机遇 + 低廉估值 = 供应商获得关注。很明显，数据中心资本支出和电池储能系统需求正在增长。UBS证据实验室分析（>访问数据集）显示，除了目前运营中的121吉瓦外，还有181吉瓦的全球数据中心电力容量正在规划或建设中。全球范围内，UBS估计电池储能系统需求将从2025年的约334吉瓦时增长至2030年的约1.6太瓦时。本报告中提及的某些产品的总可寻址市场尚不明确，因为800V直流电仍处于非常早期的发展阶段，且架构可能随时间变化/演进。对于某些关键产品，我们确实做出了（诚然范围较宽的）估计，但就目前而言，我们认为识别能够找到新用例的产品具有价值。在一个被视为增长乏力的行业中，对新增长途径的希望可能导致重新估值（例如BWA和F）。内文请见我们对APTV、BWA、DAN、LEA、MGA、PHIN、ST、VC、VGNT、QS的详细产品组合回顾。

# 新终端市场中的800V机遇

如果800V对汽车投资者来说听起来耳熟，那并不奇怪。这个电压正是纯电动汽车被认为将演进到的（且许多仍将演进到的）电压，即使大多数大众市场车型目前仍为400V。因此，汽车供应链已建立起支持800V的能力。这可能使它们能够很好地受益于其他800V用例，例如在人工智能数据中心以及电池储能系统中。

人工智能数据中心中的800V配电与传统架构对比：随着下一代人工智能数据中心计算能力的提升，电源架构正转向800V（800V直流电）。传统数据中心通过一个复杂的链条传输电力，电力以交流电形式到达，经过多次转换，并以较低电压（较高电流）输送，需要更粗的电缆，产生更多热量，并沿途损失能量。相比之下，800V架构简化了这一流程。电力仍以交流电形式从电网进入，但使用大型交流/直流逆变器（整流器）或在先进设计中使用可直接产生直流电的固态变压器，在早期阶段就转换为高压直流电。

然后，这种高压直流电（较低电流）通过母排、高压布线和专用连接器在整个设施内高效分配，这些基本上是移动大量电力的重型路径，而高压接触器则充当智能开关，以安全地控制和保护电流。在服务器附近，电压被降压至较低水平（利用直流-直流转换器）以供设备使用。由于电力以更高电压传输，输送相同能量所需的电流更少，从而减少了热量，允许使用更细的电缆，并实现更密集的计算硬件。简而言之，新系统用一个更直接、更简化的路径取代了多步骤、低效的输送过程，将更多可用电力输送到机架。我们看到的向800V转变带来的一些机遇：

- 随着电力以高压直流电形式分配，交流/直流转换（逆变器）的作用被集中化（现在仅在电网边缘），数据中心内部的配电更多地依赖于高效直流-直流转换器，以在更接近可用负载的地方降压（像BWA这样的公司具备逆变器和转换器能力）。
- 为较低电压和更简单电力配置设计的传统连接器必须被能够承受更大电气应力并优化效率的高压连接器所取代（APTV拥有用于电动汽车的高压连接器和母排，且这些能力似乎具有可移植性）。
- 更高的计算密度带来了更高的热负荷，从而推动了对更强大的液冷暖通空调解决方案的需求。在这些系统中，压力、温度和流量传感器成为监控运行的关键组件。需要800V接触器（ST可以参与）。

虽然目前采用率仍然非常有限，但主要超大规模云服务商已指出，鉴于计算/电力需求，数据中心必须进行架构转型。例如，英伟达已表示800伏直流电（VDC）将成为“下一代智能的基础架构”。他们预计，800V架构的初步部署将与2027年的下一代机架级系统（Kyber）同步进行，并在本十年末加速采用。

请注意，该架构仍处于初期阶段，因此尽管我们上述详述的内容是架构可能演进的合理路径，但仍有很大变数。

**BESS中的800V：** 在传统BESS中，存储的电池电力通过集中式不间断电源（UPS）和逆变器系统在直流和交流之间反复转换，增加了复杂性和能量损耗。相比之下，800V架构使电力更长时间地保持高压直流形式，允许电池以更少的转换次数更直接地输送能量，从而提高效率并减小系统尺寸。因此，对多级转换和集中式备用系统的依赖减少，而高压电池组和直流原生电力电子设备等新组件取而代之，使系统更高效、更具可扩展性。

从概念上讲，许多汽车公司在800V电动汽车架构方面拥有早期的领先地位和专业知识，已开发出相关能力，并具备工业化、制造、供应链管理以及达到更高质量标准（他们必须学会生产“汽车级”产品）的能力，因此他们在上述两个领域都有合理的切入点进入800V市场。我们不认为存在技术能力不足的问题，但当然需要一定的投资，并理解如何将其专业知识转化到新的终端市场，同时还需要销售方面的努力。但总体而言，我们认为，随着架构趋同，拥有800V专业知识的汽车公司完全有能力将其业务扩展到800V基础设施领域。

在本报告中，我们将逐一审视每家公司的产品组合，以评估他们如何以及是否有资格参与这些新市场。话虽如此，800VDC仍处于非常早期的发展阶段，尚未大规模部署。它也可能随着时间的推移而演变。这确实使得TAM估算变得困难。我们将继续在此方面研究潜在机遇，但目前重要的是，这些公司获得的任何业务都是增量性的，是一个新的增长途径，并且可能关联到一个周期性较弱的市场。

# 各公司能力分析

# Aptiv PLC (APTV)

# 1) 高压连接器（链接）

- 是什么？高压连接器是用于在系统间以高电压传输电力的专用组件。通常由绝缘外壳和导电金属触点制成，比标准连接器更大，保护性更强。
- 在电动汽车中如何使用？这些连接器几乎用于动力总成的各个部分，连接电池组与逆变器、车载充电器（OBC）、DC-DC转换器、充电端口等。
- 如何在BESS和/或AIDC中使用？对BESS和AIDC都有明确的适用性。特别是在AIDC中，向800V架构的转型可能会推动对更高电压互连的需求。

# 2) 母线排

- 是什么？母线排是用于承载电流的实心金属条。通常由铜或铝制成，母线排坚硬且扁平，比电缆更宽，但高度可缩短高达70%。在相同横截面积下，它们还能承载比电缆更大的电流（来源）。
- 在电动汽车中如何使用？母线排已被证明可作为电池互连件，连接现代电动汽车中电池电芯模块之间的短距离（来源）。
- 如何在BESS和/或AIDC中使用？在BESS中，刚性母线排通常用于互连机架内的电池模块，或连接大型电池串至中央逆变器或保护面板。在AIDC中，现代数据中心利用母线槽系统沿服务器机架配电，或在48V电压下集成备用电池。

# 3) 智能保险丝盒

- 是什么？这本质上是一个配电盒，用半导体开关和智能控制器取代了传统的保险丝和继电器。
- 在电动汽车中如何使用？这有助于集中管理配电，同时允许灵活地关闭/转移特定功能（如收音机）的电力。它还能防止故障和/或过载。重要的是，这些是可重复使用的，而保险丝通常是一次性的。
- 如何在BESS和/或AIDC中使用？这些可用于电网级和商业电池储能装置，提供过流保护。在AIDC中，也在使用类似的智能保险丝技术，但它正越来越多地被断路器/固态保护装置取代（或演进为后者）。

# 4) 电池断开单元（BDU）（链接）

- 是什么以及如何在电动汽车中使用？电池断开单元（BDU）旨在高效地将电力分配到整个电动汽车（EV）系统。作为针对不同电动汽车运行模式的电池开关，BDU在实现功能安全目标方面发挥着关键作用（来源）。
- 如何在BESS和/或AIDC中使用？大型电池储能系统倾向于使用类似的断开机制（电池保护单元）。在AIDC中，大型不间断电源（UPS）也需要类似于电动汽车的电池隔离和故障保护。

# 5) 高压配电单元（PDU）（链接）

3/6

- 它是什么？高压配电单元（HV PDU）充当电力分配枢纽，将电池的主电源输入分流至多个包含保险丝、继电器、有时还有断路器的电路。
- 它在电动汽车中如何使用？通常将高压电池电力分配至逆变器、DC-DC转换器、车载充电机（OBC）等组件。
- 它如何在电池储能系统（BESS）和/或人工智能数据中心（AIDC）中使用？BESS 通常包含汇流箱，多个电池组串在此汇合后再接入中央逆变器或电网连接（功能类似于 PDU）。在 AIDC 中，PDU 已被用作落地式或机架式解决方案。

# 博格华纳公司 (BWA)

# 1) 涡轮发电机 (链接)

- 它是什么？这是一种模块化、高效率的发电解决方案，预期将供应给数据中心，用于备用电源和主用电源，具备先进控制和动态响应能力，以管理功率瞬变和电网峰值。
- 潜在市场机会有多大？从技术上讲，这并非 800V 的机会，但与人工智能数据中心主题相关。BWA 提到，他们预计该产品在 2027 年将带来超过 3 亿美元的销售额，尽管尚未达到满负荷运行率。BWA 表示他们计划达到 2GW 的产能。我们估计 BWA 的每千瓦成本（CPV）约为 900-1000 美元。
- 注意，我们认为投资者正在寻求关于 TurboCell 的更多更新，包括客户、订单以及用于扩大产能的新资本支出投资。

# 2) 高压逆变器 (链接)

- 它是什么？逆变器在直流电（DC）和交流电（AC）之间转换电力。其核心技术类似于 DC/DC 转换器。
- 它在电动汽车中如何使用？它将来自电池的高压直流电逆变为多相交流电以驱动电机。如果是双向的，它还有助于将再生制动产生的交流电转换为直流电，为电池充电。
- 它如何在 BESS 和/或 AIDC 中使用？逆变器技术大体相似，但在固定式/电网应用中，它作为并网电力转换器，实现储能、现场发电和电网之间的双向电力转换。BWA 已开始推广其在此领域的能力。

# 3) 高压 DC/DC 转换器 (链接)

- 它是什么以及如何在电动汽车中使用？DC-DC 转换器是暂时存储电能，以将直流电（DC）从一个电压水平转换为另一个电压水平的设备。在汽车应用中，它们是连接车辆内不同电压水平系统的重要中间设备（来源）。其核心技术类似于逆变器。
- 它如何在 BESS 和/或 AIDC 中使用？BESS 可能利用 DC/DC 转换器为其他组件提供稳定的低压电源。在 AIDC 中，虽然通常使用 AC-DC 整流器，但一些现代架构正转向 48V 配电，DC/DC 转换器有助于实现电池组的电压转换。

# 4) 高能电池系统 (链接)

- 它是什么？这些是用于商用车的（CV）高容量电池包。注意，BWA 仅负责电池包组装，其电芯从第三方采购。
- 它在电动汽车中如何使用？这些电池包为电动汽车（或商用车电动车）提供动力源。
- 它如何在 BESS 和/或 AIDC 中使用？该产品可用于制造 BESS 模块；可将多个电池包串联/并联连接，形成用于电网储能和备用的电池组。在 AIDC 中，用例包括机架内的电池备份单元（BBU）或用于备用电源的 UPS 电池组。BWA 已开始推广其在此领域的能力。

# 5) 发电机电池解决方案 (GBS) (链接)

- 它是什么以及如何在 BESS 和/或 AIDC 中使用？在快速负载瞬变期间支持基于发电机的系统，减少发电机压力，并提高电网受限或离网环境下的稳定性（来源）。

# 6) 不间断电源 (UPS) (链接)

- 它是什么以及如何在 BESS 和/或 AIDC 中使用？在发电机完全接管运行之前，桥接短暂的电网中断，维持对关键负载的供电（来源）。

# 7) 电池备份单元 (BBU) (链接)

- 它是什么以及如何在 BESS 和/或 AIDC 中使用？保护高密度机架免受即使是短暂的电力中断影响，确保持续运行关键计算和数据工作负载（来源）。

# 8) 双向直流快速充电桩 (链接)

- 它是什么？将三相交流电转换为直流电，用于电池快速充电，既可从电网充入电动汽车电池，也可反向放电。
- 它在电动汽车中如何使用？提供电动汽车电池组的快速充电。当提供车辆到电网（V2G）电力时，它可以从电动汽车中取电，为家庭供电或在高峰时段稳定能源需求。
- 它如何在 BESS 和/或 AIDC 中使用？在 BESS 中，类似技术可用作固定式电池组与电网之间充放电的接口，但规模更大，属于电网级应用。

# 9) 车载充电机 (OBC) (链接)

- 潜在市场机会有多大？数据中心内部存在UPS机架的潜在机会（目前为数十亿美元，到本十年末增长至数百亿美元）。在数据中心外部的储能领域（但仍支持AIDC），我们估计该市场目前约为10-20亿美元，并在未来5-10年内增长至60-100亿美元。

# 估值方法与风险声明

我们采用多种基准组合来评估我们的覆盖范围。风险包括：1) 汽车行业具有周期性，受许多可能影响车辆需求和产量的经济因素影响。2) 市场竞争激烈，可能发生份额变化或关键客户流失。3) 大宗商品、外汇、劳动力和其他投入成本可能与我们假设的不同。4) 技术和内部化风险。5) 供应链和执行风险。6) 未来增长的投资可能超出我们的预期。7) 新车的定价可能远低于我们的预期。
