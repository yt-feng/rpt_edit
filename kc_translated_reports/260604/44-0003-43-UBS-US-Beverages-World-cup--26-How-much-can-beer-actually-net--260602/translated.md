# 2026年世界杯：啤酒究竟能带来多少净收益？  
# 世界杯对啤酒销售意味着什么？  

与一段时间以来的情况一致，酒精饮料行业背景依然不温不火，这主要是由于消费者偏好的演变以及更广泛的健康/养生趋势对该品类造成了压力（链接）。啤酒尤为感受到这些挑战，因为受人口结构和消费者挑战的影响，其销量仍处于负增长区间。然而，近期市场焦点更多地集中在2026年世界杯上，将其视为该领域即将到来的催化剂，我们覆盖的多家公司（STZ、SAM、TAP）均将其视为可能为销量带来增量提振的事件。在此背景下，我们认为研究该事件对啤酒及更广泛的酒精饮料板块的潜在影响会很有趣。在本报告中，我们利用尼尔森和欧睿的数据，以及此前体育赛事期间的酒精饮料销售情况，来量化未来几个月世界杯对啤酒销量的提振作用。  

# 公司对世界杯有何评论？  

在过去的几个季度中，围绕2026年世界杯的讨论在酒精饮料公司的财报和会议评论中变得越来越突出，管理层普遍将该事件视为一个有意义的、但并非变革性的需求催化剂。在TAP、STZ和SAM中，世界杯一直被强调为一个关键场合，能够推动社交聚会、堂饮消费和消费者参与度的增加，尤其是在主办城市。然而，各公司一致强调，其主要价值在于其作为长期营销平台的作用，而非基础需求的必然阶梯式变化。因此，尽管该事件被视为一个明显的顺风，但管理层尚未将显著的销量增长纳入考量，而是将其定位为一个依赖执行、并能放大现有趋势的事件。  

# 以往体育赛事的数据显示了什么？  

回顾以往的世界杯周期，啤酒始终是赛事期间增量消费的主要受益者。在过去三届世界杯中，德国（2006年）的月度啤酒销量估计增长了约+9%（或年度增长1%），巴西（2014年）年度增长+3.5%，俄罗斯（2018年）年度增长+3.2%，卡塔尔（2022年）年度增长+32.1%，这凸显了与全球比赛观看场合相关的需求存在可重复的提振效应。尽管增长幅度各不相同（卡塔尔较小的基数扭曲了结果），但更广泛的趋势表明，主办国的销量在世界杯年份有所扩张。在美国，尼尔森数据显示，过去四届超级碗为啤酒销量带来了约+7%的增量（相对于季节性调整后的趋势）。然而，将此推算到世界杯，我们估计年度总提振效应将小于1%。  

# 这对世界杯意味着什么？  

对于2026年在美国、加拿Daiwa墨西哥举办的世界杯——这些市场在结构上以啤酒为中心——我们预计销量和零售额将出现温和的低个位数百分比增长。这一预期基于：（1）赛事持续时间长，且与核心社交和家庭消费场合高度契合；（2）在德国、巴西和俄罗斯此前几届世界杯期间观察到的持续的低个位数百分比销量增长；（3）根据近期超级碗趋势估算出的低个位数百分比的年度影响。话虽如此，我们对此展望持谨慎态度，因为当前美国消费者背景仍面临一定压力，这可能会抑制增量支出的程度，即使参与度和观看场合依然强劲，且公司评论（见下文）表明一些同行预计销量反应将较为平淡。

# 过往世界杯赛事对消费有何影响？

## 世界杯期间的啤酒销量

为评估即将到来的2026年世界杯对我们覆盖范围内公司的潜在影响，我们考察了过去三届国际足联世界杯（2014年巴西、2018年俄罗斯和2022年卡塔尔）的场内和场外啤酒销量，重点关注每届赛事前后及期间主办市场的表现。总体而言，各届赛事的结果大致一致，世界杯当年的销量相对于赛事前后两年有明显提升。

巴西的场内销量在2014年同比增长+3.5%，俄罗斯在2018年增长+4.3%，卡塔尔在2022年增长+35.8%。然而，我们注意到卡塔尔的销量与之前的主办国相比仍然相对较小，年均约为巴西和俄罗斯销量的约10个基点。同样，场外销量在每个主办年也出现增长，巴西、俄罗斯和卡塔尔的消费量同比均较周边时期有可测量的增长（巴西+3.6%，俄罗斯+3%，卡塔尔+21.9%）。总体而言，巴西的总销量增长+3.5%，俄罗斯增长+3.2%，卡塔尔增长+32.1%。值得注意的是，俄罗斯世界杯的增长是在赛事前呈下降趋势的情况下实现的，其销量在赛事前自2010年以来以约-5%的年复合增长率收缩，这表明即将到来的2026年赛事可能暂时抵消品类的潜在疲软。

我们还分析了德国历史上的月度啤酒销量，以评估世界杯赛事期间消费模式的变化。自1995年以来，经季节性调整后，啤酒销量每年结构性下降-1%。然而，仅看2006年世界杯（6月9日至7月9日），我们发现该赛事在6月份带来了约+9%的销量提升。将此提升应用于全年，我们估计这意味着2006年德国啤酒年销量可能比当前趋势线所暗示的水平高出约+1%。

虽然这表明即将到来的世界杯期间，美国6月/7月的销量可能获得约9%的增量提升，但我们认为应降低预期，原因如下。首先，美国酒店与住宿协会在其2026年世界杯酒店展望中指出需求疲软，因为尽管国内旅游仍具韧性，但国际旅行正受到赴美旅行障碍增加和成本上升的制约。值得注意的是，80%的受访者报告酒店预订量低于初步预测。其次，相比之下，德国在2006年经历了自2000年以来的最高过夜住宿量，根据国际旅游博览会和IPK国际的数据，过夜量同比增长10%，这表明当时的入境旅游背景比我们现在看到的要强劲得多。第三，虽然足球是德国最受欢迎的运动，但根据《经济学人》的数据，它在美国仅排名第四，这可能会限制国内增量消费的规模。

## 世界杯期间的烈酒销量

转向烈酒，过去三届世界杯前后的消费趋势显示出与啤酒相似但更为温和的模式，仅在主办年有适度提升。巴西2014年场内销量同比增长+3.7%，俄罗斯2018年增长+4.3%，与啤酒大致持平，而卡塔尔2022年增长较小，为+26.1%，尽管基数要小得多（销量不到巴西和俄罗斯的20个基点）。场外趋势同样积极，但在所有三个国家均略低于啤酒（巴西+2.5%，俄罗斯+2.3%，卡塔尔+20.2%）。总体而言，巴西的烈酒总销量增长+3.2%，俄罗斯增长+2.4%，卡塔尔增长+23.4%，表明世界杯带来的提升与啤酒相比大致一致但不太明显。

# 人们在世界杯期间喝什么？

我们评估了过去四届世界杯（2010年南非、2014年巴西、2018年俄罗斯和2022年卡塔尔）期间的酒类品类结构趋势，考察了各主办国在赛事前后及期间的消费表现。初步来看，世界杯年份的品类结构趋势显示出酒精消费模式的转变：烈酒份额上升，而啤酒在堂食和外卖渠道均趋于温和。具体而言，啤酒销量占总酒精销量的比例在这些年份从约63%（堂食）/56%（外卖）下降至34%（堂食）/13%（外卖）。相比之下，烈酒的品类占比相对上升，从14%（堂食）/20%（外卖）增至48%（堂食）/64%（外卖）。这种品类结构的演变意味着，展望2026年世界杯，烈酒相比啤酒可能成为增量消费的更大受益者。

# 过往本土体育赛事/节假日对消费有何启示？

分析美国的主要饮酒活动（超级碗和独立日）可以发现，等量单位和外卖量均呈现明显的季节性模式，并在美国重大体育和文化活动期间出现急剧峰值。在1月和2月的冬季低谷之后，超级碗带来了全年的第一个显著峰值。此后，销量在春季稳步攀升，并在7月达到绝对峰值，与独立日庆祝活动一致。随后趋势在年内剩余时间稳步下降。

# 估值方法与风险声明

SAM估值方法：加权平均估值框架，涉及远期市盈率和EV/EBITDA，并辅以10年DCF模型。SAM目标价的风险包括以下任何重大变化：(a) 与酒精/烟草产品消费相关的普遍消费者偏好和/或政府监管（包括税收、销售限制、替代产品的引入或补贴等）；(b) 与商业和/或税收相关的政府监管；(c) 我们公司任何关键市场的宏观经济趋势、利率和/或信贷环境；(d) 我们公司任何关键市场中酒精/烟草公司之间的竞争强度；(e) 客户或供应商关系；(f) 商品成本和/或外汇波动；(g) 我们公司自身的执行能力，无论是在研发、销售和营销，和/或持续的效率提升方面；(h) 我们公司对并购（无论是收购、合资、剥离或其他）的立场，或对现金的整体优先排序（无论是用于有机业务投资、股息、股票回购等）。

BFB估值方法：加权平均估值框架，涉及远期市盈率、EV/EBITDA。BFB目标价的风险包括以下任何重大变化：(a) 与酒精/烟草产品消费相关的普遍消费者偏好和/或政府监管（包括税收、销售限制、替代产品的引入或补贴等）；(b) 与商业和/或税收相关的政府监管；(c) 我们公司任何关键市场的宏观经济趋势、利率和/或信贷环境；(d) 我们公司任何关键市场中酒精/烟草公司之间的竞争强度；(e) 客户或供应商关系；(f) 商品成本和/或外汇波动；(g) 我们公司自身的执行能力，无论是在研发、销售和营销，和/或持续的效率提升方面；(h) 我们公司对并购（无论是收购、合资、剥离或其他）的立场，或对现金的整体优先排序（无论是用于有机业务投资、股息、股票回购等）。
