# 中国功率半导体
# 供应持续偏紧，SiC渗透率提升
# 供应趋紧与SiC采用增强；上调士兰微至买入

在我们4月的行业报告中，我们强调供应紧张是中国功率半导体周期复苏的关键驱动因素。此后，我们看到全球功率半导体供应链有更多评论指出，供应将持续偏紧，原因在于：1）资本支出仍保持克制；以及2）新能源、电网、核心与物理AI领域的需求具有韧性。此外，与硅基产品相比，SiC提供了有吸引力的性价比，这将推动SiC在包括电动汽车、储能和AIDC在内的各个终端市场的渗透，使具备SiC研发能力的供应商（如士兰微和斯达半导）受益。反映这一好于预期的周期复苏和SiC渗透，我们上调了NCE、士兰微和华润微的盈利预测和目标价，并将士兰微从中性上调至买入，原因是其在供应紧张和SiC领域强大布局下可能实现的利润率扩张。我们下调了斯达半导的盈利预测，以反映其从轻晶圆厂模式转型带来的更高负担，但预计其强大的研发能力将使其能够扩大市场渗透，并在2026-28E期间实现44%的每股收益复合年增长率，而我们之前的预测为34%。

# 供应持续紧张带来利润率上行空间；偏好功率IDM

鉴于下游需求强劲且资本支出仍保持克制，供应紧张可能持续更长时间，我们偏好功率IDM。我们对华润微和士兰微的净利润预测高于Wind一致预期。随着华润微和士兰微的产能均得到充分利用，且NTM PB低于2020年以来的历史均值，我们认为这两只股票存在重估空间，因为投资者可能忽略了本轮周期由供应紧张支撑，且供应有保障的功率IDM比无晶圆厂公司拥有更好的利润率前景。我们预测华润微/士兰微的净利润率在2026-28E期间将扩大5-8个百分点，净资产收益率将从2025年的2.9/3.3%改善至2028E的9.6/12.0%。

# 令人信服的性价比释放SiC增长

随着包括xEV、ESS和AIDC在内的多个下游行业在经历多年价格下跌后SiC渗透率上升，我们也对SiC的采用更加乐观。这一趋势反映在全球供应链的评论以及华润微和士兰微满载的SiC生产线中。在我们的覆盖范围内，斯达半导和士兰微的SiC收入敞口更高。

# 在供应持续偏紧中偏好功率IDM；上调士兰微至买入

在周期复苏中，全球功率半导体股票年初至今平均上涨135%。同期中国公司仅上涨34%，但我们预计它们将迎头赶上，尤其是功率IDM。我们注意到英飞凌于5月27日宣布了2026年的第二次提价。对利润率前景和SiC增长更加乐观，我们上调了士兰微、NCE和华润微的每股收益预测，这些预测高于Wind一致预期。我们下调了斯达半导的每股收益预测，以反映其从轻晶圆厂模式转型带来的更高负担，但预计其强大的研发能力将推动2026-28E期间每股收益复合年增长率达到44%。

# 关键问题

# 问：中国功率半导体公司能否从2026年起恢复收入增长？

能。我们预计供需状况将进一步改善，功率IDM和特色代工厂的利用率提高即为证明。我们预测所覆盖功率半导体公司的合计收入复合年增长率将从2023-25年的11%加速至2026-28E的18%，原因是新能源需求强劲以及来自AI（涵盖电网、核心和物理AI应用）的需求上行。

# 问：2026年功率半导体供应商的利润率会扩大吗？

会。我们预计供需动态改善将推动价格复苏，所覆盖功率半导体股票的净利润率在2025-28E期间将扩大2-8个百分点。在该板块中，由于供应约束更紧，我们预计功率IDM（华润微和士兰微）的净利润率扩张幅度（5-8个百分点）将大于轻晶圆厂/无晶圆厂公司（斯达半导和NCE Power）（2-4个百分点）。

# UBS-S观点

我们预计功率半导体板块的供应状况将持续偏紧，原因在于：1）资本支出仍保持克制；以及2）本地化程度提高和下游需求增长带来的持续需求增长。我们估计所覆盖功率半导体公司的合计收入增长将从2023-25年的11%复合年增长率加速至2026-28E的18%。我们对士兰微、华润微和NCE Power的每股收益预测高于Wind一致预期。中国功率半导体股票落后于全球同行，但我们预计它们将迎头赶上，尤其是功率IDM，因为本轮上升周期在供应持续偏紧的条件下得以延续。

# 证据

1）功率IDM的资本支出在2023-25年放缓；2）功率IDM和特色代工厂的利用率进一步改善；3）台积电宣布计划逐步将其部分8英寸和12英寸晶圆厂转换为先进封装，英飞凌宣布将部分闲置IGBT产能转换为先进MOSFET；4）全球和国内功率分立器件公司已在2026年初宣布提价；5）全球供应链对SiC采用的评论乐观。

# 市场已反映什么？

全球功率半导体股票年初至今平均上涨135%，而中国同行平均仅上涨34%，中国功率IDM（如士兰微和华润微）仅上涨15-24%。我们认为投资者忽略了本轮功率半导体周期由更紧的供应条件支撑，功率IDM有望获得更强的利润率。

# 盈利预测与目标价修订

士兰微：供应紧张与SiC渗透率提升的主要受益者

上调2026-28E每股收益5-14%，较Wind一致预期高出8-23%；上调目标价至46.20元人民币；上调至买入

由于硅基和碳化硅基生产线以及LED生产线的利用率均高于预期，我们上调2026-28E每股收益预测5-14%，反映了更积极的利润率预测。我们2026-28E的每股收益预测现在比Wind一致预期高出8-23%。随着供应状况将持续偏紧，我们看到了长期净资产收益率前景增强的更高可见性。我们预测士兰微的净资产收益率将从2025年的3.3%改善至2028E的12.0%，现在我们以5.2倍2027-28E平均目标市净率（此前为3.6倍2027E市净率）对该股进行估值，参考其自2020年以来的历史平均市净率，因为我们预计2026-29E期间净资产收益率将改善至7-12%（而2020-25年期间平均净资产收益率为8%）。

# 华润微：供应持续偏紧下存在进一步重估空间

我们2027-28E的每股收益预测较Wind一致预期高出16-31%；上调目标价至83.40元人民币

我们对华虹半导体保持乐观，因其代工业务在供应紧张的环境下具备上行空间，并预计投资者将日益认可其通过外部客户合作获取市场份额的能力。我们对2027-2028年每股盈利的预测比万得一致预期高出16-31%。我们现以2027-2028年平均目标市净率4.1倍（此前为2027年预期市净率3.5倍）对该股进行估值，参考该公司在2023年实现7%净资产收益率时的峰值估值，而我们预测其2027-2028年净资产收益率将提升至8-10%。维持买入评级。

# 新洁能：AI数据中心进展稳健及新能源市场份额提升驱动估值重估

上调2027-2028年每股盈利预测11-17%，较万得一致预期高出8-15%；上调目标价至人民币81.30元

鉴于竞争格局更为良性，我们对MOSFET的利润率前景较IGBT更为乐观。我们持续看好新洁能，因其在数据中心、机器人和低空飞行器等多个应用领域具备研发能力，且在汽车MOS产品中市场份额持续提升。我们上调2027-2028年每股盈利预测11-17%；新预测较万得一致预期高出8-15%。我们现预计新洁能每股盈利增速将从2023-2025年的10%加速至2026-2028年的37%年复合增长率（此前为24%）。我们现以2027-2028年平均目标市盈率40倍（此前为2027年预期市盈率30倍）对该股进行估值，参考其历史平均市盈率（此前为保守目标价，低于历史平均市盈率一个标准差），得出新目标价人民币81.30元。维持买入评级。

# 斯达半导：强大研发能力助力碳化硅及新应用增长

我们下调2026-2028年每股盈利预测25-37%，以反映从轻晶圆厂转型带来的更高折旧负担；上调目标价至人民币166.60元，因预计其碳化硅能力将驱动估值重估

我们认为投资者认可斯达半导的研发能力，因其在IGBT市场拥有良好记录且碳化硅业务增长强劲。我们下调2026-2028年收入预测11-22%，计入对汽车IGBT定价更为谨慎的展望，我们认为该因素在其一季度业绩后已被市场广泛认知。我们预计将出现环比复苏，因近期全球同行宣布涨价预示着价格回升。我们下调斯达半导2026-2028年每股盈利预测25-37%，以反映其从无晶圆厂向轻晶圆厂转型带来的更高折旧成本，以及对斯达半导IGBT业务更为谨慎的利润率预测，部分被碳化硅的强劲增长所抵消。我们改变估值方法，现以2027-2028年平均目标市净率5.0倍（此前为2027年预期市盈率35倍）对该股进行估值，与我们用于其他IDM/轻晶圆厂半导体股票的估值方法一致。我们的目标市净率与中国功率半导体及模拟公司2027-2028年平均市净率一致，并考虑了斯达半导在功率分立器件及模拟产品领域的积极扩张。

# 储能：有吸引力的全生命周期成本支持碳化硅替代

作为一个成本敏感型行业，储能领域也在加速采用碳化硅，因其全生命周期成本相比硅基产品变得更具竞争力。

自2025年以来，我们看到包括阳光电源、特斯拉和比亚迪在内的领先企业推出了旗舰储能系统产品以应对大型储能需求，这些产品均采用了碳化硅，实现了更高效率。我们相信，旗舰储能产品中采用碳化硅代表了重大的技术进步，并预示着未来碳化硅在储能产品中的进一步渗透。

# AI数据中心：碳化硅的新增长驱动力

除了碳化硅在电动汽车和储能领域日益增长的采用外，数据中心越来越多地使用碳化硅可能成为其下一个主要增长驱动力，尤其是在向800V直流平台转型的背景下。

根据我们全球团队的详细自下而上分析，每个机架的功率半导体含量随功率密度提升而增加。该团队估计，每吉瓦的功率半导体含量将从Rubin NVL72机架的8000万美元翻倍以上，增至Rubin Ultra NVL576机架的每吉瓦1.8亿美元，这得益于向800V直流的转型，该转型在整个功率转换环节中需要更高性能的产品和宽禁带材料。

我们认为，随着碳化硅在电源中的应用增加，拥有超越硅基产品更广泛产品组合的公司未来可能更受青睐。

对于中国功率半导体供应商而言，多家公司正积极投资碳化硅领域的研发，尤其是针对数据中心应用，尽管目前直接来自AI数据中心的碳化硅收入敞口仍然非常有限。我们预计，碳化硅更广泛采用导致的供应进一步收紧将带来积极影响。

# 估值方法与风险声明

投资中国半导体板块涉及高度风险。快速的技术变革、日益激烈的竞争以及宏观经济周期的影响，是半导体股票投资者面临的众多风险之一。此外，由于半导体公司的运营模式高度波动且难以预测，预测其财务业绩非常困难。最后，对半导体股票进行估值可能颇具挑战，因为无论是传统还是非传统的估值方法，都未能为这些股票的走势提供太多洞见。中国的半导体公司还面临政治风险，包括政府政策和供应链限制。

我们采用市净率（P/BV）方法对斯达半导进行估值。下行风险包括：1）中国IGBT行业因晶圆产能过度扩张导致竞争加剧，可能造成市场份额流失或利润率进一步下滑；2）碳化硅MOSFET器件在电动汽车上的渗透速度慢于预期；3）地缘政治紧张局势升级，可能阻碍斯达半导的海外业务扩张。上行风险包括：1）功率半导体需求显著复苏，尤其是来自消费和工业终端市场；2）代工厂大幅降价，可部分对冲因产品平均售价下降导致的利润率下行；3）新建内部晶圆厂的生产爬坡进度好于预期；4）赢得海外汽车OEM或一级供应商的新产品设计订单。

我们采用市盈率（PE）方法对新洁能进行估值。下行风险包括：1）功率半导体消费和工业终端市场的需求复苏慢于预期；2）汽车和太阳能应用的功率半导体需求意外疲软；3）中国功率半导体行业因晶圆产能过度扩张导致竞争加剧；4）IGBT模块开发进展慢于预期。

我们采用市净率（P/BV）方法对华润微进行估值。下行风险：1）向电动汽车和绿色能源的转型慢于预期；2）下游应用需求弱于预期；3）国内竞争加剧；4）其产品无法满足市场需求。上行风险：1）向电动汽车和绿色能源的转型快于预期；2）下游需求复苏快于预期；3）车规级IGBT设计导入进展快于预期；4）其产品取得重大研发突破。
