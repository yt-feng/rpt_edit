# 苹果追踪（4月）：在萎缩市场中iPhone收入同比增长6%

苹果追踪报告解析了来自Counterpoint和Sensor Tower的最新iPhone销售与服务数据，并分析了这对苹果及供应链的意义。更多关于我们对苹果的观点，请参阅我们的苹果深度研究报告。

全球iPhone 4月渠道销售收入同比增长5.6%，销量增长2.5%，均价增长3%。尽管同比增速看似放缓，但这部分是由于2025年4月（关税公告）的高基数效应，且在萎缩市场中表现卓越。Counterpoint预计2026年全球智能手机销量将下降14%。

我们预计苹果不会像同行那样在周期内提价，而是继续通过向高端Pro、Pro Max机型以及更大存储配置的混合转变来推动均价提升。在美国，4月iPhone销量同比下降7%，出货量下降13%，均价增长6%。美国市场的同比疲软主要反映了2025年4月需求提前释放带来的高基数效应。在中国，4月iPhone销量同比增长5.6%，完全由均价提升驱动，销量基本持平。

尽管开局稳健，但17e在最初七周的需求落后于16e，部分原因是北美运营商促销力度减弱以及预付渠道仍更集中于16e。然而，若考虑iPhone "e"系列（16e加17e）的总销量，自17e发布以来的最近两个月同比去年同期有所增长。

出货量和渠道销量同比增长3%，反映了强劲的iPhone 17周期。由于渠道销量低于出货量，库存量环比增加，我们看到库存周数显著上升。

对于代工厂/台积电：iPhone 17e表现较弱拖累了台积电N3P的势头，但我们认为整体上苹果相比其智能手机同行仍更具韧性。即使苹果或任何移动客户释放领先制程产能，该产能也将被AI应用填补，台积电不会经历收入损失。

对于存储：4月DRAM内容同比增长26%，而2024至2025年全年增长率为20%。我们将关注近期存储价格上涨对未来趋势的影响。

对于苹果供应链其他部分：渠道调研显示折叠屏手机的出货可能延迟，而产品发布仍定于9月。尽管如此，我们仍预计苹果供应商今年表现将优于安卓阵营，利好立讯精密。但对于索尼，今年CIS可能不会有升级，我们预计2027年其份额被三星侵蚀的风险较高。对于高通，iPhone 17基础版和Pro机型的强劲表现短期内可能有所帮助，尽管安卓表现似乎因存储价格上涨和苹果份额增长而承压（这两者均非正面因素，尤其是随着苹果长期内越来越多地采用自研方案）。

# 1. IPHONE表现依然稳健：全球收入同比增长5.6%，销量同比增长2.5%，均价增长3%。

现状 - Counterpoint最新的智能手机市场展望追踪报告目前预测2026年全年出货量同比下降13.9%至10.8亿部，较2月预测的12.4%收缩进一步下调。疲软主要偏向低端设备，这些设备的需求和生存能力恶化最为严重。

全球范围内，智能手机批发价格在第一季度上涨14%，随着冲击前库存耗尽，上行压力预计将持续。多个低于150美元的价格层级正面临看似结构性、可能永久性的市场退出。相比之下，高端市场表现出更强的韧性。苹果和三星凭借整合的供应链和成熟的高端化战略，仍处于最佳位置。尤其是苹果，不太可能在周期内提价，而是依靠持续向高端Pro和Pro Max机型（包括更大存储配置）的混合转变。4月，iPhone表现依然稳健：全球渠道销售收入同比增长5.6%，销量增长2.5%，均价攀升3%。

在美国，4月iPhone销量同比下降7%，出货量下降13%，均价增长6%。同比疲软主要反映了2025年4月需求提前释放带来的高基数效应。iPhone 17e表现稳健，但促销活动相比去年16e有所减弱，导致了销量下降。Verizon和T-Mobile对苹果和三星设备的促销力度均已放缓。在预付渠道，需求继续集中于iPhone 16e，因为iPhone 14和15等旧款机型销售进一步放缓。Cricket在4月停止推广iPhone 13，现以16e作为其旗舰苹果产品。17e目前主要定位在后付费渠道，但预计今年晚些时候将在预付渠道获得更广泛的分销。

在中国，iPhone 4月销量同比增长5.6%，完全由更高的平均售价（ASP）驱动，销量基本持平。市场上没有苹果主导的大型折扣活动，但全国性的以旧换新和回收补贴计划仍在进行。对于即将到来的618购物节，促销活动于2026年5月15日左右开始，包括在京东和天猫等平台上对iPhone 17 Pro降价1000元人民币。

# 2. iPhone 17e 相较 iPhone 16e 的同比表现正在走弱

尽管iPhone 17e在上市初期的日均销量似乎领先于iPhone 16e，但纳入4月数据后显示，其相对16e的表现较弱。2026年4月，17e销量为160万部，低于2025年4月16e的180万部，这使得17e在2026年3月至4月的日均销量降至6万部，低于16e在2025年2月至4月上市窗口期的日均6.429万部，意味着下降了6.7%。尽管开局强劲，但17e的需求在最初七周内落后于16e，部分原因是北美运营商促销力度减弱，以及预付渠道仍更集中于16e。

然而，从合并数据看，2026年3月和4月iPhone e系列的销量高于2025年同期，16e和17e合计销量在2026年达到420万部，而去年为370万部，同比增长约14%。重要的是，2025年市场上只有16e，而2026年同时有16e和17e，消费者可以在两款机型中选择；因此，仅看17e对比16e可能会低估潜在需求，而合并的e系列销量表明2026年是更强的周期，3月至4月销量为420万部，而去年同期为370万部。

# 3. 渠道库存高企

全球iPhone出货量和销量在4月环比下降，但销量仍同比增长3%，反映出强劲的iPhone 17周期。由于销量弱于出货量，库存量环比增加。此外，我们看到库存周数显著上升。

iPhone销量环比下降，但4月出货量和销量均同比增长3%。4月，全球iPhone出货量环比下降20%，而销量环比下降15%。然而，与2025年4月相比，出货量和销量均增长了3%（图表9）。尽管环比下降，但iPhone 17系列似乎仍是关键增长动力，持续的增长势头推动了同比增长。

库存周数在4月显著增加。由于出货量1800万部略高于销量1740万部，渠道库存量环比增长2%至4140万部（图表9-图表11），而库存周数从3月的8.6倍攀升至10.3倍，而2025年4月为8.7倍（图表12）。尽管库存周数从3月到4月的部分增长符合正常的季节性规律，但今年增幅的幅度相对于往年似乎较大，且考虑到2025年4月可能已因关税相关的缓冲而库存较高，这一点更为显著。库存周数高企主要由较弱的销量驱动，因为销量环比下降15%，而渠道库存量仅环比增长2%。

# 4. 代工厂与存储——对需求和内容利好

# 代工厂

图表13总结了月度iPhone销量历年变化，更重要的是，对台积电而言，这些销量在iPhone所用制程节点上的变化。x轴上的“M”表示主要节点首次进入市场的月份，但主要节点的可能增强版本（例如2021年的N5P和2022年的N4相对于2020年的N5）也根据各自的发布年份进行了区分，以便投资者了解各年份的势头与前几年的差异。总体而言，销量在首次交付后的第一个季度显著激增，随后在大约4年内逐渐下降至每月低于100万部。当一个处理器节点或其变体被多代iPhone使用时，销量往往会在后期出现回升。例如，2022年的N5变体（即N4P）首先随2022年9月发布的iPhone 14 Pro和Pro Max推出，随后再次用于2023年9月发布的iPhone 15和15 Plus，这导致在首次发布12个月后（M+12）出现了下降趋势的逆转。

聚焦iPhone 17，我们首先发现新的iPhone 17系列和iPhone Air均基于同一代N3节点（据报道为N3P）制造。因此，这与2024年最具可比性，当时所有2024年底发布的iPhone 16机型均基于N3P之前的节点代（据报道为N3E）。比较这些周期，iPhone 17最初显示出强劲的爬坡，在相同阶段销量超过了iPhone 16。然而，iPhone 17e相对于iPhone 16e的销售表现弱于预期，使得iPhone 17（N3P）周期大致与iPhone 16（N3E）周期相当。

图表14展示了iPhone销售趋势的类似比较，但按移动处理器细分。x轴上的“M”再次表示每个处理器首次随产品发布和交付的月份。数据显示，疲软集中在A19（用于iPhone 17e），而Pro和Air机型中使用的A19 Pro的销量仍领先于A18 Pro。

展望2026年下半年，iPhone处理器将从N3制程节点迁移至N2，封装技术也将从InFO（集成扇出型封装）升级为WMCM（晶圆级多芯片模块）。这两项变化都将使台积电获得单机价值量的提升。台积电指出，由于内存价格上涨，智能手机需求有所疲软，但已将2026年营收指引从此前的“接近30%”上调至“超过30%”，原因是AI需求的“跃升”足以弥补缺口。我们的渠道调研显示，苹果正在探索与英特尔代工服务合作进行芯片生产。我们认为苹果成为英特尔代工客户的可能性存在，但主要基于地缘政治考量。三星代工在基础层面取得了一些进展，但主要是在较老的技术节点上。因此，预计台积电在可预见的未来仍将是iPhone处理器的独家代工厂商。

# 内存

图表16汇总了自iPhone 11以来所有iPhone机型的DRAM容量，包括苹果不久前发布的iPhone 17e的8GB。可能是为了支持端侧AI，苹果似乎正在加速增加DRAM容量，我们将密切关注这一趋势是否会受到近期内存价格上涨的影响。苹果从iPhone 15系列开始将Pro机型升级至8GB DRAM，随后在iPhone 16系列中将所有机型升级至8GB DRAM。到了iPhone 17系列，大多数机型再次获得50%的提升，达到12GB。2025年前8个月，超过80%的iPhone销量配备了8GB DRAM，因为销量主力是iPhone 16系列。在2025年9月iPhone 17系列发布后，搭载12GB DRAM的iPhone出货量占比迅速提升至接近iPhone总出货量的50%（图表17）。就平均DRAM容量而言，得益于iPhone 16系列的升级，2024年实现了18%的稳健增长。2025年，由于Pro和Air机型再次大幅升级至12GB，平均DRAM容量又增长了20%，达到8.4GB。

4月份，12GB机型在iPhone总出货量中的占比小幅上升至42%，但由于从3月份开始iPhone 17e被纳入产品组合，该比例仍低于2月份之前的水平。搭载8GB及以上DRAM的机型占总出货量的95%。平均DRAM容量为9.5GB，环比基本持平，但同比增幅仍保持在26%（图表18）。从今年9月开始，2025年9月形成的高基数可能会使同比增速放缓。除此之外，我们也想知道高内存价格是否会影响内存容量的增长。

我们估计，2025年整体智能手机的内存容量增长接近10%（参见我们的DRAM行业模型）。由于iPhone约占所有智能手机DRAM需求的15%（因此约占整个DRAM需求的5%），我们当前的模型隐含假设非iPhone智能手机在2025年的容量增长较慢，略低于8%。对于2026年，我们目前的预测是所有智能手机的DRAM容量增长约为8%，由于内存成本显著提高，增速将慢于2025年。

现在或许更相关的问题是，由于内存成本上涨导致的价格上升，智能手机需求将如何受到影响。年初至今，iPhone出货量同比增速依然非常强劲，1月至4月同比增长9%。我们认为内存成本将给许多智能手机OEM厂商带来压力，但iPhone将更具韧性，因其高盈利能力足以吸收成本上涨。
