# 旧存储：从Kioxia投资者日看关联影响

传统NAND技术驱动高性能SSD：在投资者日（链接）上，Kioxia（由Kazuo Yoshikawa覆盖）重点介绍了其GP系列高性能SSD，该产品具备1亿+ IOPS、超快和低延迟性能，可加速下一代AI。该公司表示，该产品兼容Nvidia的Storage-Next解决方案。GP系列SSD用于扩展GPU内存以解决系统内存限制，并支持大规模数据库和更快的生成。GP系列SSD（XL-Flash）采用了Kioxia专有的SLC芯片。

对大中华区存储股的影响：我们在报告《旧存储：即将到来的上行惊喜》中提到，传统NAND技术可能非常适合快速读写速度，因此随着在数据中心的应用，其TAM有望扩大。我们认为Kioxia的确认对兆易创新、华邦电和旺宏是利好，这些是我们覆盖范围内的传统NAND供应商，我们对这三只股票均维持超配评级。

# 估值方法与风险

# 旺宏电子 (2337.TW)

基准情形，市净率，与我们大中华区存储覆盖范围一致，鉴于存储行业的周期性。我们将目标倍数设定为7.0倍，基于我们对2026年每股账面净值的预测，而自2017年以来的历史均值为1.5倍。我们仍认为市净率目标是合理的，因为MLC和传统TLC NAND在2026年下半年可能面临更严重的短缺，供应缺口很容易达到40%。唯一能够填补这一缺口的供应商仍是旺宏。

# 上行风险

■ 传统NAND供需缺口扩大
■ NOR上行周期，由有限的供应扩张和/或更强的需求驱动
■ Switch硬件和核心游戏增长加快

# 下行风险

■ 传统NAND供需缺口缩小
■ NOR下行周期，由更快的供应扩张和/或需求疲软驱动
■ Switch硬件和核心游戏增长放缓

# 华邦电子 (2344.TW)

基准情形，2026年预期市净率5.5倍。该方法与我们针对大中华区存储IDM同业采用的方法一致，考虑到行业的高波动性。我们认为该股应获得超越自2017年以来0.5-1.5倍历史区间高端的估值倍数，因为我们看到DRAM定价上行、NOR价格可持续上涨，以及SLC NAND和SiCap代工业务的机会。

# 上行风险

■ NOR Flash价格上涨，由强于预期的需求驱动
■ DRAM定价强于预期，鉴于持续的供应短缺
■ SLC NAND发展快于预期

# 下行风险

■ NOR Flash下行周期，由需求疲软驱动
■ DRAM定价低于预期，鉴于持续的供应过剩
■ SLC NAND发展慢于预期

# 兆易创新 (603986.SS)

我们的目标价是基准情形估值，源自剩余收益模型。关键假设：股权成本8.9%（贝塔1.1，无风险利率2%，风险溢价6%），派息率40%，中期增长率16.4%，终值增长率3.0%。

# 上行风险

■ NOR上行周期，由更强的需求驱动
■ 卓越的芯片设计，导致低密度NOR敞口增加
■ DRAM发展快于预期

# 下行风险

■ NOR下行周期，由需求疲软驱动
■ 较差的芯片设计，导致中/高密度NOR敞口增加
■ DRAM发展慢于预期
