# 科技：软件：第30届欧洲金融业会议——欧洲软件与支付要点总结

我们在苏黎世欧洲金融业会议上接待了支付和金融科技领域的上市公司及私营公司。讨论中的关键主题包括：1）现代技术栈持续驱动竞争优势，实现更优客户体验和更清晰的产品差异化；2）围绕业务语境编排语义层以利用代理式AI的重要性；3）随着商业模式向基于消费的代币模式演进，优化成本基础；4）随着差异化需求加剧，支付领域企业加大营销和客户获取投入；以及5）监管更趋明确，有助于增强数字资产领域的信心。

详见内文要点总结。

# Capgemini（买入；100.8欧元）

我们在2026年欧洲金融业会议上与Capgemini副集团首席技术官Sudhir Pai进行了炉边对话。

# 关键要点

# AI创新步伐围绕代理式AI持续加速

演讲者指出，AI能力呈指数级增长，过去一年主要科技公司推出了超过1,200至1,500项新AI服务，同时还有200万个开源大语言模型（LLM）。此前，企业主要关注用例数量，但现在正识别真正的价值创造能力。目前，业界正大力推动将这些模型投入生产并向公众交付，然而对企业而言，挑战仍集中在如何有效利用这些模型，并围绕业务语境编排其语义层，以支撑从代理式AI中提取真正价值。鉴于此，

演讲者指出，鉴于与客户的长期关系和良好的业务认知，Capgemini在代理式生态系统中可发挥重要作用。截至目前，公司表示客户服务以及风险与欺诈等后台职能是AI应用最为集中的领域。总体而言，演讲者强调了随时间推移追踪并确定AI真实价值的重要性。

# 向消费定价模式转变

演讲者指出，由于使用代币执行代理式AI的情况增多，商业模式正从主要基于订阅转向订阅+消费模式。演讲者表示，代币成本可能因任务复杂度而急剧膨胀，CFO面临的挑战是为IT预算分配足够资金，而这些预算正迅速耗尽。此外，鉴于代币成本上升，企业越来越多地探索基于特定业务语境训练的领域专用/小型语言模型，作为提供更优化结果的替代方案。

# 网络安全与云端韧性的重要性

关于云迁移，演讲者指出这主要受企业看到升级带来的真实商业价值增长所驱动，许多企业对欧洲供应商感兴趣，原因是欧洲云主权。此外，鉴于前沿AI公司（如Anthropic的Mythos）能力快速发展，演讲者表示企业的网络安全和韧性正日益受到挑战。

# 员工人数可能缩减，但如何最优利用节省的时间仍是挑战

演讲者提到，AI带来的生产率提升可能会自然减少员工人数。然而，企业目前仍在摸索如何最优利用节省下来的时间。中期内企业的关键差异化因素将在于如何有效对员工进行再培训，使其转向其他创收职能。

# Temenos AG（中性；70.15瑞士法郎）

我们在2026年欧洲金融业会议上与Temenos首席执行官兼临时首席财务官Takis Spiliopoulos进行了炉边对话。

# 关键要点

# 核心银行软件的结构性增长空间依然巨大

Temenos在银行软件市场仍处于有利地位，因为许多银行的内部系统已有数十年历史，核心银行软件的渗透率仅约35%，而ERP和HR软件的渗透率接近80%-90%，因此增长空间巨大。管理层指出，银行对平台现代化改造的主要阻力历来是漫长的实施周期，他们现在预计AI工具有助于缩短这一周期。关于近期展望，管理层指出宏观背景稳定，尽管地缘政治持续波动，但管道或转化率未受影响，且基于去年的势头，在银行普遍表现良好的支撑下，潜在情绪积极。

# 三大关键收入增长引擎，美国市场持续发力

管理层概述了收入增长的三大关键引擎：（1）继续向三级及更小型银行渗透核心银行功能；（2）一级/二级银行采用特定功能模块；以及（3）周边增长引擎（财富管理、FCM、支付），其增速通常快于核心业务。其中，美国被强调为特别有动力的地区，多个旗舰客户现已上线，约20名销售人员瞄准160家多区域银行，并在奥兰多新设了创新中心（印度以外的首个）。

# 聚焦价值的均衡AI投资策略

Temenos指出，其对AI采取均衡策略，在足够的情况下利用开源或低成本模型，而非默认选择最新/最贵的选项。内部效率提升已可见，尤其在工程领域。除内部效率外，管理层指出，在AI世界中，核心银行和语境层因需要确定性、受治理的数据而变得更有价值，Temenos在此领域处于有利地位，有望受益。

# 定价模式仍以交易量为主导

Temenos进一步指出，其并非仅基于席位模式运营，而是主要基于交易量，虽然对基于结果的定价持开放态度，但银行通常更偏好SaaS或订阅费模式。

# 资本配置：持续回报与选择性补强并购并行

Temenos重申了其资本配置策略，管理层预计将在进行选择性补强并购活动的同时，继续向股东返还资本。

# Wise（买入，基于CL；868便士）

我们在2026年欧洲金融业会议上接待了投资者关系部的Diana Martinez Moscosso和Sarah Lewandowski，进行了投资者会议。

# 关键要点

# 核心使命根植于解决跨境支付低效问题

Wise重申其核心使命是解决跨境支付的低效问题（主要是速度和成本），通过提供更快、更便宜、更可靠的转账来改善客户体验。Wise的增长还得到其扩展产品组合的进一步支持，包括Wise账户、Wise多币种卡、Wise资产和Wise商业，这些有助于拓宽可触达的市场机会。

在竞争格局方面，Wise 专注于为有国际需求的客户提供最佳客户体验，而非试图成为一家银行。不过，该公司承认，美国银行牌照仍是其基础设施中的一个缺口，获得该牌照可以解锁更好的集成能力和付息能力，但代价是更高的资本要求。在定价方面，预计短期内不会出现大幅降价，但 Wise 承认，竞争对手可能会进行交叉补贴，并在跨境定价上采取激进策略。

# Wise 平台作为关键的长期增长杠杆

Wise 重申，它继续将平台视为长期增长的关键杠杆，目前占跨境交易量的 $+5\%$，预计中期将达到约 10%，这得益于飞轮效应，而 Wise Connect（6 月 30 日在美国上线）将进一步增强发展势头。

# 稳定币风险有限

关于稳定币，Wise 维持其立场，即对技术持中立态度，专注于为客户提供最佳价值的产品。虽然 Wise 仍对采用稳定币作为支付通道持开放态度（前提是它们能实现更便宜的汇款且客户需求显现），但如今客户仍然优先考虑可消费、可使用的余额，而 Wise 自身的价值主张在这一领域仍更具优势。

# 资本配置框架

在资本配置方面，管理层专注于维持高于监管要求的缓冲，但对向股东返还资本的可能性保持开放态度（更多细节将在全年业绩中公布），并指出投资者偏好回购。

关键要点：私营公司

# Zopa

我们在 2026 年欧洲金融业会议上，与 Zopa 首席执行官 Jaidev Janardana 进行了炉边对话。

# 公司简介：

Zopa 是一家拥有完整牌照并受 FSCS 监管的英国数字银行，最初是一家 P2P 借贷平台，后来扩展至全套零售银行产品。

# 关键要点

# 演变为提供全套服务的英国数字银行

Zopa 强调了其从 P2P 借贷平台向拥有完整牌照的英国数字银行的演变，如今提供日益完整的产品组合，涵盖个人贷款、信用卡、储蓄、活期账户和投资。管理层指出，该公司服务约 200 万客户（年底为 170 万），创造了 3.75 亿英镑的收入和 6500 万英镑的潜在税前利润。随着其继续扩大产品供应，管理层表示，其专注于将信任、价值和便捷作为核心客户优先事项，他们认为传统银行在这些领域结构性表现不佳，这使 Zopa 能够很好地继续抢占市场份额。

# 三大增长引擎，贷款是主要收入引擎

管理层确定了未来的三个主要增长驱动力：(1) 贷款作为主要引擎，利用 40 亿英镑的贷款组合和强大的单位经济效益；(2) 来自活期账户和信用卡的费用，通过增加营销投入来推动客户获取；(3) POS 金融，由最近的两项收购支撑，并进一步受到贷款端经济效应的推动，使其能够提供比纯支付公司更具竞争力的利率。管理层还强调，该业务对利率周期具有相当的韧性，规模化贷款与低成本收入比相结合，使 Zopa 能够将卓越价值回馈给客户。

# 英国仍是核心重点，存在欧洲扩张潜力

在地域扩张方面，管理层指出，虽然 Zopa 仍对通过机会性并购在欧洲大陆进行无机增长持开放态度，但英国仍是核心重点，因为其目前仅持有约 7% 的市场份额，近期产品发布为其提供了巨大的发展空间。

# 运营杠杆推动利润增长快于收入

在盈利能力方面，管理层继续预计利润增长将快于收入，这反映了模型中的运营杠杆，尽管 Zopa 一直专注于将利润再投资于客户增长，特别是通过增加对活期账户和信用卡的营销投入。

# Raisin

我们在 2026 年欧洲金融业会议上，与 Raisin 联合创始人兼首席财务官 Frank Freund 进行了炉边对话。

# 公司简介：

Raisin 是一家总部位于德国的金融科技公司，它将欧洲和美国的零售储户与提供存款和储蓄产品的银行连接起来，使银行能够获得所需的流动性，客户则能通过单一平台获取多家机构的高收益账户。

# 关键要点

# 持久的客户基础推动持续增长势头

Raisin 强调了持续的增长势头，这得益于其持久的客户基础：客户群体普遍年龄较大，可投资资产较多，这一人群与典型数字银行的重叠有限。管理层进一步指出，强大的客户群动态表现为负流失率、两位数的推荐率以及现有客户的持续充值，这有助于推动增长，尤其是在储蓄行为根深蒂固的德国。

# 结构性服务不足的存款市场，增长空间巨大

管理层还指出，Raisin 在存款市场中一个结构性服务不足的细分领域运营，在欧洲大陆没有规模化的直接竞争对手，而 Raisin 仅在德国 2.3 万亿欧元存款池中的渗透率仍然有限，这本身就留下了巨大的发展空间。展望未来，管理层指出了以下关键增长驱动力：(1) 地域扩张，重点是推动新近进入市场（尤其是意大利）的增长；(2) 产品广度，通过向投资领域扩展；(3) 美国市场增长，受益于当前政府放松管制的有利因素。

管理层也承认利率不确定性对其业务模式的影响，但他们仍认为这是可控的：高利率支持客户获取，因为储户会四处寻找更高收益；而低利率历来使银行更难获客。不过，核心储蓄行为——消费者每年将收入的一部分存起来——被认为在很大程度上与利率无关。

# AI 部署聚焦于内部效率

在人工智能方面，管理层指出其专注于在内部部署编码代理，并指出他们的代币支出被人员成本节省抵消了 10 倍以上，最大的效率提升体现在工程和客户服务领域。然而，在面向客户的方面，管理层仍持谨慎态度，因为更专业的代理面临着客户的信任障碍。

# 并购：有选择性且主要追求规模

在并购方面，管理层指出，在之前的并购执行之后，对小型或相邻目标的兴趣有限，只有在规模合理的情况下才会考虑进一步的交易。

关键要点：数字资产与银行业对支付和金融科技的看法

演讲者：我们在 2026 年欧洲金融业会议上，与 GS 全球数字资产主管 Mathew Mcdermott 和 GS 金融机构集团联合主管 Stephen Considine 进行了炉边对话。

# 关键要点：

# 更清晰的监管环境为数字资产行业带来利好

专题小组指出，过去12-18个月，监管和立法层面的清晰度出现了变革性提升，尤其是在美国，这增强了市场对数字资产行业的信心和投资（例如2025年7月的《GENIUS法案》），同时欧洲的MiCA 2正在推进中。这促使卖方和买方公司在构建数字资产功能方面开展了大量活动。发言人对资产代币化的前景持乐观态度，认为其能带来显著效益，例如更高的运营效率、更强的韧性以及更高的抵押品流动性。发言人举例了Robinhood上的代币化，该功能允许用户以更高的流动性和部分所有权交易基于区块链的股票。对于稳定币，发言人持乐观态度，同时指出其部分价值主张可能取决于是否产生收益。因此，发言人认为稳定币的流通速度可能会呈指数级增长，但由于客户会转向其他货币，其资产管理规模的吸收可能更为有限。

# 融资环境分化，IPO储备正在建立

专题小组将当前环境描述为快速变化且分化，围绕新一代金融科技公司的热情日益高涨，而10年前上市的公司则越来越被视为传统企业。发言人指出，私募市场需求健康，但同时注意到上市金融科技公司的交易表现仍不佳，估值承压。尽管如此，发言人指出IPO储备充足，私募股权仍在积极部署资本。

# 聚焦盈利增长与稳健商业模式

发言人强调，市场目前的关注点仍集中在增长与盈利的平衡上，而那些能够展示基于扎实单位经济性、有吸引力的客户和地域扩张的商业计划的公司，正受到市场欢迎。然而，由于更广泛的战略不确定性，市场对正在进行商业模式转型和市场进入策略演变的公司仍持谨慎态度。

# 估值/风险

我们对Capgemini给予买入评级。我们的12个月目标价为165欧元，基于约11倍2Q27E-1Q28E备考每股收益。

我们观点和目标价的主要风险包括：(1) 宏观经济环境弱于预期，(2) 并购相关的整合和执行问题，以及(3) 动态竞争格局/定价压力相关的风险。

我们对Temenos给予中性评级。我们的12个月目标价为93瑞士法郎。其基于：(i) 85%权重的基础市盈率估值83瑞士法郎，基于约20倍2Q27-1Q28E备考每股收益；以及(ii) 15%权重的并购理论估值147瑞士法郎，基于约10倍2Q27-1Q28E EV/销售额，与先例交易一致。

主要风险包括：(1) 持续强劲/疲弱的执行情况；(2) 在美国市场取得高于/低于预期的成功；(3) 行业增长好于/差于预期；(4) 与IT服务公司合作的加速/放缓；(5) 并购。

我们对Wise（在CL上）给予买入评级。我们对WISEa.L/WSE的12个月目标价为1,400便士/19美元，基于DCF估值（WACC 11.2%，TGR 3.5%）。

我们观点和目标价的主要风险如下：(1) 宏观经济风险；(2) 向数字跨境支付转型的速度慢于预期；(3) 增长执行/成长阵痛；(4) 外汇风险；(5) 竞争；(6) 监管风险；(7) 潜在的合规问题；(8) 网络安全；(9) 退款风险；(10) 加密货币/稳定币。
