# AI vs 人类 II：生成式AI颠覆手册——市场正在忽略什么

全球关于生成式AI的评论大多聚焦于AI供应链，但随着应用达到规模，其颠覆性影响将难以忽视。经济冲击是否会最严重地落在发达经济体，进而引发对AI应用的更严格管控？围绕这些问题的迷思与噪音中，我们在此提出基于数据的观点。

主流叙事存在缺陷：最普遍的AI叙事称知识产业将受冲击最重，入门级岗位将最先消失，而依赖套利增长的低成本劳动力经济体——印度、印尼、墨西哥——面临最大威胁。然而这些说法暴露出惊人的脱节。信息和知识部门在大多数中等收入经济体仅占就业的1-4%，而在高收入经济体则占6-10%，且GDP占比差距更大：服务业在中等收入国家产出中约占50-60%（中位数55%），而在发达经济体则超过70%。这是对低收入经济体风险最大的传统观点的第一个严峻挑战。

引入工资因素，叙事即告瓦解：论点的第二支柱是工资，其差异使图景更为鲜明。一名典型软件工程师在印度年收入约1万美元，而在美国约13万美元，英国约8万美元。这一模式在会计师、律师助理、数据分析师等AI快速推进的白领类别中反复出现。用AI替代1万美元的工人仅能节省边际成本；替代10万美元的工人对大多数组织而言则是变革性的。如果企业采用人机协同系统，保留有限数量的决策者（及风险承担者），那么保留哪些人类在经济上最合理？

为何市场反应相反？尽管如此，印度和印尼等中等收入经济体的股票市场承受了AI交易的主要冲击，而美国和韩国则大幅上涨。市场是非理性的吗？并非完全如此：大多数新兴市场缺乏大型纯AI标的，且支撑印度服务业繁荣的成本竞争型劳动力模式确实面临真正的颠覆。中等收入经济体的宽基指数对IT服务的敞口也更高（约5%，高收入经济体为2.9%）。这些风险真实但有限。市场定价的是未来几个季度，而非未来几十年——这种时间短视可能正在创造下一个重大盲点，而机会正藏于其中。

AI，伟大的均衡器？标题可能出人意料，但逻辑直截了当。基于当前服务业就业和现有收入不平等，我们估计中等收入经济体国民收入平均将受10%的冲击，而高收入经济体约为22%。负担将不成比例地落在最富有的约1%之后的次富裕9-10%收入群体上。从这个意义上说，AI在两个维度上成为均衡器：缩小高收入与中等收入国家之间的收入差距，以及在经济体内使前1%之外的收入分布更加平坦。

# 总结性启示

我们的分析表明，如果一切放任自流，我们可能会看到这样一种情况：每家企业都在AI应用上突飞猛进，直到其带来的岗位替代超过所能创造的新岗位。届时，真正的经济金字塔转型将发生，发达经济体将首先且更严重地受到冲击。中等收入经济体在绝对价值上受影响较小，但其沿收入梯队“升级”的机会将随时间推移几乎降至零。我们看到各经济体中异常富有的前约1%群体持有不成比例的收入份额，其后是更为平等的剩余99%。这可能对大多数依赖规模的可选消费品牌造成毁灭性后果，只有服务于前1%的超豪华品牌能勉强存活。发达经济体损失最大。

实际上，我们认为AI将成为政府严格监管的行业——无论是最低就业要求还是使用限制。最终，AI实际上可能使大多数人类的收入水平更加接近，而非拉大差距。就此而言，AI可以成为伟大的人类均衡器——无论好坏。

# 我们对AI的评估是否存在根本性错误？

我们常常歌颂人工智能带来的巨大生产力效益，或因其带来的彻底颠覆而为某些知识产业敲响丧钟。我们最终不可避免地忽略了全局。这正是我们将试图填补的空白。你会发现这份报告相当非典型。我们的想法将随着推进而演变，我们的推论将通过挑战当前关于AI的普遍认知而形成。我们将把这篇阅读材料组织得更像一篇思考笔记，在需要时使用数据来论证或挑战现有观点，但仅用我们的思考来形成新观点和启示。鼓励读者与我们一同思考。开始吧！

# AI时代——为何不同于以往的颠覆？

关于AI，我们常听到的基本错误是人们将其过度简化，等同于以往的技术创新。这是一种流行方法，确实简化了很多事情——因为它让你通过历史（事件和结果已知）的视角来看待未知。遗憾的是，这仅适用于渐进式变化。因此，将AI与工业革命或计算机时代相提并论存在根本缺陷：性质截然不同。此外，工业革命时期的机器和一百多年后的计算机都有内在目标——提高生产力。动力织机和脱粒机旨在用蒸汽和铁的机械输入替代人类的卡路里输入。其意图主要是绕过人类耐力的生理极限——使同样的人类在更高效率的规模上展现生产力。而AI，至少根据迄今的趋势，被包装为生产力助推器，实则被设计为完全替代人类的认知任务。这从未发生过。机器不是为自行操作而造，计算机不是为自行编程而造。但AI，尤其是代理式AI，正被设计来实现这一点。在此情境下，“它消灭一些岗位但创造更多岗位”的老生常谈真的还适用吗？

# 评估就业影响

这并非通常意义上评估哪些岗位受AI威胁最大——此类文章已数不胜数。本节我们将更进一步：假设某些岗位最易受AI冲击，那么这些岗位接下来最可能发生什么？这是一个长期视角的展望，设想AI饱和世界可能的面貌——因此我们不会重复此前《AI vs 人类》系列报告中关于IT影响被夸大的观点。

# 1. 识别受影响的岗位

当我们谈论AI对就业的影响时，常听到知识密集型行业、低决策岗位或初级岗位等术语。我们在之前的《AI vs 人类》报告中已驳斥了关于初级岗位及采用速度的某些迷思。然而，考虑到信息行业迟早会受到影响，让我们看看就业占比。高收入国家在信息行业就业依赖度上位居前列——IT、视听/广播、电信和信息通信等行业直接雇佣了总劳动力的7-10%。印度尼西亚和印度等中等收入国家则远远落后——即使将间接依赖数字化的非信息岗位（如使用数字解决方案的医疗、金融或零售岗位）计算在内也是如此。这对于"印度等国家面临大规模AI颠覆"这一相对固化的认知而言，是第一个警示信号。

# 2. 工资效应

让我们看看一些最可能受颠覆的岗位——业务流程外包、客服、会计师、数据录入员、律师助理和软件工程师。这些岗位的全球平均工资差异巨大——但有一个趋势不变：中等收入国家与高收入国家在同一岗位上的工资存在巨大鸿沟。以软件工程师为例——印度平均年薪约为1万美元。美国则超过10万美元，许多其他高收入国家也远高于6万美元。因此，当AI真正到来且采用率飙升时，哪些岗位最容易通过AI订阅被削减和替代？如果在那个高级阶段仍保留某种人机协同系统，那么这些人类更可能偏向中等收入国家的高技能人才——比如印度年薪4万美元的工程师，而非美国年薪20万美元的工程师。这对所有国家都令人不安——因为无论身处何地，大多数工程师都会受损，但高收入国家的长期风险似乎更为严峻。

# 人工智能时代的人类——展望未来

虽然市场可能不会想得那么远，但我们不得不思考。在计算失业工人数量或过时岗位时，我们常常忘记这些工人同时也扮演着消费者角色，并构成劳动力的重要部分。因此，随着人工智能应用日益增加、取代这些工人，消费最终必然受到影响。这是人工智能生产率繁荣中较少被讨论的代价。早期阶段不会受此问题困扰，因此快速采用者有望获益，至少暂时如此。

# 走向帕累托低效的纳什均衡？

那么这一切将如何演变？一家公司发现，用人工智能代理代替真人可以降低成本、提高效率，于是削减了一些岗位。公司起初小规模这样做，生产率开始上升。失业人数虽多但有限——其中一些人找到了新工作，许多人积累了储蓄，而从繁荣中获益的人数也足够多。总体来看，商品和服务需求上升。人工智能时代的先行者将获益。

现在，越来越多的公司加入进来，先行者转向大规模采用人工智能。生产率迅速上升，但随着更多岗位被裁减，失业人数开始超过能创造的新就业岗位，需求开始下降。这是人工智能真正规模化扩张的时代，需求不再与生产率同步增长。对公司的纯经济考量仍要求增加采用——因为如果一家公司停止而其他公司继续，那么退出者的处境会更糟。这让我们想起了什么？帕累托低效的纳什均衡——类似于囚徒困境问题。最终，采用率足够高，失业工人数量超过任何新创造的就业岗位——导致需求随时间下降，最终稳定在较低水平。

这就是我们在图表6中强调的情况，在没有任何重大政府干预或对人工智能增长的冲击下，这构成了一种自然均衡。直白地说——这不是对IT或呼叫中心等少数行业的末日场景。这是对整个全球经济的丧钟，其影响远超传统的人工智能相关行业。

# 收入金字塔会发生什么？

综上所述，让我们切入问题的核心——收入金字塔。随着知识行业的工人因人工智能浪潮而最先失业，自然会认为他们的收入份额将首先消失。假设他们通常是各经济体中收入最高的群体，图表7对中等收入国家来说是一个重大难题——这些国家收入不平等程度最高，前10%的人平均赚取超过50%的国民收入，而高收入经济体为43%。在所考虑的主要经济体中，前三名（南非、巴西和印度）这一比例高达60%。即使我们认为前<1%的人相对不受影响（因为人工智能带来的收益将集中在最顶层），中等收入国家中接下来9%的人的收入份额也相当高，尽管差距有所缩小。在中等收入经济体中，接下来的9%的人赚取国民总收入的31%，而高收入经济体为27%。

那么，在人工智能采用的后期阶段——即图表6中从替代到人工智能巅峰及巅峰后的阶段——会发生什么？我们可能会看到中等收入国家31%国民收入中的很大一部分遭受严重侵蚀。但高收入国家呢？考虑到我们注意到知识行业在总就业中的占比更高，这个数字不会仅仅是27%。相反，它可能高达，或者很可能高于中等收入国家所见的水平。考虑到图表1中服务业的平均就业占比：中等收入国家为2.9%，高收入国家为7.2%，我们计算出中等收入国家国民收入下降10%，而高收入国家国民收入下降更为严重，达22%。实际数字会略低，因为一些知识行业的工人最终会保住工作。我们的计算还假设所有知识工人都属于那9%的富人群体，且没有其他群体受到人工智能影响。这实际上缩小了高收入与中等收入国家之间的巨大差距，即使在此过程中永久损害了较贫穷国家的"富裕"前景。中等收入国家可能在农业和低端制造业拥有大量人口份额，可作为安全网。发达经济体除少数外，可能不享有这些特权。

因此，具有讽刺意味的是，同样威胁将财富集中在少数富人手中的人工智能，最终可能迅速缩小富国与穷国之间的巨大差距。其反面是，由于劳动力套利模式实际上就此终结，这种状态可能停滞不前。即使在经济体内部，收入集中度也将是倾斜的：前1%的人占据国民收入的绝大部分，而其余人口在收入分配方面变得更加"平等"。

最终，政府监管将不得不以各种形式出现，以避免人工智能对经济及其内部金字塔结构产生极端影响。在遥远的未来，当全能且无处不在的人工智能系统时代到来时，我们可能会看到全民基本收入（UBI）、对工资和最低就业的监管，甚至是对企业采用人工智能征税等措施。这将对许多群体的收入不平等产生下行压力。在这种情况下，累积的财富，而非收入，可能成为可自由支配消费的驱动因素。有趣的是，在财富方面，我们并未看到发展中经济体和发达经济体之间存在巨大鸿沟。事实上，如果从我们的经济体中剔除南非和荷兰这两个极端案例，高收入国家和中等收入国家前10%人口持有的财富份额相似，约为64%。鉴于我们之前的评估（高收入国家中有更多家庭是可自由支配消费者），即使按比例计算，富裕国家的消费影响也更大。因此，在人工智能时代，中等收入国家面对着一个几乎没有上行空间的空白未来，而高收入国家则面临最大的损失。

# 对世界的影响

那么最终会发生什么——人工智能的终局是什么？说到终局，虽然我们在之前的报告中从程序员的角度讨论过这一点，但我们在本报告中发现的长期影响值得进行更广泛的讨论。

1.  近期影响已被过度计入——尤其是对于IT服务行业而言，其估值处于近十年来的最低水平。这一点尤其有趣，因为我们在之前的报告中看到，人工智能的采用需要IT供应商，而近期的劳动力削减可能会带来更高的利润率。大多数大型IT企业已经开始从其人工智能服务部门获得收入。
2.  一旦开始展望更远的未来，事情就变得有趣了。我们在之前的报告中看到，初级劳动力并非完全被淘汰——反而成为人工智能采用竞赛中一个重要且高生产力的支柱。我们可能看到初级岗位减少，而一些稍高级别的职位受到的影响更大。虽然对整体劳动力不利，但与年轻的发展中经济体相比，这对高收入经济体的负面影响甚至更大。
3.  最终，我们看到劳动力影响转化为需求下降。此时，这不仅仅是关于IT或知识产业等暴露的行业。可自由支配需求的下降将首先冲击发达经济体，然后才波及像印度这样的中等收入国家。尽管如此，这实际上扼杀了收入转型的故事，并使各国几乎不可能过渡到高收入状态。
4.  我们认为，人工智能最终将成为一个受监管的行业，各级政府的大力干预将成为全面采用人工智能时代的一个决定性未来特征。可能会引入全民基本收入（UBI）、最低就业监管或与人工智能相关的税收等措施，从而有效限制后来者的收益。

就是这样。从长远来看，当前对特定行业的巨大影响可能最终只是虚惊一场，因为考虑到市场定价所反映的渗透率水平足以惩罚IT和信息行业，这种惩罚本应更广泛地分布。此外，一旦我们进入人工智能的顶峰阶段且政府监管出台，累积的财富可能成为消费的决定性因素，鉴于高收入国家与中等收入国家的财富分布几乎相似，且消费者家庭占比更高，高收入国家可能会损失更多。

金字塔崩塌可能即将到来，虽然它夺走了新兴经济体的光明未来，但它也夺走了工业化经济体大部分更光鲜的现在。
