# 周末科技简报：卡片的“成本”——常被误导的比较；我们的关键图表视角

卡片受理成本在关于卡片的讨论中经常出现。许多比较（与其他支付方式相比）往往并非同类比较，且有些误导。借记卡（通常在功能上与其他替代方案相似）已经相当便宜。信用卡为消费者提供信贷和奖励。此外，卡片还围绕交易提供一系列服务，如争议解决、欺诈保护、更高转化率、通用受理等。

话虽如此，在美国，商户对信用卡成本的抵制情绪正在增长（例如，一些小型商户通过附加费的方式）。退一步看，交换费需要微妙的平衡，而卡网络可以（在一定程度上）灵活调整交换费，以使某些类别变得可受理。

在这篇简短的周末科技简报中，我们通过我们最喜爱的图表，讨论卡片受理成本这一微妙话题，以及其对卡片未来增长（包括代理式未来）的影响。

# 苹果与橙子的比较

首先：许多关于卡片与其他支付方式的成本比较往往具有误导性。请记住，借记卡是你拥有的钱。信用卡，嗯，是信贷（你没有的钱）。其他支付方式（例如，银行转账支付）在功能上类似于借记卡，而非信用卡。借记卡已经相当便宜。信贷替代方案（例如，先买后付）通常比信用卡有更高的商户折扣率。

例如，在美国，受监管的借记卡商户折扣率平均约为70个基点，而信用卡为240个基点（图表1）。请注意，不受监管的借记卡（约占美国借记卡交易量的三分之一）比受监管的借记卡更贵（高出约100个基点）。

# 卡片围绕大量服务

例如，争议管理（目前稳定币不存在此功能）、拒付（稳定币交易不可逆）和奖励（浮存金收入驱动的稳定币奖励存在数学限制）（图表4和图表5）。替代支付方式（银行转账支付、稳定币）能否包含这些服务？当然可以——但这需要多年时间和数十亿美元的成本（并且会失去“便宜”的吹嘘资本）。

卡片支付远不止简单的资金转移。资金转移是一种商品（ACH交易成本不到一分钱——比许多稳定币还便宜）。而信任和治理（卡片提供的）则不是。交易中嵌入了许多增值服务（上文描述了一些），还包括治理标准（这些标准历经数十年建立，且对于替代支付方案通常极难执行）。此外，还有跨1亿多个商户地点和70多亿个经过KYC认证凭证的通用受理。

有趣的是，在包含这些附加服务的情况下，稳定币对小型商户的成本通常并不比借记卡便宜（图表6）。

# 交换费很好，但对其设上限也不坏……

交换费是支付领域一个微妙的话题。这是该行业许多反直觉的事情之一。它是由卡网络（即Visa和万事达卡）设定的费用，由商户的银行因卡片交易支付给发卡行。交换费通常对消费者不可见，但会转嫁给商户。它构成了商户为受理卡片而支付的大部分费用。

商户不喜欢它，消费者不关心它，发卡机构喜爱它，监管机构想限制它，许多律师常靠它支付账单。最重要的是，交换费总体而言一直非常出色。它为发卡机构（包括金融科技公司）获取客户和发行卡片创造了激励。它为奖励提供资金，进而激励消费者行为。

交换费为消费者金融服务创造了一种（超越贷款和保险的）盈利模式。金融科技公司（所谓颠覆者）如今越来越依赖交换费来驱动收入。具有讽刺意味的是，稳定币最好的消费者用例是稳定币关联卡片，它同样受益于利润丰厚的交换费。

话虽如此，卡网络试图在交换费上实现棘手的平衡（平衡商户与发卡机构的利益）——有时监管也并非坏事。例如，欧洲在2015年12月将借记卡交换费上限设为20个基点，信用卡为30个基点——自那以后，该地区的卡片渗透率大幅提升（疫情驱动的数字化也对此有所帮助）（图表7）。

请注意，美国目前待决的MDL和解协议，如果获批，将在5年内将信用卡交换费降低约10个基点，并将标准消费者信用卡利率上限设定长达八年。我们也在关注美联储降低美国受监管借记卡交换费的可能性。美联储早就该（自2023年起）就其提议的将有效受监管借记卡交换费降低约30%进行规则制定。近期也有一些关于受监管借记卡交换费的相互矛盾的法院裁决。

# 话虽如此，在美国，受理成本正处于一个有些微妙的时刻

美国信用卡费率高于其他国家，部分原因是高费率高端信用卡占比持续上升。美国商户平均支付2.4%的手续费，但这是一个加权平均值——大型商户（如亚马逊、沃尔玛）支付的费率远低于小型商户（后者为信用卡支付通常需支付超过3%的手续费）。因此，我们越来越多地看到小企业主采用附加费模式（图表8）。请注意，MDL和解协议（预计今年晚些时候获批）将进一步提供更灵活的附加费收取方式。详见我们的报告《支付：Visa/Mastercard商户和解协议；我们的思考》。需注意，附加费仅允许用于信用卡，而非借记卡（后者费率已较低）。

尽管目前美国附加费整体占比仍较低，但我们担忧一旦MDL和解协议获批，渗透率可能加速上升。Toast等商户收单机构因货币化模式/ARPU提升空间而更有动力收取附加费。此外，偶有报道称部分商户不再接受信用卡，例如Meta近期调整部分广告商的支付政策，要求其通过发票/借记卡（而非信用卡）进行月度付款。

虽然短期内影响不大，但我们确实担忧附加费带来的不良用户体验可能产生长期后果，以及对商户信用卡受理意愿的影响。这是卡组织需要与发卡机构客户（希望提高交换费）共同解决的棘手问题，以维持消费者和商户对信用卡的长期偏好。我们注意到，美国运通规则不允许收取附加费（该公司在2018年最高法院裁决中胜诉）。

# 商业模式历史上曾为新品类而改变，未来也将再次调整

杂货、自动售货机和交通领域在不同时期曾因定价机制（包括交换费及支付费用的固定/可变部分）而无法使用信用卡。随着时间推移，信用卡调整了定价模式（及交换费）以适应这些品类。

我们正密切关注特定品类和商户的受理成本变化，尤其是在美国（信用卡使用率和费率均较高）。我们重点关注两个"新兴市场"：

1）B2B/商业支付——卡组织已为买卖双方建立灵活的交换费模式。AI代理可能加速B2B支付数字化进程，灵活的交换费将发挥重要作用。

2）自主代理微交易——一种新型经济形态，命令行界面（CLI）成为商业平台，例如代理购买算力、图像、代币或与API交互。以Visa为例，其正在开发功能，使用户可将Visa卡加载至CLI，由代理自主完成购买（包括极小金额交易）。随着这些模式发展，V/MA可灵活调整定价模型，确保其仍是小额支付的最佳选择。

# 卡组织是否超额盈利？

# 结论

信用卡受理成本是一个复杂议题，尤其在美国。受监管的借记卡费率已相当低廉，而信用卡则不同。我们将密切关注MDL和解协议获批后美国市场（如附加费）的演变。长期来看，卡组织已展现出调整特定商业模式（如交换费）以拓展生态系统的灵活性，并能在扩大受理范围与维护消费者偏好/体验之间持续保持精妙平衡。
