# 中国保险：金融企业调研要点

我们在中国大陆进行了为期五天（5月25日至29日）的调研，与一系列金融企业进行了会面，包括银行、保险公司、券商和在线借贷平台。在保险公司中，我们会见了中国平安、中国太保、中国太平、众安在线（未覆盖）、中国人寿、新华保险和中国人保财险的投资者关系及管理团队。

寿险公司对银保渠道的强劲增长仍抱有信心，并预计渠道费用监管的收紧将利好大型保险公司。在资产端，自3月底以来股市的强劲表现推动了投资业绩的反弹，但保险公司大多认为当前股票配置水平将保持稳定，强调在成长股和红利股之间建立平衡的投资组合。财险公司普遍预计，由于费用监管（车险和非车险）以及理赔频率（车险）的下降，承保业绩将有所改善。

总体而言，我们认为行业基本面稳健，寿险公司新单销售动能持续，且随着股市反弹，所有保险公司的利润和账面价值增长正在恢复。

# 行业要点

1) **投资策略**：寿险公司普遍对利率前景持中性看法，同时关注资产负债久期和现金流匹配。长期国债仍是锁定资产久期的重要工具。然而，鉴于长期债券收益率仍处于低位（相对于历史水平），重点更多放在股权投资方面，尤其是那些可以长期持有、从而提供类债券收益率和久期的高股息率股票。

短期内，自3月底以来股市的强劲表现推动了所有保险公司投资组合收益的反弹。但保险公司普遍预计（相对于当前水平）股票资产配置不会大幅提升。在股权投资内部，尽管与人工智能相关的股票出现上涨，但保险公司正致力于在成长股和价值股之间实现更均衡的配置。红利股仍是关注焦点，这从计入其他综合收益的股权投资占比（相对于以公允价值计量且其变动计入当期损益的股权投资）提升中可见一斑。目标股息率普遍在4%或以上。

2) **银保监管与增长**：我们接触的寿险公司都欢迎国家金融监督管理总局3月份发布的银保渠道费用新规，因为他们预计对渠道费用更细致的审查将进一步鼓励银行与大型保险公司合作。尽管如此，保险公司确实预计短期内会出现一些干扰，因为销售激励措施有所减少。总体而言，保险公司预计这不会对利润率产生重大影响，因为公司可能会将大部分节省下来的费用让利给保单持有人。

3) **代理人发展**：寿险公司普遍预计未来2-3年代理人数量将保持稳定，重点主要放在（高素质的）绩优代理人上。目前已有针对性的招聘和培训流程，同时资源支持也向高素质代理人团队倾斜。尽管银保销售激增，但大多数寿险公司认为代理人能更好地服务于上层富裕和高净值客户。

4) **车险承保业绩展望**：排除自然灾害的潜在影响，保险公司普遍认为承保业绩有改善空间，驱动因素包括：1) 更好的风险承保和更大的定价灵活性，2) 高级驾驶辅助系统功能的渗透率和使用率提高，3) 维修流程的改进，以及4) 风险保费的潜在重新校准。虽然2026年的保费增长可能受到新车销量同比下降的影响，但保险公司普遍预计中期内保费增长率将恢复至低个位数。

5) **“偿二代”制度更新**：“偿二代”第三阶段的更新仍在讨论中，监管机构尚未就各项风险参数做出决定。公司预计实施可能在2026年下半年或2027年。对于大型保险公司，公司指出当前偿付能力充足率远高于监管最低要求。

# 公司会面要点

# 中国平安

- 中国平安重申了其多渠道分销策略，包括代理人、银保、社区金融等渠道。在银保渠道，平安与不到3万个银行网点合作，仅占中国超过22万个银行网点的10%多一点。平安预计将提高网点渗透率，并指出在过去两年中，单月最多可增加1000个网点，尽管未来增长速度可能会放缓。
- 在股权投资方面，平安重申了均衡策略，重点是将股票作为重要的跨周期工具，提供类债券的久期和收益率。在红利股方面，公司拥有多元化的投资组合，不仅限于银行股。目标收益率在4%以上，但公司指出，如果负债成本持续下降，门槛收益率可能会降低。
- 关于资产质量，平安继续预计资产管理板块将在2026年提供正的利润贡献。公司认为，由于已计提的拨备以及一二线城市市场情绪改善，2026年与房地产相关的减值压力有限。在资产管理板块内，平安强调其证券业务在2026年第一季度实现了高净资产收益率，远高于行业平均水平。

# 中国太保

■ **新业务价值增长与利润率展望**：中国太保旨在实现代理人和银保渠道之间均衡的价值贡献。代理人渠道的新业务价值利润率接近30%，主要由长期期缴储蓄型产品驱动。银保渠道利润率约为15%，公司认为通过减少趸交保单的占比，利润率有上升潜力。分红险是两个渠道的重要增长动力，太保认为市场有潜力向香港分红险产品模式演进，即低保底回报和多元化的投资配置。
- 关于财险，太保认为，由于车险和非车险的严格监管，费用率有进一步下降的空间。在新能源车险领域，随着自动驾驶功能的改进以及维修网络和流程的发展，综合成本率有下降空间。关于信用保证保险，太保认为在2025年初业务调整后，2026年将呈现积极发展态势。

# 中国太平

## 银保渠道贡献

太平保险指出，银行偏好3至5年期产品，且难以销售保障型产品，因此利润率上行空间有限。但鉴于银行定期存款的适度转移可成为保险公司的重要增长动力，业务量增长潜力巨大。对太平而言，2025年银保渠道新业务价值贡献率约为35%，但管理层认为该比例有潜力逐步提升至50%。太平指出，在监管对渠道费用进行整顿后，该渠道由前七大寿险公司（包括太平人寿）主导。

## 投资

太平人寿对股市表现持谨慎乐观态度，并对利率持中性看法。其重点是久期和现金流匹配，以确保投资回报能够覆盖负债成本。该公司还将寻求通过交易收益来提高固定收益投资组合的收益率。

# 众安在线

## 在线健康险

众安在线指出，中国内地健康险发展潜力巨大，同时健康险的线上渗透率仍然较低。众安是在线健康险最大的分销商，并预计随着市场发展，将保持强劲的增长势头。

# 中国人寿

中国人寿预计，在经历了异常强劲的2026年第一季度（同比增长75%）后，未来几个季度新业务价值增长势头将趋于正常化。第二季度和第三季度的基数效应较高，中国人寿还指出，新的银保渠道费用规定可能会扰乱近期的销售势头。尽管如此，中国人寿对2026全年实现两位数的新业务价值增长充满信心，并预计在2025年重新定价行动以及更加专注于长期、期交保单销售的推动下，利润率将有所扩大。

随着新保费收入入账，股权投资将继续增加，但中国人寿认为整体股权投资配置相对稳定。尽管AI供应链表现强劲，但投资组合内的配置是多元化的，追踪的是大盘指数。中国人寿指出，计入其他综合收益的股权投资占比已有所提升，达到股权投资组合的约30%，与行业平均水平大致相当。

# 新华保险

代理人和银保渠道的销售及新业务价值均远超2026年全年目标。从2026年第二季度开始，新华保险将重点放在健康险和长期产品上。关于分红型重疾险产品的详细监管规定尚未出台，因此代理人渠道主要销售传统重疾险产品。银保渠道仍然主要是储蓄型产品渠道。

在投资方面，2025年总股权投资配置比例为22%，受市场波动影响，2026年第一季度略有下降。中期来看，新华保险没有设定目标水平，但预计该比例不会升至25-30%的区间。新华保险目前认为H股存在机会，尤其是在考虑股息收益率和现金流的情况下。

在股息派发方面，即使基于2024年的高基数，2025年25%的派息率也足以推动每股股息增长。2026年股息政策尚未决定，但公司将考虑绝对每股股息金额。

# 中国人保财险

股权投资占投资组合的比例接近30%，包括对华夏银行、兴业银行、人保寿险和人保健康的持股。人保财险认为，基于其当前的综合偿付能力充足率，30%是上限，因此股权资产配置比例进一步增加的空间有限。2026年的目标投资回报率为3-4%。

人保财险将2026年第一季度车险保费行业性下滑归因于新车销量下降以及常规定价因素的变化。管理层预计汽车销量将逐步复苏，从而在未来几个季度推动车险保费增长改善。

在承保业绩方面，人保财险将其更优的综合成本率归因于以下因素的组合：1）更好的风险定价，2）内部费用管理，3）与原始设备制造商的紧密关系，以及4）理赔管理的专业知识。随着新能源汽车市场逐渐成熟，人保财险预计赔付率将普遍改善，并相信其竞争优势能够使公司持续取得优于同业的承保业绩。

下行风险：投资市场进一步疲软，可能降低偿付能力充足率并限制其提高股息的能力；10年期国债收益率进一步下降至2%以下；低线城市保险销售增长乏力（中国人寿在这些城市拥有更 dominant 的市场份额）；代理人产能提升落后于同业。

# 目标价风险及方法论 - 中国平安

我们对平安A股和H股给予买入评级。基于SOTP的12个月目标价为港币75.0元/人民币77.0元，对应2027年预期市净率1.1倍/1.3倍。我们的估值方法为：1）平安寿险基于ROA预测，对应2027年预期市净率1.9倍/2.4倍；2）平安产险基于2027年预期净资产收益率12%，对应1.0倍市净率；3）平安银行目标市净率2.125倍（由杨硕覆盖）。

下行风险：营运利润和/或合同服务边际进一步下降，将对股息增长构成下行压力；销售组合进一步恶化，导致未来利润对利率和投资回报的敏感性增强；非保险业务（如银行和资产管理业务）出现进一步的投资资产损失/减值。

# 目标价风险及方法论 - 中国太保

我们对太保H股/A股评级为买入/中性。基于SOTP的12个月目标价为港币38.0元/人民币39.0元，对应2027年预期市净率0.9倍/1.1倍。我们的估值方法为：1）太保寿险基于ROA预测，对应2027年预期市净率1.2倍/1.5倍；2）太保产险基于2027年预期净资产收益率13.2%，对应1.2倍/1.2倍市净率。

上行风险：新保单销售强劲、利润率进一步扩Daiwa/或产品盈利能力改善，推动NBV增长超预期；产险承保业绩好于预期，允许更多资本上缴集团；在强劲利润增长的支持下，近期股息政策更为积极；长期债券收益率显著回升，带来投资回报和长期产品盈利能力改善。

下行风险：核心代理人数量无法增长，导致NBV增长落后于领先同业或处于平均水平；中型竞争对手竞争加剧导致产险承保亏损增加；太保寿险储蓄型产品占比提高和资本消耗导致股息派发率降低；长期国债收益率进一步下降。

# 目标价风险及方法论 - 新华保险

我们对新华保险H股/A股给予卖出评级。基于ROA的12个月目标价为港币37.0元/人民币49.0元，对应2027年预期市净率0.8倍/1.2倍。

上行风险：鉴于新华保险对投资业绩具有更高杠杆效应，A股市场上涨；成本管控改善长期ROE及股东回报；效率提升驱动新业务价值持续增长；增加计入OCI的债务资产配置以缓解债券收益率下行带来的负面影响；未来股息政策较预期更为积极。

# 目标价风险及估值方法 - 中国太平保险控股

我们对中国人保给予中性评级。基于分部估值法的12个月目标价为21.0港元，对应0.6倍2027财年预期市净率。估值依据：1）太平人寿按0.7倍2027财年预期市净率估值，基于我们的ROA预测；2）太平财险及太平再保险分别按0.5倍/0.4倍市净率估值，基于2027财年预期ROE为7.3%/6.8%。

上行风险：寿险核心偿付能力资本状况进一步改善，向集团上缴资本增加，有望提高分红比例；香港寿险业务资本消耗减少；非保险板块经营业绩改善；投资业绩超预期及税费正常化。

下行风险：投资业绩不及预期拖累利润增长；新单保费销售增长乏力导致合同服务边际余额持续下降，新业务价值低于预期；受寿险及非寿险板块偿付能力约束及利润增长压力影响，分红比例下降。

# 目标价风险及估值方法 - 中国人民财产保险股份有限公司

我们对人保财险给予买入评级。基于ROE法的12个月目标价为19.6港元，对超额资本（超过170%核心偿付能力比率部分）按0.8倍市净率估值，对基础业务按1.2倍2027财年预期市净率估值。对应1.2倍2027财年预期市净率及10倍2027财年预期市盈率。

下行风险：无额外股东回报措施；承保业绩低于预期；自然灾害相关赔付增加。
