# IQVIA 处方指标：快速参考指南

# 核心等式

每张配发的处方都汇总到 TRx 中。有两种分解方式：

- TRx = NRx + RRx（新处方 + 续方）
- TRx = NBRx + CBRx（新品牌处方 + 持续处方）

# 处方量指标

# TRx — 总处方

所有配发的处方——新处方和续方处方的总和。顶层数量指标。

# NRx — 新处方

药剂师配发的新处方。包括当患者已用完授权续药次数并获得新处方编号以继续现有治疗时开具的处方。

# RRx — 续方处方

药剂师配发的授权续方处方，数据来自计算机化药房样本。

# NBRx — 新品牌处方

针对首次开始使用特定品牌的患者开具的处方，且在过去 12 个月（回溯期）内未使用过该品牌。

# CBRx — 持续处方

与过去 12 个月（回溯期）内持续使用某产品相关的所有处方。包括授权续方以及当患者续药用完后开具的新处方。

# NBRX 子类型

NBRx - 新品牌处方 - 由两个互斥的患者群体组成：

# NTS Rx — 新治疗起始处方

\- 患者在治疗类别中的首张处方；具体指在指定的回溯期内，患者未在定义的 USC 3 或 USC 4 相关市场中配发过任何治疗药物的情况下所配发的处方。

# 转换/加用处方

\- 患者对该品牌是新的，但在回溯期内曾配发过同一治疗类别（USC3 或 USC4）中的其他药物。

• 涵盖两种情况：

- 转换：患者从竞争品牌转向该品牌
- 加用：患者在现有同类治疗基础上加用该品牌

$$
\mathrm{NBRx} = \text { NTS Rx } + \text { 转换/加用 Rx }
$$

# 需要了解的关键区别

# NRx 与 NBRx 的区别

- NRx 统计任何新处方，包括用完续药次数的患者的续方——患者可能已长期使用该药物
- NBRx 更严格：仅统计过去 12 个月内未使用过该品牌的患者，是衡量患者获取的真实指标

# RRx 与 CBRx 的区别

- RRx 仅统计授权续方
- CBRx 范围更广——包括续方以及为用完续药次数但仍在继续治疗的患者开具的续方处方

# 回溯期

- 用于分类 NTS 与 转换/加用的标准回溯期为 12 个月
- 某些急性治疗类别使用 1 个月的回溯期，以更好地反映短期疗程模式
- 使用 1 个月回溯期的急性类别包括抗感染药、抗生素和麻醉药。
