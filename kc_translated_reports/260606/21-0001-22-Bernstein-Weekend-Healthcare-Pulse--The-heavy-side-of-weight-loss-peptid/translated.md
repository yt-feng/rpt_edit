# 肽类——新药模式中最大的市场

IQVIA预计，到2030年，全球药物使用量约为4万亿标准日剂量。在排名前20的治疗领域中，大多数呈现中个位数至低两位数的增长，但肥胖症独处一隅，预计未来五年增速最快，远超糖尿病、肿瘤学和免疫学。全球肥胖症药物支出预计将以25%左右的复合年增长率增长，在2025年至2029年间增加超过500亿美元的增量支出，并推动该类别在本十年末逼近1000亿美元的门槛。

肥胖症市场的增长推动肽类成为规模最大、增长最快的新药模式，超越了ADC、下一代抗体和寡核苷酸。尽管重组蛋白和传统抗体在绝对值上仍占主导地位，但肽类的增长泡沫现已可与那些成熟的生物药类别相媲美。

# 从公斤级到多公吨级生产

历史上，肽类原料药年产量为公斤级，而现在正进入多公斤级甚至公吨级的年产量。大多数已上市的肽类原料药通过生物反应器（重组表达后纯化）或化学合成生产，其中固相肽合成（SPPS）是中短长度及高度修饰肽类的主要路线。SPPS在树脂上逐步构建肽链，经过迭代的去保护、偶联和洗涤循环，然后通过色谱法裂解和纯化粗序列。该工艺灵活（例如可掺入非天然氨基酸、脂化），且兼容自动化，因此尽管溶剂用量大，仍已成为现代肽类原料药的行业标准。

SPPS和批处理色谱法（用于纯化）极其消耗溶剂和试剂：行业分析表明，生产每公斤GLP类肽原料药需要多达16,000公斤化学品，纯化和冻干是工艺质量强度（PMI）的主要贡献者。在更大规模下，偶联、去保护或色谱法中的任何低效都会放大为更高的销售成本和更多危险废弃物。如果原料药序列长且含有疏水片段，则会增加聚集和副产物形成，使高纯度规格更难达到。

# 因此，ESG是一个问题：像ACS绿色化学研究所这样的组织明确将肽类原料药列为最不可持续的模式之一。

肽类生产规模化面临三大挑战：

- 高PMI和溶剂消耗威胁利润率可持续性：如果CDMO无法有效降低每公斤的溶剂和原材料用量，产量上升将放大成本和环境负债。
- 批处理纯化和复杂的多步骤工作流程限制了有效产能，并增加了批次失败的概率，制约收入增长并造成供应风险隐患。
- 围绕废弃物最小化和杂质控制的ESG及监管预期正在收紧；固守传统高溶剂平台的参与者面临市场份额流失、更高资本支出或与偏好更绿色合成路线的客户签订粘性较低的合同的风险。

# SPPS的创新改进——CDMO案例研究

# Bachem——连续色谱法（MCSGP）的先驱

MCSGP（多柱逆流溶剂梯度纯化）最初由苏黎世联邦理工学院的研究人员开发。Bachem（未覆盖）是首家在2023-24年将该技术商业化的CDMO。MCSGP不是运行大型、启停式的纯化步骤并丢弃大量中间物料，而是使用两个相连的色谱柱，连续地将部分纯化的馏分来回传递，直到肽被干净地分离。在实践中，这意味着过去被视为废弃物或返工品的很大一部分可以回收为可销售产品，同时仍能达到超过99.3%的极高纯度。

# 与传统批处理纯化相比，MCSGP将溶剂消耗降低约30%，总物料使用量降低70%。

同时，过去需要5天批处理工作的工作量可以压缩到24小时的连续运行中。这减少了过程控制检查，缩小了冻干体积，并将纯化时间从大约五天缩短至一天，从而释放了设备和QC资源。

# 药明康德 - 减少溶剂使用，PMI降低超过3倍

在优化工艺过程中，药明康德（未覆盖）直接致力于减少溶剂使用。他们已将总溶剂用量削减25%，并用更可持续的溶剂替代了50%的DMF。剩余的DMF被回收，并供邻近的电池工厂使用，以最大限度减少整个工业园区的总体废弃物。

PMI是生产一单位质量产品所需所有输入材料的总质量；较低的PMI直接反映了资源密集度较低的工艺。当前对多肽生产的行业分析报告显示，固相多肽合成的平均PMI在13,000左右。药明康德的最新数据显示，他们已将其降低了超过3倍。更少的溶剂和试剂降低了可变成本和废弃物处理支出。每公斤物料足迹削减三分之二，会迅速累积成利润率的提升。此外，这还能释放产能。最后但同样重要的是——制药公司面临报告范围三排放的压力；如果他们外包给一家能够展示量化PMI降低和溶剂回收成果的CDMO，这将使其可持续发展叙事更容易。这往往能转化为更稳固的合同。更低的PMI有助于改善单位经济性、提高资本生产率，并提供差异化的ESG服务。

# 凯莱英 - 一年内交付PPQ

我们看到凯莱英（未覆盖）采用了类似的方法：

- 更绿色的合成路线（DMF替代和可持续溶剂）
- 实时过程分析技术（PAT）和预测动力学建模，以减少洗涤步骤和实验
- 标签辅助多肽合成（TAPS）加连续流反应器，以增强混合、反应速率和可放大性

针对复杂长链多肽和GLP-1药物的典型PPQ（工艺性能确认）项目通常需要18-24个月。凯莱英的Mazdutide案例研究——在12个月内完成预PPQ和PPQ，在6个月内提交NDA申报资料，在6个月内通过动态PAI检查，并交付一批>5公斤、纯度>98.5%的产品。这看起来比我们对首个同类双靶点GCG/GLP-1激动剂在吨级规模上的预期要快大约6-12个月，同时仍能满足高纯度和杂质控制的要求。
