# 日本科技：IT服务：未覆盖公司业绩传导分析（5）（制造业/汽车行业）：Systena、Argo Graphics、DIT

在本报告中，我们探讨了对三家未覆盖公司（我们对此类公司无投资观点）进行调研后，对我们所覆盖的IT服务板块的启示。这三家公司均处于制造业/汽车行业系统集成领域：

# Systena（车载系统/SI）、Argo Graphics（汽车

# CAD/半导体相关系统）以及Digital Information Technologies

（DIT；车载系统/SI）。在Systena，以移动出行和金融领域的开发项目为中心，业务环境依然良好，但由于发行新股认购权导致股权激励成本增加，公司预计FY3/27营业利润仅实现温和增长。

在Argo Graphics，由于主要汽车客户的投资限制以及数据中心折旧成本增加，FY3/27营业利润指引为同比下降。在DIT，由于多家汽车客户限制投资，第三季度（1月至3月）营业利润连续第二个季度下降，且低于指引。

# 就传导效应而言，汽车行业投资意愿下降对整体IT服务板块的需求环境构成轻微负面影响。

虽然没有大型系统集成商对汽车行业的销售敞口很高，但我们将密切关注服务于广泛行业的系统集成商的趋势，例如富士通（买入）和NEC（买入）。以下我们概述了从公司评论中得出的主要观点（参见图表1/图表2/图表3/图表4的业绩表格）。

# Systena (2317.T)（车载系统/SI）

(1) 指引：FY3/27营业利润指引为温和增长至160亿日元（同比增长4%）。主要原因是发行新股认购权导致股权激励成本增加（同比增加8.4亿日元）。剔除这一影响和折旧，公司预测EBITDA将继续以两位数百分比增长，同比增长11%。Systena预计，由于PC换机周期见顶，业务解决方案业务的销售额和利润将下降。然而，除该业务外，公司预测销售额和利润将增长，核心开发业务的良好业务环境预计将持续（公司指出中东局势的影响有限）。

(3) 数字集成业务：业绩依然强劲，核心系统更新等项目咨询量很高。按行业划分，金融领域增长尤为强劲。考虑到订单趋势等因素，公司预计这一趋势将持续。
(4) 中期计划：最终财年FY3/29的营业利润目标为202亿日元（意味着FY3/26至FY3/29的复合年增长率为9%）。虽然Systena旨在发展所有核心业务，但它预计数字集成业务将推动增长，因为该业务在核心系统更新等项目上持续收到强劲的咨询。据公司称，该目标未考虑数据驱动管理或人力资源重新配置带来的效率提升，这可能是盈利的上行因素。

# Argo Graphics (7595.T)（汽车/半导体）

(1) 指引：FY3/27营业利润指引为103亿日元（同比下降4%），这将是自新冠疫情以来六年来首次同比下降。尽管主要半导体客户的投资显示出复苏迹象，但公司预计主要汽车客户的投资将受到限制，并且4月在北海道北见市开始运营的数据中心（DC）的折旧成本将增加。公司预计该数据中心的年折旧额将超过4亿日元，该费用将从第一季度（4月至6月）开始产生。据公司称，一项提供公司作为固定资产拥有的系统的托管服务将于第一季度启动，这些系统的折旧将预先计提。

(2) 系统产品业务（非合并）：FY3/26销售额同比下降0.5%。其中，PLM销售额同比增长2%（汽车行业增长缓慢），高性能计算（HPC）销售额同比增长12%（大型项目的贡献），IT销售额同比下降13%（半导体行业下滑）。对于FY3/27，公司预测PLM销售额略有增长，HPC销售额下降，IT销售额增长。据公司称，(a) 除了整个汽车行业盈利疲软外，由于客户特定因素（战略变化），IT投资也受到限制，使得汽车业务的前景仍然充满挑战；(b) 另一方面，多家主要客户计划扩大在半导体领域的投资（在其北海道/九州/三重工厂）。

# Digital Information Technologies (3916.T)（车载系统）

(1) 3Q6/26（1月至3月）：营业利润连续第二个季度下降，同比下降5%至8.8亿日元。这归因于大型项目的退出以及高利润汽车业务投资限制。利润低于指引，主要是在嵌入式解决方案和产品解决方案业务中。公司维持全年指引不变，这意味着4Q营业利润指引为6亿日元（同比增长22%），需要实现利润的大幅增长。DIT表示，虽然实现销售指引将很困难，但其目标是通过限制战略投资（安全产品开发、AI投资、内部系统投资等）和奖金来实现利润指引。

(2) 嵌入式解决方案业务（嵌入式系统）：3Q销售额和毛利润同比分别下降1%和5%。除了3Q6/25计入的大型项目回撤外，主要汽车客户的投资意愿正在迅速下降。因此，开发和验证业务都面临强劲逆风。据公司称，这一趋势可能会持续到FY6/27，需要通过业务解决方案业务（业务系统的开发和维护）来抵消。
