# 市场真正低估的不是需求，而是供给侧的再定价

# 集装箱航运与供应链洞察

行业前景快速改善：运价飙升与积压需求推动旺季前景乐观

全球集装箱航运业在地缘政治持续不确定、供应链中断及燃油成本高企的背景下，仍展现出韧性。领先航运公司的一季度运营更新凸显了强劲需求，尤其是在亚洲区域内及区域间航线，尽管运价正常化，海丰国际和德翔海运仍报告了同比货量增长。中远海运等全球巨头也录得强劲吞吐量增长，而长荣海运在有效供给紧张、运价高企及成本传导能力支撑下实现营收回升。欧洲承运商马士基盈利超预期并维持全年指引，突显行业适应性与需求前景向好，赫伯罗特同样维持全年指引。运价仍处高位，SCFI自3月以来上涨73%，承运商为应对中东引发的成本压力而广泛征收附加费。近期周环比涨幅达两位数，尤其在跨太平洋和亚欧航线，旺季/紧急附加费已实施，运力管理保持自律。港口拥堵仍是结构性特征，吸收有效运力并支撑运价，而美国终端市场指标——LMI仍处高位，录得2022年初以来第二快扩张速度——表明尽管成本压力加剧，需求仍具韧性。中美政治局势持续演变，中国商务部表示双方就推动解决非关税壁垒达成积极共识，这有望进一步强化全球贸易前景。年初至今股价表现反映了这些动态，亚洲及亚洲区域内航运商整体跑赢/持平于MSCI全球交通运输指数，而亚洲航运商估值仍低于行业均值，表明在供需基本面支撑下仍有进一步上行空间。

个股观点：我们仍看好该行业进入旺季，运价飙升、港口持续拥堵及终端市场需求韧性共同强化了乐观前景。亚洲领先航运商，包括德翔海运、中远海运、东方海外、长荣海运和商船三井，仍是我们首选标的，提供具吸引力的短期风险回报比、可观股息收益率及稳健资产负债表。此外，尽管我们注意到近期将西港控股下调至中性评级，反映货量增长放缓、风险不对称性减弱及成本压力上升导致前景不明，但我们仍看好国际集装箱码头服务公司和CMPH，其多元化投资组合及在高增长新兴市场的布局，在地缘政治不确定性中提供了防御性。

# 基础设施、工业与运输

- 尽管地缘政治紧张局势和供应链中断持续存在，亚洲区域内集装箱航运运营商在2026年第一季度仍展现出强劲的需求和运营韧性。海丰国际报告称，其航运量同比增长7.6%，达到855,795标准箱，收入增长1.5%，即便平均运费从高位正常化，这反映了亚洲地区持续的货物流动和供应链多元化。请注意，平均运费的疲软与去年提前装运基数效应的正常化相符，而非基本需求恶化。德翔海运同样表现出运量强劲，同比增长3.3%，达到396,935标准箱，突显了区域内贸易的持久性以及该公司在航线调整和运力部署变化中捕捉需求点的网络灵活性。两家运营商均受益于更紧张的有效运力和持续的港口拥堵，这为运费提供了结构性支撑，并有利于灵活的区域性参与者，因为亚洲内部货运流量的基本实力依然完好，且该地区的供应链多元化仍在继续。德路里亚洲区域内集装箱运价指数持续上涨，周环比上涨5%，为连续第七周上涨，目前较冲突前水平上涨83%，原因是燃油成本上升、运力减少和需求强劲。

- 在亚洲区域内市场韧性的基础上，全球集装箱航运领导者长荣海运和中远海运提供了进一步证据，表明行业需求基本面依然强劲，运费动态正在建设性地演变。中远海运在2026年第一季度报告了强劲的运量增长，其行业整体吞吐量同比增长7%——受亚欧航线和亚洲区域内货运流强劲推动——而长荣海运的季度收入环比改善以及对进一步复苏的预期，反映了进入旺季时基本货物需求的正常化。值得注意的是，行业评论强调，有效供应远紧张于名义运力数据所显示的水平，因为持续的瓶颈、港口拥堵和冲突相关的绕行吸收了全球船队的很大一部分。这种结构性紧张，加上能够转嫁燃油附加费和重新谈判合同条款的能力，正在支撑一个更坚挺的运费环境，即便平均运费已从去年的高位正常化。随着供应链碎片化和贸易多元化继续重塑全球货运流，拥有网络规模、成本领先和数字化整合能力的运营商能够很好地捕捉增量需求并捍卫盈利能力，这强化了行业在主干航线旺季来临前的建设性前景。

- 台湾船公司4月运营收入更新强化了反弹趋势。2026年4月运营收入升至新台币313.6亿元（同比增长5%，环比增长14%），扭转了第一季度的下滑趋势，并自去年3月以来首次出现同比正增长。2026年前4个月累计收入为新台币1179亿元（同比下降16%）。同样，万海航运和阳明海运的月度运营收入也有所改善，分别同比增长13%和14%，并分别自去年3月和2月以来首次出现同比正增长。这一改善反映了春节后需求增强以及运费上涨的初步影响，管理层指出旺季将更为正常化，货运流具有韧性。

- 欧洲承运商的前景保持不变，马士基（由Alexia Dogani覆盖）在2026年第一季度提供了建设性的行业解读，其盈利超出预期并维持全年指引，运量同比增长9.3%——尤其来自亚洲出口——以及高船舶利用率抵消了平均运费14%的下降。赫伯罗特（由Alexia Dogani覆盖）尽管因波斯湾中断和欧洲不利天气导致运量小幅下降而未能达到市场盈利预期，但也重申了全年指引，单位运费环比上涨2%，管理层强调中东冲突带来的持续不确定性。同样，达飞轮船（信用分析师：Danielle Ward）报告第一季度运量持续增长，管理层强调，随着旺季临近，行业整体势头支持了现货运费的大幅反弹。上海出口集装箱运价指数（SCFI）自2月中旬以来已飙升超过75%，这既反映了中断溢价，也反映了托运人因预期供应链风险或关税变化而提前装运的努力。总体而言，欧洲承运商正通过附加费、对冲和运营调整积极管理更高的成本，尽管宏观经济和地缘政治不确定性持续存在，但仍保持稳定展望，并突显了该行业在进入主干航线旺季时的适应能力。

# 供应链中断和燃油价格上涨推动运费上升

- 自中东冲突开始以来（截至5月29日），运费已飙升73%，最新数据显示周环比上涨约16%，受跨太平洋和亚欧航线两位数涨幅的推动。这一上涨得到了紧急燃油附加费、旺季附加费、综合费率上涨、运力削减、空白航行以及更坚挺的现货定价的支持，因为承运商在燃油成本上升和地缘政治紧张局势下积极管理舱位。早期旺季需求以及与中东冲突相关的中断正促使托运人提前运输货物，使市场保持坚挺。截至5月29日，上海出口集装箱运价指数（SCFI）自3月以来上涨73%，同比上涨62%，反映了供应链中断和燃油成本上升。主干航线如上海-欧洲和地中海自2月底以来分别上涨70%和59%，同比分别上涨88%和61%；而上海-美国西海岸和东海岸自2月底以来分别上涨114%和96%，同比分别上涨27%和25%——考虑到2025年的提前装运效应，这一表现尤为显著，并可能显示出船公司在2026年跨太平洋合同费率谈判期间的纪律性。连锁效应也正在推高新兴市场和区域市场的运费，为2026年第二季度的业绩提供了可见性。尽管最新的周度运费略有回落，但与船公司的渠道调研预测，随着主要承运商为即将到来的旺季调整运力部署，运费将恢复增长轨迹。

- 期租市场紧张及租船费率高企，进一步加剧了不同船队所有权结构下的盈利分化，自有船队占比较高的运营商能更好地抵御成本上升。当前集装箱船期租费率处于疫情后最高水平（克拉克森期租费率指数为206点，自2月底以来上涨4%），且由于持续存在的运营瓶颈——包括创纪录的港口拥堵（克拉克森拥堵指数在2026年1-5月达到历史最高点）以及冲突导致的绕航吸收了有效运力——船舶可用性依然紧张。因此，自有船队比例较高的承运人，在结构上更能保护盈利免受租船成本上升的影响。如图10所示，长荣海运的租入船队比例相对较低（约30%，而前十大承运人平均约为43%，数据来源：Alphaliner 2026年5月月度监测），因此对高企的租船费率敞口更大。在这种环境下，像长荣海运和德翔海运（租入船队比例17%）这样以自有船队为主的承运人，受益于天然的成本对冲——避免了依赖租船的运营商在期租费率持续高企且租期延长至1-2年时所面临的利润率压缩。当前供应紧张的局面进一步放大了这种自有船队优势：港口拥堵和更长的停留时间实际上减少了可用运力，使得依赖租船的运营商难以以有利条件获得吨位。随着旺季临近且运力管理保持自律，自有运力与租入运力之间的成本差异可能进一步扩大，从而强化了船队自有率更高运营商的结构性盈利优势。

- 行业正在转嫁燃油附加费，亚洲船公司可能因相对较高的脱硫塔安装率而受益。紧急燃油附加费和更高的燃油调整系数（BAF）正在被广泛实施（德路里），伊朗冲突推动燃油价格上涨约75%，这些涨幅已反映在4月份的运费中。与此同时，高低硫燃油价差自2月底以来平均超过每吨135美元（而去年同期低至每吨30-50美元，克拉克森数据）。值得注意的是，亚洲船公司在此环境下具有结构性优势：虽然行业平均配备SOx脱硫塔的运力比例为47%，但领先的亚洲承运人，如长荣海运（95%）、德翔海运（94%）、中远海运/东方海外（58%）和阳明海运（73%），其船队中配备脱硫塔的比例显著更高。这使得它们能更多地从燃油价差扩大中受益，有助于抵消成本压力，并相对于全球同行保持更强的成本纪律。

- 监管观察：国际海事组织（IMO）海上环境保护委员会第84届会议（MEPC 84）最新动态。自2025年10月特别会议推迟对IMO净零框架进行投票以来，监管格局一直处于变化之中。在最近的MEPC 84会议（2026年4-5月）上，成员国重申了对净零目标的承诺，并同意继续就该框架开展技术工作，但未做出最终决定。委员会安排了进一步的闭会期间会议，并将下一次特别会议定于2026年底举行，这使得该框架的通过和实施时间表仍处于持续谈判之中。在此期间，船东、燃料生产商和投资者正密切关注事态发展，因为不断演变的监管进程将在塑造该行业未来的投资和合规策略方面发挥关键作用。替代燃料的采用方面持续取得进展，据克拉克森数据，目前12%的船队运力能够使用替代燃料（主要是液化天然气和甲醇）。在手订单中，75%的运力能够使用替代燃料，反映了该行业对排放合规的关注。节能技术（EST）日益普及，已安装在62%的船队运力上，高于2019年初的35%。鉴于亚洲船公司配备脱硫塔的船队比例高于行业平均水平，它们有望从中受益。

- 船公司正通过停航积极管理运力，以应对持续的干扰并维持网络稳定。截至5月28日，德路里世界集装箱指数（WCI）周环比上涨3%，至每40英尺集装箱2800美元，反映出主要东西向贸易航线的运费市场走强。亚欧航线和跨太平洋航线的即期运价均有所上涨，其中上海-鹿特丹航线运价上涨3%至2861美元，上海-热那亚航线运价上涨4%至4253美元，上海-纽约航线运价上涨6%至4597美元，上海-洛杉矶航线运价上涨3%至每40英尺集装箱3473美元。早期旺季需求、7月燃油调整前的提前出货，以及持续的地缘政治紧张局势——包括中东干扰和燃油成本高企——正推动承运人提高综合费率（FAK）和旺季附加费（PSS），同时通过停航积极管理运力。自4月底以来，亚欧/地中海航线的运价已上涨38%，跨太平洋航线运价上涨26%。运力纪律支撑了运价势头，因为在未来五周（第23-27周），即从第23周（6月1-7日）到第27周（6月29日-7月5日），在707个预定航次中，预计将有47个航次停航，取消率为7%，仍有93%的航次预计按计划航行。干扰主要集中在跨太平洋东行航线（占49%），其次是亚欧/地中海航线（占34%），而跨大西洋航线（占17%）受影响相对较小。双子星联盟继续保持着良好的船期准点率。随着运力纪律持续且需求被提前，德路里预计运价将面临进一步上行压力，这使得在持续波动和运营不确定性中，托运人必须提前规划并采取灵活的订舱策略。

# 美国终端市场显示出韧性迹象，并可能在2026年第二季度相对于去年“解放日”关税的影响出现反弹

\- 美国LMI 5月更新——扩张依然强劲，但成本压力加剧导致增速放缓。物流经理人指数（LMI）在2026年5月继续扩张，录得强劲的69.5——略低于4月的69.9，但仍为2022年初以来第二快的扩张速度。这种持续但放缓的增长反映了库存水平的减速，该分项下降1.5点至54.8；减速在5月下旬尤为明显，库存水平从60.5降至50.9。小型企业几乎停滞在51.0，而大型企业则保持较高动能于59.5，凸显了在高成本环境下规模带来的韧性。尽管库存增长放缓，物流成本却急剧飙升：库存成本跃升9.4点至84.1，为四年最高，仓储价格则维持在70.7的高位。运输价格飙升至96.0的历史新高，而运输能力进一步收缩至31.7，物流总成本达到250.9，主要归因于霍尔木兹海峡持续的干扰以及全球燃料成本上升。下游库存增长现已超过上游3.6个百分点，表明制造商此前的提前备货正在供应链中向下游传导。展望未来，对未来12个月的预期有所降温，受访者预计未来LMI为69.4，库存增长放缓，成本持续高企，即便部分运力限制可能有所缓解。总体而言，供应链在面对持续干扰和高成本时仍保持韧性，但长期成本压力和收紧的货运环境可能在未来数月带来持续的通胀风险，并对需求构成压力。

\- 2026年4月美国集装箱进口量在3月反弹后温和回落，贸易政策不确定性拖累近期动能。月度集装箱进口量环比下降3.2%，同比下降5.5%，总计2,277,965 TEU（Descartes数据）。尽管出现环比回落——打破了此前10年中8年出现的季节性环比增长模式——但进口量仍比2019年4月水平高出18.7%，反映出潜在需求的持续韧性。此次放缓发生在3月反弹（集装箱进口量环比增长12.4%，同比下降1.1%）之后，且恰逢与欧盟、印度和中国等主要伙伴的贸易关系悬而未决，以及持续的Section 122关税和关税退税时间表的不确定性。来自泰国（+36.3%）和印度尼西亚（+13.3%）等东南亚市场的进口份额在4月继续上升，部分抵消了来自中国进口量15.3%的下降。这种持续的采购来源多元化凸显了进口商在持续的贸易政策不确定性中降低集中度风险的努力。美国NRF预计5-6月进口量将同比增长，对比2025年解放日进口冲击。我们认为，这一趋势对传统的旺季规划有利，有助于承运人平滑船期并提高盈利能力。

\- 美国库存补充近几个月有所放缓，物流经理人指数（LMI）显示库存水平略有下降，但整体仍在扩张。尽管4月和5月的数据表明企业正变得更加谨慎——反映在当前与未来库存预期差距收窄上——但库存成本依然高企，表明即使实物补库放缓，单位成本压力依然存在。值得注意的是，大型企业在重建库存方面更为积极，利用其规模优势来吸收更高的燃料和物流成本，而小型企业则基本保持库存水平稳定。尽管近期集装箱进口量回落且来自亚洲的订舱趋势疲软，但潜在需求依然具有韧性，预计随着航运旺季临近，补库活动将回升。总体而言，美国供应链继续展现出适应性，库存策略正根据成本压力、消费者需求变化以及持续的供应链中断而演变。

# 中东冲突加剧港口拥堵及运营瓶颈

\- 克拉克森港口拥堵指数在2026年升至历史新高。1-5月平均拥堵指数同比上升约5%（克拉克森数据），我们认为，随着主要航线旺季临近，该指数可能进一步上升。海丰国际NDR和中远海运NDR指出，作为全球效率最高的港口之一，中国主要港口的拥堵情况正在加剧。东南亚港口，包括菲律宾、泰国和越南的港口，也面临类似的瓶颈，因为该地区的基础设施投资持续落后于需求。这种广泛的拥堵有效吸收了船舶运力，并为运费提供了结构性支撑，尽管对集装箱船而言也带来了一定的运营压力。

\- 欧洲港口问题持续，而最高效的亚太港口也出现延误。根据Kuehne + Nagel最新的港口运营更新（5月19日），欧洲港口仍受干扰，多个关键码头的堆场利用率接近或超过85%，且因劳工行动、假期安排和有限的缓冲能力叠加，运营承压。在亚太地区，上海港目前等待时间超过2天，而宁波港保持在约1.9天——这进一步表明，即使是全球运营效率最高的港口也无法顺利清理积压。在中国以外，马尼拉港（约4.6天）和丹戎帕拉帕斯港（约1.8天，因疏浚工程导致泊位运营不可用，拥堵情况预计将波动）的拥堵情况严重。两大区域广泛的延误凸显出全球集装箱网络仍在/高于压力阈值运行，即便是轻微的干扰也可能引发更广泛的服务延误。

- Drewry全球集装箱港口吞吐量指数3月环比下降1.3%，主要由于霍尔木兹海峡关闭后中东地区的中断，但同比仍上升1.1%。在最新的Drewry吞吐量数据（5月27日发布）中，尽管区域波动，全球吞吐量截至2026年第一季度末年初至今增长4%，受大中华区、大洋洲以及北/东南亚强劲增长推动。大中华区环比增长2.3%，同比增长4.5%，其中上海环比增长8%，天津环比飙升40%。北美环比反弹3.8%，纽约在2月暴风雪后恢复42%领涨，但多个港口仍低于去年水平。欧洲企稳，安特卫普-布鲁日环比增长12.9%，地中海塞得港东港继续表现优异，环比增长12%，同比增长43%。这些趋势凸显了全球港口在地缘政治和运营挑战持续背景下的韧性与分化。

- 从Westports 2026年第一季度业绩中解读。Westports Holdings（由Yen Voo覆盖）2026年第一季度业绩强化了该行业的韧性以及利用提价等运营杠杆来缓解需求和成本压力的能力，因为Westports尽管吞吐量持平（同比下降1%）且地缘政治不确定性高企，但凭借关税上调和高附加值服务录得稳健盈利。管理层指引4月货量同比增长约3%，反映出持续的供应链中断和更长的停留时间继续吸收有效运力。前景仍保持谨慎，2026财年货量增长预期为0-5%，可见性与中东局势发展相关。总体而言，Westports的业绩凸显了该行业通过定价和运营杠杆捍卫盈利能力的能力，尽管货量复苏取决于贸易流正常化。

- 招商港口2026年4月吞吐量同比增速加快至4.8%（3月为2.4%），表明其投资组合复苏范围扩大。改善由长三角（同比增长7.8%）和环渤海（同比增长5.8%）引领，而珠三角仍略微疲软（同比下降1.8%）。值得注意的是，海外货量转正（同比增长4.1%，3月为同比下降1.1%），其他国内（含台湾）的拖累显著收窄（同比下降0.8%，3月为同比下降12.2%）。几乎所有集群的环比改善与春节后需求更广泛复苏一致，并与行业层面显示中国港口吞吐量韧性的信号相符。

# 集装箱航运股价表现回顾

- 2026年年初至今，集装箱班轮公司股价表现出显著韧性，亚洲承运人普遍与MSCI全球交通运输指数持平或跑赢，该指数年初至今上涨9%（截至6月2日）。在近期中东冲突之前，股价涨幅由亚洲——尤其是亚洲区域内和日本——班轮公司领涨，持续跑赢交通运输指数，而欧洲承运人普遍落后。ZIM和Hapag-Lloyd是例外，因收购相关进展录得强劲涨幅。中东冲突的爆发带来了新的表现阶段：随着地缘政治紧张局势升级和运费在3月初飙升，与区域和亚洲区域内同行相比，长航线敞口较大的班轮公司股价涨幅更大——随着市场开始消化危机，这些涨幅最终有所缓和。近期中美贸易谈判进一步强化了全球航运的积极前景，前提是两国间贸易紧张局势缓解。尽管存在这些波动，亚洲班轮公司股价仍低于行业平均市净率（2026-2027财年预期约1.1倍），表明有进一步上行潜力。这得益于韧性的供需基本面、亚洲运营商卓越的成本管理以及有吸引力的股息收益率，使该板块在今年剩余时间内处于有利地位。
