# 高盛：亚太科技半导体存储南亚科技2Q26业绩参考

7月10日，台湾DRAM生产商南亚科技（南亚；未覆盖）公布了2Q26（六月季度）财报，我们将其作为三星电子（SEC）的业绩参考。主要要点如下：1）DRAM ASP强劲增长，OPM改善：继1Q26环比增长超过70%后，南亚科技2Q26 ASP环比增长超过60%。受ASP强劲上涨推动，OPM环比提升13个百分点至74%，公司预计3Q26经营业绩将环比改善。对于SEC，我们认为传统DRAM ASP环比增长47%，2Q26 DRAM OPM达到80%。2）需求与供需格局带来积极行业前景：南亚科技预计AI和通用服务器正推动存储需求稳健增长，并制约非服务器领域的供应。公司预计未来几个季度供应紧张将持续。3）LTA缓解存储周期性：公司预计LTA将缓解存储周期性，并认为近期宣布的新建产能扩张规模合理，且与多年LTA保持一致。我们认为南亚科技的表态与我们对于存储行业的积极观点一致，并进一步支持我们对SEC的公司观点。

## GS因子概况

GS因子概况通过将公司的关键属性与市场（即我们评级的公司池）及其行业同行进行比较，为公司提供研究背景。所描绘的四个关键属性是：增长、财务回报、倍数（例如估值）和综合（增长、财务回报和倍数的组合）。增长、财务回报和倍数的计算方法是使用每只公司特定指标的标准化排名。然后将这些指标的标准化排名进行平均，并转换为相关属性的百分位数。每个指标的具体计算可能因财年、行业和地区而异，但标准方法如下

增长基于公司的前瞻性销售增长、EBITDA增长和EPS增长（对于资金股，仅EPS和销售增长），百分位数越高表示公司增长越快。财务回报基于公司的前瞻性ROE、ROCE和CROCI（对于资金股，仅ROE），百分位数越高表示公司财务回报越高。倍数基于公司的前瞻性市盈率、市净率、股息率、EV/EBITDA、EV/FCF和EV/债务调整后现金流（对于资金股，仅市盈率、市净率和股息率），百分位数越高表示公司交易倍数越高。综合百分位数计算为增长百分位数、财务回报百分位数和（100% - 倍数百分位数）的平均值。

财务回报和倍数使用GS分析师对未来至少三个季度后的财年末预测。增长使用对未来至少七个季度后的财年输入，与至少三个季度后的财年进行比较（所有指标均基于每股）。

## 并购排名：公司情况更新

在我们的全球覆盖范围内，我们使用并购框架审视公司，同时考虑定性因素和定量因素（可能因行业和地区而异），以纳入某些公司可能被收购的潜力。然后我们分配一个并购排名，作为对我们评级覆盖下的公司进行评分的方法，从1到3，其中1表示公司成为收购目标的可能性高（30%-50%），2表示可能性中等（15%-30%），3表示可能性低（0%-15%）。对于排名为1或2的公司，按照我们标准部门指引。并购排名为3被视为不重要，并且可能在研究中讨论或不讨论。
