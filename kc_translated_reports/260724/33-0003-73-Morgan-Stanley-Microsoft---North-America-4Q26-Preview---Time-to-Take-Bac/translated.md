# 摩根士丹利：微软北美4Q26预览-夺回主动权

Azure 增长处于 40%-45% 区间、Copilot 变现加速以及严格的运营支出，应能巩固微软持续的高十几位数的总回报率。Azure 增长超出预期 1 个百分点、Copilot 席位净增超过 600 万，以及重申 2027 财年上半年 Azure 增长加速，可能推动报价上行，而 16 倍 2028 财年每股收益使得不确定性回报比极具吸引力。

## 关键要点：公司情况更新

- 在强劲的渠道调研、GPU 容量改善以及积极的 CIO 调查数据支持下，我们对第四季度 Azure 按固定汇率计算增长 41% 有信心
- 第四季度 Azure 增长指引超出预期 1 个百分点，以及重申 2027 财年上半年 Azure 增长加速，且 Copilot 席位净增超过 600 万，是微软报价的关键
- 渠道调研支持 M365 Copilot 在已有 2000 万付费席位基础上势头增强，使用率提升且客户群进一步采用
- 市场一致预期的资本支出估算可能上调；我们预计我们高于市场的资本支出估算上行空间较小。资本支出增长节奏变化对研究资本回报率和报价很重要
- 以约 16 倍 2028 财年 GAAP 每股收益计算，我们认为微软报价未能反映其持续的高十几位数总回报率，凸显了具有吸引力的不确定性回报比

微软研究论点：正如我们近期详述的（微软：AI 堆栈之战：从基础设施到知识工作者——Azure 和 Copilot 即将迎来拐点，2026 年 7 月 21 日），Azure 和 Copilot 是报价的关键，且两者似乎都将迎来拐点。我们认为，市场并未充分反映拐点的时间（短期）和程度。随着短期/中期新增供应满足强劲需求，Azure 情绪将改善，推动 Azure 增长在更长时间内高于预期。M365 Copilot 驱动的每用户平均收入贡献现在是一个三管齐下的故事：Copilot 席位、E7 SKU 和消费定价，创造了微软历史上最大的每用户平均收入扩张机会之一。资本支出带来可持续的高十几位数收入增长；规模效应带来的经营杠杆加上严格的运营支出，使得尽管毛利率承压，运营利润率仍能扩张。我们认为 16 倍 2028 财年 GAAP 每股收益对于超过 20% 的盈利增长来说过于便宜。保守地应用 1.2 倍 PEG / 25 倍市盈率（相对于同行有折价），得出 50% 的上行空间。我们认为第四财季可以成为第一个催化剂，有助于为我们关于 Azure、Copilot 和利润率的论点建立支撑

Azure 和 Copilot 势头在第四财季至关重要。上季度的业绩强劲，微软在三个业务部门均超出市场一致预期，总收入超出约 1%，得益于 Azure 按固定汇率计算增长 39%（高于指引高端约 38% 的固定汇率增长）。重要的是，公司在实现这一收入强劲表现的同时，毛利率也超出预期（尽管业务结构向 Azure 转移），并且运营利润率同比扩大约 160 个基点。前瞻指标也保持强劲，剩余履约义务（同比 +110% 至约 6250 亿美元）和合同剩余履约义务（同比 +39%）强化了持续的商业需求。对于第四季度：Azure 按固定汇率计算增长约 41%，并重申 2027 财年上半年 Azure 指引（预计温和加速），鉴于容量和分配限制，这很可能足以跨越读者的门槛。此外，第四季度运营支出可能实现高个位数/低两位数增长，2027 财年运营支出增长中/高个位数，这应有助于抵消毛利率压缩，并可能帮助在 2027 财年实现高十几位数的营业利润增长。

## 合作伙伴渠道讨论继续强化微软的广泛优势

渠道合作伙伴对第二日历季度 Azure 业绩和未来前景表示乐观。我们最新的合作伙伴对话继续指向微软商业产品组合的持久需求，其中 Azure、Microsoft 365、安全以及更广泛的 AI 工作负载仍是主要增长动力。合作伙伴普遍认为微软又迎来了一个建设性的季度，得益于持续的云迁移、Azure AI 部署的扩展、健康的 E3/E5 升级活动以及微软生态系统内捆绑销售驱动的强劲安全需求。几位合作伙伴还强调了 Dynamics、GitHub 和 Fabric 的势头正在改善，强化了微软商业增长概况的广度。尽管 Azure 需求保持健康，但我们从一位合作伙伴那里发现了潜在容量限制的迹象，这限制了某些客户工作负载的部署速度，与管理层关于 Azure 增长仍受可用容量而非需求限制的评论一致。在应用层，合作伙伴继续将 Copilot 的采用描述为逐步推进，认知度继续超过企业级部署，尽管采用率仍在改善。尽管如此，鉴于持续的 Microsoft 365 升级、对新 E7 产品日益增长的兴趣、持续的安全附加以及更广泛的 Agentic AI 产品组合（包括 Agent365）的持续产品创新，合作伙伴对长期机遇仍持建设性态度。

## 我们在财报发布前关注的 4 个领域

## 1) 证明 Azure 增长的持久性

MS观点：我们对 2026 财年第四季度 Azure 按固定汇率计算增长 40%-45% 的信心，反映了微软的持续领先地位，这体现在我们的 CIO 调查工作中，以及建设性的合作伙伴评论（指向持久的云和 AI 需求），还有随着数据中心建设持续改善而增加的 AI 容量。41% 的固定汇率增长读者基准是可以实现的，这一比指引高端高出 1 个百分点的表现对微软报价来说将是一个强劲结果，尤其是考虑到此前指引称 2026 年下半年上半年相比将进一步温和加速，这意味着未来两个季度按固定汇率计算增长 42% 以上。我们预计 Azure 增长在 2027 财年将保持良好支撑，因为微软执行其计划，在未来两年内将其总数据中心足迹大约翻一番。我们相信，不断扩大的基础设施足迹应能继续缓解容量限制，使 Azure 能够抓住强劲的 AI 和云需求，同时进一步证明微软在 AI 基础设施上的重大研究正在转化为持久的收入增长。

买方观点：对于 2026 财年第四季度，读者期望按固定汇率计算增长 41% 以上，这比 39-40% 固定汇率增长的指引高端高出 1 个百分点，同时也受到去年 4% 更难的增长率基数的影响。此外，预计管理层将重申此前（来自 2026 财年第三季度电话会议）的指引，即“2026 年下半年与上半年相比温和加速”，这意味着 2027 财年上半年 Azure 按固定汇率计算增长 42% 以上。

微软依然是企业AI领域最明确的赢家。我们最新的2Q26 CIO调查（参见报告《微软：2Q26 CIO调查要点——GenAI领导地位依然清晰》，2026年7月16日）继续强化了微软在云和GenAI两大领域的领导地位，尽管企业IT支出环境相对稳定。虽然CIO预计软件支出将从2025年的+3.8%温和加速至2026年的+4.1%，但微软仍是这部分增量支出的主要受益者，其远期软件支出预期在各供应商中最高，达到+7.6%，较我们上次调查的+7.3%有所提升。在净支出方面，微软也持续领先，72%的CIO预计未来一年将增加在微软解决方案上的支出。同时，微软的领导地位远不止于核心软件支出，已延伸至企业AI应用领域。首先，Azure仍是持续云迁移的主要受益者，在未来一年和未来三年的预期云市场份额增长中均排名第一，同时Azure的支出意向持续改善。其次，在云基础设施之外，CIO再次将微软列为GenAI增量支出的最大预期受益者，同时将其评为代理自动化计划和构建定制AI应用的首选平台。第三，在应用层，Microsoft 365 Copilot仍是微软产品组合中的旗舰AI工作负载，其采用预期持续改善，同时企业M365用户的计划部署规模也在扩大。

市场一致预期Azure增长率为同比40.5%（按报告数据；根据指引，汇率影响不显著），这意味着环比增加约33亿美元，或环比增量同比增长约41%。关于Azure收入增长的预期超预期幅度，与上季度类似，我们预计本季度市场预期将比固定汇率指引的高端（39-40%固定汇率指引）高出约1个百分点。需注意以下几点：1) 与之前几个季度类似，过剩需求信号并不能决定实际的Azure增长，因为管理层一直重申，Azure收入受限于可用容量而非客户需求。正如CFO Amy Hood在F3Q26财报电话会议上强调的，Azure指引应被视为“分配容量指引”，关键变量是数据中心建设的时间安排、GPU部署以及新安装容量何时开始产生收入。尽管Azure在核心Azure和Azure AI工作负载方面的需求依然强劲，但报告的增长仍受制于增量基础设施部署/变现的节奏。2) 可用容量不仅需要分配给外部Azure客户，还必须分配给微软快速扩张的自有AI产品组合。正如我们在近期微软深度报告中分析的那样（参见报告《微软：AI堆栈之战：从基础设施到知识工作者——Azure和Copilot即将迎来拐点》，2026年7月21日），增量AI基础设施（或新上线容量）必须在Azure、自有应用、内部研发/训练之间进行平衡，管理层始终优先考虑微软平台上的最高回报机会。话虽如此，Azure增长只是微软更广泛的AI基础设施分配策略的一个产出结果，但我们预计随着新容量上线，Azure AI将获得越来越大的增量容量份额，这反映了其作为微软通过Azure及其自有AI应用实现AI需求变现的主要基础设施层的角色（见图表9）。3) 虽然Azure AI仍是Azure增长的主要驱动力，但随着容量限制逐步缓解，焦点正日益转向微软如何高效地将不断扩张的AI基础设施转化为收入。随着微软执行其未来两年将数据中心规模扩大约一倍的计划，我们预计基础设施回报表现的提升将支撑Azure在FY27及以后的持久增长，尽管容量驱动的指引可能继续限制季度超预期的幅度。关于F4Q26的Azure AI，我们预计同比增长约100%，或环比增长约18%，而F3Q26估计为17%，F4Q25为20%。这意味着环比增加约12.6亿美元（F3Q约为10亿美元），Azure AI增长对F4Q的贡献约为19个百分点（见图表1），略高于前两个季度的估计贡献。

## 2) Microsoft 365 与 Copilot：AI变现的下一阶段

核心观点：多重变现杠杆支撑商业云持久增长。我们继续将M365商业云视为微软最被低估的AI变现机会之一，尽管越来越认为关注点应超越Copilot席位采用率，转向微软AI商业模式的更广泛演进。正如我们近期发布的微软假设报告（参见《微软：AI堆栈之战：从基础设施到知识工作者——Azure与Copilot即将迎来拐点》，2026年7月21日）所讨论的，微软正从传统SaaS许可模式转向应用层更偏向混合席位+消费的框架。虽然M365 Copilot席位目前仍是主要变现渠道，但管理层已日益强调更广泛的AI变现，并在F3Q26财报电话会议上指出，“我们正看到一种新模式出现，客户从传统席位模式转向席位加消费。” GitHub Copilot、Copilot Credits、Dynamics AI代理及更广泛的AI服务是这一演进的最早例证。我们认为，这一演进将公司的变现机会远远扩展到传统基于席位的ARPU增长之外，使AI收入能够随客户使用量同步增长，同时为M365商业云增长创造多个独立驱动力。随着这些变现杠杆（即Copilot席位、E5/E7升级、商业定价及基于消费的组件）持续并行扩张，我们预计M365商业云增长将在整个FY27及以后变得更加持久，这得益于一个更加多元化和更具韧性的ARPU扩张框架。

Copilot变现的下一阶段。我们认为，围绕Copilot的关键争论正日益从证明企业采用转向理解长期变现机会。过去一年，微软的主要目标是展示产品市场契合度并推动企业部署。然而如今，讨论正日益转向变现、采用速度及更广泛的商业云机会。重要的是，微软新披露的付费M365 Copilot席位为衡量随时间推移的商业牵引力提供了一个更切实的关键绩效指标。在F3Q26付费席位增至2000万（高于F2Q26的1500万）之后，我们预计付费席位增长仍将是未来企业采用和ARPU扩张的关键指标之一，管理层指引“净新增付费[M365 Copilot]席位将环比增加”，这强化了我们对Copilot变现持续加速进入FY27的预期。虽然席位仅代表更广泛变现机会的一个组成部分，但它们为更高价值的E7采用和随时间推移不断扩大的基于消费的AI变现奠定了基础，这与我们对未来几年付费席位强劲扩张的预期一致。因此，我们继续认为Copilot驱动的ARPU正演变为一个三头增长驱动力，包括：(1) 直接Copilot席位采用，(2) 向更高价值M365 E7订阅迁移，以及 (3) 与代理、编排和工作流自动化相关的基于消费的AI变现不断扩大。结合Copilot、GitHub、Agent365和工作流自动化方面的持续产品创新，我们认为这些变现向量支持M365商业云增长改善，同时使这种增长在长期内日益多元化、由ARPU驱动且持久。

M365涨价代表另一个增量ARPU利好。除了改善Copilot采用，微软商业M365涨价已于2026年7月1日生效，在多个核心SKU上引入更高定价，同时新增AI、安全和端点管理功能。正如我们初步分析（参见《M365涨价——对增长的利好有多大？》）所概述的，我们继续估计这些定价变化将在FY27/FY28/FY29分别贡献约20亿/40亿/60亿美元的增量M365收入，尽管这已计入报价和预期。重要的是，虽然新客户定价于7月1日生效，但现有安装基础要到合同续约时才会实现更高定价，这意味着利好应在大约三年内逐步显现。利用我们自下而上的席位组合假设，我们预计一旦在安装基础中完全反映，ARPU将提升约12美元，转化为FY27/FY28/FY29分别约+4/+8/+12美元的ARPU利好。随着首次涨价已成过去，我们预计这一定价利好将在整个FY27期间开始流入已报告业绩，为M365商业云ARPU扩张提供增量驱动力，同时伴随持续的E5/E7组合转变、Copilot采用及不断扩大的AI消费。

我们的CIO调查持续印证商业云变现的拓宽。我们最新的2Q26 CIO调查持续印证多个增长驱动因素下的商业云变现改善。首先，微软365支出意愿显著改善，65%的CIO预计未来12个月将增加支出，高于我们上次调查的55%。其次，高端SKU采用保持健康，71%的组织预计明年将使用E5或E7，支持传统席位增长之外的持续ARPU扩张。第三，M365 Copilot仍是微软的旗舰AI应用，88%的CIO预计未来12个月将使用该产品，同时计划部署量继续上升。除M365 Copilot外，GitHub Copilot、Azure AI服务、Copilot Studio和Azure AI Foundry的采用预期也有所改善，这强化了我们的观点，即微软的AI变现机会日益超越单一应用，扩展至更广泛的企业AI平台。

## 3) 资本开支轨迹如何——共识资本开支是否需要上调？核心观点：共识资本开支预期可能继续向我们的预测靠拢

资本开支讨论：市场预估仍有上调空间。我们认为，相对于微软长期AI基础设施建设，市场对FY27的资本开支共识预估仍然保守，并可能上调（主要发生在FY27下半年），但与之前几个季度不同，我们目前预计在F4Q26业绩公布后不会大幅修正我们自己的预测（见图表16）。我们的模型已经纳入了比市场共识更为激进的多年研究节奏，这反映了管理层关于持续AI基础设施研究、持续产能扩张（管理层计划在未来两年内将数据中心总规模翻倍）以及更多短期资产组合的最新指引。重要的是，在F3Q26财报电话会议上，CFO Amy Hood表示，微软预计CY26的总资本开支约为1900亿美元，其中包括约250亿美元的更高组件定价，同时重申公司预计尽管有这些研究，到2026年仍将面临产能限制。此外，管理层指出，大约三分之二的资本开支继续分配给短期资产，主要是GPU和CPU，这强化了基础设施研究与未来收入增长之间的直接联系。与此框架一致，我们的预估已经暗示，微软在FY27下半年期间，季度资本开支将从F2Q27约640亿美元的预估水平逐步小幅增加。我们认为，更可能的结果是市场预估向我们的预测靠拢，而不是我们自己的预测在F4Q26业绩公布后大幅上调。

我们最新的资本开支隐含AI收入分析：我们的资本开支假设一直在上调。因此，我们依赖资本开支驱动的预测模型，得出关于Azure增长轨迹持续看涨的结论，这继续表明我们未来的Azure预测存在显著上行空间，尽管我们最近在深入研究中已经上调了Azure收入预估。我们的资本开支模型根据专门用于AI相关项目的资本支出来衡量Azure AI的隐含贡献。我们比较了资本开支隐含的Azure AI预测（假设不同的毛利率水平）与我们模型中的Azure AI预估。正如最近财报电话会议以及我们最近的园区访问中所强调的，资本开支（以及相应的基础设施）并不仅仅分配给新的Azure需求。微软还必须支持其第一方应用程序、内部研发工作、内部培训以及一个替代性资本开支周期。管理层一段时间以来也一直强调，很大一部分资本开支用于土地和建筑等长期资产，这些资产可能产生超过15年的收入。总之，在我们最新的分析中，Azure AI（不包括收入分成）的毛利率可能已经超过20%。根据我们的资本开支隐含框架，我们仍然看到当前Azure预估存在显著上行空间，这强化了我们的观点，即微软长期AI货币化机会仍被低估。
