# 高盛：泰国越南科技考察，PCB、网络及AI服务器供应链六大要点

我们于7月7日至10日组织了一场泰国/越南考察，走访了大中华区科技板块AI服务器及网络供应链中的10家公司：(1) PCB：臻鼎 / 鹏鼎 (002938.SZ,未覆盖)、胜宏 、沪电 、中京 (001389.SZ,未覆盖)、东山 (603175.SS,未覆盖,董事长参访),(2) 钻头：鼎泰 (301377.SZ,未覆盖),(3) 光模块、FAU,(4) ODM：工业富联。我们在本报告中总结了关键要点。延伸阅读：Make in Vietnam;Vietnam Tech Tour takeaways (2019);Make in India;India Tech Tour takeaways (2023);Thailand Tech Tour takeaways (2025)。

1. 产能扩张：我们在泰国/越南走访的公司均处于产能扩张阶段，无论其在当地运营时间长短，扩张主要面向AI基础设施，涵盖AI服务器、CPO交换机、AI服务器/光模块用PCB、光模块、光引擎、边缘AI设备等。产能扩张反映了持续的强劲AI需求、东南亚新兴AI供应链/生态系统的形成，以及客户对生产基地多元化的要求，尽管自2025年底以来紧迫性有所降低。产能扩张印证了我们对AI资本支出上升周期的积极看法，其驱动力来自AI服务器机架数量增加、规格升级消耗更多产能（例如层数更高的AI PCB需要更长的压合和钻孔时间），以及AI数据中心内支持AI工作负载所需的更多IT机架（如LPU机架、CPU机架、网络机架、存储机架、电源机架、冷却机架等）。

2. 东南亚的AI集群：产能多元化由地缘政治紧张局势驱动，而中国大陆凭借其完善的供应链和强大的生产效率，仍是制造中心。靠近客户或供应链通常是公司选择特定国家进行产能多元化的关键原因：(1) 越南：微软、戴尔、苹果供应链，如鸿海/工业富联、瑞声、纬创、AVC等；(2) 泰国：谷歌、惠普供应链，如广达、英业达、Celestica、Auras等；(3) 马来西亚：亚马逊供应链，如纬颖、勤诚等。越南靠近中国大陆供应链，从广西的中越边境驾车至越南北部主要生产基地（如北江或北宁）仅需2-3小时，这意味着物流灵活性相对较好，例如公司无需等待航班或货运。泰国是东南亚最大的汽车制造中心，拥有相对完善的PCB供应链，吸引了PCB供应商。

3. 泰国/越南的产品：东南亚的生产基地通常扮演满足全球级客户多元化需求的角色，因此自然用于已量产的产品；然而，这些产品也是高附加值且面向AI数据中心的，反映了在泰国/越南生产AI产品的能力，尽管效率低于中国大陆。在当地运营时间较短的公司仍可在中国大陆生产最新产品，以确保产品质量、制造速度和专有信息保护。

4. 劳动力与招聘：我们走访的公司表示，泰国/越南的劳动力成本普遍低于中国大陆；然而，生产效率也较低。例如，中国大陆一名工人的生产力可能相当于泰国最多三名工人。我们观察到，越南的厂区拥有规模可观的宿舍（例如可容纳多达2万名工人），而泰国的大多数厂区尚未设立宿舍，但提供交通（如巴士）接送工人。与泰国相比，越南的普通话使用者更多，减少了培训中可能遇到的困难。在越南和泰国，本地工人是厂区工人的主要组成部分（占50%或以上），招聘并不困难，尤其是在泰国，因为经常雇佣来自缅甸的人员。离职率也在可控范围内。我们走访的公司提到，与当地公司相比，它们提供更好的薪酬、良好的工作环境（例如工厂内有空调）或为本地工人提供晋升管理团队的机会。

5. 生产成本：我们走访的公司强调，由于靠近供应链且经验丰富，中国大陆仍然是最高效的制造地。泰国/越南的劳动力成本低于中国大陆；然而，生产效率也较低。除此之外，如果原材料（如CCL）需要从中国大陆运输，关税和运输成本可能会使成本增加15-20%。尽管如此，公司也提到客户愿意支付比中国大陆高出最多20%的成本，并且公司正在采用更多自动化生产以减少对工人的依赖，并探索进一步提高生产力的潜力。生成式AI、AR眼镜和数字化也在工厂中得到应用，支持培训和生产线复制，这在海外扩张产能时尤其有帮助。

6. AI研究持续：我们在泰国/越南走访的ODM对AI资本支出上升周期仍持乐观态度，依据是客户对产能的需求并愿意预付或补贴设备以确保产能、AI基础设施和边缘AI设备的客户群不断扩大，以及AI应用和代币消耗的增长。我们走访的公司提到，全球领先CSP的AI资本支出依然强劲，同时来自模型开发商/NeoCloud的需求也在增长，并可能进一步扩展到政府（主权AI）和企业，为AI基础设施需求提供长期可持续性。公司还看到全球领先的品牌客户正在开发创新的边缘AI设备，打造物理AI个人助理，这也可能推动AI需求。这种积极基调印证了我们对AI服务器的积极看法，我们已将2026-28年全球AI服务器隐含AI芯片出货量预测上调14%/22%/14%，美国CSP资本支出在2026E-28E上调8%/27%/25%，中国CSP资本支出在2026E-28E上调37%/44%/55%（全球服务器TAM六月更新）。
