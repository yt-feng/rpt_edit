# 全球半导体——若存储板块失效，半导体设备能否独善其身？

在当前波动的市场中，许多读者认同我们看多半导体设备的观点，但担心它们无论如何都与存储报价相关。本报告回顾了报价历史，并破除这一迷思。

半导体设备与存储报价可以走出不同方向。有几个值得注意的时期：2015年1月至2016年12月，WFE上涨21.9%，而存储下跌16.2%，两年间超额收益达38.2%；2021年1月至2022年12月，WFE上涨15.3%，而存储下跌34%，两年间超额收益达49%。虽然我们当前对WFE和存储均持正面看法，但读者仍可通过在WFE与存储之间进行分散配置而获益，而非担忧两者必然同涨同跌。考虑到增加存储产能需要WFE增长，而这正是存储价格波动的根源，这一点尤其重要。

从基本面看，我们长期看好WFE。存储资本开支明显加速；SK海力士近期宣布对其新的清州工厂追加研究100万亿韩元（约670亿美元），韩国政府似乎也在考虑采取措施支持三星和SK海力士在韩国西南部建设工厂的举措。我们看到市场对WFE市场及公司2028年前每股收益的共识预期存在上调潜力，并预计未来将进一步增长。

对于存储，尽管我们认为长期协议（LTA）帮助有限（参见我们近期网络研讨会的回放），但供应短缺及即将到来的HBM涨价仍将带来显著的盈利上调。我们仍看好三星、SK海力士及美光，尤其是在近期回调之后（报告）。我们对KIOXIA给予"弱于大盘"评级，理由是估值及来自中国的长期威胁（报告）。

## 详情：公司情况更新

近期报价波动较大，尤其是存储股。读者当前的一个重大问题是：如果存储股停止上涨，半导体设备是否还能继续表现？为此，我们进行了历史分析，结论是：尽管存储与半导体设备之间的整体相关性较强，但存在多个半导体设备在存储股表现平淡时仍持续上涨的实例。

这些相关性较弱/较强的时期（图表4）表明，日度相关性不应被解读为累计回报的离散程度。历史上，存储-WFE低相关性并不总是导致较大的回报差异，同样，存储-WFE高相关性也不一定导致相似的回报。特别是，案例#4和#5显示，即使在强相关时期，WFE也能显著跑赢存储；而案例#3显示，弱日度相关性最终仍可能产生几乎相同的累计回报。这表明，板块相关性捕捉了共同的半导体因子敞口，但相对回报仍主要由子板块特定驱动因素决定。

我们认为这一区别很重要，因为历史数据显示，存储和WFE可以共享广泛的半导体贝塔，同时仍能产生显著不同的回报结果。因此，相关的研究问题不仅仅是存储和WFE是否相关，而是当前的波动是存储特有的，还是范围足够广泛以至于也会损害WFE的基本面。

图表4：弱相关或强相关并不能可靠地预测存储-WFE的回报差距。回报离散程度更多地取决于子板块驱动因素，而非相关性本身。

既然我们已经确定半导体设备在历史上无论相关性弱或强都能跑赢存储，我们将超越统计观察，讨论每个时期现实世界中实际发生的情况，剖析不同的半导体周期。

周期-体制表（图表5）旨在回答这一问题。下文的体制划分并非采用纯统计且略显人为的滚动相关系数断点，而是围绕可识别的半导体供需背景进行分组，例如存储上行/节奏变化周期、新冠疫情/芯片短缺、HBM和AI资本开支。

体制分析得出了与滚动相关系数阶段相同的结论：存储与WFE存在关联，但可能完全反向运行。此外，在不同周期中，强相关性也未能阻止巨大的累计回报差距。2015-16年，存储下跌而WFE上涨；2019-20年，尽管存储-WFE相关性很高，WFE仍大幅跑赢；2021-22年，WFE再次在短缺/资本开支周期及随后的利率修正中跑赢。

诚然，如果我们仅看回报的幅度，当前周期确实与以往周期/体制截然不同。存储实现了近十倍的回报，而WFE仅为可怜的220%，由此产生了巨大的存储-WFE离散度——这是该体制表中迄今为止最大的差距，在长期相对表现不佳后，于2026年2月超越了半导体设备（图表6）。尽管这造成了比样本中任何先前体制都大得多的存储-WFE离散度。事实上，存储相对于WFE的溢价近期已飙升至历史未见水平，目前高于历史均值+2个标准差（图表7），这反映了存储公司因AI服务器内存含量增加和供应紧张共同导致的HBM/传统DRAM稀缺而拥有的定价权。

这并不意味着如果存储价格正常化，WFE就应跟随存储走低。相反，历史框架表明，只要WFE基本面仍受AI资本开支、前沿代工/逻辑研究、先进封装和技术转型需求支撑，极端存储溢价的消退可以与WFE持续走强并存。换言之，相关的问题不在于存储与WFE是否相关；问题在于当前的存储波动是否足够广泛以致损害WFE需求，抑或这主要是一次存储自身从异常拉伸的周期中回归正常化。
