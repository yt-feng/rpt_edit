# 摩根大通：服务器CPU出货量模型

在本报告中，我们介绍了一种JPM专有的服务器CPU出货量模型，并预测服务器CPU总出货量将从2025年的2600万颗增长至2028年的6800万颗（年复合增长率38%）。我们将服务器CPU需求分为三类：(1) AI头节点CPU，(2) 代理型AI服务器CPU，以及(3) 通用服务器CPU。根据半导体团队基于CoWoS的估算（链接），AI加速器出货量在2025-2028财年预计将呈现约50%的年复合增长率，我们认为AI头节点CPU需求将出现阶梯式增长，且CPU与加速器的配比趋势正在上升。虽然通用服务器CPU应会继续保持约5%的稳定年复合增长率，但代理型AI CPU是突破性增长向量，预计2025-2028年年复合增长率达155%。总体而言，我们认为未来几年整体通用服务器出货量可维持20%以上的增长。这一超级周期对台积电、欣兴电子、信骅科技、嘉泽端子、纬颖科技、健鼎科技、创意电子、日月光投控以及SK海力士和三星电子等亚洲科技领域的存储厂商有利。

- AI需求重塑服务器CPU格局。我们预测AI加速器出货量将从2024年的760万颗增至2028年的3250万颗，且由于AI加速器日益复杂，头节点CPU配比不断提高。加速器与CPU的比率也在压缩——从传统HGX服务器的约4:1降至NVL72计算托盘中的约2:1，下一代TPU设计可能达到约1:1。在英伟达Vera和谷歌Axion的推动下，基于ARM的CPU正在抢占份额，我们估计到2028年ARM可能占AI头节点CPU需求的约90%。我们还预计ARM将在代理型AI服务器中扩大份额，因为超大规模云厂商正倾向于为新兴工作负载采用内部CPU路线图。因此，我们测算到2028年基于ARM的CPU将占混合服务器CPU市场的约43%（高于2025年的约22%）。尽管如此，我们仍预计x86 CPU市场在此期间将实现加速的25%年复合增长率（而上一周期为持平至低个位数增长）。

- 新型AI推理编排驱动代理型AI服务器需求。随着AI工作负载从训练转向推理，我们预计超大规模云厂商将在加速器周围部署更多通用服务器以改善总拥有成本。增量需求主要出现在外部存储服务器（例如KV缓存）和处理GPU周围查询编排的计算服务器中。虽然没有固定的加速器与CPU服务器比率，但我们的粗略分析表明今年约为0.5倍（每两个加速器配一个CPU），且随着加速器复杂性增加，该比率将随时间上升。这将成为通用服务器需求的关键增量驱动因素（到2028年占通用服务器CPU市场的50%以上，而去年不到10%）。

- 受益于服务器CPU超级上升周期的公司。服务器CPU、BMC、基板和插座需求之间存在高度相关性。我们预计信骅科技、嘉泽端子和欣兴电子将成为这一服务器CPU超级周期的主要受益者，驱动因素包括强劲的单位需求、持续的内容升级以及潜在的产品涨价。AMD在x86服务器CPU中的持续份额增长也有利于台积电和日月光投控作为主要晶圆代工/封测供应商。DRAM厂商可能受益于DIMM/SOCAMM需求的增长。在下游，我们认为服务器PCB制造商（如健鼎科技）和通用服务器ODM（如纬颖科技、英业达）也可能受益于强劲的服务器需求。

# AI推理周期加速服务器CPU增长周期

我们推出专有的服务器CPU需求模型。我们将CPU需求分为三类——(1) AI服务器头节点CPU、(2) 常规服务器CPU和(3) 代理型AI CPU——并预测服务器CPU总出货量将从2025年的2600万颗增长至2028年的6800万颗（年复合增长率38%）。随着AI应用从训练转向推理，我们预计代理型AI和AI头节点CPU需求将驱动一个"超级"通用服务器CPU周期。

## 自上而下方法论

我们以Gartner数据为基础确定了2024年服务器CPU总出货量，并预测了未来几年各细分板块的服务器CPU需求。我们基于JPM半导体团队（由Gokul Hariharan牵头）的AI加速器预测（链接）以及每个服务器节点中AI加速器与头节点CPU的比率来预测AI服务器头节点CPU需求。我们假设2024年没有代理型AI活动，并据此推导出2024年隐含的常规服务器CPU需求。

对于2025年和2026年，我们假设非AI服务器头节点CPU出货量（常规服务器加代理型AI CPU）同比增长11%/30%，从2024年的2000万颗增至2300万颗/2900万颗。再加上300万颗/700万颗的AI服务器头节点需求，2025/2026年服务器CPU总出货量可能达到2600万颗/3600万颗（同比增长16%/42%）。

## 强劲加速器需求 + 上升的CPU配比 = AI服务器头节点CPU指数级增长

我们看到AI服务器头节点CPU的配比正在上升。每台AI服务器中每个CPU对应的AI加速器数量从4:1降至2:1，未来几代甚至降至1:1，尤其是在AI ASIC服务器中。我们将此归因于AI服务器架构日益复杂，导致对AI服务器中CPU编排的需求增加。值得注意的是，AI加速器预测基于JPM半导体团队（由Gokul Hariharan牵头）的CoWoS估算（链接）。

\- Nvidia GPU服务器：NVL72计算托盘中的加速器与CPU比率从HGX服务器的4:1降至2:1。我们还在NVL72服务器机架的NVLink交换托盘中看到了CPU需求。有趣的是，我们观察到未来几代HGX服务器中加速器与CPU的比率有所上升（从4:1升至8:1），这可能是由于HGX服务器架构对CPU的需求相对较低。

\- AMD GPU服务器：我们的研究显示，MI300系列和AMD MI455 Helio服务器的GPU与CPU比率为4:1。

\- Google TPU服务器：我们的研究表明，TPU v8服务器有两种设计，TPU与CPU比率分别为1:1和2:1，未来几代可能采用1:1比率。我们假设TPU v8代中1:1和2:1设计的比例为50%/50%。

\- AWS Trainium服务器：我们的研究显示，T3液冷项目的Trainium与CPU比率将从T2和风冷T3项目的16:1降至4:1。

\- MSFT/Meta/其他AI ASIC服务器：我们假设其余AI ASIC服务器的加速器与CPU比率为4:1。

## Arm架构CPU的更快普及，得益于Arm架构CPU搭载率的上升
