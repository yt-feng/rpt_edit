# 全球半导体：CPU复兴？2230亿美元市场规模的受益者...

从生成式AI范式1.0（聊天机器人）向2.0（智能体）的转变，大幅提升了服务器CPU需求。正如我们在软银、Arm报告中所述：从生成式AI到智能体AI；以跑赢评级首次覆盖，智能体AI涉及高度自主的任务编排与执行，相比GPU，这增加了CPU的工作负载。随着从聊天机器人向智能体AI的转变，AI数据中心的CPU:GPU比率正从1:4或1:8飙升至1:1或更高。

我们将服务器CPU市场规模上调至2230亿美元（基准情形下2030年为1370亿美元，是2025年370亿美元市场规模的6倍）。这一预测基于3.5万亿美元的AI数据中心资本支出，以及推理环节1:1的CPU:GPU配对比例。另一种采用每吉瓦1.2亿个CPU核心的方法得出类似的市场规模。我们此前1370亿美元的预测现已成为熊市情形（假设3万亿美元AI资本支出，1:2的CPU:GPU比例），而乐观情形下市场规模则达到3300亿美元（4万亿美元AI资本支出，1.5:1的CPU:GPU比例）。

将Arm目标价上调至500美元，因为Arm是智能体AI时代CPU复兴的结构性受益者。Arm架构凭借其无与伦比的能效，非常适合智能体AI工作负载。此外，Arm正从单纯的IP提供商转型为CPU制造商，目标是在2030财年实现150亿美元营收，但鉴于我们将2030年CPU市场规模从1370亿美元修正为2230亿美元，我们目前预测其营收为220亿美元。Arm 2030年每股收益（2029财年截止）现上调至11.79美元（此前为9.83美元）。基于42倍市盈率（此前为40倍），我们将Arm目标价上调至500美元（上涨空间21%）。鉴于Arm目标价上调，我们也将软银目标价上调至11,200日元（上涨空间58%），基于对5720亿美元备考资产净值30%的折让。

更新数据，上调AMD和英特尔目标价。两家公司都应受益于更强劲（且更持久）的服务器需求，尽管AMD的产品目前仍更胜一筹（且我们认为其将继续保持份额增长势头）。我们现有的AMD模型已与更强的服务器CPU环境一致，预估变动不大，但我们现在将英特尔模型调整至与这些假设一致，并更大幅度地上调了预估；鉴于今年已过半，我们还将两家公司的估值窗口期向前滚动至2027/2028财年均值（此前为2027财年）。AMD目标价上调至600美元；英特尔目标价上调至100美元。我们给予AMD跑赢评级，英特尔同步大市评级。

海光将受益于强劲的x86 CPU需求，并在中国扩大份额。我们预计，随着中国先进节点供应限制的缓解以及AI投资加速释放CPU潜力，中国将从2028年起超越全球x86增长。我们预计海光将稳步扩大其在中国x86服务器CPU市场的份额，到2030年超过35%，因其在提升与国产AI芯片互操作性的同时，全球供应商供应可能受限，从而使其能够渗透到云服务提供商领域，超越其传统的政府和国有企业客户群。我们更新了海光的预测以反映这一点，将2027/2028年每股收益上调至3.6/6.3元人民币，目标价上调至450元人民币。

潜在风险是什么？我们仍在评估代工厂/内存产能是否足以支持CPU增长。此外，GPU/加速器的价值目前包含了HBM的价值以及英伟达等公司的加价，但包括HBM在内的高内存成本可能会促使超大规模企业直接从内存供应商处采购。我们的预测基于CPU/加速器价值，如果发生这种情况，将面临下行风险。

## 智能体AI范式下CPU的复兴

自大语言模型兴起以来，GPU/ASIC加速器一直是AI计算的核心。虽然训练集群曾需要密集的4:1比率来处理繁重的数据加载，但焦点已转向消除困扰大规模推理的"CPU税"。在定制推理优化部署中，如谷歌的TPU v6e和Meta的Grand Teton，GPU与CPU插槽的比率已升至8:1。

智能体AI正将CPU推回中心舞台（图表2），因为AI系统不再仅仅是运行一次模型并返回答案。GPU仍执行密集的数学运算，但CPU越来越决定整个系统能否高效编排周边工作流——提供数据、调度任务、协调工具调用、管理内存以及避免加速器闲置。

这就是为什么下一代AI基础设施可能会在硬件配对方面看到更多平衡，意味着在智能体时代，CPU不再是一个附着于大量加速器的小型支持组件。我们预计GPU与CPU的比率可能从非常偏向GPU的4:1或8:1配置，重新收窄至1:1。2026年的硬件路线图已朝这个方向发展：

• AMD Venice：每个计算托盘1个CPU对应4个MI455X GPU。
• NVIDIA Vera：每个超级芯片1个CPU对应2个Rubin GPU（4个GPU芯片）。
• 谷歌TPU7x：每个扩展单元1个CPU对应4个TPU芯片。

GPU/CPU配对在智能体工作负载中尤为重要，因为推理正变成一个循环而非单次通过。一个请求可能触发检索、规划、工具使用、中间推理、另一次模型调用，然后执行，这意味着GPU负责繁重计算，而CPU则保持工作流高效运转；如果CPU性能较弱，昂贵的GPU可能会闲置，整个系统将变得更慢且效率更低。

Agentic AI 也增加了对网络和分布式基础设施的压力，这进一步强化了 CPU 的角色（图表 3，图表 4）。随着工作负载在服务器、集群和地点之间扩展，系统必须实时移动状态、管理流量并协调资源，因此 CPU 不仅在服务器内部变得至关重要，在支持自主 AI 执行的更广泛数据中心架构中也变得至关重要。

Arm CPU 在这种环境中脱颖而出，因为新的瓶颈不仅是峰值性能，还有在功耗和空间限制下的高效编排。随着运营商需要更多 CPU 容量来支持不断增长的 AI 代理数量，Arm 围绕每瓦性能、高核心密度和可扩展数据中心计算的主张变得更具吸引力，这就是为什么 agentic AI 正在帮助 CPU 重回焦点，并让 Arm 在 AI 基础设施的下一阶段扮演更重要的战略角色。

## 将 2030 年服务器 CPU TAM 预测上调至 2230 亿美元

在我们对 Arm 的首次覆盖报告中，我们预测 2030 年数据中心 CPU TAM 为 1370 亿美元，远高于 Arm 自身估计的 1000 亿美元和 AMD 的 1200 亿美元，依据是 agentic 工作负载需要更高的 CPU 强度。

自我们首次覆盖以来，出现了一些增量进展，包括 agentic AI 的采用好于预期，以及 AI GW 和资本支出高于预期。Nvidia 还指引 Vera CPU 将带来 200 亿美元收入，这对 Arm 也应是利好。另一个值得注意的数据点是 Nvidia 提供的年度 AI 基础设施支出预测，即到 2027 年超过 1 万亿美元，到本十年末达到 3-4 万亿美元。

基于这些数据点，我们修正了对服务器 CPU TAM 的自上而下估计，上调至 2230 亿美元（图表 7），假设如下：

- 2030 年 AI 资本支出为 3.5 万亿美元，意味着 70 GW 的 AI 数据中心部署，每 GW 成本 500 亿美元
- AI GPU（包括 ASIC 加速器）市场规模为 1.6 万亿美元，占 AI 数据中心资本支出的 45%
- 推理的 CPU:GPU 单位比率为 1:1，训练为 0.5:1，CPU ASP 为 GPU 的 13%
- 这导致服务器 CPU TAM 为 2230 亿美元，包括 1740 亿美元的 agentic AI 工作负载和 490 亿美元的非 AI 工作负载

我们还基于 CPU 核心数的替代方法进行了合理性检查：

- 根据 Arm 的说法，agentic AI 工作负载每 GW 需要 1.2 亿个 CPU 核心，而传统数据中心每 GW 仅需 3000 万个核心
- 这意味着到 2030 年，70 GW 的 AI 数据中心部署需要 84 亿个服务器 CPU 核心
- 假设每核心 20 美元（可能保守），2030 年 AI CPU TAM 将为 1680 亿美元，与上述计算的 1740 亿美元相似

我们的敏感性分析表明，即使对这一数字采取相当保守的看法，也意味着可观的 agentic CPU 机会。

- 在熊市情景下，主要假设是 3 万亿美元的 AI 资本支出，加上推理的 CPU 与 GPU 比率为 0.5 倍。那么服务器 CPU TAM 将为 1370 亿美元，与我们之前的预测相符，后者现在看来有些保守。
- 在牛市情景下，我们假设 4 万亿美元的 AI 资本支出，加上推理的 CPU 与 GPU 比率为 1.5 倍。由此产生的服务器 CPU TAM 将为 3300 亿美元。

## 为什么 Arm 能在服务器 CPU 中从 x86 手中夺取份额？

核心经济理由是每瓦性能和总拥有成本。AWS 表示，与同类 x86 实例相比，Graviton 在某些用例的同等工作负载下可提供高达 40% 的性价比提升、高达 20% 的成本降低以及高达 60% 的能耗降低。Microsoft Azure 指出，Cobalt 100 上的每个 vCPU 都映射到一个完整的物理核心，这使得服务器工作负载的性能比使用超线程来增加 vCPU 数量的 x86 设计更可预测。

除了经济性，超大规模企业还获得了架构控制权。设计内部 CPU 使他们能够塑造内存子系统、I/O、加速器互连和安全卸载，以适应自己的基础设施，而不是依赖商业硅供应商的路线图。这就是为什么每个主要 CSP 现在都致力于基于 Arm Neoverse 核心的多代内部 CPU 计划。

最重要的是，功耗是 Arm CPU 更有可能在 AI 数据中心被采用的最大原因之一。世界正面临能源问题，没有足够的电力来支持新的数据中心。根据我们的预测，AI 加速器功耗到 2028 年将几乎翻三倍，达到 37 GW。包括 CPU、内存、网络等的功耗，AI 数据中心的总功耗将超过 50 GW。由于我们无法在减少 GPU/AI 加速器功耗方面做太多工作，使用 Arm 服务器来降低功耗成为唯一可行的选择。

## Nvidia 为何使用 Arm CPU

Nvidia 采用 Arm 的动机与超大规模云厂商不同：在 AI 和 HPC 系统中，关键瓶颈更多在于 CPU、内存池和 GPU 之间的数据传输——而非原始 CPU 指令吞吐量或企业应用兼容性。Nvidia 表示，其 Grace CPU（每芯片 72 个 Neoverse V2 核心，Grace CPU Superchip 通过双芯片 NVLink-C2C 实现 144 个核心，提供高达 1.0 TB/s 的 LPDDR5X 内存带宽）受益于 NVLink-C2C 互连，该互连在 CPU 和 Blackwell GPU 之间提供高达 900 GB/s 的双向带宽——而 PCIe Gen 5 约为 128 GB/s。GB200 机架中使用的第二代 NVLink-C2C 实现了 1.8 TB/s 的双向带宽，比 PCIe Gen 6 快 7 倍。（NVIDIA Grace CPU 提供世界级数据中心性能和突破性能效 | NVIDIA 技术博客，NVIDIA Grace CPU 与 Arm 架构 | NVIDIA）

Grace 于 2023 年首次部署在用于 HPC/AI 集群的 GH200 Grace-Hopper Superchip 中。重大转折点出现在 2025 年，当时 Nvidia 标准化了 DGX GB200 机架形态——每个 Superchip 捆绑一个 Grace CPU 和两个 Blackwell GPU，每个 DGX GB200 机架包含 36 个 Grace CPU 和 72 个 Blackwell GPU，总计每机架 2,592 个 Arm Neoverse V2 核心。这种从独立 HGX/MGX GPU 托盘格式向集成 DGX 机架级部署的转变，显著增加了 AI 服务器出货量中的 Arm CPU 单位数量。

Nvidia Vera CPU（Grace 的继任者，将于 2026 年与 Rubin GPU 一同推出）进一步提高了标准：Vera 提供高达 1.2 TB/s 的内存带宽——带宽是传统 x86 CPU 的两倍，功耗仅为一半——并基于 Nvidia 专有的 Olympus CPU 核心构建，这是一种为强化学习和智能体 AI 工作负载设计的定制 Arm 架构。Vera 使软件环境运行速度提升高达 50%，效率是传统 CPU 基础设施的两倍。（下一代数据中心 CPU | Nvidia Vera CPU）

## ARM AGI CPU：商业模式巨变以把握增长机遇

在 2026 年 3 月的 Arm Everywhere 活动上，Arm 宣布了一项重要战略举措，即在数十年主要通过 IP 许可和版税变现之后，提供自己的芯片——Arm AGI CPU，并明确表示该芯片产品将补充——而非取代——其现有的 IP 和 CSS 业务。

其理由是，并非每个客户都能自行设计 CPU，因此像 Meta（Arm 将其确定为第一个客户、主要合作伙伴和共同开发者）和 OpenAI 这样的公司可以直接购买 Arm 的 CPU，而其他 CSP（如 Amazon、Google 和 Microsoft）则可以继续为他们的 CPU 项目许可 Arm IP。除了 Meta 和 OpenAI，他们还确认了许多其他合作伙伴，包括 Cerebras、Cloudflare、F5、Positron、Rebellions、SAP 和 SK Telecom。这些客户预计将部署 Arm AGI CPU 用于智能体应用。Arm 与 OEM 和 ODM，以及云、内存、网络、制造等领域的其他供应链合作伙伴合作，例如 AWS、Broadcom、Google、Marvell、Micron、Nvidia、Samsung、SK hynix 和 TSMC 等。

从财务角度看，这种模式变化在百分比上显然会稀释利润率，但很可能在毛利润和营业利润上具有增值效应。管理层在活动上的目标是，到 FY31 年，AGI CPU 业务收入达到 150 亿美元，公司总收入达到 250 亿美元，非 GAAP 每股收益达到 9 美元，AGI CPU 营业利润率预计在 FY31 年超过 30%。我们认为，关键在于 Arm 选择用部分利润率来换取一个显著更大的利润池。同样重要的是，管理层表示所需的工程投资已基本嵌入当前的成本基础，这意味着近期的损益表已经承担了大部分研发负担，而来自芯片的收入机会要到更晚才会出现，一旦规模扩大，将带来运营杠杆。

我们的估计基于更激进的假设，我们预测 FY31 年芯片价值为 220 亿美元（图表 14），这大致相当于基于 FY31 年 4,600 美元平均售价的约 490 万个 CPU 单位。在我们的预测中，我们相信 Arm 芯片在 FY31 年应能产生 77 亿美元的营业利润（或占公司营业利润的 52%）（图表 15）。

## ARM在服务器CPU中的版税

## Arm服务器CPU版税增长由核心数量增加和版税率提升驱动

即使在AGI CPU贡献之前，Arm的云端CPU版税模式已经变得更具吸引力。Arm在其2026财年第三季度财报中表示，云端AI/通用数据中心版税收入同比增长超过100%，Neoverse部署量超过10亿核心，且Arm在顶级超大规模云厂商中的份额预计将接近50%。

第一个驱动因素是核心数量正在快速增加（图表20）。AWS Graviton 5现在拥有192个核心，是Graviton 4的两倍；NVIDIA Vera拥有88个基于Arm的核心，而Grace为72个；微软的Cobalt 200拥有132个核心。在Arm Everywhere活动上，管理层表示，下一波云端CPU可能会进入200-300核心范围，并且随着时间的推移，某些情况下可能达到500核心。

我们认为其根本原因与驱动AGI CPU机遇的原因相同：工作负载组合正在发生变化。智能体和始终在线的推理将更多瓶颈转移到编排、内存处理和协调工作上，这反过来增加了AI集群中对更高核心数、高能效CPU的需求。Arm自身也表示，向基于智能体的推理转变正在重新定义AI数据中心设计，并提升对具有更高能效核心的CPU芯片的需求。

图表20：服务器端CPU的核心数量正在增加。

第二个驱动因素是每核心版税更高。目前，Arm的被授权方为第一代v9服务器CPU支付约0.50美元/核心，为第一代CSS（计算子系统）支付约1美元/核心，后续CSS代际可能支付1.50美元/核心，未来代际还有更多上涨空间。换句话说，Arm不仅从更多核心上获得报酬，而且从更有价值的核心上获得报酬，而CSS是实现这一跃升的核心。

Arm将CSS描述为预集成、预验证、性能验证的子系统产品，帮助合作伙伴更快地生产出量产芯片。换言之，CSS位于核心层之上：它将CPU核心与一致性互连、MMU/NOC系统IP、内存通道和I/O封装在一起，这样芯片公司就不必从头组装整个服务器平台。

该公司表示，采用CSS是版税增长的主要推动力，客户可以节省大量工程工作，并将上市时间缩短多达约一年。Arm还表示，CSS客户报告称，从项目启动到获得可工作芯片仅需13个月，并通过外包非差异化设计和验证工作节省了80个工程年。这种更高的价值主张使得Arm能够收取比单独核心IP高得多的版税。

CSS包含的不仅仅是Neoverse核心，它还将核心与CMN网格、系统IP、系统管理、电源管理、软件以及快速将平台推向市场所需的开发工具捆绑在一起。Arm将其定位为云端、AI、5G和网络芯片最快实现量产芯片的途径，因为合作伙伴可以专注于定制化，而无需围绕核心重建通用基础设施。

产品更新的节奏也很重要。管理层的说明表明，服务器CPU过去每两到三年更新一次，但现在越来越多地转向年度更新节奏，这实际上使CSS变得更有价值，因为客户需要更快的周转时间来跟上最新的节点和架构。这种动态应该会支持更频繁的授权活动，并加速向更高版税代际的混合转变。

具体到云端，这种转变的早期证据已经可见。微软的Cobalt系列明确基于Neoverse CSS构建。公司还提到，到2027财年，CSS应占云端AI版税的10%以上，到2029财年升至30%以上，到2031财年超过50%。如果这一进展大致正确，那么未来几年版税组合应会持续向更高价值的服务器设计倾斜。

总之，我们看好Arm服务器版税收入的强劲增长（图表22），从2025财年的约1.35亿美元增至2031财年的18亿美元，这得益于核心数量的增加以及每核心版税率的提高，即使在Arm自身的AGI CPU芯片收入尚未计入任何贡献的情况下，这也构成了结构性的服务器CPU版税增长。

## 可能的风险是什么？

我们上述预测未考虑产能因素，但台积电和英特尔（以及较小程度上的三星）的产能可能不足以支撑预测的增长。台积电的产能尤为关键，因为凭借其领先的技术、效率和执行力，大多数供应商将其视为首选。与此同时，几乎所有GPU/加速器供应商也都在使用台积电生产，并且同样认为台积电的产能无法满足其需求。台积电及其客户需要共同在这些需求之间取得平衡，因为AI的发展既需要CPU也需要GPU/加速器的增长。

内存容量可能成为另一个瓶颈。CPU需要搭配足够的内存才能发挥功能，GPU/加速器也是如此。因此，内存容量可能成为另一个瓶颈，导致我们上述预测过于乐观。

我们目前正试图回答这两个问题，并将向投资者更新任何重要发现。

另一个重要但较少被考虑的因素是，HBM与GPU/加速器封装在一起。因此，HBM的成本是这些芯片销售成本的一部分。该成本随后会被英伟达等公司“加价”，使得这些GPU/加速器供应商能够对整个封装芯片维持高利润率，毛利率通常高达60%至70%。对于AI超大规模云厂商而言，此前这种“加价”带来的负担较小，但随着内存价格飙升传导至HBM，这一负担正迅速加重。因此，超大规模云厂商将尝试直接从内存供应商采购HBM，以避免这种“加价”。世芯电子和联发科目前正在其ASIC业务中提供这种商业模式。它们进行必要的认证和测试，以确保超大规模云厂商采购的HBM与ASIC芯片的其他部分兼容，并已证明这种商业模式在技术上是可行的。如果超大规模云厂商广泛采用这种模式，HBM的价值将被剥离，GPU/加速器的规模将变小。由于我们上述对CPU的预测以GPU/加速器市场规模为锚点，超大规模云厂商直接采购HBM的商业模式对我们预测构成下行风险。

## 中国X86服务器CPU市场动态

## 中国TAM vs 全球TAM

中国在全球x86服务器CPU TAM中的份额正进入一个短期压缩期，随后将在中期内实现结构性复苏。2020-2024年间，该份额历史上稳定在约30%，我们预计到2026-2027年，中国份额将下降至约21-23%的谷底，如图表35所示。我们将此短期压缩主要归因于中国AI服务器建设的结构性制约。受全球领先GPU出口管制以及国内替代品因代工厂产能限制而供应短缺的影响，AI芯片获取受限，减缓了中国AI基础设施的部署速度。此外，中国云服务提供商的资本支出扩张相对更为温和，而美国超大规模云厂商正在积极投资AI基础设施，特别是为代理型AI工作负载快速部署服务器。这一动态因全球CPU供应商优先将供应分配给大型美国CSP和AI实验室而进一步放大，这些市场需求可见性和变现路径更强，从而提升了AMD和英特尔在这些市场的CPU搭载率。因此，在该周期的早期阶段，中国TAM增长落后于世界其他地区（2025-2028年中国复合年增长率+30.6%，世界其他地区+34.8%），导致需求份额暂时下降。然而，我们预计这一动态将在后期逆转：随着国内AI芯片供应改善和AI投资加速，中国TAM增长将重新加速（2028-2030年复合年增长率+36.3%，世界其他地区+26.6%），推动份额到2030年恢复至约27%。总体而言，该图表突显了短期错位后的追赶阶段，中国在中期内仍将是全球x86服务器CPU需求的重要贡献者。

## 本土化份额提升

中国x86服务器CPU市场正稳步向国产替代转变，海光信息份额持续增长，并有望进一步加速。图表36显示，海光的份额已从2020年代初期的低个位数增长至2026-2027年的约20%，主要受政府和国有企业客户的国产化要求驱动。即使中国整体TAM增长在短期内仍受限制，这一政策驱动的采用为国产CPU渗透提供了稳定基础。展望未来，我们预计海光的份额增长将从2028年起显著加速，国内份额到2029-2030年将上升至约35%。这一拐点得益于持续的产品改进（例如性能和生态系统兼容性），以及更重要的是，与国内AI加速器更好的互操作性，这应使海光平台对云服务提供商而言越来越可行，而不仅限于传统的政府/国有企业客户群。与此同时，全球供应紧张状况可能持续，AMD和英特尔优先考虑价值更高、更具战略意义的美国客户。这种供应分配动态进一步强化了海光在中国扩大版图的机会，推动国内x86服务器CPU市场在中期内实现结构性更高的自给率。
