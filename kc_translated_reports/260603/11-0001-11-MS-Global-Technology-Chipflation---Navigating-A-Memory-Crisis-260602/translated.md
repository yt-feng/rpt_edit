# 芯片通胀——应对存储危机

存储价格飙升和供应短缺正成为跨行业风险，因为人工智能正在重新定价数字经济中的关键投入要素。最初只是人工智能基础设施的瓶颈，如今已蔓延至硬件利润率、设备可负担性、云成本、通胀和政策领域。

人工智能正将存储变为结构性瓶颈。人工智能对HBM、DRAM和企业级SSD的需求不断上升，推动存储价格在过去一年上涨了六倍。新产能需要数年时间才能建设、认证和爬坡。这使得本轮周期看起来不像典型的半导体上升周期，而更像一次持久的供需重置。

配额分配正在取代大宗商品定价模式。超大规模云服务商和人工智能买家越来越多地使用长期协议、预付款和战略承诺来锁定产能。这留给传统买家的供应池更小、更紧张且波动性更大。

HBM正在挤占传统存储。HBM对人工智能加速器至关重要，但消耗了不成比例的先进DRAM产能。随着供应商优先保障HBM、服务器DRAM和企业级SSD，留给智能手机、PC、汽车、网络和工业市场的供应减少。即使到2027年DRAM晶圆总产能扩大约30%，我们预计智能手机/PC的存储供应仍将短缺12-15%。

芯片通胀正从大型科技公司向外蔓延……大型云买家能够锁定供应并将更高的成本资本化，而非人工智能买家则面临更高的销售成本、更少的配额、价格上涨、规格降级和产品发布延迟。

……并在供应商和OEM之间制造了明显分化。存储生产商受益于更强的定价能力、利润率和可见度。下游硬件公司则必须消化成本、转嫁成本、重新设计产品，或面临需求破坏的风险，尤其是在价格敏感的消费市场。

对宏观的影响比CPI本身更大。由于在CPI篮子中权重较小，对整体CPI的影响可能温和，但压力已体现在PPI、企业利润率、云账单、资本支出预算和技术部署延迟上。

政策可能缓解压力，但需要数年时间。即使美国和中国部署补贴、税收抵免或许可改革等工具，供应端的响应也需要数年时间，且近期中国产能增长不足。我们假设美国政策保持限制性，短期内或长期内都不太可能缓解压力。

对股票的影响。定价权掌握在DRAM供应商（三星、SK海力士、美光）、NAND（闪迪、铠侠）、HDD（希捷、西部数据）和基础设施（ASML、应用材料、科磊）手中。那些过度依赖消费市场、定价权较弱且存储成本敞口较高的OEM，将面临最严重的利润率逆风。

# 什么是"芯片通胀"？

从历史上商品化微电子的通缩定价，转向持续的结构性价格上涨，这给整体消费品定价带来了持续的上行风险。对于存储而言，通胀已不再仅仅是组件价格问题。

人工智能基础设施正在吸收越来越多的存储（DRAM、HBM和企业级SSD）供应，而供应商优先考虑利润率更高的人工智能/服务器产品，而非主流的消费和工业需求。存储价格上涨的潜在影响包括：

- 供应受限和消费硬件价格上涨
- 企业利润率受到挤压
- 硬件行业出现"有"和"无"的分化
- 核心通胀面临持续上行风险

芯片通胀是由人工智能基础设施和数据中心的快速部署所驱动的需求侧现象。存储可用性趋紧导致设备平均售价上升、云和企业IT成本增加、产品规格降低、更新周期延迟以及利润率压力。

存储短缺已成为宏观经济担忧。对CPI的直接影响可能有限，但其影响日益体现在企业销售成本、云账单、资本支出预算和技术部署延迟中——这使得本轮周期比传统的半导体上升周期更为广泛。芯片供应不足可能导致数据中心项目延迟、云发展放缓并增加企业成本，最终影响生产率增长。

# 持续多年的存储瓶颈

2/15

存储芯片正成为全球AI生态系统的关键输入，支撑着当今智能体AI架构的扩张（《技术：AI智能体的崛起——全球影响》，2026年4月19日）。我们认为，存储芯片价格上涨是市场理性预期AI驱动下存储需求出现价格非弹性跃升的结果。这种定价强势，更多是终端需求指数级增长的体现，而非传统意义上生产商供给纪律的结果——这从渴望在超级智能竞赛中不落人后的超大规模云厂商的年度资本支出承诺中可见一斑。

存储芯片价格上涨形成了一种日益严峻的成本推动动态，导致服务器建造成本上升、云资本支出增加以及硬件价格膨胀。对于非超大规模云厂商的企业而言，这种通胀压力迫使其做出选择：是将价格上涨转嫁出去、降低设备规格，还是接受利润缩减。

# 结构性瓶颈

过去一年，存储芯片价格上涨超过六倍（图表1）——这与持续数十年的价格下跌趋势形成急剧断裂。从1957年到2020年，每GB DRAM的价格大约每五年下降一个数量级。自2010年以来，随着摩尔定律推动价格持续下跌，价格下降速度有所放缓。然而，这一趋势在AI经济中已不再适用，AI经济推动DRAM平均售价大幅上涨（图表2）。建设存储芯片制造厂需要数年时间，因此无法快速响应需求。这意味着未来几年消费品价格面临持续的上行风险。

# 更广泛硬件行业的利润率风险

存储芯片通胀正演变为更广泛硬件行业的利润率风险，其影响范围从PC和智能手机扩展到游戏机、服务器、云、网络、汽车、医疗设备、宽带设备、工业系统以及低成本教育/嵌入式设备。影响不仅在于DRAM/NAND定价更高，还在于分配优先级：

- 供应商优先考虑与AI基础设施相关的HBM、服务器DRAM和企业级SSD需求，而传统的消费和工业存储芯片用户则日益面临显著更高的价格、更长的交付周期和更弱的议价能力。
- 受影响更大的群体是那些无法直接通过AI变现，但仍需支付AI驱动的存储芯片价格的公司。存在会计不对称性：超大规模云厂商可以将存储密集型AI服务器资本化并随时间折旧，而消费硬件和工业OEM的存储芯片通胀则更直接地通过库存和销售成本体现。这将迫使其做出选择：是将价格上涨转嫁给消费者、降低设备规格，还是接受利润缩减。
- 存储芯片通胀不仅仅是资金从非AI行业向存储芯片生产商的转移。对于许多非科技行业而言，它日益成为制约其产品制造内容和时间的因素。

将我们的存储芯片充足性框架分别应用于PC和智能手机，我们发现这两个细分市场在2027年都将面临供应短缺。根据我们的假设（PC消耗17%的非服务器DRAM，智能手机消耗58%），总可寻址存储芯片分别比需求短缺约15%和12%。这意味着PC出货量可能减少5800万台（较MS出货量预测下降15%），智能手机出货量可能减少约1.34亿部（较MS预测下降12%）。这些数字对每台设备存储容量的假设很敏感，但我们的分析表明，如果供应建设不加速，则存在需求配给风险。

# 政策选项

存储器芯片正日益被视为一种战略资源，尤其是在HBM和先进DRAM直接赋能AI终端用途的情况下（因此，中期选举后，美国支持这一终端的政策选项可能会持续）。因此，我们预计该领域的政策努力将较少关注短期成本缓解，而更多关注通过供应链韧性、可信产能和地缘政治去风险来保护AI战略存储器。对于较不先进（非前沿）的存储器终端用途（汽车、消费电子等），政策制定者可能寻求通过差异化许可和对前一类别的可信产能进行定向供给侧支持，来区分大宗或传统存储器与AI战略存储器。重要的是，政治障碍、时间滞后以及相关的供应链约束仍可能削弱这些努力的效果。我们认为，强制分配很可能只是最后的手段。它可能在短期内保护受青睐的行业，但有可能将存储器变成一种配给制的地缘政治商品。

# 总体而言，政策选项可能缓解问题，但最终无法解决。

- 直接补贴可支持新晶圆厂、封装和测试产能，但可能无法迅速降低价格。
- 税收抵免可鼓励投资，但针对性较弱。采购担保可降低产能增加的风险，但可能扭曲分配。
- 加速审批可缩短产能达产时间，但执行困难。
- 设备准入协调可支持盟友产能扩张，但必须与出口管制目标相平衡。
- 战略储备可能有助于关键行业，但在快速变化的技术市场中难以管理。

# 股票敞口

面向AI销售的公司享有定价权，而买家则面临利润率压力。在代理型AI世界中，需求和定价权向存储器、CPU以及相关供应链倾斜。这在年初至今的股票表现中显而易见：全球消费电子股票平均下跌1%，而存储器制造商上涨了近300%，同时每股收益修正幅度达到前所未有的333%。我们继续看好DRAM供应商（三星、SK海力士、美光）、NAND（闪迪、铠侠）和HDD（希捷、西部数据）。

# 什么可能挑战芯片通胀主题

AI支出放缓。前沿大语言模型之间竞争的减少可能导致AI资本支出降低，并回归充足的内存供应。或者，AI模型架构和KV缓存/分词技术的显著改进，可能减少数据中心每次生成token所需的内存量。AI基础设施融资的高成本也可能导致主要云服务提供商缩减建设规模。

电力和供电。可靠、大规模电力的可用性可能成为障碍，因为扩展先进AI模型和运行代理生态系统需要前所未有的电力负荷。旨在长时间内进行推理、规划并持续高强度计算的新一代代理系统，正推动数据中心进入持续的峰值用电状态，远超早期聊天式AI典型的短时爆发。这对全球电网基础设施构成了重大挑战。

需求破坏。传统科技产品的内存需求破坏已经出现，可能表现为硬件利润率挤压、零售价格上涨，以及中小型供应商和中端OEM受到不成比例影响的结构性市场转变。需求的实质性放缓将缓解供应紧张，从而降低价格。

地缘政治与贸易政策。内存和先进封装处于全球供应链中。任何新的限制或中断都可能改变供需格局。

# 快速入门——什么是内存？

内存是计算机用来保存其正在处理的数据的工作空间——相当于你当前正在使用的办公桌，而非身后的文件柜。对AI经济而言，有三种重要的内存类型：

- DRAM（动态随机存取存储器）是快速但昂贵的工作内存，用于每台服务器、PC和智能手机。它是CPU用来保存和获取正在计算的数据的存储器。
- HBM（高带宽内存）是一种高端DRAM，专注于提供最大数据带宽。HBM是垂直堆叠并直接连接到AI芯片上的DRAM——它是使大型AI模型成为可能的内存层，能够以足够快的速度提供数据，从而减少AI加速器的空闲时间。可以将DRAM想象为单车道公路，而HBM则是用于数据传输的12车道高速公路。
- NAND是固态硬盘（SSD）中使用的存储内存，位于工作内存和较慢的HDD磁盘存储之间。NAND保存着训练好的模型权重、训练数据集以及AI系统检索的缓存结果。它也用于图片、视频和数据存储。

这三种内存都很重要，因为AI工作负载会同时、大量地使用它们。下一代机架级AI系统，如NVIDIA的Vera Rubin NVL72，在考虑本地或外部SSD存储之前，其GPU上附带了20.7TB的HBM，并为CPU提供了54TB的LPDDR5X。

AI需求同时在三个层面扩展——每颗芯片的内存更多、每套系统的芯片更多、每个集群的系统更多。代理式AI通过更长的上下文窗口、更大的对话内存以及跨多个代理的重复推理，增加了另一层压力。结果是AI堆栈所有方面的内存强度都出现结构性增长。

# AI内存墙

AI的瓶颈日益转向内存，而不仅仅是计算。随着推理从单轮聊天转向代理工作流，内存强度急剧上升：大型模型需要权重常驻内存，而更长的上下文窗口和KV缓存增加了每个用户、每次会话和每个代理的内存使用量。代理集群放大了这一效应，因为许多代理同时维护或重新加载上下文，将推理转变为一个更大的内存容量和内存带宽问题。因此，超大规模云服务商现在就需要更多的HBM、服务器DRAM和企业级SSD容量来满足这一内存使用激增，而不是等待几年后新晶圆厂投产。

这种紧迫性正推动大型科技公司签订多年期长期协议，通过预付款来确保未来产能。生产商面临的挑战是供应无法立即响应：EUV光刻机可用性、晶圆厂建设、工艺认证、HBM堆叠、封装、测试和良率提升都是耗时多年、耗资数十亿美元的项目。这就是为什么当前可见的需求仍可能在2027年及以后转化为短缺。

# 供给响应缓慢

新的存储产能将从2027年底开始上线，但仍无法满足所有市场的需求。从战略上看，大部分有价值的产能很可能将专用于定价、利润率和客户承诺最强的领域——即HBM客户、服务器DRAM和企业级SSD。虽然AI半导体预计到2030年将以约50%的复合年增长率增长（根据台积电在2026年5月14日年度技术研讨会上的预测），但我们预计DRAM产量的增长速度只能满足约60%的需求，因为受EUV限制，年度比特出货量不太可能大幅超过30%的水平。

我们预测，即使产能增加加速，DRAM供应仍将保持紧张。DRAM供应缺口从2023-24年的约4-5%扩大到2025-26年的约17%，然后在2027年缓解但仍保持约15%的紧张状态。关键问题在于时机。

- 年度DRAM晶圆产能增量从2025年的约105kwpm增加到2027年的约390kwpm和2028年的约460kwpm，主要由三星、SK海力士、美光和长鑫存储推动。按历史标准衡量，这代表着显著的供给增长，但这是在供应最紧张的时期之后才到来。
- NAND在2028年之前仍将供不应求，供需比率在2028年恶化至约14%的供应缺口。产能增加仅在2024-25年净削减后恢复，到2028年增至约170kwpm，主要由三星、铠侠/闪迪、SK海力士/Solidigm、美光和长江存储推动。
- 其中，长鑫存储和长江存储是中国存储生产商，它们近期的加速发展代表着供给侧格局的重大转变。从2023年到2028年，我们预计中国大陆将占全球DRAM净产能增量的约31%，落后于韩国，但领先于美国、中国台湾和日本。我们在此讨论中国在全球存储格局中的作用及其引发的 geopolitical 问题。

# 长期协议：保障供应分配和优先级的策略

从价格驱动的周期转向以供应安全为核心的长期协议。存储行业在供应合同签订方式上正经历结构性转变。历史上，存储客户通常采取机会性采购，定价主要与短期供需状况挂钩。在上行周期中，客户有时会签署长期协议以确保分配，但这些协议通常执行力有限，并可能在市场疲软时重新谈判。

本轮周期看起来不同，因为存储可用性现在直接与AI部署路线图挂钩。领先的云服务提供商不再仅仅管理价格风险；他们也在管理供应风险。因此，多年期协议、产能保证和预付款正变得越来越重要。

- 三星已讨论将季度和年度合同转变为3-5年协议。
- SK海力士强调了客户对中长期供应承诺的需求日益增加。
- 美光已宣布了一项为期5年的战略客户协议。
- 闪迪描述了由坚定财务担保支持的多年合作伙伴关系。
- 铠侠表示，与超大规模客户的长期供应协议已延伸至FY28-29财年。

我们在此看到两级市场开始出现。AI/云买家首先锁定供应，而非长期协议买家则为一个更小、波动性更大的剩余池竞争。

# HBM的蚕食效应与两级市场

HBM正日益成为AI需求挤占传统存储供应的机制，它通过消耗先进的DRAM晶圆产能，并通过长期协议锁定未来供应。这急剧减少了可用的DRAM供应——我们的分析表明，PC DRAM缺口约15%，智能手机DRAM缺口约12%，相当于约5800万台PC和1.34亿部智能手机。这可能导致一个两级市场，大型AI买家首先确保供应，而非AI买家则面临更高的价格、更弱的分配和更高的波动性。

# HBM消耗了不成比例的DRAM容量

HBM不仅仅是增量DRAM需求。由于芯片尺寸显著增大，以及3D堆叠、TSV、先进封装、密集测试和客户认证带来的良率挑战，HBM会导致显著的吞吐量损失。与传统DRAM相比，这些步骤显著降低了有效位输出，并增加了对晶圆、封装和测试产能的负担。

我们的模型显示，HBM的位输出惩罚从2021-24年约为传统DRAM晶圆的3.0倍，上升到2028年预估的约4.3倍。换句话说，每单位HBM产出消耗的晶圆产能远高于传统DRAM产出。

与此同时，HBM正在吸收最受限晶圆池中越来越大的份额。HBM在先进制程内存晶圆中的占比从2023年的约6%上升到2028年预估的约34%。AI客户不仅带来了新增需求，他们还占用了原本可能用于支持DDR、LPDDR和传统服务器DRAM的更大份额的先进产能。

HBM位需求的显著增长由AI芯片需求驱动。HBM产能正在快速提升，但市场仍集中在三星、SK海力士和美光手中。我们预测HBM年末产能将从2026年预估的约480kwpm上升到2027年预估的约610kwpm。

即使有这样的增长，供应仍然受限，因为HBM产能不仅仅是晶圆启动的问题。它还取决于良率、利用率、TSV能力、先进封装、测试产能和客户认证。认证尤其重要：并非所有HBM产能都能立即被所有加速器客户使用。

中国HBM情况如何？当前的出口限制禁止所有原始HBM堆叠进入中国；然而，只要不超过FLOPS规定，带有HBM的芯片仍可出货。长鑫存储正在快速扩张HBM产能，目标是今年实现HBM3，2027年实现HBM3e，以支持国产AI芯片。其他新进入者，如武汉新芯，正在生产HBM晶圆，新的DRAM芯片计划由长江存储在今年晚些时候投产。当前产能处于研发规模，但计划在未来几年内提升。

# LTA可能创造两级内存市场

随着顶级云服务商通过长期协议锁定多年供应，剩余的内存市场可能在结构上变得更加紧张。没有LTA的客户可能需要从更小的未承诺供应池中采购，价格可能更高且波动更大。我们认为这是每个不在LTA队列前列的买家可能承担的结构性成本。

从历史上看，疲软的PC或智能手机需求有助于缓解DRAM市场并为所有人降低价格。在本轮周期中，即使消费电子需求疲软，AI需求仍使分配保持紧张，因为HBM和服务器应用现在设定了优先级顺序，而供应商的激励机制强化了这种分配。在上一次内存下行周期之后，当AI客户提供更强的定价、更好的利润率和更持久的合同时，供应商向市场大量投放大宗供应的动力有限。

# 我们对两个最大的非服务器终端市场——PC和智能手机——进行DRAM充足率分析

从2027年DRAM+HBM总供应量573,503百万Gb出发，我们将70%分配给服务器，30%分配给非服务器应用。在非服务器部分，我们按照历史规律，将17%分配给PC，58%分配给智能手机。在PC端，自下而上的需求为34,386百万Gb，意味着存在5,138百万Gb的缺口（-15%）。智能手机的情况同样严峻：智能手机DRAM总需求为113,125百万Gb，而可供应量为99,790百万Gb，产生13,335百万Gb的缺口（-12%）。

该缺口对容量假设高度敏感。在PC端，我们的基准假设为每台设备89Gb，对应-15%的缺口；若容量同比持平于83Gb，缺口收窄至-9%；若降规至77Gb，缺口则缩小至仅-2%。智能手机遵循相同模式：基准假设99Gb（-12%），容量持平于95Gb时缺口收窄至-7%，降规至90Gb时缺口降至-2%。

由此得出两点启示。首先，出货量风险是内存容量假设的函数，而非绝对的供应壁垒——OEM厂商拥有明确的杠杆来保护出货量。其次，该杠杆并非免费：每保护一个GB的出货量，就意味着放弃一个GB的容量增长，因此调整最终通过抑制内存比特需求来解决出货量缺口。市场出清要么通过减少设备数量，要么通过降低单设备内存密度——而更可能的结果是两者兼而有之。

这强化了供应商的定价能力并改变了周期。供应越多的部分被承诺给战略性AI客户，留给机会主义或非长期协议买家的灵活供应就越少。即使部分消费需求走弱，这也能支撑平均售价的韧性。

# 芯片通胀传导与行业影响

Erik Woodring, Shawn Kim

当前内存周期由晶圆产能和供应商关注度向AI相关需求的结构性重新分配所驱动。这种内存短缺正在重塑PC和智能手机市场，因为供应商优先考虑高价值的AI/服务器需求，而非低利润的消费类应用。这已开始转化为终端需求风险。

我们现在预计，激增的内存成本将导致2026年PC出货量较2025年下降10%以上，智能手机出货量下降13%，内存和SSD价格通胀推高设备价格，需求日益向高端设备倾斜。

这也带来长期影响——设备重新设计、单位经济性的结构性转变、行业整合，以及对本地部署与云端工作负载组合的重新评估。

# 买卖双方矩阵：谁获得优先权？

买卖双方格局正从商品市场转向分配市场。供应端，三星、SK海力士和美光主导先进DRAM和HBM，长鑫存储在DRAM产能扩张中日益重要。在NAND和企业级SSD领域，主要供应商包括三星、铠侠/闪迪、SK海力士/Solidigm、美光和长江存储。

买方端，超大规模云服务商、AI基础设施提供商和GPU/加速器生态系统是HBM、高密度服务器DRAM和企业级SSD最具战略意义的客户。这些买家更有可能获得优先分配，因为他们提供规模、路线图可见性以及通过长期协议承诺的意愿——因此，他们位于分配队列的前列。传统消费和工业买家面临更大风险：PC OEM、智能手机OEM、游戏机制造商、网络公司、汽车制造商、工业企业、医疗设备制造商和小型硬件公司都依赖DRAM、LPDDR和NAND，但与AI/云客户相比议价能力较弱。

战略矛盾在于上游供应集中而下游需求广泛。当AI客户移至分配队列前列时，剩余市场面临更紧张的供应和更高的价格波动。

# 行业影响与传导——痛点落在何处

内存通胀正成为广泛的硬件行业利润率风险，从PC和智能手机扩展到游戏机、服务器、云、网络、汽车、医疗设备、宽带设备、工业系统以及低成本教育/嵌入式设备。问题不仅在于DRAM/NAND定价上涨，还在于分配优先级：供应商优先考虑与AI基础设施相关的HBM、服务器DRAM和企业级SSD需求，而传统消费和工业内存用户日益面临更高价格、更长交货期和更弱议价能力的风险。

按总成本计算，服务器、云和PC受影响最大。但按传导后的净利润率影响计算，受影响最大的行业有所不同：中低端PC、低端智能手机、消费电子、游戏机、嵌入式和教育设备，以及小型工业OEM（图表36）。尽管鉴于如此显著的价格上涨，很难预测历史需求弹性是否会在此周期重演，但我们的量化分析描绘了类似图景：低端/中端PC和智能手机面临相对有弹性的需求响应，因此比企业基础设施面临更显著的净利润率风险，后者的需求缺乏弹性，利润率保护相对更强（图表38）。这些更偏消费类的终端市场结合了更高的内存物料清单风险敞口、更弱的定价能力和更高的需求弹性。

# 会计处理不对称性至关重要

芯片通胀一个不太明显的传导机制是会计处理，对未直接通过AI变现但仍需支付AI驱动内存价格的公司影响尤为严重。这造成了会计处理上的不对称性：

超大规模云服务商可以将高内存占用的AI服务器资本化并随时间折旧，而消费硬件和工业OEM厂商的内存成本膨胀则更直接地通过库存和销售成本传导。

因此，同样的内存价格冲击，对一家买家而言可能是战略性资本支出，对另一家则直接构成毛利率压力。这是当前周期中"芯片通胀"最被忽视的传导机制之一。

# 能力成本：哪些产品无法被制造

内存成本膨胀不仅仅是资金从非AI领域向内存制造商的转移。它日益成为制约产品制造时间与类型的瓶颈。

对于汽车制造商而言，内存成本正在推迟ADAS系统的部署，并压缩电动汽车项目的经济性。通用汽车已将其2026年大宗商品和物流通胀指引上调了10亿至20亿美元，并将更高DRAM成本列为主要驱动因素之一。

- 麦格纳预计，如果DRAM成本持续高企，整车层面的定价压力将进一步加大。
- 伟世通的内存供应在2027年前将持续受限，该公司正在为2026年及以后的需求认证新兴供应商。

对于医疗保健和医疗设备领域，影响更为分散，但挑战真实存在。

- 通用电气医疗指出，在2.5亿美元的通胀逆风中，约1亿美元与芯片及成本措施相关。
- 西门子医疗表示，包括内存芯片在内的供应链通胀可能导致每股收益影响高达0.05欧元。

- 直觉外科指出，毛利率面临压力，其中约100个基点的影响来自关税、运费和半导体内存成本。

对于间接渠道——规模最大且最不显眼的渠道——所有在AWS、Azure或GCP上运行工作负载的企业都通过其云账单间接承受着芯片通胀的影响。一家运行欺诈检测的银行、一家运行路线优化的物流公司、一家运行库存分析的零售商：所有这些企业都在间接支付内存成本膨胀，却没有意识到这是一项内存成本。这是经济覆盖面最广的渠道，也是最难在任何一家公司财报中直接观察到的渠道。

# 以美元计价的芯片通胀影响

内存成本膨胀的规模已大到足以在行业层面产生影响。虽然不同产品差异巨大，但几乎每款硬件产品——PC、服务器、存储阵列、智能手机等——都包含一定比例的NAND和DRAM，我们估计其占设备物料清单的比例从5%（打印机）到70%（高端服务器）不等。简单来说，更高端、更注重性能的产品，如全闪存存储阵列、高端及传统服务器、高端PC和AI服务器，其产品物料清单中NAND/DRAM的占比在25%至70%以上。相反，打印机或网络硬件等产品的内存含量通常较低。尽管如此，这意味着大多数硬件OEM和ODM厂商对内存市场的敞口过高，尤其是那些涉足高端设备的厂商（图表37）。

预计2026年内存市场将增加超过6000亿美元的同比收入，这超过了整个独立智能手机、PC或服务器市场的总规模。为了更直观地理解内存成本膨胀的整体影响，仅在最近3个月内，2026年内存市场总收入的预期已从5200亿美元上调至8900亿美元，增幅达71%，而2025年市场规模为2200亿美元。内存买家不仅面临今年新增的3000亿美元独立内存成本——相当于芬兰或新西兰的年度GDP——而且预计2026年内存市场将增加的同比收入（约6000亿美元）超过了整个独立智能手机、PC或服务器市场的总规模（图表40）。这将在2026年以销售成本或资本支出的形式体现在内存买家的账面上。总体而言，全球硬件行业现在必须应对的新增内存成本，相当于1.3万亿美元硬件总市场规模的半数以上。根据我们的行业层面估算，承受最高美元负担的是服务器市场（2460亿美元），其次是智能手机（1750亿美元）、PC（1320亿美元）和外部存储（130亿美元）。

这并不意味着每家硬件公司都面临同等程度的直接利润率冲击。芯片通胀的负担将在超大规模云服务商、OEM厂商、组件供应商、分销商、企业和最终客户之间分配。但其量级至关重要：内存超级周期规模巨大，足以引发价格上涨、利润率压力、规格削减、产品延迟、预算重新分配和需求破坏等某种组合效应。对于超大规模云服务商而言，更高的内存成本正被作为战略性AI资本支出吸收。对于许多非AI硬件买家而言，它则表现为价格上涨、销售成本压力、产品规格降低和/或产品发布/更新周期延迟。

在非AI硬件市场，规模至关重要。供应商跨多个产品（如PC、服务器、存储）聚合需求的能力，或以异常强大的购买力进入市场（如苹果、三星），在获取内存配额方面会产生显著差异。

但即使获得了足够的内存配额，也伴随着巨大的成本——整个硬件生态系统的价格上涨。根据最新的TrendForce内存价格预测，并假设硬件供应商优先维持利润率，我们估算同类产品的单价涨幅必须达到：智能手机约35%，PC约70%以上，服务器80%以上，存储阵列110%以上。但这只是平均值。据传闻，我们已经听到大幅涨价的实例——在某些高端存储/服务器市场，由于内存加上其他半导体通胀（CPU、PCB、MLCC等），涨幅在某些情况下超过100%。

周期性风险。几乎所有硬件终端市场的价格将在2026年全年走高，设备已在降低规格。尽管有这些努力，硬件利润率仍可能在2026年下半年及之后面临压力，影响最大的可能是需求弹性最大的市场：个人电脑、智能手机和低端消费电子产品。最大的周期性变量仍是需求弹性反应，尤其是在加速采购（即提前购买）停止之后。在个人电脑领域，这似乎已经发生，我们预计2026年下半年出货量将出现两位数的同比下滑。对于服务器和存储，由于工作负载增长和AI应用场景增多，需求更具韧性，尽管价格创纪录上涨，行业分析师仍预计2026年全年及2027年出货量将增长。

# 美国/中国的政策选项无法提供短期缓解

# 关键要点

- 即使美国和中国做出旨在缓解价格压力的政策选择，实际执行也需要数年时间，原因有三：
• 美国政策努力（税收抵免、补贴、加速许可）存在制约和滞后
- 中国目前可用的增量供应无法弥合与需求的差距
- 中国刺激供应的政策激励需要几年时间才能见效

- 此外，我们的预期是，美国的政策选择实际上更倾向于更严格而非更宽松的方向：我们预计出口管制不会取消，现行制度也不会放松。

# 美国可能放松需求限制，但供应不足以缓解压力

鉴于内存被视为战略资源，我们预计关于高带宽内存和先进动态随机存取存储器的政策讨论将聚焦于全球供应链脆弱性以及补充国内供应。为此，我们预计无论2026年中期选举结果如何以及华盛顿的权力格局如何，这些讨论都将继续。

关键的政策区分在于人工智能战略内存——主要是直接支撑前沿人工智能系统的高带宽内存和先进动态随机存取存储器——与用于汽车、工业、消费及其他非前沿应用的 commodity 或 legacy 内存。起点是集中度：先进动态随机存取存储器和高带宽内存由三星、SK海力士和美光主导，而NAND供应更广泛但仍集中。中国通过长鑫存储（DRAM）和长江存储（NAND）正变得更加重要，为已经集中的市场增添了新的政策维度。

为此，政策努力可能区分高带宽内存和 legacy（非前沿）内存，但即使是后者，其范围和效果也有限。我们预计高带宽内存和先进动态随机存取存储器的政策努力将优先通过供应链韧性、可信产能和地缘政治去风险来保护人工智能战略内存，而非关注短期成本压力（即不放松现有出口管制）。对于较不复杂（非前沿）内存的终端用途（汽车、消费等），政策制定者可能寻求通过差异化许可和对前一类别的可信产能进行有针对性的供应侧支持，来区分 commodity 或 legacy 内存与人工智能战略内存。

（更多选项详见下文）。重要的是，政治障碍、时间滞后以及相关的供应链制约仍可能削弱这些努力的效果。在我们看来，强制分配很可能是最后的手段。它可能在短期内保护受青睐的行业，但有可能将内存变成一种配给制的地缘政治商品。总体而言，政策选项可能缓解问题，但最终无法解决。

具体来说，放松需求限制可能允许更多中国供应进入美国市场，但我们认为供应不足以缓解近期的价格压力（详见下文）。

# 政策选项：联邦支持是可能的……

我们通常将供应链韧性背景下的政策选项框架化为“防御性”或“进攻性”策略。“防御性”指更传统的贸易限制（即关税、非关税壁垒、许可要求、出口管制等），而“进攻性”指国内投资举措（直接联邦支出、贷款、赠款、税收激励等）以将供应链回流国内。在内存背景下，我们认为最可能的选项是旨在扩大可信高带宽内存、先进动态随机存取存储器、封装和测试产能的供应侧措施。

在此背景下，我们认为以下政策选项最有可能被讨论以缓解（尽管最终无法解决）问题：

11/15

- 直接补贴可支持新建晶圆厂、封装及测试产能，但未必能快速压低价格。
- 税收抵免能鼓励投资，但针对性较弱。
- 采购担保可降低产能扩张风险，但可能扭曲资源配置。
- 加速审批可缩短产能建设周期，但执行难度较大。
- 设备获取协调可支持盟友产能扩张，但需与出口管制目标保持平衡。
- 战略储备或有助于关键行业，但在快速变化的技术市场中难以管理。

补贴问责将变得更加重要。若存储芯片生产商在享受高定价和强劲利润率的同时获得公共资金支持，政策制定者可能会质疑补贴是否真正转化为实际产能扩张、更广泛的供应渠道、国内供应链韧性或下游成本降低。强制分配很可能成为最后手段。短期内或可保护受青睐行业，但可能使存储芯片沦为受地缘政治配给的商品。

短期内，在现有管制框架上增加出口管制的可能性低于供给侧举措。即便不考虑放松出口管制带来的地缘政治风险，若未配合国内供给侧举措，此类政策既无法缓解瓶颈，也无法促进额外供应。更明确地说，我们持此观点的四大理由如下：1）现有管制体系已将HBM列为《出口管理条例》中明确的高级计算管制项目（尽管存在结构性漏洞）；2）盟友间的协调可能难以实施和执行；3）政策方向正从广泛扩散式管制转向针对性管制，尤其针对更先进技术；4）进一步管制的潜在后果是加剧囤货并限制全球供应，这可能导致成本上升而非缓解瓶颈。

现有出口管制已将HBM纳入高级计算管制体系，但如上所述存在细微差别：美国政府将HBM置于AI出口管制框架内，但由于供应链其他环节（尤其是封装）的地理分散性，仍存在漏洞。因此，更全面的出口管制体系需要与盟友协调——两党提出的《MATCH法案》一直是投资者关注焦点，但通过之路充满挑战，我们更将其视为管制协调工具而非产能扩张手段。除程序性限制（如需立法载体）外，与盟友的协调可能难以实施和执行（尤其因为相关瓶颈分散在不同国家）。此外，鉴于美国政府近期促进跨境销售的行动及两周前中美峰会后的双边声明（见此处），我们认为在现有管制基础上进一步限制HBM获取的可能性不大。此类限制还可能使两国间的"战术性升级"边界外紧张局势升级（如我们此前所述，去年缓和后这不符合双方利益），并可能加剧稀缺性或加速囤货，尤其若未配合平行供给侧投资。

对于HBM和先进DRAM，政策可能结合现有出口管制与盟友协调的"去风险"策略，以及扩大可信产能的供给侧举措。

对于大宗或成熟制程存储芯片，我们认为政策更可能依赖差异化许可和针对性供给侧支持，而非限制性管制，尽管时间滞后、审批流程、劳动力约束、设备可用性及认证周期将限制短期影响。

# ...但存在关键制约因素：程序、时间与公众认知

因此，我们认为短期内最可行的应对措施是增加美国及盟友国家的HBM和封装供应。上述选项均为实现此目标的手段，但各有制约。主要制约因素是时间：建设本土存储产能需要漫长的物理建设周期（可能长达数年）。除审批、选址等瓶颈外，HBM相关制约还延伸至供应链其他环节。先进封装需求意味着政府激励不能仅聚焦HBM产能。劳动力同样构成制约：熟练劳动力是关键瓶颈，因为美国在按需规模建设及维护先进存储与封装设施方面的经验相对不足。因此，政策努力更可能旨在从地缘政治角度为HBM和先进DRAM构建更具韧性的供应链（这需要时间且成本更高），而非解决短期供应或定价问题。

在公众对AI日益持怀疑态度的背景下（见此处），我们还需考虑公众认知角度及其相关的政治障碍。尽管我们最终认为华盛顿两党共识是加速美国对华竞争地位，因此政策选项应支持这一目标，但公众对AI及更广泛的产业补贴仍存疑虑，这可能使短期内推行重大或增加赤字政策的难度加大。

# 中国或可增加供应，但需数年时间

中国能否成为变数？在消费领域，将中国消费级存储芯片整合至PC和智能手机或可成为解决方案。我们注意到近期有报道称，主要PC制造商已联系长鑫存储探讨DRAM合作可能性，这一转变在零售市场已有所体现——海盗船复仇者DDR5等美国模组品牌已采用长鑫存储DRAM芯片。美国科技公司虽可使用中国存储芯片，但因地缘政治紧张和国家安全担忧而日益谨慎。尽管美国政府限制向中国出售先进芯片技术，但进口标准中国存储芯片用于消费电子产品仍基本可行。阻碍长鑫存储等公司向主流制造商供应DRAM芯片的因素之一，是美国立法可能发生变化。例如，联邦采购监管委员会发布的新拟议规则旨在限制商业产品中使用长鑫存储、长江存储及中芯国际的芯片。

中国正成为常规存储的边际影响因素，但并非近期的HBM解决方案。根据TrendForce预测，中国本土DRAM产能将从2023年占行业总产能约18%提升至2028年的约23%，而中国本土供应商的份额将从约7%增至约17%。长鑫存储（CXMT）是主要驱动力，新增产能38.8万片/月（kwpm），占2023至2028年全球DRAM净增量的约30%。这可能使中国成为大宗DRAM的重要泄压阀，尤其对于面临三大原厂供应趋紧的非AI买家而言。

然而，中国厂商的有效产出因良率和技术差距而显著折价。在NAND领域，长江存储（YMTC）已跨越128层门槛，在主要技术指标上具备广泛竞争力，但可制造性和企业级良率仍是关键差异点，每晶圆比特数（bits/wafer）较西方同行低约20%。在DRAM领域，长鑫存储目前处于1znm（约16nm）节点，大致落后最先进技术三代，其技术路线从17-19nm过渡至2025年。尽管目前30%的产能用于DDR5，但时钟频率仍不足以满足主流PC、服务器、智能手机或AI工作负载。其路线图目标是在2027年利用1anm DRAM实现HBM3e——参照美光先例，无需EUV光刻即可实现——但每晶圆比特数仅为西方水平的约三分之一，其中节点劣势仅能解释约三分之一的差距。其余差距反映了结构性制造效率低下，这表明中国对HBM的供应贡献应保守建模，即便有贡献也应如此。

监管背景进一步强化了这些制约。截至今日，长鑫存储和长江存储均仍在美国国防部第1260H条"中国军事企业"名单上——长鑫存储于2025年1月被列入，长江存储于2024年被列入。该名单不附带法定贸易禁令，但《2024财年国防授权法案》（NDAA）禁止国防部自2026年6月30日起直接与名单实体签约。媒体报道称，2026年2月13日的一份更新文件曾短暂显示两家存储制造商被移除（同时新增阿里巴巴、百度和比亚迪），但国防部在数小时内未作解释便从《联邦公报》撤回了该文件，使2025年1月的名单继续生效。这一事件表明内部可能存在关于解除限制的争论，但并未带来实际效果。更具约束力的是，长江存储仍在美国商务部的实体清单上，自2022年底起便受此限制，美国技术出口至该公司受到管制。长鑫存储不在实体清单上，但运营受到更严格的审查。关键的是，这两项认定均未阻止中国企业向西方市场销售存储产品——其市场准入障碍源于声誉和合规驱动，而非法定进口禁令。

在供应端，光刻设备获取仍是硬性天花板。自2023年起，EUV光刻机已对中国禁运（ASML从未向中国交付过EUV系统），这是长鑫存储先进DRAM产能似乎已停滞的主要原因。拟议的《MATCH法案》将进一步收紧限制，将长鑫存储、长江存储、中芯国际、华虹和华为列为"受覆盖设施"，不仅禁止DUV浸没式光刻机销售，还禁止对已安装设备进行维护——DUV设备需要定期维护以维持良率。该法案仍在立法流程中，尚未颁布，但这表明政策走向是限制而非放松中国存储芯片的规模扩张。

中国无法解决战略性AI存储（HBM）瓶颈。我们的HBM模型完全集中于三星、SK海力士和美光，未纳入任何中国HBM贡献。这一区别对政策制定至关重要：中国的DRAM/NAND产能可能有助于缓解大宗存储的紧张局面，但无法解决与AI加速器相关的前沿HBM制约。

关键韧性问题不在于全球总产能，而在于可信且可获取的产能。在我们的DRAM模型中，韩国是最大的产能池，中国大陆位居第二，其次是中国台湾、日本和美国。韩国加上中国大陆约占2028年预计DRAM晶圆产能的77%。然而，并非所有产能在地缘政治情景下都具有同等先进性、合格性或可获取性。政策制定者需要了解产能分布位置、控制方、可生产的存储类型，以及买家在供应冲击期间能否获取。

# 入门：存储器101——类型、市场结构与周期

# 什么是存储器？

存储器并非单一商品，而是一系列不同产品的集合——每种产品服务于不同应用，由不同供应商制造，被不同客户购买，并受其自身供需动态影响。理解这些差异，对于理解谁将从当前市场动态中受益、谁将处于劣势至关重要。

6种主要存储器类型：

- HBM（高带宽存储器）直接位于AI加速器封装上，通过称为硅通孔的微型垂直柱体进行层叠连接。它提供非凡的数据吞吐量——远超传统DRAM——这也是单个英伟达H100能够每秒处理海量数据的原因。由于它在物理上集成于芯片封装内，HBM无法与任何其他存储器类型互换；它必须在芯片设计层面就进行集成。它也是全球技术最复杂、制造成本最高的存储器。
- 服务器DRAM是数据中心的工作存储器——即位于服务器主板上的DDR模块，用于保存CPU和GPU处理所需的活跃数据。每台AI训练服务器都需要大量服务器DRAM，而代理型AI工作负载——其中许多并行推理链同时运行——正将每台服务器的DRAM容量推至两年前难以想象的水平。
- PC和移动DRAM采用与服务器DRAM相同的基础技术，但采用更低功耗的封装形式——即笔记本电脑、平板电脑和智能手机内部的LPDDR芯片。这是一个对价格更为敏感、面向消费者的市场，也是当价格上涨时最容易遭受需求破坏的市场。
- 企业级NAND是用于数据中心SSD和存储阵列的闪存。它保存无需实时访问但必须持久保留的数据。NAND在结构上与DRAM不同——它无需电源即可保留数据——并在完全独立的晶圆厂工艺中制造。
- 消费级NAND涵盖智能手机、PC、游戏设备和U盘内部的闪存。它属于高产量、低利润产品，且是预算收紧时最先受到冲击的领域。
- HDD（硬盘驱动器）用于在计算机或其他电子设备上存储数字内容和数据。这些非易失性存储设备利用磁盘来写入和读取数据。SSD通常比HDD更快、更可靠，但也昂贵得多。

# 供应商地图：战略存储器仍由三巨头主导；中国在商品化存储器池中扩大规模

供应商格局因产品类型而高度细分。HBM和先进/服务器DRAM仍集中在三星、SK海力士和美光手中，其中SK海力士目前在HBM领域领先，三星定位为最广泛的DRAM/NAND供应商及潜在的HBM复苏候选者，美光则成为总部位于美国的关键战略供应商。NAND供应更为广泛，三星、铠侠/闪迪、SK海力士/Solidigm、美光和长江存储均占有一席之地。通过长鑫存储在商品化DRAM/LPDDR领域和长江存储在NAND领域的布局，中国正变得愈发重要，但两者短期内均无法成为全球HBM供应压力的缓解阀。关键启示在于，供应缓解是不均衡的：中国能在特定商品化存储器市场提供帮助，而前沿AI存储器仍集中在三巨头手中。

# 存储器周期监测

存储器周期已不再统一。面向AI的产品在结构上趋紧，而面向消费者的产品趋紧则主要是由于被挤出。HBM是受限最严重的池子；服务器DRAM受AI/云需求拉动；企业级NAND则因AI存储需求增长而收紧。相比之下，PC/移动DRAM和消费级NAND并非因终端需求旺盛而趋紧；它们面临压力是因为供应商优先分配产能给价值更高的HBM、服务器DRAM和企业级SSD。这种分化意味着AI买家获得优先分配，而消费者和工业买家则面临更高的价格、更低的规格、延迟的更新周期和利润率压力。

# 存储周期拐点

# 我们通过四个信号指标来监测周期中的早期拐点信号：

1.  DRAM价格持续走强。我们预计长期协议将在未来2-3年内改变存储定价的高波动特性。在4Q25-2Q26期间大幅上涨后，我们预计DRAM和NAND的季度环比涨幅将收窄至约8-13%。我们并不将此视为拐点信号，而是认为长期协议通过预付款锁定高位价格，能够为存储公司带来稳定性、提高盈利可预测性，并通过更好的供应管理降低过度建设产能的风险。（长期协议——它们如何影响存储行业）
2.  库存调整周期。在2Q26初，供应商库存仍处于历史低位，DRAM仅2-3周，NAND为4-5周。服务器客户尽管订单积极，仍在继续消化库存，而其余终端客户保持健康的库存水平。在上行周期中，芯片交付给PC、服务器和智能手机制造商的交货时间往往会延长。这促使客户超额订购并囤积库存，以防交货时间延长演变为真正的短缺。我们认为这对消费类客户而言是一个持续存在的问题，他们面临着价格飙升与有限供应分配之间的权衡。
3.  资本支出预算缩减，同时资本密集度上升。存储行业通常要么供应过多，要么供应过少。该行业具有竞争性但也理性，因此应对价格失衡时期做出反应。为应对库存增加和盈利能力下降的前景，芯片制造商降低产能增速以匹配需求。DRAM资本支出在2019年削减了23%，2020年持平，而2015年下行期仅削减了9%。然而，AI需求可能使未来下行周期中的绝对资本支出水平保持高位，并促使公司要求更高的回报来证明这些投资的合理性。
4.  盈利预测持续上调与估值扩张。市场往往领先于实际盈利修正，我们将关注HBM定价谈判带来的进一步盈利上行空间。我们的敏感性分析表明，市场尚未对存储供应商由长期协议支撑的盈利和自由现金流赋予任何有意义的市盈率溢价。举例说明，如果我们对长期协议支撑的盈利应用10倍市盈率，并假设70%的商品长期协议覆盖率，在其他条件不变的情况下，三星/海力士2027年市盈率可能扩大至约8.5倍（目前为5倍）。

# 框架概述

量化每吉瓦AI算力的存储需求需要按硬件平台细分，因为基于GPU和基于ASIC的部署在配置上存在显著差异。对于GPU平台（NVIDIA），我们的分析以GB200 NVL72和Vera Rubin NVL72系统为基准。ASIC配置非标准化且难以建模——LPDDR在ASIC部署中尚未广泛用于服务器主内存，使得直接比较不可靠——但HBM密度在各平台间应大致相似。

# 每1吉瓦算力的DRAM晶圆密集度

基于我们SPE团队对年产1吉瓦算力所需晶圆的自下而上分析，DRAM是供应链中晶圆密集度最高的组件。

对于GB200 NVL72，每1吉瓦算力的DRAM晶圆总需求约为153万片/月，其中HBM约110万片/月，LPDDR约43万片/月。对于Vera Rubin NVL72，DRAM总密集度大致相似，约为144万片/月，其中HBM约89万片/月，LPDDR升至约55万片/月——反映了Vera Rubin架构中更高的LPDDR含量。以WFE美元价值计，逻辑WFE在GB200平台层面仍是最大单一组件（约142亿美元 vs. DRAM约138亿美元），但占比因平台而异——Vera Rubin更高的LPDDR含量使天平略微向DRAM倾斜（约144亿美元 vs. 约116亿美元）。这两个组件在WFE总密集度上大致相当。

# 终端市场的可替代性与分配动态

对消费硬件敞口进行建模时，一个重要细微差别在于DRAM颗粒在不同终端市场之间具有高度可替代性：PC和服务器DRAM本质上是同一产品，而LPDDR如今在GPU服务器中也得到大量使用。因此，三大供应商并未正式按终端市场划分产能——三者均打算继续服务非数据中心客户，但增量产能将流向增长最快的终端市场。实际上，这意味着即便供应商未做出任何正式的重新分配决策，随着AI服务器需求挤占非服务器颗粒，消费类和PC的分配将面临结构性的收紧上限。

# 代理式AI：一个新的增量需求向量

在传统GPU服务器部署之外，从推理到代理式AI的转变，为CPU连接的DRAM引入了一个结构性新需求类别。与GPU训练或批量推理不同，代理式工作负载运行连续、多步骤的推理链，需要在编排层拥有大型、持久的内存状态。我们用于量化这一机遇的框架是：

代理式AI DRAM需求 = (增量编排CPU出货量) × (每CPU平均DRAM)

我们此前已将独立的代理式编排服务器确定为一个新的硬件类别，每台设备的DRAM容量可能达到1.5-3TB——这一水平在两年前对于CPU级服务器而言是不可想象的。KV缓存卸载动态进一步加剧了这一情况：此前，生成式AI模型按会话将KV缓存卸载至NAND。而代理式工作负载需要数周至数月的持久状态，显著增加了每台服务器的DRAM和NAND容量。这一等式仍在演变中，尚未被纳入共识的DRAM TAM模型，这为我们本已看好的需求前景提供了上行空间。

# 示意性WFE规模：TeraFab作为压力测试

为说明大规模AI计算建设所隐含的内存晶圆需求规模，我们SPE团队的TeraFab分析具有指导意义。一个年计算产出提升至12GW的设施，第一年将需要约330亿美元的WFE——其中仅DRAM就约占140亿美元。即使采用更保守的3GW爬坡节奏，单个设施每年的DRAM WFE需求也将达到约35亿美元。这凸显出AI数据中心部署不仅仅是芯片需求的故事，更是全栈内存容量的故事，其中HBM仍是该栈中供应最紧张且战略差异化最明显的产品。
