# 偏度信号分析后续

# 执行摘要

在之前的报告中，我们展示了短期到期偏度的变化包含关于后续利率变动的预测信息。在本后续报告中，我们测试了该结果在不同实施选择、参数规格和市场制度下的稳健性。我们发现：

- 该信号保持稳健。当久期敞口通过互换而非国债期货表达时，表现基本不变。同样，从1个月、3个月和6个月到期期限得出的偏度信号产生可比结果，表明信息内容并非与特定工具挂钩。
- 该信号还表现出有意义的信息时效。偏度变动后，预测能力至少可观察数天，尽管其价值随时间衰减。这表明偏度变化是逐渐而非立即被纳入利率中。
- 将样本扩展至2009年证实，这种关系并非后疫情时期所独有。然而，自2019年以来，表现对信号速度变得更加敏感。在回溯窗口和交易延迟方面，快速移动信号通常优于慢速移动信号。
- 自2019年以来，信号表现在2年期板块恶化最为严重，该板块利率变动日益由宏观和政策冲击驱动。相比之下，30年期尾部改善最大，表明投资者头寸仍是长端利率的重要驱动因素。

总体而言，证据表明偏度捕捉的是市场行为的真实特征，而非样本特定的偶然现象。我们认为2019年后的关键教训是市场开始变化得更快。

# 测试信号稳健性

稳健性分析涵盖了一个庞大的参数空间。我们评估了四个回溯窗口、三个到期期限和十个交易延迟，共产生120个规格。

目标并非识别表现最佳的组合——那将是数据挖掘。相反，我们想测试信号在合理的规格变化下是否仍然有效，并利用表现差异来理解信号何时以及为何有效。

# 一图胜千言

图表1使用气泡图总结了结果。对于每个规格，我们关注表现的三个方面：风险调整后收益（y轴上的夏普比率）、下行风险（x轴上的最大回撤）和一致性（气泡大小表示月度正累计收益的百分比）。透明度代表交易延迟。最深色气泡表示1天交易延迟，最浅色表示10天交易延迟（即基于10天前观察到的信号进行交易）。

这种可视化使我们能够同时比较所有120个策略规格。在其他条件相同的情况下，最具吸引力的配置是那些结合高夏普比率、有限回撤和强一致性的配置，表现为图表右上角的大气泡。

两个结论突出。首先，结果与使用国债期货获得的结果基本一致，并且在1个月、3个月和6个月到期期限之间表现差异很小。这表明该信号反映的是广泛的投资者头寸，而非特定工具或偏度曲面上某一点的定价。

其次，21天回溯窗口提供最一致的表现。较短回溯窗口可以达到类似的夏普比率，但对噪声更敏感，而63天回溯窗口通常表现不佳。

总体而言，该信号对久期工具和期权到期期限的选择似乎稳健。表现对偏度变化测量速度更为敏感，21天回溯窗口在响应性和稳定性之间提供了合理平衡。

# 比较LIBOR和SOFR时代

# 信号衰减

原始报告侧重于一天交易延迟的策略，即头寸在$(t+1)$建立并持有至$(t+2)$，基于在$(t)$观察到的信号。

在此，我们将框架扩展至考虑更长的交易延迟。具有更长持有期的策略可以复制为使用不同交易延迟形成的投资组合的线性组合，使我们能够描述信号alpha随时间演变的特征。

# 聚焦2021年至2023年

2021年至2023年期间是偏斜信号表现最差的阶段，并为其局限性提供了有益启示。

第一个挑战是偏斜在抛售初期就重新定价。随着投资者适应更高的通胀，支付方偏斜急剧走阔，并在2021年初达到历史高位。随后利率在接下来两年内进一步下跌300个基点，但偏斜并未以同样速度继续走阔，因为大部分看跌前景已被定价。因此，该信号无法再从利率更广泛的方向性变动中获益，而是依赖于正确识别短期波动。这使得表现对回溯窗口的选择更加敏感。

第二个挑战是高企的隐含波动率。到2022年，隐含波动率和支付方偏斜均已处于高位。即使利率继续下跌，偏斜进一步走阔的空间也已所剩无几。一旦3m10y隐含波动率升至约每年100个基点以上，偏斜对利率进一步变动的反应就变得迟钝。

综合来看，这些观察表明该信号在最初的重新定价阶段最为有效。一旦偏斜和隐含波动率达到高位，利率的进一步下跌几乎不会带来额外的偏斜走阔，从而削弱了信号的预测能力。

# 将分析扩展至整条曲线

自2019年以来，表现恶化在2年期尾部最为显著，而30年期尾部是曲线中唯一出现改善的部分。一种解释是，前端利率日益受到宏观和政策冲击的驱动，从而削弱了持仓信号的影响。相比之下，长端利率似乎仍更受投资者资金流的影响，使得偏斜能够保持（甚至提升）其预测能力。

63天回溯窗口在几乎所有尾部均表现不佳，而21天回溯窗口则取得了更一致的结果。

综合来看，这些发现表明2019年后的环境提升了速度的价值。能够快速适应持仓变化的信号继续表现良好，而依赖旧信息的信号则变得效率较低。

# 结论

偏斜信号在广泛的模型参数选择下依然稳健，表明它捕捉的是市场行为的真实特征，而非样本特定的假象。

自2019年以来，市场经历了更频繁的冲击和制度转变。因此，采用63天回溯窗口的信号表现不佳。该信号在前端的相关性也有所下降，因为宏观冲击日益主导利率变动，而在较长期限尾部则保留了预测能力。

3个月偏斜的21天变化仍是一个合理的基准，但适当的实施应取决于市场制度，而非历史优化。
