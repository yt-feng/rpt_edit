# 半导体 | 北美
# 因需求持续超过供给，上调存储类股盈利预测/目标价

存储类股在2025年表现强劲，并在2026年继续领跑市场，但我们认为这轮强势表现尚未结束。

# 核心要点

DRAM是AI建设中的主要瓶颈，NAND仍然非常紧张，只要AI支出持续，将推动FCF/EPS持续增长
MU和Sandisk的市盈率仍低于10倍，为进一步的估值扩张留出空间，我们认为盈利预测将继续上调
2026年底的HBM重新谈判、扩大资本回报是MU的下一个催化剂
■ 将MU目标价上调至1,050美元，SNDK目标价上调至1,750美元

正如我们在今日发布的全球报告和本周早些时候的台湾调研纪要中所强调的，内存短缺问题没有快速解决方案。（芯片通胀——应对内存危机；台湾会议纪要）。这将推动内存供应紧张状况可能再持续2-3年（或更长时间）。

短缺在DRAM领域最为严重，NAND领域也是如此。市场开始认识到这对当前盈利流持久性的意义——Micron的共识市盈率自3月底以来已从4倍扩大至11倍。那么接下来会怎样？

对于Micron，我们认为：(1) DRAM正日益成为AI建设的主要瓶颈，超大规模云服务商的支付意愿仍然很高；(2) 供应增长受限于洁净室和EUV光刻机的可用性。我们认为这将使供应状况保持紧张，盈利预测将继续上调（我们基于更高的定价，将CY26/CY27的每股收益预测分别上调4%/48%）。我们目前模型假设DRAM定价在5月季度上涨40%，8月季度上涨15%，这低于我们在调研期间从供应链听到的20%或更高的预期——但我们不能假设所有业务都会响应这些季度调整。

我们仍然认为，随着投资者对盈利能力的持续时间进行定价，估值扩张可能成为未来回报的更大驱动力。话虽如此，我们的基本假设仍然是，定价和利润率将在2028年出现一定程度的修正，但这一点目前尚未显现。与此同时，我们预计回购将从FY27开始启动（我们模型假设FY27-28期间回购500亿美元）——由于芯片法案条款的限制，MU在很大程度上一直被禁止进行回购。

Micron还将进行大规模产能扩张，就整体DRAM而言，资本支出相对于历史水平仍然相当高，但其对位元增长的影响将继续受到HBM产量增加及其相关换算比的限制。随着新供应在2027/2028年陆续到位，位元供应增长将加速，但速度仍受制于建设和设施爬坡的时间安排。我们对MU的FY27/28资本支出预测仍远高于市场共识，目前我们模型为440亿美元/400亿美元，而市场共识为376亿美元/369亿美元。这对我们的自由现金流预测构成拖累，但我们的新模型（见报告末尾）显示折旧摊销影响是可控的。此外，如果市场继续保持如此紧张的状态（我们预计如此），额外的位元增长可能成为收入/每股收益的上行来源。

对于Sandisk，情况类似。超大规模云服务商继续以显著改变该大宗商品需求格局的水平抢占高性能NAND市场，与此同时供应增长调整缓慢。在投资者日上，Sandisk的合资伙伴Kioxia（由Kazuo Yoshikawa覆盖）刚刚举行了分析师日，仅将其长期位元增长预期从20%略微上调至22%。这包括来自AI推理的更强贡献，但PC/移动市场增长乏力。鉴于长期需求仅小幅增长，资本支出预计将保持在每年4700亿日元的低位（更多信息请参见MSR：2026年投资者日）。智能手机和PC需求前景较低是我们相对偏好MU的主要原因，因为MU面临的设备规格降级更难发生，且进入数据中心和AI市场的位元比例更高。尽管如此，移动/PC/消费电子疲软并未影响NAND的定价环境，我们基于更高的定价，将Sandisk的CY26/CY27每股收益预测分别上调12%/24%。

我们认为这两只股票可以继续跑赢大盘，因为其近期盈利预测对应的估值仍然合理（两只股票CY27预测市盈率均低于10倍），且大规模股票回购可能于2027年启动，专用AI内存（HBM）合同谈判价格上调，以及Sandisk在数据中心市场的渗透率提高。

在此背景下，市场对新的多年期供应协议关注度很高，我们的观点是，长期协议应被视为“更高更久”前景的症状而非原因，并且是超大规模云服务商计划在未来几年继续扩大内存采购、并将承诺视为确保供应的必要条件的证明。我们认为市场将奖励这种隐含的持久性，但我们最关注的仍然是供需基本面。

MU盈利预测和目标价变动：我们的估值方法仍基于周期每股收益，此前525美元的目标价基于约25倍周期每股收益21美元。鉴于我们现在预测预测期内每个季度的每股收益均超过17美元，我们将每股收益预测上调至35美元，略高于我们新的FY21-FY28平均值（34美元），因为我们仍然假设盈利能力会随时间出现高峰和低谷。29.5倍的市盈率仍与半导体板块一致。

# 风险回报 – SanDisk Corporation. (SNDK.O)

NAND在加速的云需求推动下迅速改善

# 目标价 1,750.00美元
