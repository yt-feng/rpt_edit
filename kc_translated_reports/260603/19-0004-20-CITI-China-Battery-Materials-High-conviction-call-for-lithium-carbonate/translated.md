# 中国电池材料

碳酸锂价格将反弹至25万元/吨的高确信判断，股票市场将对此作出反应

## 核心观点

得益于强劲需求，锂及电池材料自2025年下半年以来已走出困境，这与我们2025年11月初发布的上一份锂行业报告（参见报告）观点一致。考虑到需求前景持续获得更强支撑，叠加间歇性供应中断因素，我们仍看好锂价走势，认为年内（可能在8-9月）有望触及25万元/吨水平。近期中国锂业股票因市场担忧高价格抑制需求而出现回调，我们上调了对锂业个股的偏好排序，认为锂价上涨时其表现将优于电池产业链其他环节。我们提升了对锂板块的偏好；最新产业链排序为：锂 > 正极 > 电池 > 电解液 > 隔膜 > 电池零部件 > 负极（参见此处）。首选标的为赣锋锂业、宁德时代-A、湖南裕能、亿纬锂能和中创新航。

重申我们对2026年锂平均售价的看涨观点——尽管锂价在触及20万元/吨后近两周有所回落，但我们仍认为年内（可能在8-9月的新能源汽车传统旺季叠加另一轮出口抢装窗口）锂价有望再次测试25万元/吨的关键水平。主要电池制造商至少应在8-9月期间欢迎新产能上线以实现年度产量目标，这意味着届时需求将出现相对显著的增长。我们认为基本面依然稳固，应能支撑锂价新一轮上涨动能。

我们覆盖的锂业个股——锂价走强反映需求增强，这将提振电池产业链的股票情绪。我们维持对天齐锂业和赣锋锂业的买入评级，认为在强劲的电池实际需求背景下，两家锂业公司凭借成本优势、规模效应及其他竞争因素，均将从锂平均售价上涨中受益。两者之中，天齐锂业股价本季度至今因估值不高而有所追赶，我们估计该交易机会短期内仍存。但长期来看我们更偏好赣锋锂业，因其在碳酸锂（包括Goulamina、Cauchari、PPG和Mt Marion项目）权益产量增长和上行周期中平均售价提升方面面临双重利好，而天齐锂业未来2-3年产量增量有限。

# 电池生产管线逐月印证强劲需求

与泽咨询的渠道调研显示，年初至今电池实际生产管线延续强劲势头，缓解了此前对（1）2026财年新能源汽车可能弱于预期，以及（2）原材料成本上涨可能因储能系统内部收益率对成本高度敏感而对其需求构成下行压力的担忧。据泽咨询数据，2025年1-4月电池产量同比增长41%至874吉瓦时，其中新能源汽车电池产量和储能电池产量分别同比增长22%和99%至567吉瓦时和307吉瓦时。

# 年内间歇性供应中断

尽管年初至今需求信心增强，但锂交易波动性加大，因年内出现间歇性供应中断，给供需动态带来上行/下行风险。以下我们列出当前热门的供应中断因素及对最新进展的看法。

- 江西钨业（对锂价负面影响）——江西钨业自2025年8月起因采矿许可证到期、作为陶瓷粘土的不当采矿许可证以及环境问题（如河道侵占、尾矿处理等）而停产。根据我们与行业人士的渠道调研及政府公开公告，宁德时代已于2026年初获得适当采矿许可证，但环境许可证仍在审批中。由于这取决于政府流程而非企业行动，市场难以就明确的复产时间表达成共识。总体而言，在最终批准完成前，这对锂价构成悬而未决的负面警报。
锂云母矿更新（对锂价正面影响）——其余4座锂云母矿年内迟早可能需要经历相同流程（即采矿许可证、环境许可证等），表明锂供应面临进一步下行风险。根据我们与行业人士的渠道调研，企业年初至今正加快锂云母生产以积累库存供后续转化。也就是说，如果其余锂云母矿确实需要停产更新许可证，今年实际影响可能小于纸面数据（每月减少8000吨碳酸锂当量，占中国锂供应的7-8%），但2027财年及以后的影响取决于审批时间表。

澳大利亚矿山更新（对锂价利空）——由于年初至今锂辉石价格具有吸引力，澳大利亚高成本锂辉石矿山自2026年下半年起逐步获得重启和/或扩产的激励。以下为高锂辉石价格所激励的增量锂辉石总结。

# 赣锋锂业（002460.SZ）

投资论点——赣锋锂业应受益于锂平均售价上涨，这得益于强劲的实际电池需求，以及低成本上游资源（即Goulamina、Mariana等）贡献增加带来的成本竞争力提升。其未来2-3年权益锂产量的持续增长（包括Goulamina、PPG、Cauchari等）为其长期竞争力奠定了坚实基础。此外，其快速发展的电池业务应在未来几年为整体净利润提供进一步上行支撑。

模型更新——我们在2025财年及2026年第一季度业绩后更新了赣锋锂业的财务模型，以纳入（1）2026年第一季度锂平均售价飙升带来的强劲开局，（2）由权益量的整合部分和纯转化业务的非整合部分驱动的锂业务重建，以及（3）电池业务趋势向好，该业务可大幅转嫁原材料成本上涨（包括锂、铜、铝等）。我们将2026/27财年整体净利润上调至84.57亿元人民币和81.61亿元人民币，假设2026财年含增值税的碳酸锂和锂辉石混合平均售价分别为每吨17.5万元人民币和每吨2300美元，2027财年分别为每吨16万元人民币和每吨2050美元。引入2028财年预测。

估值——重申对赣锋锂业A股的买入评级，新目标价设定为每股93元人民币，基于2026年预期市净率的3.2倍，处于2021年以来历史5年平均水平，并考虑到未来紧张的锂供需动态。隐含2026年预期市盈率约为22倍。赣锋锂业A股当前分别交易于2026年预期市净率的2.6倍和2026年预期市盈率的17.3倍。

江西赣锋是中国最大的锂生产商之一。公司成立于1996年，于2010年在深圳证券交易所上市，并于2018年在港交所上市。其大部分业务位于江西省，截至2025年底，公司拥有约11.6万吨碳酸锂和约13.1万吨氢氧化锂产能。

# 投资策略

我们给予赣锋锂业买入评级。公司应受益于锂平均售价在强劲的电池需求推动下上涨，以及低成本上游资源（即Goulamina、Mariana等）贡献增加带来的成本竞争力提升。未来2-3年其权益锂矿产量持续提升（包括Goulamina、PPG、Cauchari等），为其长期竞争力奠定了坚实基础。此外，其快速发展的电池业务应在未来几年为报告净利润提供进一步的上行支撑。

# 估值

赣锋锂业-A股目标价设定为每股93元人民币，基于2026年预期市净率3.2倍，为2021年以来5年历史平均水平，考虑即将到来的锂供需紧张格局。隐含2026年市盈率为22倍。

# 风险

可能阻碍赣锋锂业A股达到我们目标价的主要下行风险包括：(1) 海外采矿资产的地缘政治风险，(2) 锂离子电池需求低于预期，(3) Goulamina和Mariana项目爬坡慢于预期。

# 天齐锂业

# 公司描述

截至2024年底，天齐锂业拥有162万吨/年锂辉石产能和9.18万吨/年锂化合物产能。天齐持有泰利森26.01%的股权，泰利森控制着澳大利亚Greenbushes锂辉石（锂矿石）矿，这是全球最大的锂辉石矿，拥有最高品位的锂矿石（氧化锂含量1.3%）。此举使天齐能够确保低成本矿产资源。天齐的产品，包括碳酸锂和氢氧化锂，广泛应用于电动汽车电池、工业润滑脂、陶瓷和玻璃。

# 投资策略

我们对天齐锂业给予买入评级。该股是受益于锂行业上行周期的最佳标的之一，因其业务纯粹覆盖从上游锂辉石到下游碳酸锂的锂产业链。锂价上涨将支撑天齐锂业在2026年第一季度实现可观的盈利复苏，并预示其全年财务表现稳健。此外，与赣锋锂业相比，天齐锂业估值不高，短期内对投资者具有吸引力。

# 估值

我们采用市净率（P/B）倍数，以便与赣锋锂业进行更直接的比较。我们的目标价为每股75.14元人民币，基于2026年预期市净率的2.5倍，这是自2021年以来的历史平均水平，以反映未来锂市场供需紧张的格局。

# 风险

可能阻碍天齐锂业A股达到我们目标价的主要下行风险包括：(1) 锂离子电池需求弱于预期，以及(2) 政策不确定性导致的任何供应中断。
