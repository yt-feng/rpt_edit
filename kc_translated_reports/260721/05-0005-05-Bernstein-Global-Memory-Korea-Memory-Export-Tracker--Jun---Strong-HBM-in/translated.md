我们追踪韩国出口数据，因其是三星和SK海力士同季度HBM收入的良好先行指标，并利用6月数据更新此追踪。方法详见我们之前的报告。数据集可在此链接下载。

整体HBM出口非常强劲，环比3月增长46%，再创历史新高。6月数据因季节性因素环比增长45%，更重要的是环比增长46%。2026年第二季度整体出口环比增长39%。

数据显示三星2026年第二季度HBM增长可能超出我们的预期。忠清南道（三星封装HBM的所在地）出口环比增长2倍，强于预期。2026年第二季度整体环比增长75%。回归模型预测三星2026年第二季度HBM收入环比增长89%至67亿美元，高于我们的模型。

SK海力士出口保持强劲。6月忠清北道和利川出口环比回升11%，环比增长5%。回归模型预测SK海力士2026年第二季度HBM收入环比增长25%至76亿美元，符合我们的预测。

数据显示三星HBM4持续爬坡。由于HBM单位重量价值更高，我们追踪“单位重量价值”，因其可能指示HBM价格变化方向。三星6月“单位重量价值”环比再增长30%，但SK海力士基本持平。我们认为这可能是三星HBM4持续爬坡所致，而非广泛的HBM价格上涨。过去几个月的趋势对三星总体积极，但对SK海力士持平或下降。

数据显示HBM价格未受传统存储器价格波动影响。传统存储器价格飙升，但HBM价格（如单位重量价值所示）基本维持原有区间，SK海力士数据可佐证。

对马来西亚出口大幅反弹。6月飙升至11亿美元，主要得益于三星出口复苏。过去几个季度对马来西亚出口总体显著增长。除台湾和马来西亚外，未见HBM出口至其他目的地，也未发现三星或SK海力士在我们未追踪的地点生产HBM。因此我们的方法仍然稳健。

整体6月数据显示2026年第二季度HBM增长强劲，三星HBM4爬坡迹象显著。两者中，三星表现强于预期，SK海力士符合预期。我们仍认为三星在HBM4中地位提升，并将在2026年下半年获得更多动力。另一方面，HBM价格当前重新定价应引发2027年盈利上调。

传统存储器价格将在2026年第三季度继续上涨，HBM价格上涨也应带来盈利修正。我们预计2027年第三季度价格持续上涨，且2027年HBM价格上涨将带来更多盈利修正。我们仍结构性看好三星、SK海力士和美光，但看空KIOXIA（受中国竞争影响，见我们的行业更新）。我们的详细SOTP估值也发现KIOXIA估值过高。

## 详情：公司情况更新

韩国海关总署已发布6月出口数据。如我们之前的报告所述，特定存储器产品的出口数据与三星和SK海力士的HBM收入高度相关。因此我们追踪月度数据，为读者提供两家公司同季度HBM收入的预览。方法详见之前的报告。您也可在此链接下载出口数据。

出口数据显示，得益于6月非常强劲的表现，三星2026年第二季度HBM收入可能显著超出我们的预期。SK海力士HBM收入显示健康增长，符合我们的预期，但增速明显慢于三星。

- 6月韩国对台湾和马来西亚的多芯片存储器出口总额环比强劲增长45%，达到62亿美元的历史新高。6月数据环比（对比3月）增长46%，同比增长119%（图表1）。整个2026年第二季度，出口环比显著增长39%。如我们之前分析，对台湾和马来西亚的多芯片存储器出口与三星和SK海力士的HBM收入紧密相关，因此6月数据表明2026年第二季度势头强劲且加速。

- 若聚焦忠清南道（三星后端工厂所在地，可能也是其HBM封装地）的出口，6月出口飙升至34亿美元，较5月翻倍。我们还注意到，三星6月单月出口自2024年初HBM出口启动以来首次超过SK海力士（图表2）。2026年第二季度整体出口环比增长75%，显著强于我们对三星2026年第二季度HBM增长51%的预测（图表3）。根据历史数据的回归模型，4-6月数据显示三星2026年第二季度HBM收入为67亿美元，较我们估计的54亿美元高出25%，环比增长89%（图表4）。若仅使用2025年第一季度数据点进行回归，4-6月数据同样显示2026年第二季度HBM收入约为67亿美元（图表5）。与之前几个季度相比，三星2026年第二季度HBM出口月度季节性确实更偏向后端，55%的出口来自6月。但我们注意到2025年第二和第三季度的季节性也高度偏向后端，我们想知道2026年第三季度是否会呈现类似模式（图表6）。总体而言，三星2026年第二季度HBM增长势头快于预期，主要受6月强劲表现支撑。这也与三星关于HBM4爬坡将在2026年下半年显著加速的指引一致，因此我们仍看好三星今年HBM市场份额增长（见三星2026年第一季度业绩要点）。

- 对于SK海力士，我们确定其HBM出口应几乎全部来自忠清北道和利川市（其晶圆厂所在地）。6月出口数据环比增长11%，环比（对比3月）增长5%（图表7）。2026年第二季度整体出口环比增长19%，与我们当前对SK海力士2026年第二季度HBM收入增长25%的预测相当接近（图表8）。回归模型也发现出口值显示SK海力士2026年第二季度HBM收入为76亿美元，完全符合我们的预测（图表9）。与三星偏向后端的季节性相比，SK海力士出口的月度季节性继续相对均衡（图表10）。综合来看，数据显示SK海力士HBM可能健康增长，符合我们的估计，但增速明显慢于三星。

## 三星的单位重量出口价值在6月进一步飙升，可能得益于HBM4出货量增加。

- 韩国多芯片存储器的单位重量出口价值与HBM平均售价大致相关，尽管可能仅具有方向性指示意义，不足以进行精确估算。6月，忠清北道+利川（SK海力士的代理指标）的单位重量出口价值环比基本持平。但忠清南道（三星的代理指标）的数据在6月继续强劲增长，环比再增30%，较4月累计增长70%（图表11）。这与月度出口激增一起，可能都与HBM4出货量增加有关，HBM4的单位重量价值应显著高于HBM3E。三星预计其HBM4将在2026年第三季度超越前代产品，过去两个月的数据确实

- 另一个重要观察是，虽然传统存储器价格快速上涨，但数据显示HBM价格要稳定得多。忠清南道的单位重量出口价值确实增长，但这是由于HBM4带来的产品组合改善，而非HBM普遍涨价。考虑到SK海力士在HBM领域规模更大且其单位重量价值呈下降趋势，综合平均值甚至有所下降。尽管如此，我们相信供应商和客户目前正在就2027年的HBM合同和价格进行谈判。我们预计这将引发2027年盈利的上调，并将在短期内支撑存储器报价。

\- 6月对马来西亚出口环比大幅反弹231%，至约11亿美元，可能主要受季节性因素影响。过去6个月平均运行率为5.5亿美元，而对台湾出口为35亿美元。据了解，马来西亚是英特尔高端封装工厂所在地，部分配备HBM的高端服务器CPU在此采用EMIB封装。此外，我们注意到客户对EMIB的兴趣日益增长，且英特尔今年也将投产一座新的先进封装厂（链接）。然而，即使客户决定采用，我们认为任何量产仍需1-2年时间，并质疑为何HBM对马来西亚出口如此之早。总体而言，对马来西亚出口值得持续关注。

\- 对马来西亚出口反弹主要归因于三星，且明显也受季节性驱动。尽管三星对马来西亚出口在2026年第二季度整体增长强劲（图表15）。SK海力士工厂出口在6月略有回升，但整体基本持平（图表16）。总体而言，对马来西亚出口增长迅速，且三星受益更多，这也是三星HBM收入增长的原因之一，同时支持了三星在HBM领域客户认可度的扩大。

\- 从出口来源地看，6月数据显示，忠清南道、忠清北道和利川继续占据对台湾和马来西亚多芯片存储器出口的绝大部分（图表17）。因此，三星或SK海力士似乎均未在韩国其他地点开始HBM封装。

\- 总体而言，上述所有数据表明，HBM出口继续主要集中在台湾，马来西亚程度较低。然而，我们想指出我们方法的局限性。其一，如果其中任何一家将HBM封装移至韩国境外，该出口数据将无法捕捉。但我们认为这短期内不会发生。其二，如果其任何HBM出货在韩国境内被消耗（即封装成其他产品），也不会反映在我们的分析中。我们认为第二个局限性可能随着Amkor（AMKR US，未覆盖）已在韩国进行小规模类CoWoS生产，且未来可能进一步增加而变得更加相关。

## 总体而言，6月数据非常强劲，尤其是三星，表明三星2026年第二季度HBM收入增长快于预期，同时HBM4持续爬坡。

\- 总结而言，6月数据非常强劲，部分受季节性因素驱动。三星数据更为强劲，通过回归分析，表明三星2026年第二季度HBM收入环比增长89%，SK海力士增长25%。三星的快速增长可能部分得益于HBM4出货量增加，这从其6月出口单位重量价值持续飙升中得到支持，且显著领先于我们当前的预测。SK海力士的预测增长基本符合预期。尽管Rubin进展较慢，但HBM需求势头依然非常强劲。对马来西亚出口也已反弹，且过去几个季度总体保持显著增长。
