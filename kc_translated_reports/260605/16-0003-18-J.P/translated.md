# 监管转向的真正含义：小微贷款从“量”的竞赛进入“质”的清算

# 中国银行业

# 小微企业政策转向——短期资产质量阵痛，中期收益率回升。对银行影响各异

中国金融监管机构已从鼓励银行扩大普惠贷款转向关注贷款质量与可持续性（表4）。我们认为，这一转变是对小微企业信用风险上升（表2-表3）及贷款需求相对疲软的反应。鉴于小微企业偿债能力恶化，普惠贷款增速放缓可能在短期内加剧资产质量压力。但中期来看，这可能缓解定价竞争，并支持普惠贷款收益率温和回升。对银行的影响各不相同。我们偏好建设银行、浦发银行和重庆农商行，这三家银行2025年个人经营性贷款（普惠金融子类别）不良率均有所下降，并有望受益于贷款收益率改善。相比之下，我们对此议题上的邮储银行和沪农商行保持谨慎，因其普惠金融敞口较大（图8）且资产质量压力持续。

- **有何新变化？** 5月19日，国家金融监督管理总局发布《关于2026年小微企业金融服务工作的通知》（链接），最重要的变化是取消了明确鼓励小微企业贷款增长的要求。2026年通知不再聚焦于规模增长，而是将政策目标重新定位为信贷结构优化和资产质量提升。

- **重温小微企业贷款监管转向——从数量竞赛到质量竞争（表4）。** 国家金融监督管理总局于2018年正式引入“两增两控”框架，要求银行确保普惠型小微企业贷款增速不低于各项贷款增速、有贷款余额的户数不低于上年同期水平，并对五大行设定了更高目标。自2023年起，“两增”硬性要求被取消，但监管机构继续在方向上引导银行保持较高的小微贷款增速。2026年通知标志着从数量到质量的更决定性转向，未提及小微企业贷款增长目标，同时强调资产质量改善。

- **我们看到小微企业贷款资产质量风险上升：** 国家统计局PMI数据显示，5月大型企业PMI环比上升至51.1，而小型企业PMI下降至48.5（图1）。数据还显示，自新冠疫情以来，大型与小型企业之间的利息覆盖倍数和应收账款周转天数出现显著分化。小型企业的利息覆盖倍数明显更低（图2），应收账款周期显著长于大型企业（图3）。中国人民银行的指导变化可能导致普惠贷款增速进一步放缓（图4、图5）；我们认为这将在短期内加剧小微企业贷款的资产质量压力。

- **近年来小微企业贷款的经济效益显著恶化：** 从2022年到2025年，新增普惠金融贷款利率收窄1.2个百分点至3.31%，而普惠金融子类别个人经营性贷款的不良率上升70个基点至1.66%。我们尚未看到这一恶化趋势的拐点，但浦发银行和建设银行除外，其个人经营性贷款不良率在2025年同比略有改善。

# 银行与金融服务

- **一线希望在于普惠金融贷款收益率可能在中期内改善：** 随着贷款增速放缓，尤其是国有大行，我们可能看到贷款定价温和改善。但幅度可能较小，因为银行风险偏好依然较低，且小微企业偿债能力尚未恢复。
- **对国有大行和股份行的影响——偏好建设银行和浦发银行，规避邮储银行。** 我们认为民生银行在此议题上面临风险：积极方面，建设银行和浦发银行2025年个人经营性贷款不良率有所收缩（表2），因此如果竞争缓和后贷款收益率能够改善，普惠金融的经济效益可能提升。消极方面，邮储银行对普惠金融贷款的敞口最高，且2025年该组合的贷款收益率持续收缩、不良率持续上升（表1、表2）。对于民生银行，尽管过去三年其在个人经营性贷款资产质量管理方面表现较好，但由于其普惠金融组合规模相对较大，股价表现可能仍将滞后。
- **对城商行和农商行的影响：** 我们认为，对于具备真正小微企业服务能力的区域性银行，短期阵痛但长期受益。短期内，压力在于资产质量。我们尚未观察到所覆盖银行个人经营性贷款不良率的拐点（表3），且任何大型银行从小微企业领域的信贷退出都可能放大还款压力。长期来看，大型银行非理性定价压力的减轻应为净息差复苏和在其主要经营区域逐步稳定市场份额创造空间。在我们覆盖的银行中，我们认为沪农商行面临更大的短期资产质量下行风险，因其普惠金融敞口最大（图8）且个人经营性贷款资产质量持续恶化（表3）。然而，长期解读是建设性的。自2020年以来，沪农商行的小微企业增长一直受到大型银行激进竞争的重大制约（图9）。随着竞争动态正常化，我们相信沪农商行凭借其深厚的本地知识和有效的“信贷工厂”信贷模式，将处于最佳位置以重获市场份额。在观察到其资产质量的积极信号之前，我们对沪农商行保持谨慎。我们看好重庆农商行，因其个人经营性贷款不良率在2025年下半年环比收缩49个基点，可能受益于当地宏观复苏和更好的承贷能力（表3）。
