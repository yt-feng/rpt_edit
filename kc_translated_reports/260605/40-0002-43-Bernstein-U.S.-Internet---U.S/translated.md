# 美国互联网与美国中小盘软件股
# AWS网络指标数据：2026年第二季度中期出现警示信号？

过去几个季度，我们定期更新的网络指标显示需求信号异常强劲——可以说是新冠疫情以来最强。这一强势已转化为已公布业绩，随着AI工作负载逐步增加，AWS收入增长加速，Datadog、Snowflake和Cloudflare等与云消费相关的公司也是如此。话虽如此，我们想提醒一个正在密切关注的变化趋势：过去四周（加上本周初），增长异常持平，与过去三年观察到的模式形成对比（图表2）。提醒：这是历史拟合度良好的替代数据，但出于多种原因，它可能不再具有预测性。基本面解释仍然重要。

预计对第二季度收入影响有限。重要的是要记住，我们的数据实际上比已公布的财务数据领先一个季度。我们衡量的是更接近本季度新增的年度经常性收入（ARR），而已公布业绩反映的是来自现有ARR的后付费账单和收入确认。因此，第二季度收入应主要反映我们在第一季度网络指标信号中看到的强势（图表1）——我们认为第二季度可能再加速100个基点。

对第三季度非AI收入影响可能有限。第二季度开局强劲，因此如果近期隐含的疲软在6月逆转，第三季度仍将实现“正常”的环比增长。请注意，由于2025年第三季度基数强劲，非AI增长可能面临适度的数学上的同比逆风。

第四季度可能成为问题。更具挑战性的情况是，如果当前的持平趋势持续到第三季度的网络指标数据。如果趋势保持低迷，结果将是第四季度非AI消费面临显著的同比增长逆风。

是什么导致了疲软。我们询问了顶级软件公司的领导者、大型成长型软件私募股权组合以及与企业买家合作的顾问，听到的共同观点是：超大规模云服务商正面临容量限制，增量计算资源大量分配给前沿AI实验室，留给其他买家（例如企业、软件供应商）的可用供应减少。更具体地说，从产品团队买家内部一个深度整合的来源，又出现了几个论点：1) 由Mythos引发的网络紧急事件造成了巨大的待处理问题积压。公司正在争分夺秒地处理这些问题，而不是着手下一个增量新工作负载。2) tokenmaxxing后遗症，一些产品团队试图减缓在编码代理和AI副驾上的支出增长。在快速采用一段时间后，正在努力重新调整并施加纪律。

无论驱动因素是什么，这种转变都值得注意，并引发了一个我们将持续关注的警示信号。第三季度及以后消费环境疲软可能会影响传统企业买家和云软件供应商的需求，而对“生于AI”群体（即与AWS和Datadog相关的AI轨迹）的问题较小。

AWS能否受益？实际上，供应限制意味着获取容量以将新工作负载投入生产的环境更具竞争性，这可能会给AWS带来定价优势。同样，如果可用容量已转向利润率更高的AI工作负载，那么AWS的财务状况也可能处于更有利的位置。

# 我们为何关注AWS网络指标数据

# SSO数据作为AWS非AI收入的领先指标

正如我们在过去几年中分享的，我们观察到AWS单点登录（“SSO”）页面的上一季度（上个季度）参与度与当前季度AWS收入增长之间存在强相关性。这合乎逻辑，因为与SSO的人机交互量不太可能因个人工作偏好而大幅波动，相反，它更可能代表实际负责在AWS上执行项目的人员比例。而且，由于任何个人能够完成（并被期望交付）的工作量随时间推移保持相当稳定，并且他们的工作会转化为相似数量的收入（存在一些由价格表变动和生产率变化等问题造成的曲率，可以进行修正），那么人员数量将通过SSO流量转化为消费量。

然而，这种人力工作水平是在收入被观察到之前发生的。为什么这说得通？他们的工作转化为消费，而消费在接下来的时期才更充分地实现（介于项目和使用量的爬坡期，以及季度内的时间安排无法提供整个季度的使用量之间）。我们的数据每日可用，因此我们测试了各种时间偏移，发现最高相关性约为一个季度。因此，上一季度SSO的人力参与水平是本季度收入确认变化的领先指标。

但仅凭参与水平本身仍有拟合上的变化。随着时间的推移，AWS会调整其费率卡、提供积分、经历合理化调整（改变人均消费），甚至存在可能拉动部分收入的销售行为。我们试图调整这些变化，并仅对“基础”AWS收入进行回归分析。

# 提醒：即使历史拟合度良好，替代数据也可能因多种原因失效。

我们过去曾看到该数据在短期内出现波动。鉴于这一现实，我们此前并未提及这种偏差。但持续4周以上的疲软似乎更可能成为一种趋势。话虽如此，这种解读可能出错的地方很多。例如，供应商本身甚至偶尔会改变其数据收集方法，在过渡期造成异常。当基本面解释支持数据时，我们最感兴趣。我们正在持续收集可能反驳（或进一步确认）该趋势解读是否合理且能预测未来财务结果的数据点。

# 估值方法

# Amazon.Com Inc

我们基于目标价315美元对亚马逊进行估值，采用50/50的SOTP方法与DCF组合。SOTP方法对其最大业务板块（零售）按2027年预期EV/销售倍数3倍进行估值；DCF采用9%的WACC和3.5%的终值增长率。

# Datadog Inc

我们180美元的目标价是DCF（WACC 11%，终值增长率3%）与P/S（未来5-8个季度）可比倍数的平均值。P/S（未来5-8个季度）可比倍数14倍，基于我们“40法则”估值框架分析中，其相关运营利润率>10%的云SaaS同行的回归结果。我们假设当前云SaaS倍数回归线在未来1年以上保持一致。

# Twilio Inc

我们183美元的目标价是DCF（WACC 11%，终值增长率3%）与P/S（未来5-8个季度）可比倍数的50/50平均值。P/S（未来5-8个季度）可比倍数4.5倍，基于我们“40法则”估值框架分析中，其相关运营利润率云SaaS同行的回归结果。我们假设当前云SaaS倍数回归线在未来1年以上保持一致。

# Cloudflare Inc

我们136美元的目标价是DCF（WACC 10%，终值增长率3%）与16倍P/S（未来5-8个季度）可比倍数的平均值。P/S（未来5-8个季度）可比倍数选自我们估值框架分析中运营利润率超过10%的云SaaS同行。我们假设当前云SaaS倍数回归线在未来1年以上保持一致。

# 风险

# Amazon.Com Inc

目标价下行风险：

- 亚马逊目前在美国国内及海外，因反垄断和隐私问题，正面临多项监管程序的调查。FTC、DOJ或欧盟机构的任何法规或行动都可能对公司的财务状况和估值产生负面影响。
- 在杂货、医疗保健、AI及其他押注领域的新投资，可能导致新的投资周期，从而增加资本密集度、压缩运营利润率并降低自由现金流。
- 来自新电商进入者和主要AWS竞争对手的核心业务市场份额流失，可能导致两个核心业务的相关倍数下降。

# Datadog Inc

除宏观经济风险外的下行风险包括：来自行业内资金雄厚竞争对手的竞争加剧；由于运营成本项目规模杠杆效应不佳，利润率扩张慢于预期；鉴于当前估值，执行失误或盈利不及预期可能导致显著下行。

# Twilio Inc

除宏观经济风险外的下行风险包括：未来协同并购活动放缓；CPaaS板块整体增长放缓，尤其是来自暴露于零售消费的客户群；来自行业内资金雄厚竞争对手的竞争加剧；鉴于当前估值，执行失误或盈利不及预期可能导致显著下行。

除宏观经济风险外的上行风险包括：规模杠杆带来的单位经济效益好于预期；行业竞争对手未能赶上Twilio的产品。

# Cloudflare Inc

除宏观经济风险外的下行风险包括：持续与云增长挂钩，销售模式转型的执行风险；消费和收入可预测性较低；构建可信的第二/第三阶段产品并展示需求，超大规模云厂商进入其核心CDN和扩展安全业务，高估值。

上行风险包括：AI推动对其边缘PaaS的需求，以及成功销售更广泛的网络安全平台，两者任一或共同导致收入超预期。
