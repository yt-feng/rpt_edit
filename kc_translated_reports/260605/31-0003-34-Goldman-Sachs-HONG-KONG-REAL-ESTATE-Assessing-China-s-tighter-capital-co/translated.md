# 香港房地产  
# 评估中国更严格的资本管制。分析需求驱动因素、风险敞口及盈利敏感性  

在中国证监会于5月22日发布新规以打击非法境外经纪和投资活动（链接）后，国务院于6月1日又发布了一份文件，为企业及个人的境外投资制定了指导方针（链接）。部分评论人士认为，该指导方针的范围从仅涵盖企业扩大到也涵盖“个人”投资者，这标志着中国政府可能更严格地审查境外个人投资者，从而可能增加内地居民在香港购房的难度。在本报告中，我们通过分析人口/移民趋势及近期销售交易数据，以更好地了解买家画像和住房需求驱动因素，从而回应上述担忧。

# 内地买家已成为主要购房群体。他们倾向于购买新房而非二手房。

回顾一下，去年香港共成交6万套住宅单位，总销售额达5170亿港元，较疫情期间2022-23年的约3900亿港元大幅回升，但仍低于2021年7120亿港元的此前峰值（图表1）。这一势头延续至今年，2026年前四个月销售额同比增长71%至2230亿港元。正如我们此前报告（链接、链接）所讨论的，我们将楼市复苏归因于强有力的政府支持——2024年初取消了所有紧缩措施（如买家、卖家印花税），并出台了更积极的人才和移民吸引政策。活跃的股市也吸引了更多流动性和内地投资者来到香港，否则这些资金可能流向上海、深圳及其他内地城市。事实上，根据中原地产的销售数据（该数据通过普通话拼音记录买家姓氏的交易；注：中原地产的“内地买家”分类是基于普通话拼音姓名的代理指标，未考虑居住身份，因此数据包括常驻香港的内地居民及拥有拼音式姓名的本地居民），内地买家购房总额从2023年的960亿港元翻倍至2025年的1820亿港元（成交量从5800套增至14800套，增长两倍），分别占去年香港房地产总销售额和成交量的35%和25%（2023年分别为25%和14%）。数据还显示，内地买家倾向于购买新房，按价值计算占其购房总额的63%（即1140亿港元）。香港

# 维持我们对香港楼市多年上升周期的看法

虽然我们对任何结果不持立场，但该指导方针本身并未明确新增任何收紧资金流向香港的措施。我们认为，潜在影响（如有）将主要针对大额交易。过去我们观察到，当管制收紧时（例如2016年），会出现替代/新的渠道将资金转移至香港，这在一定程度上缓解了影响。如图表9所示，内地居民有几种合法方式将现金携带或转移至境外：（1）国家外汇管理局设定的个人年度限额为5万美元或34万元人民币；（2）每次出境旅行可携带2万元人民币；（3）每日通过银联卡在ATM取现1万元人民币，年度上限10万元人民币；（4）自2021年9月启动的跨境理财通计划下，大湾区合资格居民可向香港汇款最高300万元人民币（链接）。将这些渠道加总，个人每年可转移或携带至境外的资金不超过400万元人民币（或双人家庭不超过800万元人民币）。假设内地买家承担典型的70%按揭贷款并需支付30%首付，其购房价值个人买家可能低于1300万元人民币（或家庭低于2600万元人民币）。事实上，去年内地买家购买的14800套住房中，78%（即11500套）价格低于1200万港元（图表6）。

尽管如此，现在评估还为时过早，但考虑到购房资金转移的合法渠道，风险可能集中在价格远超上述水平的房产上。与此同时，我们也有其他理由相信当前的上升趋势不太可能被逆转。

# ■ 中国买家的大多数购房行为由被压抑的需求驱动。

投资需求仍占少数——正如我们在行业报告（5月19日、2月18日）中所讨论的，我们提出香港住宅市场“多年上升周期”的核心驱动力是供需失衡。供给端方面，经过数年市场情绪低迷，土地销售（即政府卖地、港铁项目招标、市区重建等）仍落后于政府2026财年2.2万套的目标，表明住宅供应持续难以达到每年2.6-3.4万套的目标。需求端方面，各类新签证计划（即2022年推出的面向年薪超过250万港元或毕业于全球百强大学人士的“高端人才通行证计划”）吸引了大量申请，使2023-25年每年获批签证总数增至12-14万份（疫情前为6-7万份）（图表11）。自2018年社会动荡以来，政府累计批准了66万份签证申请，媒体（链接）此前报道其中约一半或约30-40万人目前居住在香港（2018年为6-7万人）。如果我们假设这些新增的24-33万人或家庭中有一半决定在香港购房，这将转化为12-16万套的增量住房需求。根据中原地产数据，同期仅有5.2万宗内地买家交易，由此可推断：（1）近年来售出的5.2万套单位中，大部分由终端用户需求驱动，而非投资目的；（2）积压需求仍然相当可观，对未来的成交量趋势构成支撑。量化来看，如前所述，香港住宅交易中35%/25%的成交额/成交量可归因于内地买家。如果我们假设其中约20%为投资需求，根据开发商观察，那些更易受资本管制或审查影响的部分仅占约7%/5%。

# 租金增长前景乐观，空置率低。香港住宅物业的租金收益率仍优于中国内地一线城市及其他亚洲门户城市——

在过去3年累计上涨约20%之后，年初至今租金仅增长+1.4%，增速放缓表明部分需求已从租房转向购房。尽管房价年初至今已上涨约10%，但香港业主仍可享受温和的正利差，平均租金收益率为3.3%（B类单位），而按揭利率为3.25%。这仍优于其他中国内地一线城市及亚洲门户城市，例如新加坡/北京/深圳/上海的租金收益率分别为2.9%/2%/1.8%/1.7%。我们认为，购房与租房的选择将继续影响未来几个季度的短期物业销售势头。积极的一面是，基本面依然向好，2025财年末空置率仅为4.3%（历史均值约5%），而住宅供应紧张（即1.6万套未售库存加上1.2万套计划推出新盘）。利率方面，我们的宏观团队仍预计美联储将在2026年12月和2027年3月分别再降息25个基点（5月11日），但通胀上升引发了对降息可能延迟或逆转的担忧。即使在美国加息的情景下，正如金管局此前并未跟随美联储降息，如果银行体系流动性依然充裕（如当前情况），也未必需要跟随加息。

# ■ 政府在移民政策、购房政策方面仍保持支持。过往周期表明人民币贬值是需关注的关键风险——

尽管更严格的审查和资本管制可能影响市场流动性并可能抑制购房（尤其是上述豪宅），但我们认为政府在住房相关其他领域的政策仍总体保持支持，例如签证/移民政策、北部都会区发展。去年，香港财政司司长陈茂波据报曾与内地政府讨论，探索适当放宽对定居香港并希望购买香港物业的内地工人和移民的资本转移限制（链接）。从过往经验看，流动性收紧和资本管制通常与人民币大幅贬值相伴。而本轮周期中，人民币兑美元在过去一年实际上升值了6%。

# 开发商对高端、豪宅的敞口。盈利及资产净值敏感性分析

如上所述，我们认为更严格的审查和资本管制，尤其是针对可能出现的任何替代渠道，可能会影响：（1）豪宅单位的销售去化；（2）并非真正终端用户、也不一定计划定居香港的内地投资者——根据我们上述假设，这意味着内地投资需求占香港物业销售的比例不超过10%。在我们覆盖的开发商中，我们注意到嘉里建设、长江实业和恒基兆业的高端（售价每平方英尺2.5万港元或以上）可售资源（剩余库存+今年计划推出项目）占比较高，分别为41%、44%、32%，而新鸿基地产为22%（图表15）。

回顾一下，我们预测2026/27/28年香港房价分别上涨+15%/+7%/+4%。在悲观情景下，假设我们的房价/成交量预测分别下调-5%/-10%，合计导致合同销售预测下调-15%，我们预计2026-28财年覆盖的开发商盈利平均影响为-2%至-9%。我们2026财年的资产净值预测可能下调-3%至-9%，其中新世界发展和嘉里建设因财务杠杆较高而最为敏感（图表17）。图表20列出了我们覆盖的所有香港地产股的详细资产净值分解。虽然并非直接可比，但我们注意到，过去每当出现与流动性收紧或资本管制相关的消息时，澳门博彩股往往会出现相当大幅度的回调（图表18）。与香港地产股相比，澳门博彩业对中国灰色地带流动性的敞口要大得多（周期内为20-50%），而如上所述，香港地产股的内地投资者占比不到10%。我们认为近期的回调是持续积累我们给予买入评级的香港地产开发商股票的好机会：恒基兆业地产（位于确信买入名单）、新鸿基地产和信和置业。

# 目标价风险及方法论 - 新鸿基地产

我们对新鸿基地产的评级为买入。我们的12个月目标价为170.0港元，基于2027财年预期资产净值（目标资产净值折让为-30%）。

主要下行风险包括：1) 股息派发率低于预期。2) 美元利率较预期更高更久；3) 香港及内地购房者信心持续低迷；4) 银行或债券市场融资条件收紧。

# 目标价风险及方法论 - 信和置业

我们对信和置业的评级为买入。我们的12个月目标价为16.0港元，基于2027财年预期资产净值（目标资产净值折让为-30%）。

主要下行风险包括：1) 政府土地出售政策更为保守，导致缺乏合适的土地收购目标及未来上行潜力不足。2) 香港零售及写字楼板块复苏逊于预期，租金回报率未达预期，对公司投资物业组合表现构成压力。3) 住宅物业需求低于预期，例如人口流入慢于预期及内地买家热情减退，导致香港住宅项目销售低于预期。4) 政府为冷却香港楼市而实施比预期更严格的调控政策。

# 目标价风险及方法论 - 恒基兆业地产

我们对恒基兆业地产的评级为买入。我们的12个月目标价为41.0港元，基于2026财年预期资产净值（目标资产净值折让为-40%）。

主要下行风险包括：1) 政策支持力度不及预期，可能严重削弱购房者信心，导致市场复苏低于预期。2) 美联储降息幅度不及预期，意味着美联储维持紧缩货币政策的时间长于预期，可能通过增加借贷成本及降低潜在购房者的购买力，直接影响买家负担能力。3) 农地收回进度慢于预期（这对城市扩张及新开发项目通常至关重要），可能延迟新土地及基础设施的供应。同时，北部都会区政策支持不足（例如针对特定区域发展计划），可能阻碍相关区域的投资，导致物业需求疲弱及项目执行进度放缓。4) 香港投资物业组合表现逊于预期，原因包括零售复苏不及预期、写字楼供应过剩、商业活动减少或投资者对该区域情绪转变。

# 目标价风险及方法论 - 新世界发展

我们对新世界发展的评级为中性。我们的12个月目标价为11.0港元，基于2026财年预期资产净值（目标资产净值折让为-85%）。

主要上行风险包括：1) 资产出售好于预期。2) 利率低于预期。3) 房价复苏好于预期。主要下行风险包括：1) 商业地产市场弱于预期。2) 资本开支削减幅度低于指引。3) 银行贷款及债券市场收紧程度高于预期。

# 目标价风险及方法论 - 嘉里建设

我们对嘉里建设的评级为中性。我们的12个月目标价为26港元，基于2026财年预期资产净值（目标资产净值折让为-70%）。

上行风险包括：1) 企业重组举措，可能导致投资物业部门分拆以释放价值；2) 政策支持改善购房者信心；3) 美联储降息提高买家负担能力。下行风险包括：1) 美元利率较预期更高更久；2) 香港及内地购房者信心持续低迷；3) 银行或债券市场融资条件收紧。

# 目标价风险及方法论 - 长江实业集团有限公司

我们对长江实业的评级为中性。我们的12个月目标价为56.0港元，基于2026财年预期资产净值（目标资产净值折让为-50%）。

主要风险：(1) 香港住宅物业销售好于/差于预期，导致收入、盈利及股东回报水平上升/下降；
(2) 中国内地一手房市场状况好于/差于预期，导致销售水平及/或潜在土地储备重估价值上升/下降；
(3) 香港写字楼市场动态好于/差于预期，导致租金回报率水平上升/下降；
(4) 基建/公用事业及公共业务表现好于/差于预期。
