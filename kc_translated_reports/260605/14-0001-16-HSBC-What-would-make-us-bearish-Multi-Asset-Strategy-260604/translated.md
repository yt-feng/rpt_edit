# 什么会让我们转向看空？
# 多资产策略

这是我们目前最常被问到的问题：鉴于我们激进的risk-on立场，什么会让我们转向看空？
- 更高的盈利预期、地缘政治以及美债收益率上升，在我们的清单上都排名靠后
◆ 任何情绪和仓位过热的迹象、AI支出放缓以及芯片供应增加，是我们最大的担忧

# 极度看多

尽管我们在战术资产配置上仍保持激进的risk-on，但在近期的交流中，我们一直收到一个相同的问题：什么会让我们转向看空？

# 排名靠后

1. 过高的盈利预期：市场一致预期美国二季度每股盈利将环比小幅下降。因此，短期内的盈利预期实际上应成为另一个上行催化剂，因为其很容易被超越。下半年超越的难度更高，但如果二季度出现与一季度类似的惊喜，这些担忧很可能会烟消云散。
2. 地缘政治：近期能源价格已趋于稳定，因此要让冲突再次广泛拖累风险资产，我们需要看到局势升级到足以盖过科技/AI/潜在二季度盈利惊喜带来的乐观情绪的程度。
3. 更高的利率：强劲的一季度盈利、掩盖了股票和信贷市场内部疲软的高度指数集中度、较低的利率波动水平，以及美国对利率敏感度显著降低，都是风险资产保持稳定的原因。自上次FOMC会议以来，美国前端利率（2026年12月）已重新定价约30个基点。因此，要超出这一鹰派预期可能颇具挑战。

# 排名靠前

4. 情绪和仓位：我们并不太担心即将到来的大型IPO。股票供应增加带来的潜在逆风，很可能被此前“困在”私募市场、如今被“解锁”的财富所抵消。我们更担心的是，来自中东的任何利好消息流可能引发股票和信贷市场的真正广泛上涨——这反过来很容易在我们的仓位框架中触发一个明确的卖出信号。

5. 科技/AI放缓：科技/AI作为美国股市的主要驱动力，目前对美国居民财富构成了风险。如果科技/AI走弱，将对整体增长构成下行风险。AI支出放缓当然是一个风险。但大量的积压订单使得这种情况在未来几个月内不太可能发生。潜在效率提升以及中国在DDR5市场追赶带来的内存价格下降是另一个风险，但不太可能在下个季度出现。

# 1. 盈利预期过高

过去几个月我们一直警惕的一点是，盈利预期（尤其是在美国）在持续上调。在连续出现高于平均水平的正向盈利惊喜之后，任何失望都可能使当前美国股市估值受到质疑。

但可以肯定的是，对于二季度而言，盈利预期看起来非常容易超越（图表1）。

# 2. 地缘政治

地缘政治可能是最明显的风险——不仅包括中东冲突，还包括美国新的关税公告（参见5月25日美伊谈判；以及6月3日美国关税公告）。但同样，这在我们看空担忧清单上的排名并不靠前。过去13个月，美国政府频繁在关税问题上退缩，因此风险资产不太可能计入显著的风险溢价。

中东冲突仍然是影响石油、利率以及部分外汇市场的主要力量（图表4和5）。但要让冲突再次广泛拖累风险资产，我们很可能需要看到局势升级到足以盖过围绕AI、芯片和内存的任何乐观情绪的程度——在全球一季度财报季大丰收之后，市场对这些领域的情绪高涨。

# 4. 更大的担忧：情绪与仓位...

我们最担心的两件事是：i) 情绪与仓位过度拉伸；ii) AI支出、AI部署放缓，或芯片价格下跌。

就情绪与仓位而言，我们的短期框架并未发出风险资产的卖出信号（图表14）。系统性策略的仓位情况也是如此——尽管有迹象显示仓位终于趋于中性（CTA、风险平价、波动率目标策略，图表15）。此外，即将到来的大型IPO并不令我们真正担忧，因为更高的股票供给应会被此前"锁定"在私募市场的流动性"解锁"所抵消。

与"解放日"不同的一个方面是长期投资者的仓位（图表16和17）。他们显然没有像去年那样大幅降低风险，并且迅速逢低买入，尤其是股票（信贷方面则较少）。

不同寻常的是，迄今为止股票和信贷的上涨相当狭窄。任何持续的中东正面消息流都应导致广度改善，落后板块迎头赶上。这种更广泛的上涨很容易触发卖出信号，尤其是长期投资者目前的股票敞口已经高于"解放日"之后。

# 5. ....以及真正的大问题：AI放缓

我们最大的担忧是AI支出、AI应用放缓，或内存价格下跌。科技和AI现已成为美国和新兴市场股票的主要组成部分（图表18）。

尽管这听起来可能有争议，但消费或劳动力市场等前景对风险资产而言已不再那么重要。换言之，强劲的劳动力市场、消费和整体增长的任何组合，如果恰逢AI和内存主题放缓，都可能被视为非常利空。

如今财富效应可能更为重要，尤其是在美国。与金融危机前相比，这种财富效应更成为股票的函数（图表19）。这意味着科技和AI股价的任何持续下跌也会拖累整体股价。这种下跌随后可能导致负财富效应。鉴于高收入家庭现在在消费中占比更大，这也可能对消费产生负面影响——典型的厄运循环。

AI/科技主题的放缓可能来自何处？一个角度是AI支出/资本支出放缓：然而，需求依然如此强劲，产能受限，而且——更值得注意的是——积压订单如此庞大，以至于很难看到未来几个月AI支出大幅放缓。

另一个角度是内存价格下跌：我们的科技分析师预计，较高的内存价格趋势应持续到年底，并可能延续至2027年上半年（参见《全球科技》，5月22日，以及SK海力士（000660 KP），5月12日——图表20和21）。

风险来自：1) 新模型的效率提升可能抑制需求——例如，谷歌最近的TurboQuant论文强调了可能减少内存使用量的新方法（TurboQuant指出，LLM KV缓存压缩潜力高达6倍且无质量损失，可释放GPU内存并提升推理速度，例如可能使处理速度提高8倍，且无需重新训练）。

2) 随着中国大陆在DDR5市场迎头赶上，内存价格也可能下跌，但缓解可能要到明年下半年才会出现。市场可能会预期这种变化，并在此之前开始对供应缺口的任何潜在逆转进行定价——这可能在今年第四季度或2027年初出现。
