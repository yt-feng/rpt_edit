# 中国车企的欧洲攻势，市场低估的不只是销量

# 中国汽车行业

# 比亚迪与吉利在欧洲汽车会议上的要点总结

- 中国OEM在欧洲的代表性日益增强：我们参加了JPM在伦敦举办的年度欧洲汽车会议（6月1-2日），并主持了比亚迪、吉利和奇瑞汽车的专题讨论。其他参会的全球OEM包括奔驰、宝马、大众、雷诺、日产、沃尔沃、戴姆勒卡车以及多家全球供应商。在所有讨论中，中国始终是焦点，包括：1) 中国OEM的海外扩张及其对全球OEM和供应商的影响，2) 全球OEM利用其中国产品或中国业务的成本优势进军全球市场的战略——即全球参与者所称的“在中国，为全球”策略。会议上，比亚迪、吉利和奇瑞展示了最新车型（图1-3）。我们还参观了比亚迪在金丝雀码头的展厅。
- 令我们惊讶的是，中国品牌海外销量的增长速度，这得益于有竞争力的产品组合、多样化的动力总成选择（纯电动、插电式混合动力和混合动力）、优于同价位外国品牌的内饰配置以及激进的渠道扩张。在我们覆盖的范围内，我们看到了当前海外销量预测的上行潜力：比亚迪可能超过170-180万辆（JPM当前预测为150万辆），吉利汽车约100万辆（JPM预测为75万辆）。
- 要点1：对比亚迪和吉利而言，海外产品战略正从单一动力总成出口转向产品组合加品牌/技术故事，并将欧洲视为混合动力过渡市场。例如，比亚迪的目标是实现纯电动/插电式混合动力平衡，并计划在2026年下半年推出插电式混合动力车型（海豚和aito DMi SUV），而高端品牌“腾势”在2026年下半年将是一项战略举措（起售价约8万英镑）；吉利则强调将人工智能集成到高级驾驶辅助系统中。
- 要点2：在扩张战略上，比亚迪优先考虑密集覆盖（到2026年底在欧洲拥有2000家经销商/门店），并声称试驾转化率为45-50%；吉利采用“轻资产模式”，利用合作伙伴关系（例如领克通过沃尔沃渠道）。所有中国OEM都强调售后服务的深度和经销商的信心，以建立信任、残值以及月付竞争力。
- 要点3：本地化/布局信号显示出不同的策略。吉利的路径是合作/全散件组装主导（例如雷诺韩国全散件组装零件、雷诺巴西合作），并以马来西亚宝腾合资公司为依托（吉利持有49.9%的股份）。比亚迪表示其目标是在2026年下半年将最新的闪充和刀片电池技术带到欧洲，最初通过腾势高端产品实现。

# 亚太汽车研究主管

# 中国OEM参与JPM年度欧洲汽车会议要点

我们在下方总结了会议上中国OEM评论的关键要点。

# 1) 中国OEM最新海外产品策略（纯电动/插电式混合动力/混合动力组合、品牌、充电、软件）

会议要点指出，产品策略正通过动力总成组合、品牌架构以及充电解决方案和软件等“支持性”产品主张来适应海外市场，而非依赖单一的头牌优势。比亚迪明确表示，欧洲需要比纯电动定位更广泛的动力总成策略，而吉利的重点则更集中于软件主导的竞争力，并将其与“轻资产”的市场进入模式相结合。

# 比亚迪

比亚迪的欧洲产品策略围绕在欧洲保持纯电动和插电式混合动力的平衡，并计划在2026年下半年推出特定插电式混合动力车型（海豚和aito DMi SUV）。比亚迪的海外品牌架构也定位为多层级，明确描述为比亚迪、腾势和仰望，这意味着有意进行品牌定位的阶梯式布局，而非单一品牌出口策略。产品规划周期被描述为3-4年的车型周期，比亚迪还指出，年长买家更看重功能性，这表明其愿意根据买家人口统计特征和实际需求调整功能优先级。

充电是比亚迪最直接、最具体地解决的问题，它既是拥有体验的卖点，也是商业化的杠杆。比亚迪表示，将从今年9月起在英国部署闪充网络，并设定了到2026年底在欧洲拥有3000个闪充桩的目标。我们认为，如果比亚迪能够实现这一规模，充电网络的部署可以通过减少首次购车者和车队的感知障碍来支持转化和接受度，并且通过改善整体价值主张（而不仅仅是标价），有助于强化比亚迪所宣称的避免价格竞争的意愿。

比亚迪更广泛的产品定位明确与残值管理挂钩：比亚迪明确表示旨在避免价格竞争以保护残值，并将买家的决策与月付和残值挂钩。

# 吉利汽车

吉利在会议中最明确的产品和技术亮点是软件主导：吉利被提及将人工智能集成到高级驾驶辅助系统中。吉利战略性地专注于“轻资产”商业模式，在不同市场与选定的全球OEM合作——包括在韩国和巴西与雷诺合作，以及在马来西亚与宝腾合作。

# 2) 分销与市场进入策略（渠道、门店布局、车队、合作伙伴关系）

各公司的分销策略在如何快速扩张的同时，在海外市场建立渠道、信任和售后信誉方面有所不同。比亚迪的方法强调庞大的经销商/门店目标加上可衡量的转化率，而吉利的方法则强调合作伙伴关系和利用现有渠道的“轻资产”姿态。

比亚迪在欧洲的市场进入计划以实体规模和转化表现为基础。比亚迪的目标是到2026年底在欧洲拥有2000家经销商和门店，并声称其试驾转化率为45-50%。

比亚迪在英国的重点渠道包括车队销售加零售，并且由于需求旺盛，英国供应短缺被提及为当前的运营制约因素。比亚迪表示其正在从奔驰、宝马和特斯拉手中夺取份额。

吉利的经销姿态则有所不同，更侧重于合作伙伴关系和渠道杠杆，以此作为以较低资产密集度进行扩张的方式。吉利将其海外扩张描述为“轻资产模式”，例如领克的分销通过沃尔沃渠道进行。管理层还提到，其英国银河系列即将上市是近期的市场行动，而极氪纯电动车在香港的成功也增强了公司在欧洲开展高端业务的信心。

# 3) 海外销量、出口与市场份额势头

在会议上，比亚迪强调海外绝对规模与目标，而吉利则强调出口规模并明确会计边界（出口与CKD），同时采用“轻资产”框架。

# 吉利汽车

吉利的出口目标包括2026年出口75万辆，5月出口量已超过8.5万辆。

此外，吉利还通过CKD方式出口，表明吉利正在管理多条海外市场路径，并有意识地将“出口”与散件组装路径区分开来。这可以解读为，即使在“出口”报告有明确边界的情况下，吉利在国际销量交付方面仍具有灵活性。

# 比亚迪

比亚迪的规模叙事以更大的绝对数字呈现。比亚迪年初至今出口量已超过60万辆，2026年海外销量指引为150万辆。

此外，比亚迪还关注残值管理和充电网络布局，表明比亚迪正试图将销量增长与支持月付竞争力的价值主张相结合，而非纯粹在前期价格上竞争。

在中国整车厂中，我们还注意到动力总成组合正被用作欧洲的商业化工具。比亚迪表示，其目标是在欧洲实现纯电动与插电混动的平衡。

# 4) 海外本地化、生产布局及“轻资产”与“重资产”路径

海外市场的一个显著商业模式差异在于，比亚迪侧重垂直整合，而吉利则更倾向于轻资产方式：

吉利的海外产能规划以合作为导向。管理层强调，吉利在韩国雷诺的KD零部件业务是其海外产业布局与合作方式的体现，雷诺巴西的合作也在会议上被提及。吉利还提到马来西亚宝腾合资公司（吉利持股49.6%）是其海外市场准入和运营的支点。换言之，吉利相信通过合作架构、KD路径和渠道杠杆来扩张，而非全资拥有、全栈制造布局。

另一方面，比亚迪已在海外建设多家工厂——泰国工厂于2024年完工，巴西工厂于今年早些时候完工，匈牙利工厂正在建设中。

# 建议

我们在中国的投资结论很明确：1) 关注海外收入占比高或增长快的新能源汽车核心标的：比亚迪（约50–60%）、吉利（约40%）、小鹏汽车（约20%），基于JPM预测，同时规避国有整车厂（含合资企业）。2) 关注2026年第二季度环比或2026年下半年环比增长优异的整车厂。3) 关注盈利有望超预期的公司——吉利汽车。

我们重申对比亚迪、吉利的偏好，其次为零跑汽车、小鹏汽车和蔚来，同时对上汽集团、广汽集团、华晨中国、理想汽车和长安汽车持保留态度。
