# Bernstein能源与电力：热泵——电力需求增长中被低估的杠杆？

2022年欧洲能源危机及2026年伊朗战争，极大地推动了欧洲脱碳技术的普及，包括电动汽车保有量及户用太阳能/电池储能安装量的增长。在本期快评中，我们分析了在最新危机之后，户用热泵部署加速的前景，以及在此情景下的潜在受益方。

# 引言

如图表1所示，热泵是包括英国在内的欧洲各国政府脱碳计划中的核心技术。英国政府的目标是到2030年每年新增超过45万台安装量，国家能源系统运营商预计到2035年，10%-25%的家庭将安装热泵设备，而目前这一比例约为1%。此外，根据工党政府的《未来住宅标准》，从2028年起，英国所有新建住宅必须安装热泵。在欧盟，2022年的REPowerEU计划提出到2030年安装3000万台热泵，而2026年的能源计划/加速欧盟计划则提出到2030年每年销售400万台热泵。在本期快评中，我们将概述热泵技术，包括其历史、工作原理及主要类型，并探讨其对更广泛电力系统的潜在影响。

# 什么是热泵？

热泵是一种以电力驱动的供暖设备，利用环境热量与压缩技术的结合来为建筑或其他结构供暖。该技术最常用的版本是空气源热泵，它从空气中吸收环境热量。其他版本，例如地源热泵，则从地下管网中获取热量。热泵具有显著的能效优势，因为该设备能够将比其运行所用电能更多的热能传递到被供暖的建筑中。

# 热泵如何工作？

热泵基于四步制冷循环原理工作，即：1）蒸发，2）压缩，3）冷凝，4）膨胀。

# 蒸发

在空气源热泵中，风扇用于将室外环境空气吹过含有液态化学制冷剂的热交换器。这种液态化学制冷剂的沸点足够低，以至于即使是室外的环境热量也足以使其蒸发成低压、低温的气体。

# 压缩

新蒸发的气体被导入电动压缩机。压缩过程通过提高气体压力来进一步提升其温度。

# 冷凝

压缩过程之后，气体被转移到第二个热交换器，将其储存的热能传递给水回路，从而加热水，随后这些热水要么为供暖系统终端（如散热器或地暖装置）提供动力，要么用于生活热水供应。

# 膨胀

在将热量传递给热水系统后，新冷却但仍处于压缩状态的气体通过膨胀阀以降低其压力。减压过程进一步降低了气体的温度，使其再次准备好从室外环境中吸收环境热量。

# 热泵技术历史

欧洲热泵技术的首次应用可追溯到瑞士。据报道，“早在1852年，开尔文勋爵就对热泵有了直觉，他指出‘逆向热机’不仅可用于制冷，也可用于供暖。” 第一台大型热泵于1948年在美国安装，随后20世纪70年代的石油危机加速了该技术的发展势头。

# 热泵类型

两种主要的热泵类型是：1）空气源热泵和2）地源热泵。前者从周围空气中汲取环境热量，而后者埋设于地下，从周围土壤中汲取环境热量。空气源热泵更为普遍，原因是：1）所需空间更小，2）安装成本显著更低，尽管由于空气温度变化比地温更大，其运行效率也略低。

# 安装成本

由于安装过程复杂得多，可能需要升级管道系统、安装额外的散热器以及升级现有热水储水罐，热泵的安装成本通常远高于可比燃气锅炉。

排除初始安装成本后，燃气锅炉与电热泵之间技术决策的关键考量因素包括：1）能效等级对比，以及2）燃料成本对比。在正确安装的情况下，热泵能效等级可达约400%，即仅需将其产生的热能中的25%作为电能来驱动制热过程。这是通过蒸发、压缩、冷凝和膨胀过程的物理原理实现的。相比之下，燃气锅炉通常最高能效等级约为93%，其燃气输入量大于产生的热量输出。然而，尽管热泵效率远高于燃气锅炉，但在包括英国在内的多个国家，其使用的电力燃料成本也显著更高。

热输出与电能输入的比率称为性能系数（COP）。与电力成本及室外与室内温差一样，COP是决定热泵运行成本的关键因素。

热泵的运行效率随以下因素变化：1）室外温度，温度较高时效率更高；2）室内温度，室内供暖及热水系统在较低温度下运行时效率更高；以及其他与系统设计相关的因素，我们将在本报告中稍后详细说明。

除了安装质量外，影响热泵实际运行效率的一个关键因素是房屋的保温水平；保温效果越好，房屋热量损失越低，热泵所需的“出水温度”也越低，出水温度是指水离开热泵机组时系统内的水温。保温性能更好的房屋可以在较低的出水温度下运行，因为考虑到热量泄漏减少，房屋的散热器（或其他散热装置）无需那么费力即可维持目标温度。这减轻了热泵的负担并提高了其效率。

# 日益增长的创新可能推动成本下降

在英国能源研究中心2023年的一份报告中，菲尔·赫普顿斯托尔和马克·温斯克尔发现，“在英国，过去十年中，热泵的平均总安装成本几乎没有或根本没有下降。同期，国际上取得了一些成本降低，随着时间的推移，特定国家已成功地将市场增长与降低的安装成本相结合。未来十年，降低安装成本（尤其是非设备成本）确实存在前景。大多数英国预测表明，到2030年，总安装成本将降低约20-25%。非设备安装成本（包括劳动力成本）的预期节省高于设备成本。”

# 运行效率呈现有利趋势

有证据表明，热泵的运行效率可能会随着时间的推移而显著提高。牛津大学能源与气候政策教授扬·罗森诺与特里斯坦·李合作，分析了安装在heatpumpmonitor.org上的一组热泵，发现该组热泵的平均季节性能系数约为3.9，而英国政府2024年12月“供暖电气化”试验中使用的组别为2.81。作者估计，这些结果相当于英国政府组别比燃气每年多出19%的运行成本溢价，而热泵监测器组别则节省了17%的成本。随着安装人员的专业知识和经验随着时间的推移而增加，我们看到运行效率和成本竞争力随之提高的潜力。

我们在图表20中列出了英国政府“供暖电气化”试验项目中一台性能不佳的热泵的运行数据。热泵监测器网站上系统EOH0567的数据显示，温度控制不佳且存在短循环，表明能效欠佳。随着该技术更广泛地部署，安装人员的知识和经验不断增长，所达到的能效水平应会提高。

# 安装成本方面存在一些乐观空间

与上述较为悲观的描述相反，英国政府于2026年3月估计，自2022年以来，英国热泵安装成本实际下降了11%。此外，安装行业也进行了重大创新，以解决特定的采用瓶颈。例如，正如英国政府所解释的那样，“为了提供热水，热泵需要一个储水罐，类似于老一代燃气锅炉系统。新型组合式燃气锅炉不需要这些储水罐，因此英国约50%的住房存量现在缺少储水罐。此外，较小的房屋和最后一批房屋缺乏安装储水罐的额外存储空间。”为了解决这一瓶颈，一些安装商设计了更小的热水储水罐，可以放入现有的厨房橱柜中。我们看到了进一步创新以降低安装成本的潜力。

# 抑或又是一次虚假启动？

尽管英国等国家对热泵前景乐观，但我们需提醒，作为主流家用供暖技术，其广泛普及仍面临重大障碍，主要是高昂的安装成本和英国较高的电价比。本节我们将详细阐述这些潜在障碍。

# 成本竞争力仍依赖政府补贴

热泵的安装成本远高于同等燃气锅炉。法国电力集团（EDF）给出的空气源热泵和可比燃气锅炉的指示性成本范围分别为3,999-10,000英镑和3,000-4,000英镑，其中空气源热泵范围已计入政府补助的影响。此外，空气源热泵范围假设无需升级现有热水储水罐或散热器系统。鉴于许多情况下这些升级是必需的，显然即使包含政府补助，热泵的前期成本仍远高于同等燃气锅炉，且无补贴则不可行。

# 热泵加速对电力系统有何影响？

如果各国成功推动热泵技术的广泛普及，我们认为将对整个电力系统产生深远影响，需要进一步升级配电网，并大幅增加总体电力需求。

# 更广泛的热泵采用将成为总消费量和峰值需求的显著推动力……

英国每台热泵平均每年用电量约为2-4兆瓦时，这意味着如果热泵采用率持续上升，英国电力需求可能大幅增长。根据英国国家能源系统运营商的规划假设，预计到2035年，约有300万至800万户家庭将使用热泵，而2024年这一数字约为30万户。如图表28所示，这意味着到2035年，热泵将带来8至22太瓦时的额外电力需求，相当于2024年总需求的5%-14%。

# ……推动配电网络增长，并为发电企业带来更多机遇

鉴于热泵可能推动峰值负荷大幅增长，我们认为配电公司可能成为主要受益者，增长动力来自为应对负荷增加而进行的电网加固需求。此外，考虑到总体需求可能上升，可再生能源和火电发电企业也将迎来机遇。

# 配电网络

热泵安装量的增加将需要大量投资来加固配电网络。《应用能源》2017年的一项研究指出："接入燃气管网的地区的住宅，其配电网络容量通常设计为仅满足极少量电采暖需求。大量热泵接入带来的问题是电压降超出允许范围，以及低压馈线和变压器热容量不足，除非进行加固，否则会导致这些元件过热。"季节性因素进一步加剧了电力需求的影响；同一研究报告称："冬季供暖能源需求可达英国住宅电力需求的约5倍。"热泵在气温最低、使用率最高时效率最低，这一事实进一步加剧了潜在需求影响。

# 其他系统影响

我们认为热泵还可能对总电力消耗和系统灵活性产生其他重大影响。

# 需求

热泵有潜力显著增加欧洲的电力需求。以英国为例，《能源与建筑》2023年的一项研究建立了一个统计模型，用于"预测在当前和未来（2050年）气候、住宅能效和热泵部署情景下，英国发电和配电基础设施的额外负荷"，研究发现："在2020年代的寒冷年份，如果英国现有住宅全部安装热泵，热泵的峰值电力需求将达到78吉瓦，年电力需求达到189太瓦时……这意味着英国峰值电力需求增长超过100%，年电力需求增长约60%。"

# 灵活性

热泵未来可能以需求侧响应或需求灵活性的形式为电力系统稳定性做出贡献。当系统接近需求峰值时，参与灵活性服务项目的热泵可以短时间关闭，从而缓解电网需求压力，且由于建筑物在热源关闭后仍能保温一段时间，对用户体验影响很小。研究与创新基金会Nesta在2024年2月至4月期间进行了一项试验，他们在"HeatFlex"活动期间远程控制参与者的热泵长达4小时，验证了需求灵活性项目的可行性——见图表32。

# 结论

显然，热泵的采用将显著推动经济电气化进程，而当前的危机显然再次提升了其前景。然而，目前该技术仍需补贴、高隔热水平和有利的电价与气价比才能具备可行性。如果热泵成本能够像电池（电池储能系统——投资者经济学入门）和太阳能一样下降，该技术将得到更广泛的应用，从而增加电力需求，并需要对配电网络进行更多投资。我们支持英国监管机构在即将到来的配电周期中采取更为谨慎的做法，不提前投资于热泵需求。
