# 房地产底部在望

中国房地产下行似乎正进入后期阶段，多项指标表明，一个持久的底部可能正在临近，而非又一次短暂的政策驱动反弹。本轮调整的持续时间和深度，已与其他经济体的典型房地产下行周期大致相当。

我们认为，本轮反弹之所以不同，在于其主要并非由广泛的宏观刺激驱动。相反，它反映了潜在市场动态的改善：在重点城市，成交量正在上升，而二手房挂牌量正在下降。我们尚未观察到的是租金的稳步改善，这可能在今年发生于大城市。

展望未来，我们预计中国房地产行业的复苏将是渐进的，由一线城市和经济竞争力强的城市引领，而非全国范围内的广泛复苏。如果房地产行业在未来1-2年内确实企稳，则可能通过改善家庭信心、地方政府财政以及传统经济部门的需求，帮助中国从当前狭窄的K型复苏走向更广泛的宏观扩张。

# 我们处于中国房地产下行的哪个阶段？三个方面

过去几个月，中国房地产市场显示出初步的企稳迹象——尤其在一线城市和部分二线城市的二手房市场。上海领涨：成交量显著上升，部分板块的价格已停止下跌，甚至小幅走高。问题是，本轮反弹是标志着中国房地产下行结束的开始，还是又一次虚假曙光。

我们从三个维度来探讨这个问题。首先，我们将中国的下行周期与国际经验进行对标——其持续时间和深度是否已足够？其次，我们将当前复苏与之前两次虚假启动（2023年初和2024年末）进行比较，以识别本次的不同之处。第三，我们借鉴香港近期的房地产复苏经验，为内地尤其是其核心城市汲取教训。

# 1. 下行周期已走完其历程

我们此前的研究表明，在主要经济体中，房地产下行周期的中位数——从峰值到谷底——大约持续五年，典型区间为四到七年。峰值到谷底的价格跌幅中位数约为20%。

中国当前的下行周期始于2021年上半年房价见顶，刚刚超过五年大关。仅从持续时间来看，已接近全球中位数。从调整深度来看，官方统计数据显示，新房累计价格跌幅约为14%，二手房约为22%，而坊间指标显示许多城市的跌幅接近30%。无论以哪种指标衡量，中国的下行周期已与国际先例大致相当。

中国不是日本。一些观察人士本能地联想到日本类比——一个持续了十五年之久的房地产下行周期。我们认为这是错误的参照点。日本的"失去的几十年"始于其全球竞争力达到顶峰并逐渐被后来者侵蚀之时。过去五年中国的故事恰恰相反：竞争力上升，全球市场份额扩大。这是两国在各自房地产下行周期开始时最根本的区别。因此，我们将分析锚定于更广泛的国际经验，而非以日本作为基准情形。

# 2. 本轮与之前的短暂反弹不同

在2023年初（疫后重启）和2024年末至2025年初，中国房地产市场均出现过成交量和价格的短暂反弹，但都在几个月内消退。我们是否正在目睹另一个虚假信号？我们认为，当前复苏在两个方面与那些阶段不同：

1. 不同的驱动力。前两次反弹主要由政策驱动。这里不仅指房地产行业政策，如降低首付比例和房贷利率、取消限购；更重要的是，2023年的反弹发生在中国疫后重启之后，而2024年末的反弹发生在全面刺激计划之后。这些政策释放了一波一次性需求，但一旦政策脉冲消退，价格便恢复下跌。然而，本轮虽然也有一些房地产政策调整，但我们并未看到宏观政策有任何重大变化。

2. 不同的反馈循环。在前两次反弹中，都出现了一个熟悉的模式：成交量一回升，二手房挂牌量便激增，迅速打破供需平衡，压制了初现的复苏。本轮在一线城市，情况恰恰相反——二手房成交量上升的同时，挂牌量却在下降。此前扼杀复苏的负反馈循环，至少到目前为止尚未出现。

后一点尤为重要。在房地产下行前的五到十年间，中国房地产市场成交量巨大，其中很大一部分反映了家庭将房产作为储蓄和投资工具。一旦周期逆转，家庭资产配置偏好急剧转变：投资性房产的持有者急于抛售。这意味着，当前的下行周期不仅是一个消化新房库存的过程，而且可能更重要的是，一个消化二手房存量积压的过程。一线城市二手房挂牌量的持续下降，可能预示着这一库存消化过程正接近尾声。

# 3. 人口与租金，而非政策与利率

香港的房地产复苏可作为评估内地房地产行业的有益参考。香港房地产市场于2025年第二季度触底，此后强劲复苏：价格较谷底上涨约10%，成交量活跃，新房销售强劲到出现局部供应短缺。

政策宽松与利率并非主要驱动因素。我们发现，主流叙事——即认为香港楼市复苏是由特区政府全面撤销所有楼市辣招及美元利率下降所驱动——并不完整。香港特区政府于2024年2月撤辣，但价格底部及成交量反弹直至2025年7月才出现，整整相隔18个月。在利率方面，请注意香港按揭市场存在有效利率上限，当美联储政策利率高企时，该上限将按揭利率维持在约3.5%的水平。实际上，美国利率下降并未显著减轻香港家庭的按揭负担。

那么，是什么推动了香港的复苏？我们认为有两个决定性因素：第一，香港自身经济环境的改善。人才引进政策使人口增长重回正值。已下跌数年的股市在2024年见底。随后的上涨恢复了投资者信心，吸引企业重返香港进行IPO和再融资，并提振了整体经济。第二，租金在房价之前回升。人口流入和经济复苏影响楼市的最根本渠道是租赁市场。香港租金在下跌超过三年后，于2023年初停止下跌。到2025年，租金几乎完全恢复到2018-19年的水平。租金的稳步上涨给了购房者对未来租金收益率的信心。

2025年是中国经济的转折点；2026年可能成为租金的转折点，至少在顶级城市如此。最新数据显示，在持续吸引人口流入的四个一线城市，租金已企稳并开始反弹。

# 未来展望

综合以上三条线索，我们对中国房地产市场得出以下结论。

# 1. 底部临近：关注二手房挂牌量与租金

首先，楼市下行周期可能已接近尾声。无论是调整深度还是持续时间，目前都已处于国际可比案例的范围内。即使确切底部仍需确认，未来一到两年内（2027年底前）出现拐点的可能性很大。

虽然难以预测确切拐点，但有两个领先指标值得密切关注。我们建议监测两个变量以评估复苏是否可持续：

1. 二手房挂牌量。如果成交量继续扩大，同时二手房挂牌存量持续减少，则表明供需正在重新平衡，市场终于吸收了繁荣时期积累的过剩住房供应。这将是未来房价持续上涨的必要条件。
2. 主要城市的住宅租金趋势。租金的稳步上涨将是楼市最终反弹的关键信号。需要明确的是，我们不同意那种认为租金收益率必须超过按揭利率房价才能复苏的流行观点。事实上，高租金收益率应被视为负面信号，因为它意味着市场预期未来几年租金和房价将持续下跌。这可以通过与股市类比来理解：对于股票（房产）价格要上涨，关键在于观察到盈利（租金）的稳定增长，这将证明更高的市盈率（更低的租金收益率）是合理的。低市盈率（高租金收益率）本身从来不是未来价格表现的良好理由。

# 2. 房地产板块复苏可能滞后于整体经济复苏

我们预计房地产复苏将滞后于整体经济复苏。过去十多年，在经济高速增长、城镇化加速以及日益严格的限制性政策背景下，房地产行业曾作为逆周期工具，引领经济复苏。考虑到经济发展阶段和政策意图的转变，房地产行业已不能再充当逆周期稳定器；相反，它已逐渐成为经济趋势的放大器。如果房地产行业在未来一两年内再次回暖，这种复苏应被视为整体经济复苏的结果，而非原因。

最终的复苏很可能是区域性的，而非普涨。城市的经济表现和人口动态将成为其房地产市场的决定性因素。复苏将首先出现在部分一线城市和经济活跃的二线城市。相反，许多持续面临人口外流且缺乏有竞争力经济结构的城市和地区，其房地产市场可能在相当长时期内都不会复苏。

# 3. 增长传导可能缓慢，但对广泛复苏至关重要

传导将是缓慢而渐进的，其对GDP增长的贡献将逐步转正。复苏将从部分城市开始，需要时间才能成为全国性现象。从二手房市场传导至新房市场及新住房投资也需要时间，考虑到大多数民营开发商要么已退出市场，要么在下一轮楼市复苏中失去了快速扩张的能力。剩下的主要参与者，多为国有开发商，对复苏的反应往往较为谨慎。

即使今年一线城市二手房成交量有所回升，这些城市的新房销售仍未停止收缩。全国土地出让收入同比仍深度为负，对地方财政的拖累持续存在。从少数城市扩散到多数城市、从二手房扩散到新房、从销售扩散到投资，这个过程可能很缓慢。

房地产复苏将是中国从K型复苏走向广泛复苏的桥梁。当前中国经济呈现K型格局。一方面，新经济部门——人工智能、可再生能源、电动汽车、储能——活动激增，外部需求强劲，价格上升，企业盈利改善。这是K型复苏的上升支。另一方面，传统部门——基础设施投资、居民消费——增长乏力，制约了宏观复苏的广度。

关键在于，“新经济”规模虽在扩大，但基础仍然狭窄。中国大部分劳动力仍受雇于“旧经济”；政府收入也与传统部门（尤其是土地出让）关联更紧密；中国家庭在住房上的投资远超对高科技股票的投资。

如果房地产市场能够企稳，并从拖累经济转为推动复苏，我们可能会看到中国从不均衡的K型复苏转向更平衡、更广泛的扩张。这将是一个关键的转折点——不仅对房地产行业如此，对整个经济而言，更重要的是，对消费者信心而言。
