# 外汇指南针：等待开局  

外汇市场仍受美伊谈判主导。上周G10货币兑美元的大部分涨幅在本周初被逆转，因伊朗威胁中断关于以色列在黎巴嫩行动的谈判，导致油价大幅上涨。这种地缘政治驱动的反复波动目前已为市场充分理解，因此未能重新点燃隐含外汇波动率，后者继续走低。由于美元在G10利差排名中接近顶部，我们认为这种低波动环境可能继续支撑美元，尤其是在AI叙事和高实际利率带来的顺风因素完好无损的情况下。我们没有明确理由改变这一观点，特别是考虑到世界杯将于下周开幕，而历史数据显示该事件期间实际外汇波动率往往较低（图1）。基于此，本周我们聚焦于可能挑战我们观点的潜在风险。

第一个关注点是日本央行行长植田和男今日的讲话，这是6月16日利率决议前日本央行最后一次预定沟通。从外汇策略角度看，日本央行紧缩计划的不确定性是我们继续将美元兑日元视为逢低买入机会的关键原因。我们认为，需要日本央行有力重申甚至延长加息意图才能打破这种日元负面动态。否则，美元兑日元可能测试160上方，若触发新一轮外汇干预，则逢低买入者将迅速回归。

关于美伊谈判，市场似乎聚焦于特朗普总统的言论和行动继续支持市场友好型解决方案的预期。这些预期表明风险不对称现在倾向于谈判破裂，这一情景可能伴随美元再度走强。这不是我们的基准情景，但在波动率低迷的情况下值得考虑。

至于美国数据，市场已为5月就业报告做好准备，该报告应支持当前对美联储小幅加息的定价。鉴于沃什主席主持的首次FOMC会议还有两周，我们认为需要非常大且明确的数据意外才能显著挑战这一定价前景。

本周我们还研究了支撑英镑韧性的基本面资金流背景，重点突出了年初至今强劲的入境并购活动。

# 宏观概述：等待开局

# 风险#1：植田和男的讲话  

第一个关注点是日本央行行长植田和男今日的讲话。这是6月16日利率决议前日本央行最后一次预定沟通，目前市场隐含加息19个基点；市场将警惕任何在会议前影响预期的尝试（我们的经济学家预计加息）。近期数据和市场发展指向鸽派倾向的风险正在酝酿：油价仍低于100美元，4月和5月全国及东京CPI均意外下行，"核心核心"CPI同比分别从4月的2.4%和1.9%降至1.9%和1.6%，且自5月中旬以来日本国债长端抛售大幅缓解。这削弱了那些认为日本央行需要重申其抗通胀立场以控制长端利率的观点。

更温和的财政宽松前景也可能削弱日本央行紧缩的紧迫性

从外汇策略角度看，日本央行定价的稳定性及其导致的与G10其他货币的利差支持丧失，是我们继续将美元兑日元视为逢低买入机会并仍认为该货币对可能突破160的关键原因，尤其是在能源价格重启升势的情况下。虽然10年期日本国债收益率略高于通胀盈亏平衡点，但日本央行政策利率仍远低于实际通胀，且日本央行缩小这一差距的意愿仍因不确定性而模糊。因此，植田行长任何延续这种不明确性的信号都可能强化日元走弱的理由。在此情景下，我们仍认为升至160上方可能触发财务省新一轮外汇干预，但由此导致的美元兑日元任何回落都可能吸引寻求利用低波动市场条件的利差交易买家。

只要日本央行的紧缩意图仍不明确，日元就可能进一步走弱

我们认为，需要强力重申甚至延长日本央行加息意图，才能打破这种日元负面动态。我们不排除这种可能性，但美元/日元前端风险逆转偏斜仍在本年度区间内对看跌期权保持买盘。因此，尽管在风险逆转偏斜曲线的远端，美元/日元看跌期权相对于看涨期权的溢价正在消退，但在短期内，日元多头似乎并不那么明显处于劣势，这意味着围绕这一事件的外汇风险可能是平衡的，并非过度偏向于预期日元走弱。

# 风险二：美伊谈判

转向美伊谈判，市场似乎关注到特朗普总统的言论和行动继续支持市场友好型解决方案的预期。这有助于抑制隐含波动率，尽管谈判仍未解决且偶尔发生局部军事冲突。我们长期以来的观点是，解决方案的宣布最初将导致美元在条件反射式下跌后，因美国基本面强劲而重获动能；近期的跷跷板式价格走势增强了我们对这一观点的信心。然而，鉴于市场对解决方案的预期如此一边倒，更大的风险不对称性现在在于谈判可能持久破裂，进而导致军事活动重新抬头。虽然这看似可能性较低的情景，但值得考虑，仅仅因为它将对市场定价的宽松波动率预期构成巨大冲击。在这种情景下，能源价格重新上涨将推动美元测试我们第二季度区间的上端（欧元/美元1.1450，澳元/美元0.70，美元/日元162）。需要明确的是，我们认为这是尾部风险而非基准情景，但这再次凸显了美元进一步升值的不对称风险特征。

随着市场预期冲突得到解决，风险不对称性可能倾向于升级

# 风险三：美国5月就业报告

本周收盘前，市场预计5月非农就业人数增加8.5万，平均时薪环比增长0.3%，失业率4.3%（4月为+11.5万/环比0.2%/4.3%）——略低于我们经济学家预测的9万总人数和环比0.37%的薪资增长。在该数据公布前，美国数据表现不一，5月ISM制造业指数改善（54.0，4月为52.7），4月JOLTS职位空缺改善（761.8万，3月为688.7万），但也有疲软意外，包括4月个人收入（环比0.0%，3月为0.5%）和支出（环比0.5%，3月为1.0%），以及4月耐用品订单（非国防资本品除飞机外环比0.4%，3月为1.3%）。这表明，符合预期或更强的数据可能进一步使意见平衡偏向积极方向，且几乎不会削弱当前对美联储可能加息的定价（年底前加息18个基点，2027年3月17日会议前加息25个基点）。

我们怀疑，市场需要明显的负面意外才可能质疑当前的美联储定价，尤其是考虑到克利夫兰联储主席哈马克和堪萨斯城联储主席施密德等官员近期评论的鹰派倾向。同时，距离沃什主席领导下的首次联邦公开市场委员会会议还有两周，市场可能不愿在缺乏数据明确依据的情况下将定价推向鹰派极端，并注意到当前美联储框架的关键要素（如前瞻指引）可能在新领导下发生变化。总而言之，我们认为需要任一方向的大幅意外才能挑战当前叙事；否则，仅凭美国数据推动波动率反弹的门槛似乎很高。

# 英镑：受基本面资金流支撑

尽管围绕首相基尔·斯塔默爵士任期未来的政治事态持续发展，英镑仍表现出韧性。在上月地方选举前，我们曾撰文指出，英镑的关键担忧最终在于财政前景，只要现有财政规则被打破/放松的感知风险足够低，英镑对政治消息流缺乏反应可以说是有道理的。此后这一情况基本成立。鉴于我们近几周已详细讨论过（链接、链接、链接），本文暂将政治因素搁置一旁，转而审视英镑的基本面资金流背景，认为这继续在噪音背后为英镑提供基本面支撑。我们第二季度末欧元/英镑目标为0.8750，即年初至今区间的上端，随后英镑逐步升值，年底前达到0.8500。

并购公告最终应体现在官方国际收支数据中，作为金融账户下的直接投资（FDI），但我们注意到FDI还包括其他组成部分，如再投资收益和公司间贷款。公告与完成之间的前置时间也可能存在很大差异。因此，我们并不将并购公告视为FDI流入的先行指标，而是将其视为一个信号，表明经济体商业环境的相对吸引力。年初至今强劲的入境并购公告，加上贯穿2025年的稳健投资组合流入，支持了我们的观点，即英镑在基本面上受到良性资金流背景的支撑，这为英镑近期尽管围绕政治风险的消息面波动剧烈但仍保持韧性增添了理由。

我们预计第二季度末欧元兑英镑汇率为0.8750，处于年初至今区间的上端，这反映了随着我们经历6月18日梅克菲尔德补选前后财政叙事可能发生变化的风险，曼彻斯特市长安迪·伯纳姆正寻求重返威斯敏斯特挑战首相斯塔默的领导地位。在此之后，我们继续预计年底欧元兑英镑汇率为0.8500，因为今年晚些时候政治噪音消退，我们上文强调的积极资金流背景可以推动英镑逐步升值。我们注意到，这一对英镑的看多观点取决于整体风险环境保持支撑性；转向避险/高波动环境可能会使英镑处于不利地位。

作为最后一点的延伸，英镑对风险高贝塔值背后的一个关键因素在英格兰银行货币政策委员会成员凯瑟琳·曼于5月13日最近的演讲中被指出——旧敞口，新参与者：英国外部失衡对货币政策的影响。关于英国国际收支趋势的详细分析，我们强烈建议阅读该演讲。从外汇角度来看，我们的关键收获是曼的观察，即英国的国际投资头寸（NIIP）显著受益于估值效应，因为英国持有的海外资产价值随时间升值幅度超过了英国负债价值的升值幅度。因此，尽管持续存在经常账户赤字，但自20世纪90年代末以来，英国的NIIP占GDP的比例一直保持在约6.5%不变。我们认为这是英镑高风险贝塔值的重要驱动因素，因为在避险时期，随着海外资产贬值，英国的外部状况恶化，而在风险偏好时期，随着这些资产增值，外部状况改善。

# 估值方法与风险声明

多资产投资的风险包括但不限于市场风险、信用风险、利率风险和外汇风险。不同资产类别收益的相关性可能偏离历史模式。地缘政治事件和政策冲击会带来可能降低资产回报的风险。在高市场波动、流动性不足和经济错位时期，估值可能受到不利影响。所有期权讨论均为“场外交易”。除非进行对冲/中性化，否则某些期权交易的损失可能是无限的。
