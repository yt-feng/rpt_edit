## Lightcast Data

Lightcast provides detailed job information including posted date, employer name, job title, job descriptions and so on for every job posting. To identify software engineer (SWE) type jobs, we start with job title containing Developer, Engineer, or Programmer. Then we summarize the patterns of SWE type jobs and use them to tag each job.

We design the SWE job pattern as keyword\_1 + keyword\_2 combination, where keyword\_1 can be any word from: [Software, System, Cloud, Full Stack, Front End, Back End, Java, HTML, Python, C#, C++, PHP, SQL, Go, Rust, Ruby, Swift, .NET, Application, Web, Cyber, DevOps, Data, AI, ML, Machine Learning, Android, IOS, iOS, Linux, Computer, AWS, Azure, Oracle, Salesforce], and keyword\_2 can be any word from [Developer, Engineer, Programmer]. The job would be tagged as SWE type job if any combination appears in the job title. For example: Software Engineer, System Developer, and Java Programmer.
