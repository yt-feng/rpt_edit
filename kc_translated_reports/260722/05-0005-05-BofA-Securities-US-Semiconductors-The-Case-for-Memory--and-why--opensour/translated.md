# 美银：半导体行业数据与主题变化观察

## 中国开源大语言模型对内存需求不构成威胁

包括7月16日发布的中国Kimi K3在内的最新开源模型发布，强化了我们对内存/MU的看涨论点。从宏观层面看，我们认为激进的中国开源模型API定价（比西方模型便宜5-350倍）反映了商业模式的选择，并不一定反映硬件成本。重要的是，这些模型使用了各种效率技术（下文详述），能够降低计算/GPU强度，但随着其模型权重和活跃参数的增加，它们需要相同或更多的内存。我们还指出，每一次开源权重下载都会创建一个新的客户侧内存插槽，这在闭源模型环境中是不存在的。

## 中国模型收费更低，但仍需要相同的内存

中国开源模型API定价激进，腾讯混元为每百万输入tokens 0.06美元，而Claude Opus 4.8为每百万输入tokens 15美元；尽管性能“相似”，但月之暗面最新的Kimi K3每百万tokens仅收费3美元。然而，我们指出API价格是商业模式的选择，不一定是硬件成本的反映。例如，Kimi K3每个服务实例仍需要约1.4 TB的HBM才能运行。这与OpenAI的'oss-120b'开源模型类似，该模型采用相同的MXFP4原生精度（同类压缩），总参数为120B（比Kimi K3小23倍），运行需要约63GB的权重内存（小22倍）。换句话说，即使对于中国的开源大语言模型，API定价通常也与总内存权重和活跃参数成正比。“开源”指的是权重分发，而非部署成本，客户仍然需要购买HBM、DRAM、NAND才能在自己的硬件上运行该模型。

## 效率技术和补贴可能有助于降低定价

中国模型确实具有定价/成本优势的领域通常与硬件无关。我们估计中国的成本优势在于架构效率（MoE稀疏性、MLA/混合注意力、原生FP8/MXFP4量化），以及物理基础设施效率方面高达1.5-2倍的优势（较低的中国电力、劳动力和土地成本）。其余的定价差异可能来自国有资本补贴以及中国云服务提供商（阿里巴巴、腾讯、百度）的云收入/自由现金流。有趣的是，月之暗面的Kimi K3在发布后仅48小时内就暂停了新订阅，很可能是GPU容量耗尽（或为了削减成本/亏损），而小米在2026年5月将其MiMo模型定价削减了99%（可能不盈利），很可能是为了争夺市场份额。

## 长鑫存储不构成威胁，在回购恢复前重申对美光的

我们重申对美光的公司观点。虽然中国本土的长鑫存储正在积极扩张产能（目前占全球晶圆产能的10%左右），但我们认为在AI内存领域竞争有限。长鑫存储主要服务于服务不足的消费/通用DRAM领域，而非HBM3E/HBM4。此外，美国OEM厂商能否很快获得政府批准从长鑫存储采购仍不明朗。关键是，美光的《芯片法案》回购限制大约在2026年12月（即2024年12月收到第一笔资金后两年）到期，这为大规模回购打开了大门——鉴于其未来几年每年超过1200-1300亿美元的自由现金流展望。40%的派息政策将导致每年约500-600亿美元的回购，约占其约1万亿美元市值的5-6%。

## 成本优势通常来自非硬件效率

我们怀疑中国大语言模型的许多成本优势（比西方模型高5-50倍）实际上来自非硬件效率。

## 架构效率（2-3倍）

- 极致的MoE稀疏性：Qwen3-Coder-Next仅激活80B总参数中的3B（约3.75%）；Kimi K3激活约1.8%。中国大语言模型中每个解码token的计算量仅为同等规模稠密模型所需的一小部分。

- MLA/混合注意力：DeepSeek的MLA和Kimi的KDA将KV缓存压缩至标准注意力的10-90倍，因此批处理密度也高得多——每GPU的并发用户更多。

- 原生低位量化：Kimi K2 Thinking采用W4A16，K3采用MXFP4，DeepSeek原生使用FP8训练。与Meta Llama 4或Google Gemma 4开源模型的FP16相比，这又带来了2倍的吞吐量提升。

综合来看，与同等规模、原生采用BF16/FP8但没有这些效率提升的西方模型相比，每token的净架构效率可达到2-3倍。

## 输入侧基础设施成本（约1.5-2倍）

- 中国劳动力：工程薪资比美国同行低40-60%

- 土地/房地产：中国内陆地区（宁夏、贵州）的数据中心资本支出及相关土地/厂房/电力支出显著降低

综合来看，根据底层计算账单的不同，每token的净输入成本优势也可达到1.5-2倍。

## 竞争与补贴以争夺市场份额

最后，我们指出月之暗面在K3发布后仅48小时内就暂停了新订阅，原因是GPU容量耗尽，或者可能只是为了削减成本/亏损。

如果K3的低价真实反映了相应的硬件节省，我们预计月之暗面会配置足够的容量。因此，Kimi K3每次查询的实际硬件成本可能高于其更便宜的API价格所暗示的水平，月之暗面可能正在通过补贴来争夺市场份额。

类似的情况还有，小米在2026年5月将其MiMo模型定价削减了99%，很可能是为了争夺市场份额。

## 开源模型的权重规模持续增长

前沿开放权重模型的规模持续急剧增长（闭源模型通常不公布权重数据）

- DeepSeek-V3 达 671B（2024年12月）
- Kimi K2 达 1T（2025年中）
- DeepSeek-V4-Pro 达 1.6T（2026年4月）
- Kimi K3 达 2.8T 参数（2026年7月16日）—— 迄今发布的最大开放权重模型

## 更大权重直接转化为内存需求。

权重内存与总参数（如 K3 的 2.8T 参数）成正比，而非活跃参数。

即使行业通过从 FP8 到 MXFP4 的压缩/量化实现 2 倍节省，模型规模的参数增长仍高出约 4 倍，完全抵消了压缩带来的效率提升。例如，Kimi K3（2026年7月）在原生 MXFP4 下所需内存是 DeepSeek-V3 在 FP8 下（2024年12月）的 2 倍。

## 活跃参数减少计算量，而非内存量

通过使用 MoE（即仅使用活跃参数），Kimi K3 每次仅激活 896 个专家中的 16 个，即每个 token 仅激活其 2.8T 总参数中的 50B。这大幅降低了推理过程中的总计算需求。

然而，模型仍需将几乎整个专家池（即整个模型权重）保留在近端内存中。事实上，HBM 容量与总参数的相关性远高于与活跃参数的相关性。

这是因为 MoE 路由器会针对每个 token 动态选择专家，因此无论激活稀疏度如何，每个专家（即总权重）都必须驻留在快速内存中。结果，总参数翻倍需要每个实例的 HBM 翻倍，这就是为什么 K3 需要 64+ 个加速器，而 V3 仅需 8 个。

## 更大模型权重推动多层内存架构

最后，更大权重迫使采用多层内存层级：热专家数据存于 HBM，非活跃专家数据溢出至 CPU LPDDR5X/DDR5，冷 KV 缓存存于企业级 NAND。每次部署中，每一层的内容量都在增加。

## 开放模型相比闭源模型扩展了内存端点

机制很简单：闭源模型只有一个部署足迹；开放模型有多少次下载，就有多少个足迹。

例如，当 OpenAI 提供 GPT-5.6（闭源模型）服务时，模型权重驻留在少数微软 Azure 数据中心。全球数百万用户都访问同一个共享 HBM 池。总内存内容由所有用户合并后的峰值并发需求决定，并且由于使用模式跨时区和工作负载的多样性，成本可以分摊。

但当 Moonshot 发布 Kimi K3 权重（开放模型）、DeepSeek 发布 V3、或 OpenAI 发布 gpt-oss-120b 时，权重会被下载并加载到每个购买者自己的硬件上。运行 gpt-oss-120b 的企业需要自己的 80 GB HBM3E。运行 DeepSeek-V3 的主权云需要配置自己的 8× H200 集群（约 1.1 TB HBM）。Moonshot 对 K3 的指导要求每个服务实例配备 64+ 个加速器——这个足迹会被每个下载权重并自行部署的企业、政府和云服务商复制。如果同样的智能仅通过闭源 API 提供，这些内存将完全不会被购买，因为客户会租用计算周期而非拥有硬件。

因此，对于开放模型，模型权重和 KV 缓存都必须驻留在快速内存中以提供推理服务——它们不能在各自拥有的集群之间共享。与一个共享 API 中 10,000 名用户有效共享 HBM 中的一份权重副本不同，10,000 家企业自行托管同一个开放模型意味着 10,000 份权重副本被加载到 10,000 个独立的 HBM 池中。每个部署还需要根据其自身用户群规模配置自己的 KV 缓存容量——在 2026 年常见的 128K–1M 上下文窗口下，每个活跃用户会话的 KV 缓存可能超过 40 GB，因此这会在每个端点上独立地随并发量扩展。

## 内存端点受益于更便宜的 API 定价

开放模型拥有独立的内存端点也有利于最终内存部署，因为中国大模型实验室提供更便宜的 API 定价，从而推动整体需求上升。换句话说

- 更便宜的中国 API 定价 = 更多推理工作负载量 + 更多开放权重企业自行托管 + 全球部署更多内存插槽。

当前沿模型实验室投入资本争夺市场份额时，市场整体计算和内存容量可能在此过程中扩张；而每个下载 Qwen、GLM、Hunyuan 或 MiMo 而非付费使用 Claude Opus 的企业，都会创建一个在纯闭源 API 世界中不存在的客户侧内存足迹。

总体而言，闭源模型整合内存需求；开放模型将其倍增——而效率创新带来的压缩无法抵消端点数量带来的倍增效应。

## 规模增长远快于效率提升

最后，我们强调，由杰文斯悖论带来的工作负载强度和总体需求增长，远大于 MoE、量化、KV 缓存压缩技术带来的效率提升。

## 中国模型带来颠覆，但也扩大了市场，利好半导体

虽然没有完美的模型排名方法，但我们依赖第三方基准测试，这些测试根据各种 AI、编码和智能体能力分数对模型进行排名。

最新的排名（截至7月4日）显示，根据 AI 指数

1. 来自 Anthropic 和 OpenAI 的美国前沿模型保持领先，尤其是在 Anthropic 的 Fable 5 模型获批之后
2. 中国模型现在占据了前 16 名中的 8 个席位。最高排名由智谱（Z.ai）发布的 GLM 5.2 占据，这是一个 7500 亿参数/100 万上下文窗口的开放权重模型。中国模型的成功表明，去年中国 DeepSeek 的成功引发的冲击波是未来趋势的预兆，而非一次性事件。根据媒体报道，中国模型在训练中使用了多少西方模型蒸馏技术尚有争议，但事实是，尽管中国无法获得最新的计算、网络和存储芯片，其技术仅落后美国数月而非数年
3. NVDA 也正在成为开源社区的主要贡献者。我们认为，NVDA 的努力不仅有助于改进其硬件，也有助于扩大缺乏与前沿实验室合作资源的中小型 AI 采用者群体。

如开源模型所述——模型的权重、代码和训练方法广泛可用，使开发者能够检查、修改、微调并自行托管模型。开源模型通常能最大化透明度、创新性和生态系统采用率，但创建者的直接控制力较弱。

开放权重模型——训练好的模型权重被发布供下载和部署，但部分训练数据、代码或方法可能仍为专有。开放权重模型通过允许自行托管同时保留部分知识产权，在开放性与商业化之间取得平衡。

专有（封闭）模型——模型权重和训练细节均不公开；客户仅能通过API或云服务访问模型。专有模型通常能实现最强的货币化和控制力，但随着开源和开放权重替代方案的改进，可能面临更大的定价不确定性。
