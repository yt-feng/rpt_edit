# 详情

# 泛林集团（LRCX）

# Timothy M. Archer，总裁兼首席执行官

总体而言，讨论聚焦于AI的普及如何积极影响了未来WFE支出的轨迹。泛林阐述了需求的潜在驱动因素，并概述了其在这些预计将强劲增长的市场中的敞口。泛林继续看到未来强劲的WFE需求，并维持其2026年1400亿美元的指引，同时承认该数字可能存在上行倾向。管理层指出，洁净室空间是该领域最大的制约因素，明年也将如此，因此2027年WFE预计也将实现增长，但他们未提供无约束条件下的WFE数字。过去几年，泛林有意投资于产品开发，使其能够实现终端市场敞口的多元化，从而能够利用代工/逻辑和先进封装领域的增长，但泛林仍以其在内存领域的领导地位为傲。随着客户制定其技术路线图，长期可见度相当强劲，泛林目前正在参与并认证要到2030年代初才会量产的产品。毛利率现在处于“50%区间”，管理层对其进展感到自豪，并将其归因于战略性制造足迹扩张以及其工具提供了更多价值。虽然产品组合可能是毛利率的驱动因素，但尽管中国敞口降低，他们仍看到了毛利率的扩张。预计今年中国敞口将持平或略有上升，因为管理层在该地区只能在落后节点上竞争。

# 要点

- AI的普及积极影响了未来WFE支出的轨迹，AI需求推动了所有设备类型的强劲增长。AI需要更多的一切，包括前沿计算、存储、内存、先进封装，并且还需要器件架构中的不同材料。需求经历了不同的浪潮，AI训练需求带动了更先进的代工/逻辑需求，而现在AI推理则带动了NAND需求和CPU需求的增长。
- 公司维持其2026年1400亿美元的指引，同时承认该数字可能存在上行倾向。管理层指出，洁净室空间是该领域最大的制约因素，明年也将如此，因此2027年WFE预计也将实现增长，但他们未提供无约束条件下的WFE数字。
- 过去几年，泛林有意投资于产品开发，使其能够实现内存以外的终端市场敞口多元化，从而能够利用代工/逻辑和先进封装领域的增长，但泛林仍以其在内存领域的领导地位为傲。
- 随着客户制定其技术路线图，长期可见度相当强劲，泛林目前正在参与并认证要到2030年代初才会量产的产品。
- 毛利率现在处于“50%区间”，管理层对其进展感到自豪，并将其归因于战略性制造足迹扩张以及其工具提供了更多价值。虽然产品组合可能是毛利率的驱动因素，但尽管中国敞口降低，他们仍看到了毛利率的扩张。
- 预计今年中国敞口将持平或略有上升，因为管理层在该地区只能在落后节点上竞争。

# 应用材料公司（AMAT）

# Gary Dickerson，总裁、首席执行官兼执行董事

总体而言，行业背景依然异常强劲，需求可见度前所未有。AMAT将AI视为我们生活中最大的技术拐点之一，它驱动着巨大的需求。AMAT认为，凭借其在材料科学等关键领域的实力，以及对先进逻辑、DRAM和先进封装等关键技术拐点的敞口（这些领域驱动了2026年约80%的增量WFE支出），其处于极佳位置，能够抓住行业增长。

管理层认为，行业利润池比以往任何时候都大，并相信其能够从为客户提供的价值中获取公平的份额。

# 要点：

2/3

- 尽管未提供2026年WFE预测，AMAT认为行业前景极具吸引力，且因AI对前沿逻辑/代工、DRAM（HBM）及先进封装（预计将驱动2026年80%的增量WFE需求）产生巨大需求，至2027年需求可见度前所未有（客户提供滚动8个季度预测）。
- 在先进逻辑领域，作为布线和材料科学领导者，AMAT为BSPDN和GAA晶体管等新架构与技术提供关键创新，随着这些技术爬坡，AMAT认为可捕获50%的增量支出。同样，在DRAM和先进封装（预计今年增长超50%）领域，AMAT因深度嵌入客户路线图并共同创新未来架构（如3DDRAM、面板级封装等）而占据强势地位。
- AMAT认为利润池比以往更大，这为捕获公司所交付价值提供了机遇。现有及新工具的定价持续增长，因其向客户提供的创新极具价值。因此，管理层预计毛利率和营业利润率将随时间推移而上升。
- 关于中国，AMAT认为在2025年限制大幅收紧后，其在被允许竞争的领域表现良好。中国目前约占营收的25%左右，主要由AMAT的ICAPS业务构成，管理层预计中国业务将持平或略有增长，ICAPS将实现中个位数至高个位数增长，部分受推向市场的新创新驱动。

# 高通 (QCOM)

# 克里斯蒂亚诺·阿蒙，总裁兼首席执行官

对话聚焦于QCOM的多元化故事、终端市场表现、未来机遇及需求驱动因素。核心手机业务虽当前受内存供应人为限制，但基本面健康，预计在第三季度触底，因QCOM可见度良好且出货量持续低于需求。长期来看，公司对由代理型AI驱动的AI手机升级周期充满信心。汽车和物联网两大板块均有望实现2029财年目标，前者受不断增长的450亿美元以上管道和份额增长支撑；后者在AI设备（AR/VR和可穿戴设备）中表现优异，但PC同样受内存供应影响。数据中心机遇预计将在2027财年贡献数十亿美元营收，并提升营业利润率。

# 要点：

- 手机业务受内存供应人为限制，但预计在第三季度触底，管理层因出货量持续低于终端需求且可见度强，对复苏充满信心。长期来看，QCOM对由代理型AI驱动的AI手机升级周期非常乐观，当前手机算力不足以支持此类应用。
- 汽车业务健康，有望实现或略微提前达成2029财年80亿美元目标，受不断增长的450亿美元以上管道支撑。QCOM正凭借汽车计算需求增长（ADAS L2++、数字座舱和连接性）在市场中获取份额。
- 物联网（包括核心工业物联网、PC、个人AI设备（AR/VR、智能眼镜、可穿戴设备））同样有望实现2029财年目标，其中智能眼镜是亮点（当前数千万台，未来可能达数百亿台）。PC虽短期受与手机相同的内存动态影响，但市场份额也在提升。
- 数据中心机遇被视为重要（2027财年数十亿美元营收），预计将提升营业利润率。QCOM认为自身凭借宝贵IP、执行能力和规模在市场中占据强势地位，并瞄准推理市场，将其CPU方案和不同内存架构（无需HBM）视为差异化优势。

# 德州仪器 (TXN)

# 哈维夫·伊兰，总裁兼首席执行官

TI认为行业背景有利，定价环境积极，营收增长来自工业板块复苏（仍低于此前峰值15%，同比增长超30%）、汽车板块接近峰值水平（同比增长中个位数）以及蓬勃发展的数据中心板块（第一季度同比增长超90%，占总营收12%以上）的组合。尽管公司可见度较低，但管理层不认为客户需求由补库存驱动，并相信客户需要零部件支持其爬坡。随着持续多年的大规模资本支出周期接近尾声，TXN预计毛利率将随时间推移持续扩张，更重要的是，随着折旧被持续增长吸收，自由现金流/每股将增长。

# 要点

- TI接近其五年投资周期的尾声，管理层认为这将使公司能够参与半导体市场的长期增长，并可能因份额增长而增速更快。TI拥有产能、库存及洁净室空间，可在所有市场环境和不同地缘政治背景下服务客户。投资包括其谢尔曼超级工厂中四个潜在晶圆厂中的两个300mm晶圆厂（已建成两个），每个支持约100亿美元营收。位于利哈伊的晶圆厂专注于嵌入式业务，并支持内部化努力，目标是在项目结束时实现超过90%的内部供应（目前约50%）。TI已关闭剩余6英寸晶圆厂，第二季度是相关费用的最后一个季度。
- 管理层认为行业背景有利，工业业务同比增长超30%（仍低于峰值15%，工业自动化复苏，航空航天与国防强劲），汽车业务同比增长中个位数，数据中心业务第一季度同比增长90%（约占第一季度营收12%）。结合资本支出周期结束以及2026年可能比去年更有利的定价环境，TI预计毛利率将随时间推移持续复苏，更重要的是，将重回自由现金流/每股增长轨道。
- 数据中心市场虽仍占业务较小份额（第一季度营收占比12%），但已成为强劲增长驱动力（同比增长90%），目前年化营收达20亿美元。TI认为其在该可寻址市场中已获得份额，该市场预计2026年约为125亿美元（去年约75亿美元），并认为自身凭借在电源、传感、散热和保护领域的广泛产品组合（尤其在架构向800V演变时），处于持续增长和份额提升的有利位置。该市场总可寻址市场中50%来自计算，35%来自网络，15%来自其他领域。
- 中国目前约占业务20%，仍是非常重要的市场，中国客户在汽车和机器人等领域占据领先地位。TI非常重视竞争，每季度审视主要竞争对手，但也认为自身凭借产品组合广度、分销能力及成本竞争力拥有强大竞争地位，并相信已维持市场份额。

# 英特格 (ENTG, 未覆盖)

# David Reeder, 首席执行官

Entegris受益于非常有利的行业背景，其驱动力来自节点迁移和NAND层数增加，进而推动材料含量增长。ENTG预计将把中低个位数至中高个位数的营收增长转化为更高的利润增长，因为公司正将毛利率从目前的约46%中段扩大至50%区间，管理层正在优化其产能布局、良率以及采购，目标是将杠杆率逐步降至约1.5-2倍，并将现金返还给股东。一旦实现杠杆率和股东回报目标，ENTG预计将有选择地开展收购，其视此为无机研发，以填补技术和能力缺口。

# 要点：

- 公司的两个主要部门是材料解决方案（约占25财年营收32亿美元的44%）和先进纯度解决方案（约占25财年营收的56%），这两个部门对半导体制造至关重要，因为它们影响良率。ENTG的主要客户是晶圆代工厂、IDM和WFE设备制造商，约25%的营收来自资本支出，其余来自晶圆出货量增长。自首席执行官约8个月前上任以来，行业背景显著改善，过去12个月滚动单位（以百万平方英寸计）增长约7%，为营收实现中低个位数至中高个位数增长提供了良好的可见性。
- 该行业主要由产量驱动，目前平均售价并未对材料营收增长做出贡献，因为材料和纯度市场更为广泛，且公司拥有充足产能（营收超过10亿美元）以满足需求。然而，管理层认为定价应反映产品组合所提供的价值。
- 管理层预计毛利率将从目前约46%中段逐步提升至50%以上，驱动力来自运营改善和产能布局优化，因为公司在过去15年中进行了13次收购，这些收购具有进一步整合的潜力。管理层预计，由于销售、一般及行政费用可保持持平或略有增长，同时将约10%的营收再投资于研发，因此大部分毛利润改善将传导至营业利润和每股收益。一旦实现1.5倍至2倍（目前约为3.6倍）的杠杆率目标，资本将流向股东，管理层预计在杠杆率目标实现且股东回报启动后，将有选择地进行一些并购。
- 与半导体领域的其他公司相比，中国限制对ENTG而言不是问题，因为该公司提供1000多种SKU，而监管机构的关注点集中在WFE设备等大额项目上。中国市场的关键在于能够保证供应，公司通过专门的中国产能做到了这一点，到今年年底，公司约90%的中国市场将通过亚洲或中国本地供应直接服务（目前约为85%）。
