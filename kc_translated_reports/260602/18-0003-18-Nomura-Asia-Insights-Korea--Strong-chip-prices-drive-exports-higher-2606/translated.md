# 韩国：强劲芯片价格推动出口走高

强劲的AI周期可能支撑韩国央行对强劲增长的信心，并推动其鹰派立场

- 5月出口同比再次飙升53.2%（市场预期：49.3%；NOM预测：61.5%），主要受半导体和石油产品强劲出口价格推动，抵消了汽车出口疲软。5月进口同比增长20.8%，贸易顺差从4月的238亿美元扩大至5月的269亿美元。1-5月累计顺差达到1019.1亿美元，已超过2017年全年创下的952亿美元纪录。5月日均出口也达到42.8亿美元的历史新高，同比增长60.7%。
- 出口周期正由AI半导体繁荣主导。5月半导体出口同比增长169.4%，占出口总额的42%以上。主要用于AI服务器的SSD电脑出口同比飙升290.7%，有色金属出口也因数据中心投资相关需求而强劲增长。复苏质量仍不均衡，汽车、汽车零部件、通用机械和钢铁依然疲软。
- 我们还认为，韩国央行的出口价格指标可能无法捕捉近期芯片出口价格的飙升，这可能会夸大芯片出口量，进而夸大其对GDP增长的影响，尽管我们认为AI资本支出繁荣将继续通过价格效应而非数量效应推动强劲出口，并维持韩国央行对增长的乐观态度。
- 我们维持2026年GDP增长预测2.4%，并重申政策观点：三次25个基点加息，首次在7月实施，随后在2026年10月和2027年1月会议各再加息25个基点（终端利率：3.25%）。

# AI驱动周期

5月出口同比再次飙升53.2%（市场预期：49.3%；NOM预测：61.5%），主要受半导体和石油产品强劲出口价格推动，抵消了汽车出口疲软。5月进口同比增长20.8%至608亿美元，贸易顺差扩大至269.5亿美元。

1-5月累计顺差达到1019.1亿美元，已超过2017年全年创下的952亿美元纪录。5月日均出口也达到42.8亿美元的历史新高，同比增长60.7%。

数据证实，出口周期正由AI半导体繁荣主导。

- 电脑/SSD：AI需求正从芯片向外扩展：电脑出口同比增长290.7%至41.8亿美元，创历史新高。增长动力来自与AI数据中心相关的企业级SSD需求。SSD出口增至约39.7亿美元，同比增长337.7%。

# 材料、电池和消费品

5月有色金属出口同比增长41.5%，受与AI数据中心相关的铜铝需求支撑。5月二次电池出口同比增长31.4%，受益于ESS/EV需求和矿物价格上涨。

# AI资本支出繁荣提振对多数目的地的出口

九个主要地区中有七个出口增长。中国、美国和东盟是主要驱动力，而中东和独联体是下降的两个地区。

- 中国（半导体供应链需求主导）：5月对华出口同比增长80.9%，连续第七个月增长。半导体是主要贡献者，5月对华半导体出口同比增长超过200%。
- 美国（AI资本支出强劲与关税敏感领域疲软并存）：5月对美出口同比增长59.1%。半导体（同比增长651%）和电脑（同比增长675%）增长迅猛，反映出强劲的AI基础设施投资。汽车（-5%）和汽车零部件（-4%）出口下降，受关税和生产本地化影响，这表明半导体和AI硬件受益，而汽车和机械仍面临风险。
- 东盟（广泛的供应链优势）：5月对东盟出口同比增长58.4%，创月度新高。半导体、石油产品、显示器和石化产品均实现增长。东盟受益于韩国在区域IT和中间品供应链中的角色。其增长动力比中国或美国更为广泛，尽管石油和石化产品的部分增长由价格驱动。
- 欧盟（整体温和，IT支撑）：5月对欧盟出口同比增长2.4%。汽车出口疲软，但半导体和电脑在5月录得三位数增长。石化产品和通用机械出口也有所增长。

# NOM观点：强劲芯片价格支撑韩国央行增长乐观情绪

我们预计强劲的AI资本支出周期将在今年全年维持强劲的两位数增长，这将支撑增长乐观情绪。事实上，韩国央行将2026年GDP增长预测从2.0%大幅上调至2.6%，并指出强劲的半导体周期可能通过企业利润、工资和税收收入帮助提振内需。

# 但仍是K型增长

尽管我们去年指出了韩国的双超级周期，并且我们认为复苏正在进行中，但我们仍对更广泛的经济复苏持谨慎态度。

- K型出口：韩国的出口引擎运行非常火热，但核心动力狭窄且强大：AI相关的半导体、存储和基础设施，而半导体以外的出口则面临需求疲软和地缘政治干扰（图2）。事实上，尽管油价上涨提振了石油相关产品的出口，但数量增长大幅下滑。
- 出口数量增长放缓：更重要的是，基于海关的出口数量增长正在急剧下降。事实上，基于海关的出口数量在4月下降17.7%后，5月再次同比下降18%，连续第二个月录得两位数的同比降幅。韩国央行的出口数量指数在二季度也可能放缓，尽管可能仍保持两位数增速（图4）。

# 出口数量指标出现分化

有趣的是，这两个出口数量指标在2025年开始分化，现在呈现出更加不同的趋势，反映出高价值、低重量的半导体出口权重日益增加。这种分化主要反映了出口价格衡量方式的差异。两个指标都基于相同的海关出口数据，但它们使用不同的价格平减指数来推导实际出口数量。

# ……主要由于对近期芯片价格飙升的反映较慢

海关统计的出口量基于产品层面的单位价值，而韩国央行（BOK）的出口量指数则采用以2020年为基准结构的出口价格指数进行平减（图5）。因此，两者出现差异的一个合理解释是：BOK的出口价格指数可能未能及时反映近期HBM及AI相关半导体价格飙升的情况。这可能导致其测算的出口量增长强于海关指标所暗示的水平，进而可能夸大了出口对实际GDP的贡献。

这表明，由于出口溢出效应可能依然有限，国内经济复苏所需的时间可能比强劲外部部门所暗示的更久。因此，鉴于内需复苏较为缓慢，我们维持2026年GDP增长率为$2.4\%$的预测。

话虽如此，由于在增长乐观情绪下，BOK的政策反应函数在通胀和金融稳定问题上已变得更加鹰派，我们预计BOK将在2027年初将政策利率上调至更具限制性的$3.25\%$，具体路径为：7月首次加息25个基点，随后在2026年10月和2027年1月的会议上各加息25个基点。
