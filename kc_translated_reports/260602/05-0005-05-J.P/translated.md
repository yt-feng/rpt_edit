# 全球数据观察：亚洲
# EMAX对能源冲击的韧性促使更多央行转向鹰派

亚洲一直被认为是最易因霍尔木兹海峡长期关闭而遭受供应短缺的地区，因其对该地区的能源依赖。然而，最坏的担忧并未成为现实，因为该地区（中国除外）已能够从其他地区获取进口。例如，每日油轮进口量数据显示，EMAX和印度5月的能源进口正迅速接近正常水平。加强采购的同时，各国还动用国家能源储备并转向其他燃料来源（煤炭、生物燃料），以缓冲对经济活动的冲击。这些动态，加上持续强劲的科技动能（本周该地区4月工业产出数据进一步强化了这一点），以及部分经济体的财政政策支持，意味着能源冲击对经济活动的影响虽然可见，但并未如最初担忧的那样严重。但这种韧性是有代价的，通胀压力在该地区持续累积，反映在4月PMI中投入和产出价格飙升。鉴于增长保持坚挺，央行已将注意力转向通胀，并逐渐转向鹰派。

菲律宾央行和印尼央行已在最近几周加息，尽管原因不同（前者因通胀冲击，后者因外汇承压），本周韩国央行也加入了鹰派阵营。尽管韩国央行如我们预期维持利率不变，但发出了强烈的鹰派信号，表明加息周期将比此前预期更快、更强劲。该央行的前瞻指引现在指向最早在7月加息，明年可能还会进一步加息。这一转变源于韩国持续的增长动能，尤其是科技领域，以及日益担忧这种强势将溢出至需求侧通胀压力。因此，我们现在预计未来一年将加息四次，每次25个基点（此前预测为到2027年底累计加息50个基点），首次加息就在7月。

相比之下，预计将保持耐心的央行是印度储备银行。尽管市场已消化多次加息，我们长期以来的观点是印度加息的门槛很高。本周，行长重申印度储备银行只会在能源压力蔓延至核心通胀时才会采取行动，而目前核心通胀非常温和，我们预计印度储备银行将在下周的评估中安心维持利率不变。

# 中国：5月PMI将考验近期韧性

中东冲突和能源冲击在4月拖累中国的生产和内需，引发了对经济韧性的质疑。石油供应中断导致加工油和石化产品产出收缩，部分反映了小型炼油厂更换供应商的困难，以及国有炼油厂在出口禁令下增产动力减弱。替代指标显示，5月原油加工量可能进一步收缩。同时，焦炉开工率上升表明石油向煤炭的转换增加，部分抵消了拖累。

4月活动疲软似乎还与财政支持力度有所减弱和政策耐心增加（相对于一些地区同行的补贴推出）有关。一般预算支出转为收缩，原因是基础设施支出疲软，尽管收入增长尚可。经过三个月的减少后，财政存款在4月大幅增加，超出季节性规律，这有助于解释近期的投资下滑。总体而言，财政支持的前置程度低于我们最初的设想，这意味着下半年预期的回补也将没有担忧的那么剧烈。

与此同时，4月出口保持韧性并承担了重任：强于预期的4月反弹抵消了国内疲软，尽管近期的顺风似乎越来越集中在劳动密集度较低的类别，如存储芯片、电动汽车、太阳能和电池。港口追踪数据显示，出境集装箱和散货载重吨位环比放缓，表明出现部分降温。综合来看，对于下周的5月PMI，我们预计国家统计局制造业PMI将小幅下降至50.1（4月为50.3），RatingDog PMI降至51.0（4月为52.2）。

# 澳大利亚住房：换挡减速

• 投资者住房税收规则的变化应会强化近期放缓
- 杠杆处理方式的差异表明，这将更多体现在成交量走弱而非价格上
- 历史上，住房成交量下降对家具、家居用品和休闲服务等消费支出构成负面影响

本月公布的FY27联邦预算确认，相对于2025年，财政政策环境将在2026/27年成为经济增长的逆风。这一评估主要基于财政脉冲估算，该估算将政策选择导致的政府收入和支出变化，通过财政乘数转化为GDP（见此处）。

然而，FY27预算还对资产税收引入了重大政策变化，这些变化通过经济产生次级激励效应。我们在此重点关注其中一项：取消投资者住房的负杠杆。市场参与者尤其关注其对住房价格的影响，但我们认为更大的影响将体现在住房成交量上。以下我们阐述支持这一观点的逻辑，以及对住房敏感消费群体的影响。

# 规则变更

FY27预算揭示了自1990年代末以来最重大的资本税收变化。在（不保证）获得参议院通过的前提下，政府计划取消当前50%的资本利得税折扣（对持有超过一年的资产，边际税率减半），转而采用通胀指数化方法。这将按个人边际税率与30%两者中的较高者，对资产超过通胀部分的收益征税。这些最初旨在解决房地产投机问题的变化，也将适用于股权财富和其他形式的企业所有权回报。

政府计划同时取消现有住宅投资房的负扣税政策。负扣税是指将净租金损失（即利息及相关成本超过租金收入的部分）从其他应税收入中扣除的权利。重要的是，预算案公布前持有的房产将被豁免（"祖父条款"），因此现有投资者持有的房产安排不会改变。

# 成交量游戏

通过降低持有投资房产的税后收益，投资者对此类资产的购买意愿应会下降，这意味着短期内房产成交量和价格将走弱。我们此前观察到，在政策利率预期急剧转变后，住房前景已经恶化。即使在预算案公布前的数据中，由于买家兴趣减弱，住房成交量已经下降，表明房价即将出现转折（图1）。税收变化很可能与已经开始的住房市场放缓相互作用。

图1：住宅销售成交量和价格

[[KC_IMAGE_003]]

图1中关系的稳定性揭示了一个重要特征：价格与成交量之间的关系似乎可靠地呈正相关。历史上，成交量的变化大多来自需求冲击，而市场供给相对稳定，推动价格和数量朝同一方向变动。还需注意，价格对成交量的弹性平均约为+0.3，即远小于1。因此，在大多数情况下，我们应预期任何需求冲击导致的交易量百分比变化大于价格百分比变化。

# 卡在齿轮之间

负扣税规则的改变特别有趣之处在于，祖父条款保留了现有业主的税收优惠。在图2的示意图中，这由投资房现有持有者的不变报价（O）曲线表示。潜在投资者无法获得同一资产的税收优惠，会感知到较低的价值，由出价曲线从B到B'的位移DT表示。

图2：税收处理下的投资房买卖价差曲线

[[KC_IMAGE_004]]

由于报价曲线相对平坦（斜率约为+0.3，如上所述），从（O,B）移动到（O,B'）导致的成交量变化大于由此产生的价格变化，比例约为3比1。换句话说，我们应再次预期成交量下降将承担大部分调整。

此外，对于市场的这一投机性板块，资产较低的持有价值意味着，在所有未来预期价格状态下，出价曲线都更低。通过强化正在进行的下行趋势，需求转移可能更大，因此价格需要完全反映税收影响。这不会改变对价格和成交量的相对影响，但确实会导致更大的绝对成交量收缩（由DV表示）。如果买方和卖方现在对资产的持有价值存在分歧，成交量的更大错位是一种直观的结果。

表1给出了对价格影响的粗略计算，成交量/成交额效应DV假设为三倍。我们展示了一些粗略模拟，取决于负扣税损失的平均税收优惠，以价格的百分比表示（大多数估计认为这在价格的0.5-2%范围内）。然后，我们取每年的杠杆收益，将其视为10年期的固定票息流，以5.5%的抵押贷款/贴现率计算净现值。对于总体价格效应，再乘以当前投资者在房产所有权中的份额（约1/3），以及其中负扣税敞口的份额（取决于这是房产百分比还是投资者百分比，得出0.5至0.7）。

由此产生的价格影响在1-3%范围内，与财政部对整个税收方案中期影响的估计相似。请记住，这一估计是在价格的基本轨迹之上，如上所述，该轨迹已经走弱，因此可能推动价格进入温和收缩。成交量/成交额效应更大，可能超过10个百分点。

我们认为，住房成交量很可能承担负扣税取消带来的大部分短期调整。过去我们还发现，虽然资产价格的财富效应有时可能很重要，但消费者支出中最具周期性的部分与住房成交量的关系更为可靠。

# 日本

- 政府宣布计划通过预算外资金为投资预算提供融资，...
- ...这在政治上可能掩盖财政扩张，但留下了日本国债供需问题的担忧未解
- 下周：一季度企业资本支出和利润，5月工资数据

最新数据表明，经济活动继续保持韧性，政府补贴抵消了原油价格上涨的大部分影响，而中东冲突则导致生产库存减少。在科技需求稳健和总体通胀下降的背景下，4月工业生产和零售销售均强于预期。制造商的生产计划也保持坚挺，表明他们的担忧并非需求，而主要是供给约束。

这一势头也得到了政府财政措施的支持，这些措施有效承担了全球范围内出现的通胀压力。本周，除了上周政府已预告的、规模超过3万亿日元（约占GDP的0.5%）的能源补贴相关补充预算外，政府表示将通过一般账户之外管理的框架，为目前在高市政府领导下讨论的增长战略相关的财政成本提供资金。虽然具体规模和细节将在适当时候明确，但政府似乎正在考虑一种类似于现有财政投融资计划（FILP）的方案。如果是这样，未来在此框架下执行的投资预算，在统计上将被归类为独立于政府的公共部门实体，因此不会影响一般政府的基本收支平衡或未偿政府债务。在政治上，这很可能被用来论证政府即使在采取扩张性财政立场的同时，也在“负责任地”关注财政纪律。

然而，对市场的实质性影响可能与这种说法有所不同。无论政府如何在行政上划分这些项目，或者它们在官方统计中如何被分类，根据该计划发行的日本国债（JGB）将具有与普通日本国债相同的特征，并将从下一财年起被纳入政府的债券发行计划。首相高市也表明了不受传统预算上限约束、确保必要金额的政策，这表明可能正在考虑一个规模可观的预算。如果从今年夏天开始的增长投资讨论，提高了通过预算外账户增加日本国债发行的可能性，那么本已面临压力的日本国债市场的供需担忧可能会进一步加剧。

# 四月产出增长，库存收缩

日本4月工业生产环比（m/m sa）增长0.8%，高于我们的预期（0.5%），也远高于市场共识预期（-0.9%）。部分增长反映了此前两个月下降后的反弹，但整体基调依然稳健：三个月年化环比（3m/3m saar）增速为3.9%。继一季度强劲增长之后，制造商的预测也保持乐观（图1）。经济产业省（METI）的生产展望显示5月将增长2.1%，这与5月PMI所显示的韧性一致。由于预计6月仅会出现小幅回调，制造商的预测指向二季度的复苏比我们预期的有限复苏更为明显。

# 补贴范围扩大压低东京CPI

5月东京CPI低于预期。官方核心（剔除生鲜食品）指数环比上涨0.2%，同比上涨1.3%（市场共识和JPM预期：1.5%）（图3）。主要拖累因素是政策驱动的价格降幅进一步扩大。除了自春季以来一直对通胀构成压力的扩大化免费托儿措施和免费学校午餐计划外，水费从5月起开始免费。虽然免费水费并非全国性措施，但在东京，从5月起将免除四个月的水费。据估计，这使5月份官方核心（剔除生鲜食品）通胀率降低了约0.2个百分点。加上来自托儿服务的约0.5个百分点的拖累，政策的总影响是将通胀率降低了至少约0.7个百分点。剔除这些政策影响后，潜在通胀趋势仍与日本央行的政策目标一致。

潜在通胀依然坚挺。截至5月，尚无明确迹象表明原油价格上涨导致的生产者通胀正在扩大至消费者价格。相比之下，由包括工资在内的累积成本上升所驱动的通胀仍然普遍存在。这在通信（同比6.9%）、公共交通（同比4.5%）和娱乐服务（同比2.4%）等类别中表现明显（图4）。与此同时，医疗保健在5月小幅下降（同比-0.1%），连续第三个月出现微幅负通胀。这主要反映了自春季以来，在6月份医疗服务费计划上调2.8%之前，对管制药品价格的削减。十多年来，政府一直在削减包括药品价格在内的医疗成本，但去年最终决定进行自1996年以来最大幅度的正向调整。反映这一点，医疗保健通胀很可能从下个月起再次回升。

展望未来，政策驱动的通缩效应可能会暂时持续，但越来越多的迹象表明，其他商品和服务的价格压力正在积聚。虽然经济活动数据并未发出急剧放缓的明确信号，但生产商正面临巨大的成本压力。我们预计，这将从夏季开始逐渐传导至消费者价格，将通胀（剔除政策影响）推高至日本央行目标水平之上。

# 四月销售稳健，信心回升

4月零售销售环比增长1.3%（季调后），超出我们预期的0.4%增幅。部分意外源于耐用品支出强于预期，可能受到政府政策的支撑。尽管如此，今日报告显示，尽管消费者信心疲弱（图5），家庭支出仍保持韧性，三个月滚动年化增速为2.8%。信心与实际支出之间的差距在本周期中并不罕见，我们认为，能源及其他补贴降低了整体通胀超过1个百分点，并在本季度初帮助维持了实际购买力，从而支撑了消费的短期韧性。

转向更鹰派立场源于MPC对韩国增长前景重燃乐观情绪。增长预测上调至2.6%，反映对科技行业引领持续上升周期并溢出至内需的预期。这与4月MPC会议形成对比，当时会议强调中东地缘政治紧张局势的下行风险并采取观望态度。如今，需求侧通胀压力被更严肃地考虑，行长言论表明增长、通胀和金融稳定方面方向明确，使MPC内部能达成更大共识。沟通显示委员会更担忧科技引领增长带来的通胀溢出效应，并准备更果断行动。

鉴于这些进展，我们将2027年底前的政策利率预测从3.0%上调至3.5%。点阵图和反对票表明今年可能加息两次，若明年增长和通胀仍高于潜在水平和目标，则可能进一步行动。我们还预计加息时间提前，7月加息现在极有可能，随后10月再加一次。预计明年1月和4月各再加息25个基点，在2027年4月会议达到3.5%。总体而言，韩国央行更鹰派的立场反映了对增长影响通胀的更大重视，我们预计未来几个月增长展望将进一步上调。

# 4月工业生产仅温和下降

# 预计印度央行将维持利率不变

我们预计货币政策委员会将在下周的货币政策评估中维持政策利率不变，强化其“观望”态度，并表明只有在通胀的第二轮效应开始显现时才会采取行动。正如上次会议及会议纪要所述，货币政策委员会强调，货币政策应对供给驱动型通胀冲击直接影响的能力有限；只有在第二轮效应显现时，它才具有操作相关性。我们预计货币政策委员会将重申这一信息。

随着厄尔尼诺现象发生的概率上升，印度央行可能会在其2026-27年通胀预测中纳入一些影响。目前对2026-27年通胀的预测为4.6%，印度央行此前估计厄尔尼诺现象可能使通胀上升约40个基点。气象部门的第二次预测显示，今年季风季节的降雨量将比正常水平低10%。我们预计，考虑到温和的厄尔尼诺影响，2027财年通胀平均为5%。

值得注意的是，如果出现“超级厄尔尼诺”，食品通胀面临上行风险，但天气模式如何演变存在很大的不确定性。庞大的缓冲库存也有助于缓解与厄尔尼诺相关的干扰对食品价格的压力。此外，也有过像2015年（另一个“超级厄尔尼诺”年份）这样食品通胀保持受控的情况。

在增长方面，货币政策委员会可能指出，迄今为止经济活动尚未受到中东危机的实质性影响。然而，如果油价持续高企，它可能承认其2027财年GDP增长预测（6.9%）存在下行风险。

重要的是，鉴于近期货币疲软，印度央行可能重申通胀目标制框架下的“可分离性”原则：政策利率用于管理增长-通胀动态，而外汇波动则通过外汇储备和其他监管措施来解决。自2014年采用通胀目标制框架以来，印度央行一直坚持这一可分离性原则。

# 2026年第一季度增长预计保持强劲

我们预测2026年第一季度GDP同比增长7.5%，略低于2025年第四季度的7.8%。这高于统计局的第二次预估7.3%。如果我们的预测正确，则意味着2026财年全年增长率为7.7%，而统计局的预测为7.6%。

分行业看，服务业增长预计将保持强劲，受到信贷增长持续加速和商品及服务税征收增加的支撑。相比之下，制造业增长可能更为温和，反映出盈利增长放缓。值得注意的是，制造业盈利的疲软主要来自石油行业。剔除石油后，制造业盈利增长在2025财年第四季度加速，与整体盈利增长的广泛回升一致。

重要的是，2026年第一季度包含了油价上涨一个月的拖累。然而，这不太可能体现在GDP数据中，因为其影响被政府的石油营销公司吸收，而零售油价保持不变。

尽管如此，我们GDP预测的误差范围很大。首先，我们是使用旧的工业生产指数序列构建的预测，而GDP发布将纳入预计周一发布的新工业生产指数序列。其次，这将是新GDP系列下的第二次数据发布，该系列包含若干方法上的改进——特别是关于平减指数——并且这些平减指数的表现仍存在不确定性。

更广泛地说，虽然2026年第一季度应会录得强劲增长，但这在很大程度上是回顾性的。从2026年第二季度开始，增长可能开始反映中东危机的影响。
