# 韩国科技：2026年5月出口追踪：DRAM出口创历史新高，同比增长370%

**存储：连续4个月同比增长超200%；DRAM出口同比增长370%；NAND芯片出口延续强劲趋势，连续7个月实现三位数增长（同比增长207%）**

5月存储出口同比增长255%，将同比增长超200%的趋势延续至第4个连续周期。DRAM出口也呈现强劲增长，同比增长370%，为自2008年1月开始追踪以来的最高值。NAND和SSD出口均表现强劲（NAND芯片出口：同比增长207%，SSD出口：同比增长338%）。韩国产业通商资源部将整体稳健的业绩归因于主要出口市场（美国和中国）大型科技公司的强劲需求。对于韩国公司，我们预计SK海力士2026年第二季度营收将同比增长271%，三星电子存储业务营收将同比增长452%，三星电子更强劲的增长源于其对传统存储产品的更高敞口以及HBM营收的低基数。

**HBM：4月SK海力士环氧树脂进口同比增长57%；三星电子塑料薄膜进口同比增长96%**

我们追踪1）从日本进口到利川/清州（SK海力士HBM生产基地所在地）的环氧树脂数据，因为我们相信SK海力士主要从日本公司Namics采购其MR-MUF材料，以及2）从日本进口到华城/平泽（三星电子HBM生产基地所在地）的塑料薄膜数据，因为我们相信三星电子主要从日本公司Resonac采购其TC-NCF材料。环氧树脂/塑料薄膜的进口趋势分别与SK海力士/三星电子的HBM出货量（SK海力士：图表1 / 三星电子：图表2）显示出强相关性；因此，我们认为这些指标可作为衡量SK海力士/三星电子HBM出货规模的良好代理指标。

4月，从日本进口到利川/清州的环氧树脂进口额同比增长57%，从日本进口到华城/平泽的塑料薄膜进口额同比增长96%。

# 显示器：同比反弹至高个位数百分比

5月显示器出口同比增长9%，OLED（同比增长3%）和LCD（同比增长30%）均呈现正增长。韩国产业通商资源部指出，尽管由于半导体成本上升导致终端市场需求萎缩，但新款OLED移动产品的推出推动了这一增长。对于韩国显示器公司，我们预计2026年第二季度LG Display营收将因LCD业务缩减而同比下降5%，但三星显示营收将同比增长15%。

# MLCC：4月小幅下滑后，5月出口额增长转正

MLCC出口在4月短暂下滑（同比下降4%），结束了连续12个月的正增长趋势后，于5月重返正增长区间（同比增长14%）。对于三星电机，我们预计其2026年第二季度MLCC营收将同比增长22%，主要得益于AI服务器/汽车MLCC的持续强劲表现。

# 锂离子电池：再次出现强劲反弹

锂离子电池出口在4月负增长（同比下降10%）后，于5月同比增长53%。韩国产业通商资源部评论称，对主要市场（美国和中国）的电动汽车和ESS电池出口增加，以及关键矿产价格上涨导致的平均售价提升，共同促成了这一积极结果。

# WFE：5月进出口均实现强劲同比增长

5月半导体WFE出口和进口分别同比增长66%和99%，我们认为强劲的进口增长来自于存储供应商为缓解供应紧张而增加的资本支出，而稳健的出口增长则来自于全球建设半导体产能的强劲支出。

# 目标价风险及方法论 - Samsung Electronics

主要下行风险：1）存储供需严重恶化，2）智能手机利润率急剧收缩，以及3）移动OLED市场份额流失。

# 目标价风险及方法论 - SK Hynix Inc.

估值方法：我们基于2026E/27E平均市盈率的12个月目标价为3,500,000韩元，应用9.0倍的目标市盈率。

主要风险：主要风险包括1）存储供需严重恶化和技术迁移延迟，2）智能手机/PC/服务器需求减弱，这将影响整体传统存储需求，3）三星电子HBM业务的积极进展，这将影响HBM营收和利润，4）AI相关资本支出降低，这将影响整体HBM需求，进而影响公司的HBM营收/利润。

# 目标价风险及方法论 - Samsung Electro-Mechanics

估值：我们对三星电机给予买入评级，基于SOTP（2027E EV/EBITDA驱动）的12个月目标价为1,000,000韩元。

主要下行风险：行业MLCC供应增长强于预期，以及AI服务器/汽车/智能手机需求弱于预期。

# 目标价风险及方法论 - LG Display

估值：我们对LG Display给予中性评级，基于12个月远期市净率的目标价为13,500韩元（目标倍数为0.9倍）。

主要风险：IT LCD面板价格上升/下降以及电视OLED出货量上升/下降。
