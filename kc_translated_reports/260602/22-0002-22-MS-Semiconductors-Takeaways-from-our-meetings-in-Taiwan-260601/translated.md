# 半导体 | 北美
# 台湾会议要点

我们在AI峰会及周边会议的交流，强化了对NVDA、AVGO和存储的积极看法。NVDA仍是我们进入下半年产品周期前的首选。

# 核心要点

NVDA的数据点依然非常强劲，产品周期为Rubin、Vera Rubin和Vera做好了充分准备。
AMD和Intel的服务器CPU趋势依然强劲；我们认为AMD是两者中的份额增长者。
■ 存储依然非常强劲

NVIDIA Rubin的爬坡正在按计划进行。此前存在数周的实施延迟，我们在NVIDIA预览报告中曾提及，但对芯片爬坡基本没有影响，我们预计年底前将按计划强劲爬坡。这不应引起争议，因为管理层已说明，但市场上仍持续存在重制、爬坡慢于预期或推出HBM3e版Rubin的说法——这些说法似乎都不正确。根据供应链多个环节的核查，情况并非如此。芯片性能看起来强劲，尽管首次迭代通常可以优化，但没有任何迹象表明会出现Grace Blackwell时期机架级别的爬坡挑战。我们持续听到Vera Rubin将以最低的每token成本成为性能领导者。是否会有增量延迟？当然可能，但重大延迟的说法并无证据。

Blackwell的生产也在重新加速。Blackwell的生产生命周期似乎已推迟了数月，Blackwell的产量高于我们最初的预期。我们的感觉是，这反映了更强劲的需求，因为Rubin的供应在之前的预测下受限，而对即将成为上一代产品的Blackwell需求依然强劲。

根据我们听到的数据点，NVIDIA 200亿美元的CPU目标似乎是合理的。NVIDIA在财报电话会议上出人意料地声称，今年将实现200亿美元的CPU收入——使其跻身市场领导者之列。这遭到了普遍质疑，有人认为这200亿美元包括了存储或其他产品。管理层向我们保证情况并非如此。我们估计，约100-120亿美元的CPU收入来自头节点，诚然，其价格点有些随意（大多数头节点CPU作为包含两个GPU、一个CPU、一个NVswitch和存储的卡解决方案的一部分出售，价格点并未拆分）。这意味着今年还有70-100亿美元的独立Grace或Vera收入，这是一个令人惊讶的数字——但多个联系人证实了这一点，他们表示NVIDIA可以从6个已公布的客户那里获得数十亿美元的独立CPU。

除了NVIDIA之外，商用ARM服务器的供应并不多，而Grace和Vera经过验证的性能使其成为一个具有吸引力的选择，且供应充足。

对我们来说，这继续指向CPU短缺，但似乎没有DRAM短缺那么严重，因为我们看到多个实例中服务器部署的DRAM数量低于预期。我们认为CPU供应商应谨慎大幅提价，以免将更多业务推向x86生态系统之外。

Intel的Panther Lake是18A工艺的重要验证点，但其代工业务的长期竞争态势仍不明朗。18A显然处于更稳固的基础上，Intel在该节点上构建其笔记本Panther Lake芯片，良率持续改善——虽低于经济目标，但已达到可靠水平。但我们仍感觉，路线图中一些最关键的部分仍可能转向台积电（由Charlie Chan覆盖），包括桌面级产品，但长期可能包括服务器产品的Rapids版本。明年的Coral Rapids将采用18AP，但除此之外，台积电可能仍能提供更好的性能。此外，虽然EMIB机会依然诱人，但我们确实听说，考虑到各种挑战，一些EMIB-T用户仍存在不确定性，并将台积电视为B计划。

我们仍然认为Intel故事中最重要的元素是服务器路线图，而非代工/可选性机会。话虽如此，我们可能看到足够的进展来维持代工业务的生存，鉴于服务器CPU短缺，短期内显然有能力实现超预期并上调指引。

# AMD在x86 CPU领域仍处于潜在份额增长的位置。

客户报告称，AMD在服务器CPU上实现了同类产品的价格上涨，但涨幅低于Intel和ARM替代品。2纳米产品Venice将在下半年开始爬坡，客户称其价格昂贵但性能非常强劲，我们注意到5纳米和7纳米产品也极具竞争力。客户表示，2026年的大部分供应目前已被分配，明年的可见度正在建立。

在数据中心GPU方面，供应链对MI455的整体信心很高，但我们尚未收到刚刚开始评估机架的客户的直接报告。我们预计在7月的发布会上会有新客户。

# 我们继续看到AVGO的TPU（张量处理单元）将在明年强劲爬坡——并对与客户自有工具/联发科替代品的潜在竞争充满信心。

TPU当然是为谷歌（由Brian Nowak覆盖）定制的ASIC。在描述其长期可服务市场时，该公司曾表示，最大的长期风险是其ASIC客户通过“客户自有工具”开发更低成本的ASIC，或与更便宜的供应商合作；为此，谷歌一直在与联发科（由Charlie Chan覆盖）合作开发低成本版本，最早可能从明年开始。其影响已成为一个争论点，甚至在我们自己的研究团队内部也是如此。AVGO表示，他们打算随着时间的推移保持该业务的显著多数份额。

我们继续预计AVGO将长期维持其ASIC客户80%以上的份额，并指出这实际上与联发科所阐述的长期实现15-20%份额的战略一致。尽管联发科正在取得进展，但我们仍看到潜在的启动问题，并注意到在商品采购中实现某些成本节约的愿望——特别是绕过AVGO的转手收入直接采购高带宽内存——可能面临挑战，因为公开市场的HBM价格远高于AVGO此前签订的合同价格。从我们的角度来看，目前的准备状态感觉与未来几年80/20的份额划分相符。但需要指出，我们的联发科团队持不同看法，他们仍预计到2028年时间框架内联发科将获得多数份额；这是一个争论，在芯片实际推出前无法确定结果。

内存短缺预计将持续一段时间。正如我们在过去几个月一直强调的，内存仍是AI基础设施建设的主要瓶颈——在许多情况下是关键瓶颈。这在当前股价水平上似乎已开始被市场消化，我们可能会寻找类似8-10周前出现的另一个买入机会——因为历史上的煤矿金丝雀现在可能已不重要——但我们在此报告，短缺在可预见的未来很可能会持续。

关于第三季度定价问题，目前仍不明朗，因为谈判尚未正式开始，但我们接触的大多数供应链联系人预计价格将上涨20%或更多。鉴于非常明显的上涨趋势，供应商根本感觉不到谈判价格的紧迫性。完全没有迹象表明这指向任何形式的供需平衡。

我们认为长期协议很重要，主要是作为客户对内存供需感受的信号机制；我们并不真正认为多年协议能提供多年保障，我们的关注点仍然是供需平衡的可见性。

我们继续略微偏好DRAM而非NAND，认为DRAM是更具体的瓶颈，而客户在某些情况下已能提前布局NAND，但我们不会夸大这一点——两种商品都面临创纪录的短缺，当然NAND在供给端有更好的动态，因为资本支出有限。

# 估值方法与风险

# 超威半导体 (AMD.O)

我们对AMD的360美元目标价相当于基于情景分析的2027财年预估每股收益11.10美元的约37倍，反映了以英特尔为代价进一步获取市场份额，以及数据中心业务同比增长77%（AI业务约100%）。

# 上行风险

■ 数据中心GPU表现超预期，缩小与英伟达的差距
■ PC和服务器市场份额加速增长；英特尔的竞争回应不及预期
■ 服务器更新换代推动数据中心收入超预期

# 下行风险

■ 英特尔2027年的服务器CPU抑制AMD的增长势头，使其重新夺回份额
■ AMD在图形领域输给英伟达
■ 数据中心GPU表现不及预期

# 博通公司 (AVGO.O)

我们按2027日历年度ModelWare每股收益17.33美元的28倍估值博通。这大约是调整后每股收益19.34美元的25倍，反映了相对于AI同业的轻微溢价，考虑了其超大规模的AI增长潜力和ASIC领域的长期前景。

# 上行风险

■ AI收入更强劲
■ 核心半导体业务更快复苏
■ VMware协同效应实现

# 下行风险

■ 网络份额输给英伟达（Mellanox）
■ ASIC芯片缺乏竞争力；客户流失给竞争对手
■ VMware收购执行不力

# 英特尔公司 (INTC.O)

约42倍2027日历年度每股收益1.73美元，42倍高于大型逻辑半导体同业集团的高端，反映了在仍处于低迷的业绩数据上的高杠杆潜力，以及代工业务的选择权，尽管我们长期持怀疑态度。

# 上行风险

■ 代工合作伙伴关系降低风险并进一步改善估值倍数
■ 公司在CPU短缺后重新夺回桌面和服务器失去的份额

# 下行风险

■ AMD竞争日益加剧，可能导致处理器份额进一步流失及平均售价承压
■ 代工业务成效甚微导致成本结构膨胀

# 英伟达公司 (NVDA.O)

约22倍我们模型加权2027日历年度每股收益预估13.08美元，与大盘一致，相对于计算半导体同业（AMD/AVGO/INTC）存在折价，因为高市场份额和毛利率使得近期估值倍数扩张的杠杆有限。

# 上行风险

■ 训练和推理增长推动数据中心收入
■ 基于GPU的AI PC获得牵引力，游戏销售加速
■ 英伟达可重新夺回中国市场的损失收入

# 下行风险

■ AI终端市场未如预期实现，客户大幅削减GPU采购
■ AMD重新成为可行的GPU竞争对手
■ 谷歌以外的云客户能够开发出有竞争力的定制硬件
