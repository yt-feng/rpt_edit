# 摩根士丹利：中国半导体观察，存储器周期变化率见顶，AI资本开支结构性牛市未变

我们与读者讨论了最受关注的存储器话题：(1) 当据报道最大的AI支出方有算力可出售时，故事是否开始转变？(2) 为何在长期协议签署后公司没有重新估值？(3) 变化率峰值与延长的存储器周期。

变化率见顶……存储器仍是一个周期性行业——尽管这次有所不同——并且在以下方面正接近变化率峰值：(1) 价格同比变化、(2) 库存、(3) 盈利修正广度。这可能会达到市场开始横盘整理的程度，也是存储器在此处可能暂歇的原因之一。自生成式AI（2022年11月）以来，存储器领域已出现三次周期性回调，我们倾向于在AI资本开支结构性牛市的背景下看待这些回调。

……但并非周期终点。市场要么因好消息要么因坏消息而波动。出售多余的AI算力是新的争论点，“芯片通胀”可能将超大规模企业挤出前沿AI竞赛，而我们仍看好AI堆栈变现以及AI需求/代币渗透率，这一观点依然成立。

市场最拥挤领域的波动性。一些读者正在减仓，因为近期存储器的波动使得该领域历史高位的敞口水平更难维持。过去一周我们与读者的交流反映出对这一动态的敏感性，以及对扩大滞后机会日益增长的兴趣。存储器动能可能进一步减弱，因为该板块的每股盈利修正广度接近历史高位，且超大规模企业公司承压。

我们关注什么——企业财报。在此阶段，市场对财报的反应以及超大规模企业的表态对报价的影响比存储器公司的评论更重要，后者在周期当前节点可能仍持看多态度。对于AI支出方而言，代币最大化应有助于第二季度财报，但鉴于代币最小化、具有竞争力的低成本开源大语言模型以及芯片通胀对利润率的影响，第三季度指引弱于市场预期是另一个争论点。

结论。长期来看，基于2027年预计盈利增长超过35-40%以及代理式AI的崛起（AI代理的崛起——全球影响），我们仍持看多态度。但短期内，我们越来越预期在财报公布前报价将出现一些疲软。我们的公司偏好是资金正在投入且瓶颈正在出现的地方，偏好DRAM和传统存储器而非NAND，最不偏好的是存储器模组制造商。

## 当前存储器的三大争论

当据报道最大的AI支出方有算力可出售时，故事开始转变，但潜在动机并不完全清楚，我们的观点仍偏建设性（关于Neocloud与超大规模企业机会的5个观点）。这一点——连同长期协议公告后缺乏重新估值以及存储器周期变化率见顶——是过去一周我们与读者交流中争论最多的存储器话题。

## 算力——过剩还是不过剩？

市场正在做它们通常做的事情——在头条新闻之前贴现未来。那条头条新闻（未获该公司证实）是上周关于算力容量的叙事转变。看空解读显而易见——如果一家超大规模企业有闲置算力，也许整个AI建设已经供应过剩。另一种解读是，这只是公司明智地变现基础设施以提高资本开支回报，这与算力过剩不同。真正的信号将是2026年第二季度财报，以及超大规模企业是维持还是提高资本开支——这将成为存储器公司的良好入场点。如果它们削减，那么供应过剩的叙事将继续。

代币最大化与最小化。关于算力的另一个争论点是AI代理。许多公司曾试图鼓励员工生成尽可能多的代币，但这导致IT预算支出过高，公司现在开始削减和/或寻找更便宜的代币使用替代方案。

- 我们现在看到公司正在想办法用更便宜的模型解决这个（代币最大化）问题——这可能意味着使用更多开源模型，其中最好的大语言模型来自中国。
- 我们现在看到企业越来越多地在前沿模型之上添加编排层，其中基本的AI查询发送给开源模型，更复杂的查询发送给前沿模型。
- 在代币最小化的背景下，读者的关注点在于当代币提供商报告业绩并随后发布指引时，这些动态如何显现。

结论，第二季度对AI供应链来说应该没问题，但市场担忧正转向更便宜的代币以及进入2026年下半年后的指引可能是什么样子。这对存储器的影响重大，因为它是AI资金支出的关键受益方。

## 为何长期协议后没有重新估值？

存储器公司并不贵，因为市场在理性行事——它知道盈利具有很强的周期性，市场正在合理定价（而非狂热）。许多读者相信AI重新估值论点（我们也相信），但我们认为长期协议后缺乏估值倍数重估反映了过去的经验，即长期协议要么被重新谈判，要么最终要求客户接受他们不需要的库存。我们在疫情期间的模拟半导体公司中看到了类似的动态，当时长期协议是周期性的——但可以说当前的存储器长期协议是结构性的（只要AI保持强劲）。

盈利预测能否继续上调？也许与我们交流的许多读者面临的最大逆风是，存储器价格何时、如何以及在多大程度上能继续超预期上涨并推动2028年每股盈利的时间线非常不确定。在AI受益方中，存储器相关公司的盈利修正迄今为止最为强劲，但市场对此已充分了解。

## 周期峰值与延长周期

价格的重新设定并不意味着周期结束。相反，这更可能是周期最终得以延续的必要调整。请记住，自2022年秋季生成式AI问世以来，我们已经经历了三次这样的调整。拥挤板块的进一步去不确定性和间歇性波动，与超买行业正在构筑底部（而非进入新熊市）的特征相符。价格动能开始减弱，这首先体现在超大规模企业（本轮繁荣的关键支出方）近期表现落后。我们认为，资金从超大规模企业轮动出去，可能是一个领先信号，表明存储器（关键支出受益方）接下来可能进入一段相对于市场表现落后的时期，因为该板块的每股收益修正广度正触及历史极端水平，同时市场整体也面临更具挑战性的季节性因素。

公司需要调整。AI受益股正在推动抛售——并非因为它们估值昂贵，而是因为持仓变得极度拥挤。这些公司大幅上涨，盈利修正也验证了这些涨幅。当持仓变得如此拥挤时，急剧回调既正常又健康。市场不会直线运动，像我们目睹的这种极端情况的修正，是牛市持续的必要条件。我们在这方面的观点基于一个理念：盈利基本面仍然相当强劲。然而，基本面的加速变化（即大宗商品价格）在变化率上总会达到顶峰，而公司往往会对此做出反应。

正如我们之前讨论过的，这并不意味着周期结束，尽管目前该板块缺乏价格动能，可能会为市场其他领域提供表现空间，这些领域拥有更好的相对顺风，例如周期早期的MLCC或落后的半导体设备。至少，我们近期在存储器（市场持仓最集中的板块）中看到的波动，使得在该板块维持历史高位的净不确定性敞口变得更加困难——这种动态在现货上涨/波动率上升的背景下（正如我们近期所见）已愈发明显。这一观点在我们过去一周与读者的交流中也得到了呼应，同时他们也表现出开始考虑分散化交易的意愿。
