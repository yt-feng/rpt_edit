\subsection{AI与科技：从模型竞赛到生态落地}
\textbf{AI产业正从模型参数竞赛转向生态构建与货币化验证阶段。企业采购重心从‘选模型’转向‘选生态’，边缘推理、SaaS嵌入与基础设施升级成为下一阶段关键驱动力。}
\subsubsection*{主流共识}
\begin{itemize}
  \item AI货币化仍处早期，尚未成为收入加速的拐点，但增量贡献已开始显现。
  \item 先进封装设备订单持续回暖，TCB与光通讯工具是核心驱动力。
  \item 企业AI采购从模型选择转向生态构建，平台型公司受益。
  \item 模型参数规模竞赛加速，领先优势持续时间缩短。
\end{itemize}

\subsection{AI驱动硬件需求的结构性扩张与分化}
\textbf{AI基础设施投资正从GPU向存储、测试、被动元件和HDD等硬件领域扩散，但各环节复苏节奏和定价权出现明显分化：存储和HDD定价持续走强，测试设备受益于AI推理芯片需求，被动元件产能趋紧，而模拟芯片和部分设备公司则面临产品组合调整的短期压力。}
\subsubsection*{主流共识}
\begin{itemize}
  \item AI推理芯片需求正在成为测试设备、被动元件和存储市场新的增长引擎，而非仅依赖GPU。
  \item HDD和DRAM定价在2026年下半年保持双位数季度环比增长，供应紧张是核心驱动。
  \item 半导体设备板块2027年工艺控制强度回升，先进封装和1D/1.4nm节点是主要驱动力。

\subsection{消费与零售：分化加剧，品牌力与渠道重塑成关键}
\textbf{全球消费与零售市场呈现显著分化：高端消费中，爱马仕利润率超预期但区域增长引擎切换；大众运动品牌中，阿迪达斯营收增长但利润承压，Nike主动收缩中国线上渠道；中国本土品牌如古茗、海底捞面临增长模式切换；婴幼儿奶粉行业受质量事件冲击，头部品牌份额扩大。}
\subsubsection*{主流共识}
\begin{itemize}
  \item 高端消费市场增长动力从中国转向欧洲本土和日本，高净值客户韧性显著强于大众消费者。
  \item 运动品牌正从潮流驱动转向功能驱动，阿迪达斯运动表现品类高增长，Nike通过渠道调整提升品牌质量。
  \item 中国消费市场结构性增长空间仍在，但增长基础收窄，本土品牌在多个细分领域抢占份额。
\end{itemize}
\subsubsection*{分歧与条件差异}
\begin{itemize}
  \item 爱马仕利润率超预期 vs 市场对产量和定价的担忧：Bernstein认为品类组合向上延伸是未被定价的增长来源，而市场聚焦皮革制品增长算法。
  \item Nike主动收缩线上批发以换取利润率 vs 短期收入下滑风险：Bernstein测算约10亿美元收入影响但利润率改善200bps，但份额已从27\%降至16\%。
  \item 古茗开店节奏放缓但利润改善 vs 市场担忧增长故事结束：GS认为门店密度仍低于头部竞品，中长期同店销售有望更健康。
  \item 海底捞核心业务恢复慢于预期 vs 新业务增长但稀释利润率：GS下调FY26-28净利润预测7-15\%，核心品牌单店收入转负。
\end{itemize}

\subsection{工业与能源：电网投资与AI驱动结构性增长}
\textbf{全球电网投资与AI算力扩张正驱动工业与能源板块的结构性增长，但区域分化与政策风险加剧，企业盈利质量成为关键区分因素。}
\subsubsection*{主流共识}
\begin{itemize}
  \item 全球电网投资持续高景气，变压器等关键设备供需缺口短期难以弥合，中国供应商凭借交付周期优势填补美国市场缺口。
  \item AI算力扩张带动数据中心电力需求爆发，施耐德电气、高端CCL等受益标的业绩超预期，且增长具备结构性特征。
  \item 工业自动化板块在中国市场出现边际回暖信号，施耐德、西门子等企业中国区增速显著高于预期，可能预示制造业资本开支周期底部。
\end{itemize}
\subsubsection*{分歧与条件差异}
\begin{itemize}
  \item 美国对华逆变器限制政策（FCC DA 26-786）采用《购买美国产品法》测试标准，第三国产能无法规避，市场此前对此风险定价不足。
  \item 化工行业（巴斯夫）呈现“量强价弱”组合，利润改善依赖下游补库而非终端需求，与电网/AI驱动的结构性增长形成对比。
  \item 力拓等矿业公司成本削减与项目执行超预期，但市场对其盈利结构改善的定价尚未充分反映。
\end{itemize}

\begin{itemize}
  \item 跨国药企在华业务表现分化，创新产品（如诺华Leqvio）纳入医保后增长弹性显著，而受集采影响的成熟品种（如罗氏、阿斯利康部分产品）持续承压。
  \item 中国保险行业集中度持续提升，头部寿险与财险公司市场份额稳固，中小险企在品牌、渠道和资本缓冲方面处于劣势。

\begin{itemize}
  \item 对跨国药企在华业绩前景的判断存在分歧：乐观方认为医保目录新增品种和新药审批将驱动增长（如阿斯利康管理层），悲观方则强调集采与定价改革的持续冲击（如罗氏诊断业务）。
  \item 保险行业资本缓冲的充足性评估不一：部分观点认为核心偿付能力低于100\%的中小险企面临迫切的资本补充需求，另一些则认为监管容忍度可能提供缓冲空间。
  \item GSK成本节约计划对利润率的增量贡献存在分歧：JPM测算额外节约仅带来约20个基点增量，而市场共识已部分提前反映，但公司自身目标更为积极。

  \item 管理层在业绩会上的评论和整体基调，比季度数字本身对报价的影响更大。

  \item AI驱动的预测性维护和航线优化成为永久性成本改善的关键工具，而非临时性费用削减。

\subsection{人力资本与教育不平等：结构性障碍与干预效果}

  \item 亚洲开发银行报告显示，亚洲因不平等导致的人力发展指数损失在9.7\%至35.3\%之间，教育不平等是主要驱动因素，阿富汗教育不平等达48.8\%，不丹48.2\%。

\subsection{AI竞争格局：动态不均衡，非生成式AI未推高市场势力}
\textbf{经合组织基于微观数据的初步证据表明，非生成式AI的采用并未显著提升企业市场势力，但生成式AI可能同时为小企业创造机会并强化已有优势企业地位，AI专利活动与利润率增长正相关。}
\begin{itemize}
  \item 利用法国和葡萄牙2011-2022年企业数据，非生成式AI采用者规模更大、生产率更高，但利润率未显著高于非采用者，未系统推动企业向上移动市场份额分布。
  \item 生成式AI的扩散可能加剧分化：为小企业提供机会的同时，强化已有优势企业的地位，AI创新领域的集中度与销售集中度正相关。
  \item AI专利活动与更高利润率增长相关，尤其在ICT行业，但整体AI采用率仍较低（约20\%），竞争效应尚未完全显现。
  \item 报告建立区分AI使用者与开发者、生成式与非生成式AI的分析框架，强调AI对竞争的影响需区分技术类型、企业角色和行业特征。
\end{itemize}
