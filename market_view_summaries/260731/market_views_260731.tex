\subsection{宏观与市场策略：AI驱动的贸易重构与政策不确定性下的资产定价}
\textbf{全球宏观交易主线正从单一利率预期转向AI资本开支周期与政策信誉的交叉定价：中国贸易强势由AI硬件价格驱动而非数量，日本光通信出口量价齐升，ASMPT逻辑TCB订单放量，微软capex指引打消AI基建疑虑；同时美联储信誉问题引发美元扭曲陡峭化，新兴市场货币在油价冲击下表现分化，人民币中间价模型大幅下调暗示政策响应加速。}
\subsubsection*{主流共识}
\begin{itemize}
  \item AI资本开支周期仍是全球贸易与科技硬件需求的核心驱动，中国出口、日本光通信、ASMPT订单均验证AI需求从云厂商向供应链扩散。
  \item 美联储信誉不确定性成为美元短期定价的关键变量，2s30s扭曲陡峭化与通胀盈亏平衡上行对美元构成压力，但短端利差保护仍存。
  \item 亚洲保险业杠杆水平整体可控，除非出现严重宏观冲击，准备金计提保守的公司享有估值溢价。
  \item 中国内需偏弱与出口强劲的K型分化持续，官方与出口导向PMI背离反映增长动能差异在企业是否接入出口链。
\end{itemize}
\subsubsection*{分歧与条件差异}
\begin{itemize}
  \item 中国贸易强势的可持续性：UBS认为价格驱动反映供给受限，但NOM提示内需疲弱与政策刺激规模有限，分歧在数量动能能否跟上价格。
  \item 美元走势：JPM维持做多美元，认为回调是信用折价而非趋势转变；但市场对美联储可信度的质疑可能持续，若通胀预期进一步松动，美元支撑将被消耗。
  \item AI基建资本开支：微软上调FY27 capex指引并维持正自由现金流，缓解板块担忧；但ASMPT的C2W放量要等到2027下半年，短期订单能见度需逐季验证。
  \item 新兴市场货币：GS模型显示多数货币实际表现略好于预测，但南非兰特因央行逆共识决定跑输，巴西十月大选前波动率较高，利差交易需精细选择。
\end{itemize}

\subsection{AI资本开支与算力产业链：从基础设施扩张到变现路径分化}
\textbf{全球科技与AI板块的核心叙事正从单纯的算力基础设施扩张，转向对AI变现效率与产业链结构性变化的深度审视。云厂商资本开支维持高位但指引趋于务实，AI需求从GPU向ASIC、CPU及测试设备等环节扩散，同时以AWS为代表的云业务增长动能强劲，为产业链提供了坚实的需求底座。}
\subsubsection*{主流共识}
\begin{itemize}
  \item AI基础设施投入仍处于高速增长期，主要云厂商资本开支维持高位，且普遍表示供给跟不上需求。
  \item AI需求正从单一GPU向ASIC、CPU及配套测试设备等多元化领域扩散，产业链景气度提升。
  \item 云服务商（尤其AWS）的AI相关收入呈现爆发式增长，成为整体业绩超预期的重要驱动力。
  \item AI变现路径开始清晰，从单纯出售算力向提供更高附加值的智能服务转变。
\end{itemize}
\subsubsection*{分歧与条件差异}
\begin{itemize}
  \item 关于开源权重模型对算力需求的影响：部分观点认为开源模型将降低对自研前沿模型的依赖，从而减少算力需求；但Meta和微软均表示将采取混合模型策略，开源与自研并行，算力需求结构可能更复杂。
  \item 关于AI基础设施投入的回报周期：有观点担忧过度投入，但AWS等公司通过积压订单和产能预订（如2028年产能已被预订）展示了需求的可见性，缓解了市场担忧。
  \item 关于半导体测试设备市场的竞争格局：Teradyne在超大规模客户二供认证上取得进展，可能打破Advantest的单一供应商主导地位，但份额迁移将是渐进的，最早2027年才会显现。
\end{itemize}

\subsection{半导体与设备：AI驱动下的供需重构与盈利上修}
\textbf{AI算力需求正从芯片向载板、存储、设备全链条传导，推动ABF载板毛利率、存储长协比例、WFE市场预期等关键指标系统性上修；同时，行业内部出现分化，射频前端合并交易与设备毛利率拐点提前成为新的边际变量。}
\subsubsection*{主流共识}
\begin{itemize}
  \item AI是半导体需求的核心驱动，存储、载板、设备均受益于AI算力扩张。
  \item 存储行业供需紧张将持续至2027年甚至2028年，长期协议（LTA）锁定60-70\%产能，改变定价逻辑。
  \item HBM技术迭代加速，HBM4成为竞争焦点，三星等厂商份额有望提升。
  \item 半导体设备市场增长强劲，2027年WFE市场规模预期上调至1900亿美元。
\end{itemize}
\subsubsection*{分歧与条件差异}
\begin{itemize}
  \item ABF载板毛利率能否达到60\%的长期目标：JPM认为2027下半年可实现，但市场对此存疑。
  \item 存储供需缺口2027年是否比2026年更大：GS认为缺口扩大，但部分观点担忧高利润刺激供给释放。
  \item 东京电子毛利率50\%以上目标能否提前至FY3/28初期实现：Bernstein和GS均认为可能，但市场原预期在FY29/3。
  \item 射频前端合并交易对两家公司盈利影响分化：Qorvo盈利上调，Skyworks因融资成本下调。
\end{itemize}

\subsection{消费与零售：分化加剧，高端韧性与大众承压并存}
\textbf{全球消费与零售板块呈现明显分化：高端奢侈品（爱马仕、法拉利）凭借定价权与个性化配置维持韧性，大众消费（啤酒、运动服饰）则受中国市场疲软拖累，增长动能分化。新业态与产品结构升级成为对冲需求疲软的关键，而成本压力与区域差异将主导下半年盈利走势。}
\subsubsection*{主流共识}
\begin{itemize}
  \item 高端品牌通过个性化配置和产品组合提升单价，抵消销量增长放缓，盈利韧性显著。
  \item 中国市场消费信心恢复缓慢，亚太（除日本）增长疲软，欧美日市场相对稳健。
  \item 产品结构升级（高端化、新业态）是应对需求疲软的核心策略，但量的恢复仍需时间。
\end{itemize}

\begin{itemize}
  \item 爱马仕皮具部门增速低于长期目标，但丝绸超预期、香水大跌，品类分化是否预示增长模式承压存在分歧。

  \item adidas服装与鞋履增速差达34个百分点，供应链受益程度因品类而异，市场对鞋履复苏时点判断不同。

\subsection{医疗健康：临床测序需求回暖，中国创新药进入全球后期开发}
\textbf{医疗健康板块呈现结构性分化：临床测序需求强劲驱动Illumina超预期增长，CRO行业受益于新兴生物制药融资回暖，而中国创新药资产正获得跨国药企大规模后期临床投入，标志着从许可引进到全球商业化的关键转变。}

\subsection{电力设备与自动化：AI驱动的结构性扩张与国产替代共振}
\textbf{AI数据中心需求正将燃气轮机、气体发动机、SOFC等电力设备订单周期拉长至2030年代，同时中国自动化市场在OEM端驱动下加速复苏，国产化率持续提升，两大主线共同指向工业与自动化板块的结构性上行周期。}
\subsubsection*{主流共识}
\begin{itemize}
  \item AI数据中心电力需求强劲，分布式发电与电力设备订单能见度延伸至2030年代，供给持续紧张。
  \item 中国自动化市场2026年复苏加速，OEM端增长显著快于项目端，全年增速预期上调。
  \item 国产替代持续推进，工业机器人、伺服、PLC等核心产品国产化率明显提升。
  \item 下游需求复苏覆盖面扩大，电池、电子、半导体、机器人等多行业同步回暖。
\end{itemize}
\subsubsection*{分歧与条件差异}
\begin{itemize}
  \item 电力设备供给紧张的持续性：JPM认为订单排期至2030年代，供给紧张持续数年；但未提及产能扩张可能带来的中期供给过剩风险。
  \item 自动化复苏的驱动力：MS强调AI及物理AI应用、设备更新等四因素；Citi在宏发案例中更侧重提价与银价回落的成本端逻辑。
  \item 项目市场与OEM市场的分化：MS数据显示项目市场仍同比下滑1\%，与OEM市场17\%的增长形成鲜明对比，复苏的持续性存疑。
  \item 毛利率走势：Citi预计宏发毛利率三季度回升至35\%，但银价波动和提价持续性存在不确定性。
\end{itemize}
\subsubsection*{机构观点}
\paragraph{JPM} JPM通过交叉比对Bloom Energy、Innio和GE Vernova三家不同技术路线公司的二季度业绩，确认AI数据中心对电力设备的需求正将订单周期拉长至2030年代，分布式发电和供电设备订单簿饱满，供给持续紧张，未见需求断崖或供给过剩。Bloom Energy数据中心订单已超FY25全年两倍，客户能见度延伸至2030年；潍柴动力SOFC业务爬坡路径明确（2026年30MW，2027年200MW），AIDC发动机2026年出货指引3500-4000台，产能规划2027年底达8000-10000台。估值已回调至工业周期股水平，H股和A股分别回调约19\%和13\%，股息率约4\%，大股东增持提供支撑。

{\small\color{refgray}数据：潍柴SOFC：2026年30MW，2027年200MW\par}

\subsection{区域市场：政策落地与结构性轮动}
\textbf{亚太区域市场正处在政策预期与资金流向的再平衡阶段：中国核心城市地产成交企稳、财政货币以落实存量工具为主，日本则面临日元阶段性走强与权益内部轮动的风险，韩国回购篮子提供防御性分散。}
\subsubsection*{主流共识}
\begin{itemize}
  \item 中国核心城市新房与二手房成交量已企稳，一线城市领跑，8-10月低基数下销售有望延续回升。
  \item 日本国债收益率上行使市场关注点从汇率稳定转向抑制长端利率的政策工具，日元存在阶段性走强风险。
  \item 中国下半年政策以加快落实已规划措施为主，不急于推出新一轮大规模刺激。
  \item 财政资金存量额度充足，债券发行与使用进度将加快，新型政策性资金工具规模超去年。
\end{itemize}

\subsection{全球产业与宏观的边际变化：从AI算力到消费修复的分化}
\textbf{本期其他主题覆盖的12篇报告呈现一个共同特征：全球主要资产和行业的边际变化正在加速，但方向高度分化——AI算力链条（ASML、AWS、英飞凌）景气持续超预期，消费与零售链条（中国消费、Canada Goose）仅现温和企稳，而政策与地缘变量（中国财政转向、LNG资产变现）正在重塑部分资产的定价逻辑。}
\subsubsection*{主流共识}
\begin{itemize}
  \item AI算力需求是当前全球资本开支的核心驱动力，半导体设备、云服务和功率半导体均受益于这一结构性趋势
  \item 消费修复呈现K型分化：必需消费和低客单价场景率先企稳，可选消费和跨区域出行仍偏弱
  \item 多数新兴市场产出缺口仍为负或接近潜在水平，半导体带动的增长尚未形成广泛过热
  \item 企业资产负债表修复（去杠杆、现金流改善）成为信用和股权定价的共同支撑
\end{itemize}

  \item 半导体增长的传导范围：GS认为台湾、韩国等地的增长集中在少数企业，未传导至整体劳动力市场，与传统统计滤波方法得出的过热结论不同
  \item 消费修复的持续性：商品零售和餐饮改善与航空客运走弱并存，市场对修复能否从必需消费向外扩散存在分歧

\subsection{需求韧性下的信用债供给消化与药企管线重估}
\textbf{全球信用债市场在创纪录供给下利差仍维持偏紧，核心在于被动ETF驱动的需求韧性；而赛诺菲案例显示，商业执行力强劲但研发管线折价成为估值核心变量，市场对长期增长来源的定价分歧加大。}
\subsubsection*{主流共识}
\begin{itemize}
  \item 信用债需求端总量仍能对冲供给压力，主要市场均录得正资金流入，利差维持历史区间偏紧位置。
  \item 被动ETF是资金流入主力，主动共同产品普遍净流出，显示投资者通过ETF实现信用敞口管理。
  \item 赛诺菲短期盈利动能扎实，Dupixent驱动商业执行超预期，2026-2027年EPS预测上调2-3\%。
  \item 研发管线不确定性成为药企估值核心折价因素，市场关注Dupixent专利到期后的增长接续。
\end{itemize}
\subsubsection*{分歧与条件差异}
\begin{itemize}
  \item 信用债需求持续性：GS认为总量需求技术面仍能对冲供给，但AI相关债务发行集中度可能推动利差温和走阔，且不确定性偏向更大幅度走阔。
  \item 久期偏好分化：资金明显偏向短中久期，长久期需求落后，反映对长端供给压力和利率路径不确定性的担忧。
  \item 赛诺菲股价反应：GS认为财报后9\%的跌幅可能过度，部分被终止资产预期本就不高，但市场对管线接续的长期疑虑难以短期消除。
  \item 研发转型时间表：GS测算完整转型周期可能超过七年，但管理层未给出具体时间表，市场等待2026年下半年可能的研发更新活动。
\end{itemize}

\section{辅助信号｜战略咨询}
本板块整合波士顿咨询近期关于并购与资产剥离、替代性交易结构以及AI赋能现场服务的研究，提炼出三个主题：并购市场结构性分化与区域差异、资产剥离与替代性交易的价值创造逻辑、以及AI在产业应用中的战略机遇。这些主题为宏观、产业和企业战略提供辅助信号，强调执行细节和边际变化的重要性。
\subsection{并购市场结构性分化：区域与交易规模的不均衡复苏}
\textbf{全球并购活动在2025年前三季度温和复苏，但增长主要由北美少数超大型交易驱动，亚太地区跌至十年低点，中大型交易活跃度仍低于历史常态，市场呈现结构性机会与系统性不确定性并存的格局。}
\begin{itemize}
  \item 2025年前三季度全球交易总额同比增长10\%，但增长集中于少数大型交易：超100亿美元交易达27宗（高于2024年同期的21宗，但低于2021年40宗峰值），其中联合太平洋铁路以715亿美元收购诺福克南方铁路、银湖资本等以约550亿美元收购艺电。
  \item 区域分化显著：北美交易额达1.20万亿美元，同比增长约26\%，占全球62\%；加拿大增长96\%，南美和中美洲增长47\%；欧洲整体下降5\%（英国-35\%、法国-29\%、西班牙-58\%，但荷兰+263\%、瑞士+109\%、德国+45\%）；亚太交易额2840亿美元，为十年最低，同比下降19\%。
  \item 大型交易（>5亿美元）数量仍处于历史平均区间低位，表明市场整体活跃度未全面恢复，买卖双方在估值和宏观预期上可能尚未达成一致。
  \item 私募股权和风险投资活动升温：2025年前三季度全球PE交易额同比增长38\%，大型收购（如艺电）是主要驱动力。
  \item 行业层面，工业（+77\%）、科技媒体电信（+10\%）、能源（+20\%）和医疗健康（+20\%）交易额同比增长显著，交通运输领域的大型交易贡献突出。

\subsection{资产剥离与替代性交易：价值创造的关键在执行与结构选择}
\textbf{资产剥离和少数股权、合资等替代性交易正成为企业主动创造价值的常规工具，但价值实现高度依赖执行细节和结构选择，不同路径的股东回报差异可超过100个百分点。}
\begin{itemize}
  \item 资产剥离占并购市场的比重持续上升，2013年已接近50\%；BCG实证显示，剥离后公司EBITDA利润率平均提升超过1个百分点，资本市场明确奖励主动剥离非核心业务的企业。
  \item 生物制药行业剥离面临五重独特复杂性：全球布局与本地运营的矛盾、严格且动态的监管环境、高度整合的全球供应链、需验证的IT系统以及产品供应连续性；这些执行挑战导致仅约50\%的剥离交易在中长期创造价值，表现最佳与最差交易的股东总回报差距超过100个百分点。
  \item 替代性交易（少数股权、合资、战略联盟）占比从1990年的20\%-25\%升至约35\%，并在2009年和2020年扰动期间达到峰值；2019年全球合资与联盟交易量达1.1万笔历史新高，软件与IT服务、商业与专业服务、医疗设备与服务领域增长最显著。
  \item 驱动替代性交易增长的因素包括技术变革（54\%受访者提及）、商业模式迭代（54\%）以及不确定性分担与经验获取（45\%）；这些结构在扰动期间占比上升，反映买方在不确定性中主动选择更低风险、更高灵活性的交易方式。
  \item 尽管替代性交易的公告回报率呈上升趋势，但中长期表现并不乐观：不到一半的合资与联盟交易在一年后创造价值，执行和治理仍是关键挑战。
\end{itemize}

\subsection{AI赋能现场服务：从成本中心到增长引擎的战略转型}
\textbf{现场服务行业面临技师短缺与知识断层的双重约束，应用型AI和AI智能体能够将隐性知识系统化，实现15\%以上的收入增长和5个百分点以上的毛利率提升，成为企业战略转型的新引擎。}
\begin{itemize}
  \item 结构性矛盾突出：美国卡车运输业每年因技师短缺损失24亿美元，工业制造商非计划停机损失高达每年500亿美元；美国HVAC技术人员需求增长15\%而供给仅增6\%，航空维修2025年技师缺口10\%，风电行业到2030年面临12.4万人缺口。
  \item 知识断层加剧：美国航空维修技师平均年龄54岁，风电技师42岁，生物医学技师45岁；退休技师带走的“部落知识”难以传承，即使增加招聘，知识传递效率瓶颈依然存在。
  \item 三重技术变化正在重塑行业：设备联网成为新标准、生成式AI助手释放生产力、AI智能体重塑服务执行和沟通生态；报告基于与超1000家客户合作经验提出转型路径。
  \item AI工具的核心价值在于将老技师的隐性经验转化为可检索、可复用的系统知识库，缓解知识断层对业务连续性的冲击。
  \item 对投资者和企业战略的启示：现场服务行业的AI应用不仅是效率工具，更是改变成本结构和收入模型的战略杠杆，相关企业的盈利能力和估值逻辑可能面临重估。

\begin{itemize}
  \item 亚洲开发银行研究所基于2025年人类发展报告数据测算，亚洲因不平等导致的人力发展指数损失介于9.7\%（文莱）至35.3\%（阿富汗）之间，教育不平等是南亚最严重维度（阿富汗48.8\%、不丹48.2\%），收入不平等在印度（37.4\%）、斯里兰卡（36.6\%）突出。

  \item 干预效果呈技能梯度：字母与发音对应关系效应量最大（0.764个标准差），基础技能对高阶能力形成约束，差异化教学与高质量教学存在互补性，为教育政策设计提供可扩展的模型。
\end{itemize}

\subsection{AI竞争格局：动态不均衡，集中度与利润率信号分化}
\textbf{AI对市场竞争的影响因技术类型和企业角色而异：非生成式AI未显著推高市场势力，但生成式AI可能同时赋能小企业与强化在位优势；AI创新集中度与销售集中度正相关，专利活动与利润率增长挂钩，尤其在ICT行业。}
\begin{itemize}
  \item OECD基于法国、葡萄牙2011-2022年企业微观数据发现，采用非生成式AI的企业规模更大、生产率更高，但利润率未显著高于非采用者，市场份额分布亦无系统性上移，挑战了“AI必然导致集中”的简单叙事。
  \item 生成式AI的扩散呈现双重效应：既为小企业创造机会，也可能强化已有优势企业的地位，AI创新领域的集中度与销售集中度之间存在正相关。
  \item AI专利活动与更高的利润率增长相关，尤其在ICT行业；早期AI创新集中度较高，随后指标下降，显示创新扩散的动态演变。
  \item 报告强调当前AI采用率仍低（约20\%），竞争效应尚未完全显现，需持续监测；政策上应区分技术类型与行业特征，避免一刀切的反垄断预设。
\end{itemize}
