  \item AI对就业的影响呈现‘互补多于替代’特征，中等暴露岗位被增强，高暴露常规岗位面临替代风险。

\subsection{软件与互联网：AI重塑安全与变现，估值分化加剧}
\textbf{AI正从叙事转向实际支出驱动，网络安全预算增速持续跑赢IT整体，但AI也带来定价不确定性与身份管理新挑战；互联网板块估值分化明显，数字广告与共享经济承压，旅游相对稳健；监管与宏观因素对部分公司的影响被市场过度解读，结构性机会与周期性风险并存。}
\subsubsection*{主流共识}
\begin{itemize}
  \item 网络安全支出增速持续高于整体IT支出，AI是主要推动因素，既带来新风险也保障内部AI项目。
  \item AI代理和自动化工作流正在改变身份管理需求，非人类身份成为安全新边界。
  \item 数字广告与共享经济板块估值承压，旅游板块相对稳健，市场对盈利可见度进行重新定价。
\end{itemize}
\subsubsection*{分歧与条件差异}
\begin{itemize}
  \item AI对IT服务公司的影响：是增长加速器还是定价压力源？Citi认为AI尚未带来明显增长加速，反而体现为定价不确定性；Bernstein的CISO交流显示AI是安全支出的最大催化剂。
  \item 携程反垄断整改：是结构性变化还是周期性调整？JPM认为监管改变的是变现形式而非盈利基础，市场可能过度反应；但部分投资者担忧长期变现能力受损。
  \item Snap的信用风险：现金流改善与监管/竞争压力哪个主导？JPM认为信用基本面稳健但估值折价合理，市场已部分定价风险但折扣是否足够存疑。
\end{itemize}

\subsection{金融与数字资产：代币化加速与AI融资重塑信用定价}
\textbf{代币化资产正从试点走向规模化部署，基础设施巨头入局与监管清晰度提升是核心驱动力；同时，AI资本开支的债务融资模式正在改变超大规模企业的信用-权益定价关系，长期信用利差波动性显著上升。}
\subsubsection*{主流共识}
\begin{itemize}
  \item 代币化资产市场规模将在2030年显著增长，基准情景达5.5万亿美元，乐观情景达8.2万亿美元。
  \item 传统市场基础设施机构（如DTCC、NYSE、纳斯达克）正将代币化整合至核心发行、交易和结算流程。
  \item AI相关资本开支的债务融资正在改变超大规模企业的融资结构，长期信用利差波动性上升。

  \item 自由现金流改善的方式对债券和股票的影响不同：削减资本开支改善现金流对债券有利但对股票影响偏弱，而经营现金流增长则对两者均有利。

\section{辅助信号｜战略咨询}
本板块整合波士顿咨询与麦肯锡最新研究，聚焦三个核心主题：航空业成本重构与利润分化、城市竞争逻辑转向居民体验与变革速度、以及AI部署从实验走向组织变革。各报告均被实质整合至对应主题中。
\subsection{航空业成本重构与利润分化}
\textbf{全球航空业单位成本增速已全面超过单位收入增速，利润分布极不均匀，竞争焦点从恢复运力转向重构成本结构。}
\begin{itemize}
  \item 截至2025年Q3，全球所有地区单位成本（CASK，不含燃油）增速均超过单位收入（PRASK）增速，机组人员成本同比上涨5\%-7\%，地面处理成本上涨4\%-7\%，单纯依靠票价上涨已无法覆盖成本增长。
  \item 全服务航司与低成本航司利润分化加剧，北美全服务航司靠高端需求维持利润率，而欧洲和亚太航司面临更明显的成本挤压。
  \item AI驱动的预测性维护和航线优化成为航司降低非计划停场时间、提升资产利用率的关键工具，尤其对老旧机队效果显著。
  \item OEM交付缓解和新机型引入正在重塑航线网络，航司需从运营结构层面寻求永久性成本改善，而非临时性费用削减。
\end{itemize}
\subsection{城市竞争转向居民体验与变革速度}
\textbf{城市竞争的新标尺是居民体验价值，变革速度成为可持续优势的新来源，中东和中国城市主导全球变革最快阵营。}
\begin{itemize}
  \item BCG《Cities of Choice 4.0》报告引入居民倡导度指标，通过满意度、推荐意愿和长期居住意愿测量城市竞争力，倡导度高的城市居民长期留居比例更高。
  \item 变革速度排名中，深圳（92分）、利雅得（91分）、塔什干（88分）位列前三，前十名中中国城市占四席、沙特城市占四席，欧洲城市整体偏慢。
  \item 线上活跃居民在超过70个城市中的倡导度高于其他群体，数字服务能力正成为城市留住人才的关键杠杆。
  \item 城市竞争逻辑已从基础设施资产（道路、机场）转向居民实际生活结果，包括可支配时间、体验质量和可支配价值。
\end{itemize}
\subsection{AI部署从实验走向组织变革}
\textbf{企业AI部署正从实验性转向系统性变革，工作流程重新设计和CEO直接参与治理是影响利润的最强因素，但企业级利润影响尚不显著。}
\begin{itemize}
  \item 麦肯锡全球调研显示，超过四分之三受访者已在至少一个业务职能中使用AI，但超过80\%称生成式AI尚未对企业级EBIT产生实质性影响，价值创造仍处早期。
  \item 工作流程重新设计是影响生成式AI EBIT的最强组织属性，21\%受访者已因部署AI而从根本上重新设计部分工作流程，技术本身不创造价值，价值来自运营重构。
  \item CEO直接监督AI治理与更高利润回报显著相关，28\%受访企业由CEO负责AI治理，17\%由董事会监督，大型企业中CEO监督对EBIT影响最为显著。
  \item 企业正在学习将技术能力转化为组织能力，大型企业领先，但风险与合规、数据治理等职能多采用集中化架构，员工对AI输出的审核覆盖范围差异大。
\end{itemize}
