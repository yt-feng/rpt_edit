\begin{itemize}

\subsection{消费与互联网：监管落地与结构性分化}
\textbf{中国消费互联网板块迎来监管终局信号，但行业内部结构性分化加剧：携程反垄断罚款落地消除不确定性，但排他协议取消将重塑竞争格局；奢侈品欧洲市场表现取决于对中国游客依赖度与价差；大众消费品面临渠道转型与增长业务切换的阵痛。}
\subsubsection*{主流共识}
\begin{itemize}
  \item 携程反垄断调查结案消除政策不确定性，市场更关注业务调整的长期影响而非一次性罚款。
  \item 欧洲奢侈品市场表现分化由对中国游客依赖度、区域价差和美国游客替代能力三个结构性因素决定。
  \item 中国大众消费品公司传统批发渠道持续承压，需通过产品结构升级和渠道改革应对。
\end{itemize}
\subsubsection*{分歧与条件差异}
\begin{itemize}
  \item 对携程排他协议取消后的竞争格局判断：GS认为监管未额外限制抽佣率或市场份额，竞争影响可控；NOM认为酒店产品供给趋同将加剧竞争，参考阿里案例份额可能下降。
  \item 奢侈品板块中，硬奢（如卡地亚）因低依赖度和统一定价表现稳健，软奢（如Moncler）因高依赖度和高价差承压，但美国游客能否持续缓冲存在分歧。
  \item 旺旺估值折价（9x PE vs 同行11-14x）是否合理：GS暗示市场对增长路径存疑，但部分投资者可能认为估值已反映悲观预期。
\end{itemize}

\subsection{全球宏观与产业主题：通胀、算力与贸易格局的再定价}
\textbf{全球市场正经历多重结构性力量的重塑：中国财政紧缩与贸易模式转变对全球通胀产生可量化影响，AI算力需求长期供不应求但短期面临技术性调整，HDD行业进入结构性涨价周期，而美联储在通胀改善与地缘风险之间面临更复杂的政策权衡。}
\subsubsection*{主流共识}
\begin{itemize}
  \item 中国广义财政赤字率大幅收窄是二季度GDP增速放缓的主因，7月政治局会议预计释放更强宽松信号
  \item AI算力需求长期供不应求，非线性能力提升将驱动持续资本开支，短期回调属技术性调整
  \item 中国贸易模式转变（多出少进）已对非美发达市场商品价格产生可量化的通缩效应
\end{itemize}
\subsubsection*{分歧与条件差异}
\begin{itemize}
  \item 美联储7月利率路径：通胀改善支持按兵不动，但地缘风险与油价反弹使加息概率从25\%上调至35\%，市场定价约40\%加息概率
  \item 中国数据中心需求节奏：上半年芯片供应瓶颈导致新增算力放缓，但GS维持2025-2028年20\%复合增长率，下半年有望再加速
  \item HDD行业定价持续性：MS认为结构性供应缺口持续至2028年，合约价已上移至25-30美元/TB，而市场担忧产能过剩与竞争侵蚀
  \item 人民币中间价方向：NOM模型预测值下移254个基点至6.7685，但驱动来自美元走弱而非政策主动引导
\end{itemize}
\subsubsection*{机构观点}

\section{辅助信号｜战略咨询}
本板块整合波士顿咨询与麦肯锡最新研究，聚焦AI部署对城市治理、企业转型及银行业战略的深远影响，揭示投资者情绪修复与长期回报预期之间的落差，以及精准化、数据驱动成为竞争新核心的趋势。
\subsection{AI部署加速：从城市治理到企业运营的范式转变}
\textbf{AI正从试点走向规模化部署，在智能城市、企业转型办公室和银行业中引发结构性变革，但成功关键在于精准聚焦高影响场景而非广撒网。}
\begin{itemize}
  \item 波士顿咨询智能城市指数显示，AI用例数量与居民生活质量呈正相关，但存在非线性跃升区间——部分城市通过精准部署少数高影响场景即可显著提升居民体验，无需追求用例数量最大化。
  \item 伦敦以85分领跑全球61城，迪拜、纽约、华盛顿和阿姆斯特丹并列80分；上海（77分）、北京（76分）、深圳（75分）进入加速发展梯队，中国城市在AI赋能公共服务上走在前列。
  \item 居民对生成式AI的乐观情绪形成正向循环：高频使用者（AI爱好者）对AI未来角色最为乐观，非洲、亚洲和中东城市展现出最强势头，高使用率伴随高乐观度，为城市管理者扩大AI部署提供民意基础。
  \item 波士顿咨询提出，到2030年AI代理将重构企业转型办公室：项目管理从被动追踪转向实时预警与自动协调，财务追踪从定期验证转向动态预测，变革管理从自上而下推动转向赋能业务部门自主决策。

\subsection{投资者情绪修复与长期回报预期落差：估值驱动的上涨面临盈利验证}
\textbf{市场短期情绪明显修复，但投资者对估值过高和盈利可持续性的担忧同步上升，长期回报预期低迷，暗示当前上涨更多由估值驱动而非基本面改善。}
\begin{itemize}
  \item 波士顿咨询6月调查显示，看涨2026年剩余时间的投资者比例从3月的26\%跃升至46\%，预期年底前调整的比例从43\%骤降至17\%，情绪修复显著。
  \item 然而，认为标普500被高估的投资者比例从62\%升至67\%，51\%预期未来12-24个月内出现有意义的盈利重置；市场对未来三年平均年化总股东回报率预期仅6.2\%，与3月持平，显示长期回报空间并不乐观。
  \item 利率和通胀取代地缘政治成为首要宏观不确定性：关注利率风险的投资者比例从47\%升至61\%，关注通胀的从35\%升至47\%；49\%预计通胀在2026年底后仍高于美联储2\%目标，平均通胀预期为3.6\%。
  \item 投资者对资本配置纪律要求明确：69\%回避杠杆率超三倍的公司，79\%期望稳定股息支付，58\%要求同时实现长期增长和短期每股收益指引（高于3月的52\%），79\%认为公司应考虑剥离业务。
\end{itemize}
\subsection{银行业告别规模驱动：精准化成为跑赢资金成本的关键}
\textbf{2024年全球银行业净利润创历史新高，但资本市场估值折价近70\%，反映市场对盈利可持续性的怀疑；未来十年银行需从规模扩张转向精准驱动，聚焦技术、客户、资本效率与并购。}

\subsection{气候融资进入执行阶段：多边开发银行的资金流向与机制创新}

  \item ADB 2025年气候融资承诺135亿美元，占年度总融资51\%，较2024年的111亿美元增长显著，其中88亿美元用于减缓、45亿美元用于适应。

\subsection{创业扶持的有效性：筛选机制比资金规模更重要}
\textbf{世界银行在肯尼亚的随机实验表明，决定企业能否持续增长的核心变量是筛选机制而非资金规模；多阶段筛选的就业效应在三年后持续，而简化筛选的效应逐渐消失，且更大额度的赠款并未带来成比例的长期回报。}
\begin{itemize}
  \item 多阶段筛选组的9000美元赠款使企业三年后平均增加2.0名员工，而简化筛选组的同额赠款仅增加0.6名员工，后者在统计上已不显著。

  \item 在多阶段筛选组中，获得36000美元赠款的企业在第三年的就业增长并未显著优于获得9000美元的企业。
  \item 实验覆盖超过12000份申请，三年追踪数据提供了关于高增长创业企业扶持策略的直接证据。
  \item 结论对政策制定者具有重要启示：在创业扶持中，筛选的“质量”比“速度”和“资金规模”更为关键。
\end{itemize}
