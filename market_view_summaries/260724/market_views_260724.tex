\subsection{宏观与市场（2）：行业出清与资本回流的结构性信号}
\textbf{中国连锁药房行业出清带来客流再分配，同店增长在2026年二季度加速；日本GPIF潜在资金回流规模达33.8万亿日元，可能推动日元显著升值；全球光纤价格因AI数据中心需求创历史新高，但中国产能扩张预示2026年为周期顶点。}
\subsubsection*{主流共识}
\begin{itemize}
  \item 中国连锁药房行业正经历结构性出清，门店总数预计从70万家缩减至40-50万家，单店服务人口从2000人升至3000人。
  \item 日本GPIF增加国内资产配置的讨论升温，即使不修改基本组合框架，仅利用现有目标区间上限即可产生约33.8万亿日元的日元买盘。
  \item 全球光纤价格因AI数据中心需求突破历史高点，2026年均价预计达146元/芯公里，较2018年峰值高约18\%。
\end{itemize}
\subsubsection*{分歧与条件差异}
\begin{itemize}
  \item 药房行业：市场担忧线上比价和政策不确定性，但JPM认为这些已从基本面问题转为情绪扰动，客流再分配才是核心驱动。
  \item GPIF调整时间表：部分观点认为调整可能随时发生，但JPM指出修改基本组合更可能在2027年3月财年末，且无中途修改先例。

\subsubsection*{主流共识}

\subsection{欧洲化工的结构性重置：从周期思维到资产级决策}
\textbf{欧洲化工行业正经历非周期性的结构性重置，能源成本高企、全球产能过剩、碳监管收紧与需求模式转变叠加，导致装置利用率较2015-2020年均值下降约10个百分点。行业分化加速，组合平均指标已失去指导意义，战略决策必须下沉至细分领域、资产甚至客户层面。}
\begin{itemize}
  \item 欧洲化工行业分裂为三个群体：差异化可防御领域（创新优势+客户粘性）、不确定性过渡型业务（成本劣势+监管暴露）、结构性暴露的大宗化学品（能源密集+易贸易+难差异化）。
  \item 四个结构性分化变量：能源强度、贸易暴露度、终端市场周期性、监管负担。高能源强度产品直接受制于欧洲成本位置，易运输化学品面临更强进口竞争。
  \item 碳成本压力持续上升：EU ETS过去五年上涨约40欧元/吨，叠加更广泛的监管收紧，构成结构性成本劣势。
  \item 2026年Q2中东局势曾短暂改善欧洲生产商竞争地位，但BCG定性为暂时性好转，非结构性复苏——核心问题（需求调整、投入成本高、全球产能过剩、亚洲/中东低价竞争）未解决。
  \item 增量改进计划无法弥合结构性竞争力差距，企业需通过资本重新配置、组合重塑、在差异化可防御领域建立更强地位来创造价值。
\end{itemize}

\subsection{AI算力商品化：从固定费率到实时定价与暗价值释放}
\textbf{企业级AI定价模式正从固定订阅费转向按量计费，下一步将是动态定价——算力价格随供需实时波动。这一转变可能释放高达每年1400亿美元的暗价值，集中在芯片、租赁与token三个环节的优化套利，以及数据中心融资成本降低。}
\begin{itemize}
  \item 定价模式转变已明确：Anthropic改为每人20美元基础费+按token付费API费率；OpenAI Codex从固定消息定价转为按token计量；GitHub收紧Copilot限制；Windsurf取消固定积分制。
  \item 下一步是动态token定价：推理价格随底层算力供需波动，类似批发电力市场——早高峰实时客服请求价格更高，夜间批量摘要任务更便宜。
  \item 模型可替代性是动态定价有效运行的前提：开发者可在Claude、GPT或开源模型间切换，竞争使价格贴近实际算力成本。
  \item 暗价值释放路径：芯片/租赁/token三个环节的优化与套利（每年320-460亿美元），以及数据中心运营商通过标准化定价与开放基准降低融资成本。
  \item 企业需区分AI工作负载的可替代性：深度生态集成（定制芯片、微调模型、数据驻留）创造切换成本，削弱现货市场定价约束，需采取不同成本管理策略。
\end{itemize}

\subsection{全球贸易政策进入高频波动期}
\textbf{IMF与WTO联合构建的贸易政策活动指数（TPA）显示，2019年后全球贸易政策从低频稳态跃升至高频波动，政策工具联动性增强，且促进与限制措施同步增加。}
\begin{itemize}
  \item TPA指数显示，2008-2018年全球贸易政策活动基本平稳，但2019年后出现持续显著上行，结构性分水岭由中美关税升级、疫情和乌克兰战争叠加驱动。
  \item 贸易促进类措施与限制性措施同步增加，反映各国将贸易政策作为综合性工具箱而非简单开放/封闭二元选择。
  \item 方法论上，动态因子模型融合WTO与GTA数据库，过滤单一数据源噪声，可推广至产业政策、气候监管等多源监测场景。
  \item 边际变化：传统依赖关税战单一维度的观察方式被系统化、实时化的TPA指数替代，政策分析框架升级。
\end{itemize}

\textbf{IMF对所罗门群岛的国别评估表明，气候变化对渔业等关键部门的负面效应在2050年前不同排放路径下几乎无差异，适应政策需提前布局；同时，南非保护区长期经济与生态效益显著，但需数十年积累。}
\begin{itemize}

  \item 所罗门群岛主导气候不确定性为短时强降水引发的洪水与基础设施反复受损，而非极端高温或干旱，适应优先级需重新排序。
  \item 南非保护区面积每增加1\%，家庭收入提升约0.2\%，但效应仅存在于老保护区（如1926年建立的克鲁格国家公园），新保护区（2002年后设立）效应不显著。

\subsection{人力资本的结构性分化：流离失所与公共就业保障}
\textbf{世界银行研究揭示，流离失所原因决定儿童发展缺口维度（难民偏认知/身体，国内流离失所偏心理），而埃及公共就业保障政策则导致城市劳动力从私营部门向国有企业再分配，且未提升整体受教育程度。}

  \item 边际变化：流离失所干预需针对具体发展维度设计，而非笼统援助；公共就业保障的短期人才储备可能以长期私营部门活力为代价。
\end{itemize}
