\subsubsection*{主流共识}
\begin{itemize}
  \item AI需求正从GPU/ASIC/HBM向存储器、电源管理IC和逻辑半导体扩散，300mm硅片中AI相关需求占比已近30\%（R020）。
  \item x86服务器CPU在AI基础设施中的角色被客户重新评估，需求加速而非放缓，供给约束成为行业主导挑战（R024）。
  \item 玻璃基板在先进封装中的优势（更大尺寸、更低信号损耗、热膨胀匹配）获广泛认可，多家显示企业已布局，量产时间集中在2027-2029年（R005, R023）。

\subsection{医疗与消费：分化加剧，全球化与一次性收益成关键变量}
\textbf{中国医疗与消费板块在2Q26呈现显著分化：医疗板块内，全球化能力强的公司（如手术机器人、隐形正畸）与国内政策敏感型标的差距拉大；消费板块中，啤酒高端化趋势稳健但成本承压，黄金珠宝受金价波动冲击，而游戏公司则受益于产品结构优化。一次性收益（如石药GLP-1合作首付款）显著扭曲了利润表，需关注核心业务的可持续性。}
\subsubsection*{主流共识}
\begin{itemize}
  \item 医疗板块国内需求复苏参差不齐，全球化能力成为区分项，具备海外扩张记录的公司（如手术机器人、隐形正畸）表现更优。
  \item 啤酒行业高端化趋势持续，华润啤酒量价增长跑赢行业，但铝价上涨（1H26同比+19\%）部分抵消大麦成本节约，成本压力在2Q26更为突出。
  \item 黄金珠宝行业受金价走弱和提价影响，2Q26销售环比明显减速，老铺黄金线上渠道天猫销售额同比跌超60\%，运营去杠杆导致利润率低于预期。
\end{itemize}
\subsubsection*{分歧与条件差异}
\begin{itemize}
  \item 石药集团利润大幅增长主要来自阿斯利康GLP-1合作首付款（约57.4亿元），但GS认为成品药销售增速加快（1H26同比+10\%）是更可持续的信号，而NOM指出剔除一次性收入后经常性收益可能同比下滑43\%-5\%。
  \item 老铺黄金短期估值已反映2Q26压力（12个月前瞻PE仅9.4倍，远低于历史均值20.3倍），但NOM强调门店升级和VIC客户培育等长期运营改善尚未被定价，而GS认为金价回升至年底4900美元是情绪改善的关键。
  \item 网易游戏业务基本面稳健（2Q26收入同比+6\%），但持有阿里和拼多多的股权公允价值变动导致非GAAP净利润可能低于市场预期约8\%，运营改善（经营利润率提升至37\%）与外部投资波动形成对比。
\end{itemize}

\subsection{宏观与市场：财政脉冲转负与结构性分化}
\textbf{中国财政脉冲在上半年显著转负，广义财政赤字收窄至7.0\%，叠加土地收入持续收缩，是二季度GDP增速放缓的核心拖累。与此同时，工业利润结构从上游向下游转移，光伏产业链盈利拐点从玻璃环节开始，但上游产能出清仍需时间。离岸信托税务新规与携程反垄断落地，分别重塑财富管理与互联网平台估值框架。市场定价正从总量宽松预期转向结构性修复验证。}
\subsubsection*{主流共识}
\begin{itemize}
  \item 中国广义财政在上半年实际呈现收紧态势，收入改善但支出收缩，财政脉冲为负，对总需求支撑减弱。
  \item 工业利润结构正在从上游向下游转移，下游利润增速加快，上游利润增速因高基数回落，终端需求可能企稳。
  \item 光伏产业链盈利拐点从玻璃环节开始，龙头企业协同减产推动库存下降，但多晶硅等上游环节供需不确定性尚未解除。
\end{itemize}
\subsubsection*{分歧与条件差异}
\begin{itemize}
  \item 离岸信托税务新规的影响：Citi认为短期情绪冲击、中期重塑IPO结构；GS认为对汇率和利率影响有限，是税收合规措施而非资本管制。
  \item 财政政策下半年力度：NOM预计政治局会议推出大规模增量刺激的可能性有限，债券发行将提速但基调稳健；GS认为二季度GDP低于目标区间将促使决策者强化宽松措辞。
  \item 携程反垄断后佣金率前景：GS认为有效酒店佣金率不会受到结构性冲击，参考美团/阿里历史经验；但市场担忧行业RevPAR趋势变化可能带来调整不确定性。

\section{辅助信号｜战略咨询}
波士顿咨询2026年全球投资者调查显示，AI长期信仰未动摇，但投资者对AI溢价的容忍度下降，要求AI投入转化为可量化的基本面改善。
\subsection{AI定价透支与基本面预期裂痕}
\textbf{投资者对AI长期前景保持乐观，但认为市场已过度定价AI利好，未来TSR将更依赖增长、利润率扩张和自由现金流等基本面改善，而非估值扩张。}
\begin{itemize}
  \item 45\%的读者将AI开发与监管列为前三重要因素，较2024年上升22个百分点，增幅最大。
  \item 56\%的读者认为市场对AI定价过于乐观，净乐观度高达41\%，远高于其他宏观因素。
  \item 约三分之二的读者认为当前估值和AI预期可能阻碍未来回报，估值倍数压缩将成为TSR主要风险。
  \item 读者对未来三年市场情绪偏多，但对三年期TSR预期温和，显示‘看多但不追高’的姿态。
  \item 边际变化：AI叙事已从‘讲故事获溢价’阶段转向要求可量化回报路径，非AI基础设施公司需证明AI研究何时、以何种幅度体现在营收和利润表中。
\end{itemize}
\subsection{AI执行能力与财务纪律审查}
\textbf{投资者对AI执行能力存疑，不愿为AI牺牲利润率，要求管理层主动强化近中期基本面以应对审查不确定性。}
\begin{itemize}
  \item 调查显示，投资者对AI能否转化为可持续竞争优势持审慎态度，不到一半认为积极股东能真正推动中期或长期TSR改善。
  \item 投资者正在用更严格的财务纪律审视每笔AI投入，要求看到可量化的回报路径。
  \item 企业当前最紧迫任务不是继续抬高AI研究规模，而是证明现有研究正在转化为增长、利润率和现金流的改善。
  \item 边际变化：管理层不能简单依赖积极股东驱动价值，需主动强化近中期基本面，以应对日益增加的审查不确定性。
\end{itemize}
