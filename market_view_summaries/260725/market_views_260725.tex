  \item 韧性拆解为三个维度：降低即时冲击（贡献63\%）、恢复速度（23\%）、恢复程度（15\%），抗压能力比事后追赶更重要。
  \item 15\%的企业具备“通用韧性”（在超80\%扰动季度跑赢行业），25年年化TSR比行业高出5个百分点，韧性并非成本而是长期超额回报来源。

\subsection{成本管理优先级上升，但执行能力存短板}
\textbf{2025年企业战略优先级中，成本管理超越增长扩张成为第一要务，但企业平均仅实现48\%的成本节约目标，文化阻力是最大障碍。}
\begin{itemize}
  \item 2024年底全球570余名高管调查显示，33\%将成本管理列为2025年第一优先级（较2024年上升8个百分点），70\%有足够中期可见度做出决策，企业并非盲目调整而是有选择收紧。

  \item 2026-2030年净炼油产能增长将超过需求增长，即使保守情景下供应仍超乐观需求；航空煤油和石脑油需求更具韧性，汽油因电动化面临侵蚀。
  \item AI应用覆盖全价值链：规划与排程（每桶0.15-0.30美元）、运营（0.1-0.5美元）、物流与贸易（0.2-0.3美元）、维护与可靠性（0.05-0.1美元），已有可量化落地案例。
  \item 东南亚炼油企业通过AI数字孪生实现短期排程优化，每桶提升0.15-0.3美元；AI从周期性孤岛优化转向实时利润导向决策闭环，是波动中创造竞争优势的核心杠杆。
\end{itemize}

\section{辅助信号｜智库/国际机构}
本板块整合了亚洲开发银行、IMF等机构的最新研究，聚焦三大主题：全球国防支出与补贴的结构性变化、人民币国际化的渐进路径、以及能源转型中的“加法”悖论。这些研究揭示了新兴市场国防支出的持久乘数效应、中国补贴对贸易的显著拉动、人民币计价扩张的条件依赖、以及清洁能源占比上升并未减少化石燃料绝对消费量的历史规律。
\subsection{全球国防支出与工业补贴的结构性变化}
\textbf{新兴市场国防支出和工业补贴正以结构性方式重塑全球宏观与贸易格局，其效应取决于初始条件与行业选择。}
\begin{itemize}
  \item 亚洲开发银行研究显示，1990-2023年间新兴市场国防支出冲击产生温和但持久的正向产出响应，乘数在8年后达0.7\%-1\%，而发达经济体效应偏弱甚至为负；差异源于财政空间、制度质量与冲突暴露程度等初始条件。
  \item 亚太地区国防支出增速显著高于其他新兴区域，2023年全球军事支出达2.4万亿美元，亚太新兴地区贡献超三分之一增量；中国支出2960亿美元，占区域近40\%，越南、菲律宾十年间国防预算增幅超50\%。
  \item IMF工作论文量化2015-2023年全球工业补贴效应：中国对战略行业补贴使其出口增长约12\%，而美欧同类补贴仅带来约2\%出口提升；中国补贴率从0.5\%升至1.8\%，75\%以上流向半导体、机器人等战略行业，欧美则更多流向农业等非战略领域。
  \item 中国在电子行业的规模经济效应放大补贴对出口的影响，模拟显示中国电子行业出口增长约20\%，而农业等非战略行业出口下降；补贴的行业选择比总额更能解释贸易效应差异。
\end{itemize}

\subsection{人民币国际化的渐进路径与条件依赖}
\textbf{人民币计价扩张并非对美元的直接替代，而是在美元主导框架下，通过贸易依赖、制度安排和政策工具共同推动的渐进过程。}
\begin{itemize}
  \item 亚洲开发银行研究所基于70个地区2016-2023年贸易计价数据发现，对中国的出口依赖度是解释人民币计价份额最稳定的变量，进口端效应比出口端更显著，显示中国作为买方在推动人民币计价方面拥有更强议价能力。
  \item 贸易依赖度本身不充分：许多对华贸易依赖度高的地区人民币计价比例仍较低，存在结构性障碍限制贸易关系向计价货币选择的传导。
  \item 报告引入汇率制度类型、资本管制程度、人民币清算行和货币互换协议、政治制度联系强度及高层互访频率等新变量，发现这些制度安排显著影响人民币计价扩张。
  \item 2016-2023年跨越中美贸易摩擦、新冠疫情和俄乌冲突，外部冲击未根本改变美元主导地位，但改变了部分地区在计价货币选择上的边际行为。
\end{itemize}

\subsection{能源转型中的“加法”悖论与结构性粘性}
\textbf{全球能源与材料流动遵循“加法”而非“替代”逻辑，清洁能源占比上升并不必然导致化石燃料绝对消费量下降。}
\begin{itemize}
  \item IMF工作论文提出“广义杰文斯悖论”：全球碳排放强度持续下降，但排放总量仍在上升；2012年以来全球化石燃料消费总量与排放总量仍在增长，即便可再生能源在电力结构中份额持续扩大。
  \item 历史数据显示，20世纪和21世纪技术创新未导致任何主要能源或材料的绝对消费下降（羊毛、石棉、汞除外）；所有能源载体和工业材料全球消费总量均呈上升趋势。
  \item 能源转型在历史尺度上更应描述为“能源叠加”：新技术的引入在既有体系之上增加新的能源和材料需求层，如可再生能源基础设施建设本身需要大量钢铁、水泥和化工产品，其生产目前仍高度依赖化石燃料。
  \item 报告将市场力量、地缘政治格局、贸易安排和资金因素纳入分析框架，解释为何全球能源与材料消费呈现结构性粘性。
\end{itemize}
