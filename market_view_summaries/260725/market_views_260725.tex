\textbf{AI基础设施投资持续加速，但变现路径出现分化：超大规模云厂商资本支出主动超前配置，推动服务器、测试与电源架构升级；企业级AI应用开始贡献可量化收入，但网络安全防御体系面临新挑战。}
\subsubsection*{主流共识}
\begin{itemize}
  \item AI/HPC芯片测试工序增加，推高单颗芯片测试价值，探针卡、SLT、老化测试等环节受益。
  \item 超大规模云厂商资本支出持续上调，Google 2026年指引上调至1950-2050亿美元，下半年环比增长约50\%。
  \item 企业级AI应用开始贡献可量化收入，ServiceNow AI相关年化合同价值突破10亿美元。
\end{itemize}
\subsubsection*{分歧与条件差异}
\begin{itemize}
  \item AI芯片测试设备需求是结构性增长还是短期项目驱动：NOM认为测试工序增加锚定于结构性力量，但Bernstein指出中国OSAT研发活动正在调整。
  \item 传统SIEM/XDR能否有效防御LLM驱动的自主代理攻击：MS认为多数企业部署状态不足，而Hugging Face依赖LLM分析而非传统工具。
  \item AIDD在中国商业化路径的可持续性：JPM看好中国成本与监管优势，但AI溢价倍数和成功概率假设仍是估值敏感性的主要来源。
\end{itemize}

\subsection{汽车与电动化：中国商用车定价逻辑分化，欧洲电动化需求与基建缺口扩大}
\textbf{中国商用车龙头潍柴与重汽的股价驱动力已结构性分化，前者与AI数据中心电源需求高度相关，后者仍依赖出口基本面；欧洲BEV注册量加速增长，但充电桩建设速度放缓，供需缺口扩大；宁德时代以量补价，储能占比提升至25\%，并启动大规模回购，资本配置转向股东回报。}
\subsubsection*{主流共识}
\begin{itemize}
  \item 欧洲BEV注册量在2026年上半年同比增长35.1\%，渗透率达22.2\%，6月单月增长51\%，德国、法国、英国增速均超35\%。
  \item 宁德时代二季度电池销量同比增长约60\%，储能占比从20\%提升至25\%，海外出货占比接近50\%。
  \item 欧洲公共充电桩季度建设量同比下降20\%，供需缺口扩大，直流快充桩渗透率尚未跟上需求节奏。
\end{itemize}
\subsubsection*{分歧与条件差异}
\begin{itemize}
  \item 潍柴股价与AI硬件指数（Generac/Bloom Energy）R²达0.84，而重汽仅0.22，市场对两家公司的定价逻辑已完全不同。
  \item 欧洲充电需求增长从存量利用率提升转向增量车辆入场双重驱动，但建设速度放缓，各国分化明显（意大利+21\%，德国仅+14\%）。
  \item 宁德时代单位净利润环比下降7\%至97元/kWh，但通过规模效应和费用控制实现净利润同比增长36\%，市场对利润可持续性存在分歧。
\end{itemize}
\subsubsection*{机构观点}

\subsection{消费与工业：分化加剧，结构性机会浮现}
\textbf{中国消费市场总量增长趋平，但企业间份额转移加速，高端美妆与啤酒行业均呈现外资品牌反弹与国产品牌持续扩张的分化格局；工业领域，机器人手术渗透率提升、数据中心电力需求扩张以及供应链运价高位运行构成结构性主线，但成本通胀与区域分化带来不确定性。}
\subsubsection*{主流共识}
\begin{itemize}
  \item 中国高端美妆市场2025年同比增长6\%，规模达1860亿元，高端品类占比从2019年37\%升至44\%，结构性增长趋势确立。
  \item 全球机器人辅助手术渗透率预计从33\%升至48\%（5年CAGR约11\%），增量来自开放手术向微创转换及腹腔镜向机器人迁移。
  \item 全球供应链运价维持高位，海运较冲突前上涨超100\%，空运同比升25-30\%，供给端收紧是主因。
  \item 数据中心驱动的电力需求成为公用事业和石油公司长期增长新引擎，NextEra大型负荷管线从6GW上调至8GW，雪佛龙与微软签署20年期天然气发电协议。
\end{itemize}
\subsubsection*{分歧与条件差异}
\begin{itemize}
  \item 中国啤酒行业：华润6月价值增速+6\%领跑，百威中国-4\%持续垫底，企业间分化加剧；市场对下半年基数效应和渠道库存调整节奏存在分歧。
  \item 雅诗兰黛中国复苏可持续性：2025年份额从17.6\%回升至18.7\%，但增长节奏不规律，市场对2026年能否延续双位数增长看法不一。
  \item Schindler利润率扩张节奏：Q2调整后EBIT利润率同比仅扩张35bp，成本通胀加速（全年约3500万瑞郎），下半年压力更大，与上半年暂时性支撑形成对比。
  \item 美联储利率路径：油价上涨约15\%使7月加息概率回升，但GS维持按兵不动基准判断，市场对长端利率和通胀不确定性溢价重估存在分歧。
\end{itemize}

\subsection{消费与工业：内需分化与结构升级}
\textbf{中国6月经济活动指标回升主要由制造业和消费拉动，但内需增长仍偏弱，呈现生产端强于需求端的特征。工业板块中，大马力农机与AI供应链盈利加速，而钢铁行业供需背离、库存被动累积。海外市场成为增量收入主要来源，但整体需求结构仍以非生产性用途为主。}
\subsubsection*{主流共识}
\begin{itemize}
  \item 中国6月经济活动指标（CAI）环比年化增速回升至5.3\%，主要由制造业和消费领域拉动。
  \item 工业板块内部分化明显：信息技术与AI供应链盈利加速，而传统钢铁行业供需背离、库存累积。
  \item 海外市场成为增量收入主要来源，但整体需求结构仍以非生产性用途为主。
  \item 政策预期集中于‘速度而非规模’，财政额度加速落地但不会追加预算。
\end{itemize}
\subsubsection*{分歧与条件差异}
\begin{itemize}
  \item GS认为内需增长仍偏弱，CAI改善更多由供给端和外部需求驱动；而JPM指出二季度盈利预期可实现，但板块间分化明显。
  \item MS认为A股短期情绪偏冷但处于修复窗口，而NOM强调人形机器人量产拐点已至但需求侧拐点尚未到来。
  \item GS关注隐含相关性低位对指数波动率的推升作用，而MS更关注政策预期与资金行为对市场情绪的影响。
\end{itemize}

\subsection{企业韧性：扰动时期的超额回报来源}
\textbf{基于25年近1800家美国公司数据，扰动季度仅占研究周期的11\%，却解释了约30\%的长期相对股东总回报（TSR），韧性是长期超额回报的关键来源。}
\begin{itemize}
  \item 扰动季度内，行业第25与第75百分位公司TSR差距达30个百分点，是平稳期（16个百分点）的近两倍，扰动是区分优秀与普通公司的关键窗口。
  \item 韧性拆解为三个维度：抵御即时冲击（占相对TSR贡献的63\%）、恢复速度（23\%）、恢复程度（15\%），抗压能力比事后追赶更重要。
  \item 15\%的企业具备“通用韧性”（在超80\%扰动季度跑赢行业），这些公司25年年化TSR比行业高出5个百分点。
  \item 韧性并非效率的牺牲，而是长期超额回报的重要来源，企业应重视扰动前的缓冲设计（如财务储备、供应链冗余）。
\end{itemize}

\subsection{成本管理优先级上升与执行短板}
\textbf{2025年企业战略优先级中，成本管理取代增长扩张成为第一优先级（提及比例33\%，较2024年升8个百分点），但企业平均仅实现48\%的成本节约目标，文化阻力是最大障碍。}
\begin{itemize}
  \item 70\%的受访高管表示有足够中期可见度做出研究决策，企业并非在调整，而是在有选择地收紧。
  \item 企业平均仅实现48\%的成本节约目标，未达成目标的企业在股东总回报上比成功者平均落后9个百分点。
  \item 文化阻力是成本削减的最大障碍，主动推动文化对齐与敏捷管理的企业，成本削减效率高出最多11个百分点。
  \item 供应链优化与产品组合简化是优先方向，67\%的高管计划将节省资金重新投入增长和创新。
\end{itemize}

\begin{itemize}
  \item 廉价土地是驱动扩张的首要因素，美国土地成本最低的十个州装机增速（24\%）是最高十个州（9\%）的2.6倍。

  \item 美国需求增长解释了13\%的扩张，而中国因西部基地远离负荷中心，增长动力更多来自国家能源转型战略和跨区输电规划。
  \item 美国州级可再生能源目标在短期与装机增长相关，但长期无显著影响，政策目标本身不足以成为持续驱动力。
