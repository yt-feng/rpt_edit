\subsection{AI基础设施与商业化：从算力集群到企业级应用}
\textbf{AI产业正从单点技术突破转向系统级竞争，算力集群的互联规模、电力资源的稀缺性以及企业级AI的货币化进程成为当前市场关注的三大主线。国产AI加速器竞争焦点已从单卡规格转向SuperPod系统级互联，而企业软件领域AI变现仍处于早期，但ServiceNow等公司已开始产生可量化的商业价值。}
\subsubsection*{主流共识}
\begin{itemize}
  \item AI算力竞争从单芯片转向系统级集群，国产厂商普遍展示64卡/128卡SuperPod方案，华为Atlas 950实现1024卡互联。
  \item 电力资源成为AI基础设施的关键瓶颈，比特币矿工凭借现成电力接入和站点优势，在第三方算力供应中占据独特地位。
  \item 企业级AI应用货币化仍处早期，但ServiceNow等先行者已实现AI ACV超10亿美元，L1 ITSM等产品开始规模化部署。
\end{itemize}
\subsubsection*{分歧与条件差异}
\begin{itemize}
  \item NVIDIA认为AI推理瓶颈在单核性能，推出Vera CPU强调单线程速度；AMD则认为并发工作流数量是关键，EPYC机架级吞吐量可达Vera的2.4倍。
  \item 东南亚电信商AI代币套餐能否成为持续盈利来源存在分歧：JPM认为门槛低、易复制，收益最终流向消费者；但自建AI基础设施的运营商可能受益。
  \item 日本AI半导体板块回调性质存疑：JPM量化团队认为主要是情绪和仓位调整，盈利预期未恶化；但高贝塔/高动量策略反弹力度有限，板块重回领涨仍需时间。
\end{itemize}

\subsection{区域市场与综合：AI资本开支、信贷扩张与财政分化}
\textbf{全球市场正经历AI资本开支扩张与区域信贷结构分化的双重叙事：美国科技巨头以资本开支换取云收入增长，亚洲（除中国）信贷创18年新高，而中国财政脉冲转负、地产收入持续收缩。}
\subsubsection*{主流共识}
\begin{itemize}
  \item AI基础设施投资正直接转化为云业务收入增长，资本开支扩张与收入加速的正向循环已可验证。
  \item 亚洲（除中国）信贷扩张由AI、能源、国防等领域的多年代际资本支出超级周期驱动，企业贷款增速创18年新高。
  \item 中国广义财政赤字（AFD）持续收窄，二季度财政脉冲转负，对GDP形成拖累。
\end{itemize}
\subsubsection*{分歧与条件差异}
\begin{itemize}
  \item AI货币化路径：BofA认为Alphabet云业务资本开支与收入正循环已确立，而UBS认为成本端（资本开支+股权激励）上升将压缩未来盈利。
  \item 日本市场结构：Bernstein看好外资流入与估值修复，但出口与内需板块基本面信号分化，7月内需反超出口。
  \item 中国CDMO板块：GS认为估值修复从alpha转向beta复苏，但持续性取决于二季度财报兑现。
\end{itemize}

\section{辅助信号｜战略咨询}
本板块整合波士顿咨询近期研究，聚焦企业韧性、成本管理优先级、可再生能源扩张驱动因素、欧洲太空经济乘数效应及炼油行业AI转型，揭示扰动期超额回报来源、成本执行短板、土地与装机基础对风光部署的关键作用、太空投资的高杠杆回报以及AI对炼油利润的结构性改善。
\subsection{企业韧性：扰动期超额回报的核心来源}
\textbf{基于25年近1800家美国公司数据，扰动季度仅占研究周期的11\%，却解释了长期相对TSR的约30\%，韧性并非成本而是长期超额回报的关键。}
\begin{itemize}
  \item 扰动季度行业内TSR差距（第25至75百分位）达30个百分点，是平稳期（16个百分点）的近两倍，扰动是区分优秀与普通公司的关键窗口。
  \item 韧性的三个维度中，降低即时冲击对扰动期相对TSR的贡献占63\%，恢复速度占23\%，恢复程度占15\%，抗压能力比事后追赶更重要。
  \item 15\%的企业具备“通用韧性”（在超80\%扰动季度跑赢行业），这些公司25年年化TSR比行业高出5个百分点。
  \item 财务缓冲（低负债）是通用韧性企业的显著特征，提示企业应优先构建扰动前的缓冲设计（财务储备、供应链冗余、早期预警机制）。
\end{itemize}

\subsection{2025年企业战略优先级转向成本管理，执行能力存系统性短板}

\begin{itemize}
  \item 成本目标达成率不足五成，未能实现长期结构性降本的企业在股东总回报上比成功者平均落后9个百分点。
  \item 最大障碍是“员工与组织文化”层面的阻力，主动推动文化对齐和敏捷管理的企业成本削减效率高出最多11个百分点。

  \item 成本管理本质是组织能力问题，而非单纯财务或运营技术，激励机制、沟通方式和组织惯性决定长期效果。

\begin{itemize}
  \item 廉价土地解释了中美约20\%-21\%的装机增长，美国土地成本最低十州装机增速（24\%）是最高十州（9\%）的2.6倍。

  \item 美国需求增长解释了13\%的扩张，而中国增长动力更多来自国家能源转型战略和跨区输电规划，与本地需求关联微弱。
  \item 美国州级可再生能源目标短期与装机增长相关，但长期无显著影响，暗示政策目标本身不足以成为持续驱动力。

\section{辅助信号｜智库/国际机构}
本板块整合亚洲开发银行与IMF最新研究，聚焦三大主题：亚太国防支出温和但持久的产出乘数、人民币计价结算的渐进渗透条件、以及全球能源消费的“加法”而非“替代”历史模式。
\subsection{亚太国防支出：温和持久但高度依赖初始条件}
\textbf{亚洲开发银行研究发现，新兴市场国防支出冲击带来温和但持久的正向产出响应（8年后乘数约0.7\%-1\%），但效果高度依赖财政空间、制度质量与冲突暴露程度，并非普适增长工具。}
\begin{itemize}
  \item 1990-2023年全球样本显示，新兴市场国防支出冲击8年后产出乘数约0.7\%-1\%，而发达经济体效应偏弱甚至为负。
  \item 亚太地区国防支出增速显著高于其他新兴区域：2023年全球军事支出达2.4万亿美元，亚太新兴地区贡献超三分之一增量；中国一国支出2960亿美元，占区域近40\%。
  \item 越南、菲律宾过去十年国防预算增幅超50\%，印尼、马来西亚国防负担升至GDP的1.2\%-1.5\%；拉丁美洲维持约1.3\%，撒哈拉以南非洲从2.3\%降至1.6\%。
  \item 乘数差异源于初始条件：财政空间、收入能力、制度质量与冲突暴露程度是关键调节变量，而非支出规模本身。
  \item 研究采用联合国政府职能分类数据，通过局部投影方法识别经周期调整的国防支出冲击，稳健性检验覆盖样本选择、变量定义与模型设定。
\end{itemize}
