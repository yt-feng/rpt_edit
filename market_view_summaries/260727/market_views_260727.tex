\subsection{AI基础设施扩张与结构性分化}
\textbf{AI基础设施投资持续扩张，但不同环节出现显著分化：服务器CPU需求强劲，PC端受内存涨价拖累，而TPU即服务等新模式正在重塑算力供给格局。}
\subsubsection*{主流共识}
\begin{itemize}
  \item AI驱动服务器CPU需求保持两位数增长，AMD和英特尔数据中心业务均超预期。
  \item 全球算力供给持续紧张，自建数据中心和提前锁定硬件成本成为关键竞争优势。
  \item AI资本支出预期仍在上调，但信用利差走阔和融资压力开始引发关注。
\end{itemize}
\subsubsection*{分歧与条件差异}
\begin{itemize}
  \item TPU即服务模式能否成为谷歌新的增长引擎，市场对其规模和利润率的认知存在分歧。
  \item AI相关公司盈利预期已大幅上调，高期望下财报超预期的门槛显著提高。
  \item PC端需求受内存涨价影响的程度和持续性，不同机构判断不一。
\end{itemize}

  \item 燃油车市场结构性收缩加速，1H26零售同比下降26.3\%，二季度降幅扩大至38.2\%，经销商库存高企、折扣加大。

\subsection{区域市场与跨境：关税、政策与地产的分化信号}
\textbf{全球贸易关税不确定性缓解、中国政策重心转向存量执行、地产盈利持续分化，三大主线共同构成当前区域市场的核心图景。}
\subsubsection*{主流共识}
\begin{itemize}
  \item 美国新关税税率低于此前市场预期的20\%对等关税水平，全球工具行业成本端不确定性显著下降。
  \item 中国二季度GDP增速4.3\%低于目标，但上半年4.7\%仍在区间内，决策层倾向于加速现有预算执行而非推出大规模新刺激。
  \item 中国开发商盈利持续承压，1H26净利润同比下滑26\%，土地投资审慎导致未来可售资源收缩。
\end{itemize}
\subsubsection*{分歧与条件差异}
\begin{itemize}
  \item 关税降低对工具企业盈利的提振幅度存在分歧：Citi认为创科实业下半年利润率扩张可达130bp，但其他企业受益程度取决于越南产能占比和品牌组合。
  \item 中国政策节奏分歧：JPM认为财政执行优先、增量刺激概率低，但若三季度增长不及预期，年底前仍可能调整。
  \item 地产企业盈利分化显著：华润置地通过处置收益实现盈利持平，而龙湖、越秀降幅超90\%，市场对一次性收益与经营能力的定价存在分歧。
\end{itemize}
\subsubsection*{机构观点}
\paragraph{Citi} 美国对60个贸易伙伴加征10-12.5\%新关税，低于此前市场预期的20\%对等关税，全球电动工具行业关税不确定性消除。创科实业（TTI）和史丹利百得（SWK）此前已将20\%关税纳入财务规划，新税率低于基准，存在盈利预测上调空间。创科实业2026年上半年净利润预计同比增长12\%至7.02亿美元，下半年增速有望加快至26\%，全年盈利前低后高。利润率扩张核心驱动：关税降低贡献30bp、HART品牌亏损消除贡献20bp、产品组合向Milwaukee倾斜贡献10bp。下半年利润率扩张幅度更大，达130bp，其中80bp来自HART亏损消除、40bp来自关税降低。Citi按偏好排序：创科实业、巨星科技、泉峰控股、史丹利百得。

\begin{itemize}
  \item 波士顿咨询研究显示，仅5\%的企业从AI中获得可规模化价值，核心障碍是运营模式仍为纯人类劳动力设计，导致流程碎片化、所有权不清、规模化受限。
