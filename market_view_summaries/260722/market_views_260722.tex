\subsection{AI驱动下的半导体结构性分化：从算力基建到应用兑现}
\textbf{AI正从算力基建阶段向应用兑现过渡，半导体行业内部出现显著分化：存储与先进封装受益于AI推理需求的结构性增长，而传统逻辑芯片与设备进口则面临周期性与地缘政治的双重压力。开源模型的普及并未削弱算力需求，反而通过更长的上下文窗口和更广泛的部署场景，推高了HBM和计算资源的总需求。同时，长期协议（LTA）对存储行业盈利波动性的平滑作用有限，市场对此的定价可能过于乐观。}
\subsubsection*{主流共识}
\begin{itemize}
  \item 开源大模型（如Kimi K3）的普及增加了对HBM和计算资源的总需求，而非削弱，因为更长的上下文窗口和更广泛的部署场景推高了内存和算力消耗。
  \item 混合键合技术正从逻辑芯片向HBM存储渗透，逻辑芯片采用趋势明确，HBM的采用时间表存在不确定性但长期方向确定。
  \item 中国半导体设备进口在2026年6月出现环比大幅回升，光刻设备进口从4月低点恢复，但上半年累计仍同比下降。
\end{itemize}
\subsubsection*{分歧与条件差异}
\begin{itemize}
  \item 长期协议（LTA）能否有效平滑存储行业的盈利波动：Bernstein认为当前担保规模（约330亿美元）相对于需覆盖的收入（约5.2万亿美元）比例过低（0.6\%），无法从根本上改变周期特征；而市场部分定价已隐含LTA能大幅平滑盈利的预期。
  \item 苹果自研AI服务器芯片（Baltra ASIC）的性能与时间表：MS认为其性能可能面临挑战，首批产量有限且本质属试验性产品，可能影响Siri AI表现或增加外部云服务成本；而供应链信息显示其仍在按计划推进。
  \item 微软Azure AI的货币化路径：MS认为市场目前按“基础资源供应商”定价Azure AI，忽略了更高层AI服务和平台拉动的收入乘数，其新建模型显示即使最保守情景也能贡献可观收入增量；而市场对此拐点的幅度和持续性存在分歧。
\end{itemize}
\subsubsection*{机构观点}
\paragraph{Bernstein} 混合键合正从逻辑芯片的明确趋势向HBM存储的渐进渗透演进。逻辑芯片领域，台积电SolC产能预计从2025年的1万片/月增长至2028年的8.5万片/月，驱动混合键合设备市场2028年达8.87亿美元。HBM领域，三星可能在2027年HBM4E中率先采用混合键合，但仅限于16层堆叠中的1层；若HBM4E仅12层，则引入可能推迟至2028年HBM5。2028年HBM用混合键合设备市场规模预计4.89亿美元，设备密度不到逻辑芯片的一半。

\paragraph{UBS} 半导体行业正在进入一个“现金创造能力与市场定价背离”的阶段。开源模型Kimi K3（2.8万亿参数）的发布并未削弱算力需求，反而因更长的上下文窗口和KV缓存需求增加对HBM和存储的需求。存储子行业到2028年的累计自由现金流占市值比例最高，美光尤为突出，但市场并未充分定价这一差异。英伟达在开源模型竞争中仍是重要受益者。

\subsection{消费与零售：分化加剧，结构性亮点与调整并存}
\textbf{全球消费与零售市场呈现显著分化：美妆、高端手表及部分电商平台展现韧性，而家庭护理、中档手表及部分品牌库存清理仍在进行。AI驱动的购物助手成为电商下一阶段增长动力，中国市场高端白酒定价权修复但非标产品承压。}
\subsubsection*{主流共识}
\begin{itemize}
  \item 美妆品类成为消费中相对少见的增长亮点，宝洁美妆部门增速是整体2.5倍，e.l.f. Beauty护肤品类增长38.8\%。
  \item 东南亚电商平台（Shopee、TikTok Shop）正从补贴换增长转向关注运营效率，最终商品价格上行，竞争噪音减弱。
  \item 瑞士手表出口6月同比增长11.2\%，但剔除工作日效应后仅增1.1\%，美国市场增长12.7\%是主要驱动力，大中华区仍在调整。
\end{itemize}
\subsubsection*{分歧与条件差异}
\begin{itemize}
  \item 茅台飞天提价后批价迅速反弹（原箱涨55元至1705元），但非标产品发货量同比下降约30\%，定价权修复路径分化。
  \item Puma库存清理在英国取得进展（DTC SKU数量较峰值下降近50\%），但美国市场仍处于回购阶段，进度落后。
  \item Ulta促销活动客流分化：Big Summer Beauty Sale客流增10.9\%，而Jumbo Love与21 Days of Beauty客流下降约1.7-1.8\%。
  \item Agentic Commerce对电商格局影响：MS认为大型平台将受益，而非被颠覆，预计2030年线上渗透率升至27\%。
\end{itemize}
\subsubsection*{机构观点}
\paragraph{Bernstein} 达美乐Q2美国同店销售仅增0.1\%，但订单量增长显著，外卖和外带渠道均实现正增长。管理层预计Q3同店销售加速，但客单价不确定性、加盟商盈利能力和国际业务调整使公司距离恢复长期增长轨道仍有距离。新品成败是下半年关键变量，但消费者偏好周期缩短增加不确定性。

\subsection{工业与材料：供应链重构与区域分化}
\textbf{全球工业与材料板块正经历供应链重构与区域需求分化：数据中心储能需求爆发式增长，欧洲工业品面临增长瓶颈，中国工业自动化外资配置回暖，而能源与材料市场则受地缘政治冲击呈现结构性紧张。}
\subsubsection*{主流共识}
\begin{itemize}
  \item 数据中心储能需求强劲，美国数据中心电力容量预计2030年达103GW，配套电池需求将从5GWh增至66GWh。
  \item 欧洲工业品（如电梯、汽车）面临增长放缓，中国市场调整及产品组合下移拖累业绩。
  \item 中国工业自动化外资持股比例回升，恒力液压和双环传动领涨，但修复路径分化。
\end{itemize}
\subsubsection*{分歧与条件差异}
\begin{itemize}
  \item 对卡塔尔LNG冬季供应恢复速度存在分歧：部分机构认为2-3周内可能停产，而市场定价隐含乐观预期。
  \item 中国玻纤市场粗纱与电子纱走势分化：粗纱承压，电子纱供需偏紧，价格有上行空间。
  \item 油价风险偏向上行，但市场对极端情景的定价弹性已高于战争初期，需求弹性与库存容忍度提升。
\end{itemize}

\subsection{网络安全预算加速扩张，AI治理成为新焦点}
\textbf{网络安全预算增速显著超过IT预算，且差距扩大；AI代理型安全治理成为专业服务软件领域的关键差异化因素，但不同公司的路径和壁垒各异。}
\subsubsection*{主流共识}
\begin{itemize}
  \item 网络安全预算增速持续快于IT预算，且差距较2025年底进一步扩大，超过半数CISO上调了全年支出预期。
  \item 软件/SaaS是网络安全支出增长的主要受益方，身份安全、云安全和端点安全仍是优先投资方向。
  \item AI/LLM被视为网络安全支出的净新增预算来源，而非替代现有预算，主要受益领域是SecOps。
\end{itemize}
\subsubsection*{分歧与条件差异}
\begin{itemize}
  \item 关于AI安全治理的壁垒：Intapp认为结构性壁垒来自企业专有的机构数据和工作流，而SS\&C则强调规模和数据深度带来的执行优势。
  \item 关于端点安全支出前景：虽然基线较高，但未来12个月支出计划增幅出现下降，而身份安全和威胁情报的增量支出意愿提升明显。
  \item 关于SSE（安全服务边缘）需求：支出增长预期最弱，且较上次调查进一步走弱，可能因早期采用者已部署完毕，新买家被其他AI相关优先项挤占。
\end{itemize}
\subsubsection*{机构观点}
\paragraph{Bernstein} 2026年6月对100位美国CISO的调查显示，43\%的受访者预计网络安全支出增速快于IT支出，仅20\%认为IT更快，差距较2025年底扩大。超过半数CISO上调全年支出预期，暗示下半年支出将明显强于上半年。软件/SaaS是最大受益方，70\%受访者预期未来12个月软件支出增长。身份安全、云安全和端点安全是优先级最高的三个领域，但端点安全支出计划增幅下降，而SecOps、身份安全和威胁情报的增量支出意愿提升明显。SSE支出增长预期最弱。

\subsection{稳定币美元化：新兴市场货币政策的新挑战}
\textbf{稳定币提供传统存款美元化相似的宏观驱动因素，但对资本管制几乎免疫且高度持久，可能放大银行体系脆弱性。}
\begin{itemize}
  \item BIS工作论文基于130+地区1990-2019年存款美元化数据及2017-2024年跨境稳定币流入数据，发现两者均与汇率传递效应强度、主权或银行扰动显著相关。
  \item 银行扰动对稳定币流入的推动作用尤为突出，符合稳定币的非银行属性——银行体系不稳定时，非银行渠道美元获取方式更具吸引力。
  \item 两种美元化均高度持久：存款美元化具有显著自回归特征，稳定币初步证据同样显示高度持续性，一旦形成难以逆转。
  \item 存款美元化与稳定币之间替代效应有限，暗示两个市场存在一定割裂，稳定币可能成为银行体系脆弱性的放大器。
