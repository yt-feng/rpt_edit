LLM Agent已经能操作生物工具了？

AI+生物安全

新报告：Agent初步可用

RAND出了一份新报告，专门评估LLM Agent能不能选对、用对生物研究工具（BT）。

核心发现很直接：能，但没那么稳。

1/ 选工具还行
7个前沿模型在“选对工具做对事”上表现都不错，得分接近80%。
但一旦换成具体生物场景（比如“设计某蛋白”），准确率就掉。
而且闭源模型在涉及“风险场景”时会频繁拒绝回答。

2/ 操作工具：能跑，但容易翻车
用EVEscape预测免疫逃逸、用ESM3做蛋白重设计，Agent都能上手。
但一致性很差，换个蛋白目标就掉链子。
常见翻车点：自主操作出错、数据处理失误。

3/ 加提示词不一定有用
给更多生物信息，结果并不稳定。
有的任务变好，有的反而变差。
也就是说，即使你懂生物学，也不一定能预测Agent会怎么反应。

4/ 闭源模型“拒绝”是常态
涉及病毒蛋白的任务，闭源模型经常直接拒绝执行。
这种“拒绝”本身也是风险——如果模型只拒不安全任务，但坏人可以用开源模型绕过。

一句话总结：LLM Agent已经能完成生物工具的基础交互，但可靠性和安全性都还远没达标。未来需要更深入的能力和风险评估。
