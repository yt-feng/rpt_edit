关税加到谁头上？一篇看懂最新研报

关税成本，谁在买单？

关税加到谁身上，真不是简单一句话。

最近翻到一篇IMF工作论文，专门拆解2025年美国关税对进口价格的影响，逻辑链条很有意思，分享几个关键点👇

1️⃣ 出口商价格几乎不动
- 论文发现，在“品种-国家”层面，出口商几乎没有通过降价来消化关税。
- 也就是说，关税成本基本完全转嫁给了美国进口商，进口含税价格几乎一比一上涨。

2️⃣ 但产品层面价格反而下降
- 奇怪的是，看单个产品（比如HS10位码）的平均进口价格，关税越高，价格反而越低。
- 这不是出口商降价，而是进口商在“换供应商”。

3️⃣ 核心机制：重新分配
- 关税高的产品，进口商迅速把订单从高价来源国转向低价来源国。
- 低价的新供应商进入，高价的旧供应商退出，拉低了平均价格。
- 这种调整在关税涨幅越大的产品中越明显。

4️⃣ 代价：质量下降
- 论文进一步用“产品吸引力”模型分析，发现这种低价转移，部分是因为转向了更低品质的供应商。
- 用调整后的价格指数算，关税对进口价格的“降价”效果明显减弱，说明低价≠高效，更多是质量降级。

5️⃣ 对福利和生产率的影响
- 进口原材料和中间品质量下降，长期可能拖累生产率和消费者福利。
- 短期看着进口价格降了，但背后可能是“便宜没好货”。

📌 小结：关税的传导不是简单的一刀切，价格信号背后有复杂的供应商重组，而重组的方向不一定是效率提升，有时是质量妥协。
