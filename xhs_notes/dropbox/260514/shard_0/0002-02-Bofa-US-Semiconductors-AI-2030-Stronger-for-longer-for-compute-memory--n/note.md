2030年AI数据中心市场将达1.7万亿美元，年复合增长45%📈

**AI超级周期，才刚刚开始**

一句话结论：某外资投行最新研报大幅上调AI数据中心市场规模预测至2030年1.7万亿美元，核心逻辑是AI算力需求“更强更久”，而并非市场担心的资本开支见顶🚀

1️⃣ **算力需求加速而非减速**
- 2026年将是AI销售和回报加速年（OpenAI、Anthropic等IPO将提供催化剂）
- 2027年新架构（计算/内存系统）将提升token经济性
- 尽管供应链瓶颈存在，但提前布局的厂商将继续超预期

2️⃣ **计算/内存多元化是增量，不是替代**
- AI加速器TAM上调至1.2万亿美元（原1万亿），主要因超大规模云厂商自研芯片（Google TPU、AWS Trainium）出货增加
- CPU服务器TAM上调至1100亿美元（其中AI CPU 880亿美元）
- 新架构下，CPU将与GPU协同工作，SRAM超低延迟内存与HBM并存——这是“做加法”，不是“做减法”

3️⃣ **内存是最大惊喜，供需结构已质变**
- 研报认为内存需求将持续超过供给，价格维持坚挺
- 内存供应弹性结构性降低（受资本、封装、电力限制）
- **最核心变化**：内存厂商将跑赢设备厂商——这是中期投资逻辑的转折点
- 目标价大幅上调：美光MU从$500→$950（基于分部估值法）

**我最想提醒的一点**：别被“资本开支见顶”的担忧吓跑。研报明确说2026-2027年AI销售和回报会加速，而且内存供应弹性已经结构性降低。如果你还在等“回调再买”，可能等不到深度回调——因为基本面在变好，不是变差。
