# 以太网市场的发展观察

**以太网市场正在经历一个结构性变化阶段**

某研究机构最新报告指出，以太网交换机市场预计将从2025年的约500亿美元增长到2035年的2000亿美元以上。这一增长趋势并非线性，而是呈现出结构性转折的特征。

**三个主要推动因素👇**

**1/ AI网络从“计算密集”转向“互联密集”**
- 以太网在AI数据中心中，正从机架间互联（scale-out）扩展到GPU间互联（scale-up）
- 传统NVLink路线开始面临以太网的竞争，因为后者在异构加速器生态中更具标准化优势
- 报告判断：网络需求会滞后于计算需求，但弹性更大

**2/ 园区网络迎来“4倍GDP增长”**
- 传统园区网络增速是GDP的2倍，现在将提升至4倍
- 两个主要推动因素：企业IT预算因“Project Glasswing”相关关注而增加、思科老款交换机进入停服周期
- Wi-Fi 7升级也是重要增量

**3/ 传统服务器市场预测上调31%**
- 650 Group将2026-2030年传统服务器预测上调约31%
- 核心逻辑：AI agent与数据库/应用层的交互密度提升，驱动CPU升级
- 新型服务器核心数密度显著提升，将带动网络同步升级到400-800G

**一个关键时间节点**
以太网数据中心网络市场预计在2026年同比增长约40%，增速仍在加快。不是因为需求突然爆发，而是因为客户还在“摸索需要多少互联”——一旦明确需求，网络投入会加速跟上。

**延伸思考**
当网络从成本项变成性能瓶颈，企业会愿意为互联付出更高溢价。这个逻辑在AI算力链上，可能被低估了。
