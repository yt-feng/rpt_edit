# Stripe联手Advent，有意收购PayPal？

**每股60.50美元**

一则可能影响全球支付格局的消息

近期市场关注到一则动态：Stripe（私有）与Advent reportedly 以每股60.50美元的价格，向PayPal提交了收购意向。该报价较消息传出前PayPal的报价高出约28%，对应整体估值约530亿美元。

这一动向并非毫无征兆。今年2月，PayPal就曾吸引多方收购兴趣，Stripe也表达过相关意向。目前，Stripe与Advent据称已获得约500亿美元的承诺融资。

**为何关注PayPal？**
PayPal的核心资产颇具价值：
- Braintree和Venmo两大旗舰业务
- 2.31亿月活用户，其中Venmo拥有6700万用户（约占美国人口20%，年轻用户占比高）
- 覆盖约90%的在线商户
- 年处理交易量约1.8万亿美元
- 在美国电商支付处理中占据两位数份额，数字钱包领域约占50%

尽管品牌业务增长面临一定调整，但在报价处于历史低位区间后，受到关注并不意外。

**这笔交易能否落地？**
存在几个关键因素：

1️⃣ **报价问题**：PayPal刚更换管理层，正在推进业务重组（拆分checkout、Venmo、Braintree），目标在未来2-3年节省15亿美元以上成本。当前报价仅比消息前报价高28%，接近上市以来最低估值区间，现任管理层未必接受。

2️⃣ **融资压力**：Stripe一直未表现出上市意愿，若报价进一步上调，融资安排将更复杂。即便已有500亿承诺融资，交易完成后PayPal的杠杆率可能升至5-6倍——对于自由现金流可能波动的业务而言，存在一定风险。

3️⃣ **监管审视**：两家公司合并后规模可观——总支付量约3.2万亿美元，净收入约200亿美元，覆盖超过30%的全球电商和40%的美国电商。监管机构大概率会进行详细审查。

4️⃣ **整合难度**：现代架构与原有系统的融合、B2B公司运营B2C客服基础设施，文化和基础设施层面的挑战不容忽视。

**Stripe为何对PayPal感兴趣？**
研究分析认为有多重战略考量：
- 规模驱动的横向与纵向整合
- 通过捆绑服务扩大市场覆盖
- 提升对商家的价值主张（例如通过拥有PayPal数字钱包实现更高转化率、更低欺诈率）
- 交叉销售机会（将Stripe产品推广至PayPal的大量中小企业客户）
- 闭环支付带来的更优经济性和数据价值
- 在AI代理电商时代，整合PayPal的消费者基础设施（BNPL、借记…）
