# 存储行业近期观察

近期某机构报告梳理了存储领域的几个关注点，逻辑较为清晰，整理如下供参考。

**1️⃣ AI相关投入：正面**
- 大型云服务商的资本支出仍在增加
- 头部大模型训练强度未见减弱
- 关键观察节点在明年二季度，而非当前讨论“算力过剩”

**2️⃣ 长期协议定价：中性**
- 市场对长期协议（LTA）尚未重新定价
- 参考疫情期间模拟芯片情况，LTA存在重新协商和强制去库存的可能
- 市场对存储盈利的定价较为理性，未出现过度反应

**3️⃣ 存储周期：中性**
- 同比增速接近阶段性高点，但周期呈现拉长趋势而非快速下行
- 库存方面：DRAM和NAND库存二季度有所回升，主要受模组厂商影响
- “好消息即坏消息”的逻辑正在体现

**价格与估值信号**
- DRAM合约价格同比增速从周期高点回落，但估值（NTM P/B）尚未重新定价
- 这与历史规律一致：价格在四季度附近达到阶段性高点

**NAND潜在变数**
- 某国内厂商产能扩张速度是重要观察点
- 如果AI SSD需求保持年增30-60%，且该厂商扩产节奏克制，NAND供需可维持相对平衡至2028年
- 反之，快速新建产能可能带来供应过剩风险

**一个思考**
存储周期从“明显上行明显回落”转向“长尾波动”，对产业链各环节的利润分配会有什么影响？欢迎一起交流。
