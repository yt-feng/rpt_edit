# HBM出口数据透露了什么：三星HBM4正在加速，SK海力士稳扎稳打

市场对HBM（高带宽存储器）的讨论，最近一直围绕两个问题展开：第一，三星在HBM领域的进展是否真的在提速？第二，HBM的价格会不会像传统存储一样出现明显变化？这两个问题直接关系到2026年下半年到2027年全球存储芯片行业的格局。

最近，一份基于韩国海关出口数据的研究报告，提供了一些值得关注的线索。这份报告通过追踪韩国特定地区的“多芯片存储器”出口数据（已被证明与三星和SK海力士的HBM收入高度相关），对2026年第二季度的HBM出货情况做了提前预判。结论较为清晰：三星的HBM4正在显著放量，其增长势头超出了此前预期；而SK海力士则保持稳健，符合市场预估。同时，HBM的价格似乎并未跟随传统存储芯片变化，而是呈现独立走势。

**三星HBM收入可能超预期，HBM4是核心驱动力**

报告最核心的发现，来自对韩国忠清南道出口数据的分析。这个地区是三星HBM封装的主要基地。数据显示，2026年6月，该地区向中国台湾和马来西亚（HBM的主要出口目的地）的多芯片存储器出口额升至34亿美元，环比5月有一定增长。整个第二季度的出口额环比增长了75%，高于研报此前预测的51%的HBM收入增速。

通过历史数据的回归分析，这份报告测算，三星2026年第二季度的HBM收入可能达到67亿美元，环比增长89%，比其模型预测的54亿美元高出约25%。这个数字背后，最关键的变量是HBM4的出货。报告特别提到一个指标——“单位重量出口价值”。6月份，三星这个指标环比再涨30%，累计较4月已上涨70%。由于HBM4的单颗价值量显著高于HBM3E，这种“价值密度”的上升，被解读为HBM4正在从试产转向批量出货的有力证据。三星此前也给出指引，称HBM4将在2026年第三季度超越前代产品成为主力，而这两个月的出口数据似乎正在印证这一判断。

**SK海力士稳健增长，HBM价格保持独立**

与三星的积极推进不同，SK海力士的数据显得更为平稳。报告追踪了其位于忠清北道和利川的工厂出口情况。6月出口额环比增长11%，整个第二季度环比增长19%。回归分析显示，其第二季度HBM收入预计为76亿美元，环比增长25%，与研报此前的预测完全一致。SK海力士的月度出口节奏也更为均衡，不像三星那样明显集中在季度末。

一个值得注意的观察是HBM的价格走势。尽管传统存储芯片（如DDR5、NAND）在2026年第二季度价格有所变化，但HBM的价格（同样通过“单位重量出口价值”来间接观察）却表现得相当稳定。SK海力士的数据显示，其价值密度在过去几个月基本持平甚至略有下降。三星的价值密度上涨，也被归因于产品结构向更高价的HBM4切换，而非全面提价。这似乎说明，HBM的定价逻辑与传统存储市场存在一定隔离，更多取决于长协合同和客户定制化需求。

**马来西亚出口反弹，EMIB封装需求值得关注**

另一个值得关注的数据点是，韩国向马来西亚的HBM相关出口在6月反弹至约11亿美元，环比增长231%。这主要归功于三星出货的恢复。马来西亚是英特尔高端封装（EMIB）的重要基地，一些搭载HBM的高端服务器CPU需要在此完成最终封装。研报指出，客户对EMIB技术的兴趣正在增长，英特尔也计划在今年启用新的先进封装工厂。虽然任何大规模量产可能还需1-2年，但当前出口数据的增长，或许暗示着下游客户正在进行某种提前备货或技术验证。对于三星而言，马来西亚出口的增长也意味着其客户认可度在拓宽。

**传统存储价格变化，HBM价格重设定将影响2027年预期**

报告最后还提到一个关键时间点：目前供应商和客户正在就2027年的HBM合同进行价格谈判。由于传统存储价格已有变化，而HBM价格此前相对稳定，市场普遍预期2027年的HBM合同价格将会调整。这种“价格重设定”一旦落地，很可能会触发对2027年存储厂商盈利预测的调整，并成为影响相关公司市场表现的短期因素。

当然，这份报告的研究方法也有其局限性。比如，它假设HBM的封装全部在韩国境内进行，且出口目的地仅限于中国台湾和马来西亚。如果三星或SK海力士未来在海外（如美国）建立HBM封装产能，这套追踪模型的有效性就需要重新评估。

总结来看，2026年第二季度的韩国出口数据描绘了一个清晰的图景：HBM市场正在经历“三星追赶、SK海力士守成”的格局变化，HBM4的放量是三星最大的变量；而HBM与传统存储的价格脱钩，以及2027年合同价格的潜在调整，则是影响行业中期预期的关键。完整报告里还有不少关于各家厂商情况和风险点的细节，适合在社群中继续交流讨论。
