ZH_A: 远超预期？具体超了多少？这意味着什么？

ZH_A: 那SK海力士呢？它一直是HBM的领头羊，这次表现怎么样？

ZH_A: 这确实是个转折点。报告里还提到一个关键指标叫“单位重量价值”，它为什么重要？
ZH_B: 这个指标可以大致反映HBM的价格走势。6月份，三星的单位重量价值环比又涨了30%，而SK海力士基本持平。报告认为，这很可能不是整体涨价，而是三星的HBM4开始大规模出货了，因为HBM4比上一代HBM3E价值更高。
ZH_A: 所以三星在HBM4上领先了？那HBM的整体价格趋势呢？
ZH_B: 有意思的是，虽然普通存储芯片价格在猛涨，但HBM的价格一直很稳定。报告通过SK海力士的数据判断，HBM价格没有出现普涨。不过，现在供应商和客户正在谈判2027年的HBM合同，这可能引发新一轮的盈利上调。具体能涨多少，报告里没有完全展开，需要看后续谈判结果。

ZH_B: 有的。比如，报告发现韩国对马来西亚的HBM出口突然大幅反弹，6月达到11亿美元。马来西亚是英特尔封装设施所在地，但报告认为，即使客户采用新技术，大规模生产也要一两年后，所以这次反弹的原因还需要继续观察。
