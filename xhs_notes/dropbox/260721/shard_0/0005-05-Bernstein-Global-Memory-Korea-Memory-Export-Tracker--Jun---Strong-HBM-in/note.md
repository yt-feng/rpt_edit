HBM出货数据更新，三星表现超预期

📊 韩国HBM出口创历史新高

6月韩国HBM出口数据出炉，环比增长46%，再创新高。三星和SK海力士的HBM业务走势出现明显分化。

1️⃣ 三星：HBM4量产加速
- 6月忠清南道（三星HBM封装地）出口环比弹性较高
- 二季度出口环比增长75%，超出此前预期
- 推测HBM4已开始放量出货，价值/重量比环比再增30%

2️⃣ SK海力士：稳健但增速趋稳
- 6月忠清北道+利川出口环比增长11%
- 二季度出口环比增长19%，符合预期
- 价值/重量比持平，暂未看到HBM4出货信号

3️⃣ 关键信号
- 存储产品价格有所回升，但HBM价格相对稳定
- 马来西亚出口大幅回升（英特尔EMIB封装需求）
- 2027年HBM合约谈判中，预计将带动相关业务盈利预期上调
