长协是记忆体行业的一个观察角度吗？

**长协 ≠ 万能保障**

**一份来自外资研究机构的观点拆解**

记忆体行业最近有个新名词受到较多关注：**长协（LTA，长期供货协议）**。大家在讨论它能否改变行业周期波动的特征。

我读了一份外资研究机构的最新报告，里面把多空双方的逻辑梳理得比较清晰。今天直接整理重点，供你建立自己的判断框架。

**1/ 谨慎逻辑：长协的“有限性”一面**

*   **约束力存疑**：客户是否履约，核心看实际成本。如果市场报价远低于合同价，节省的成本比违约金多，客户可能会选择调整。长协的约束力，取决于违约成本是否足够高。
*   **覆盖范围有限**：并非所有客户都适合签长协。只有云服务商和AI基础设施商这类对供应稳定性要求高的客户有较强锁定供应的动机。消费电子、交易型买家更看重灵活性和价格。报告估算，可能有**30-50%**的市场份额难以被长协覆盖。
*   **保证金比例较低**：目前披露的保证金总额（约330亿美元）对比要覆盖的未来收入（可能高达5.2万亿美元），比例低至**0.6%**。在真正的下行周期里，这部分资金的缓冲作用相对有限。

**2/ 积极逻辑：长协的“缓冲”价值**

*   **提升盈利底线**：长协不能阻止周期，但能通过**保证金**来减轻下行幅度。即使市场出现波动，客户放弃的保证金也能让公司从“较大亏损”变成“较小亏损”甚至“盈亏平衡”。历史最差时期，某公司的营业利润率曾跌到-60%以上，有长协后，理论底部可以抬升到**0-30%**。
*   **客户质量较高**：签长协的主要是大型云服务商，他们资产负债表较强、收入来源多元，违约意愿和概率都相对较低。需求背后是真实的AI基础设施部署，而非过往的库存囤积。
*   **保护随时间增强**：长协的保证金通常是“后置”返还的。随着合同执行，剩余采购义务减少，客户违约的成本相对合同价值会越来越高，后期保护反而更强。

**3/ 关键分歧：NAND vs DRAM**

*   **关注NAND的一方**：AI需求主要利好DRAM（HBM），NAND受益有限，且面临其他厂商的长期竞争。
*   **看好NAND的一方**：AI工作负载（如大上下文窗口、海量存储需求）正在变得越来越“NAND密集型”，在供给受限的背景下，供需关系反而可能有利。

**4/ 哪些公司在积极采用长协？**

*   **较积极的一方**：SanDisk和Micron。他们已经签下了大额长协，并积极使用财务保证金来锁定客户。
