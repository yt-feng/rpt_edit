# Bernstein：美国IT硬件-全球内存-新内存长期协议第三部分-多空观察

一份来自Bernstein的研究报告，围绕新内存长期协议（LTA）展开了一场多空观察。核心问题并不在于LTA本身是否有效，而在于其保护力度是否足以改变内存行业的周期性特征。报告认为，LTA能够提升盈利底部，但无法消除周期波动，更无法在缺乏结构性短缺的情况下维持峰值盈利。

LTA的有效性取决于一个简单的宏观环境计算：当客户违约所放弃的财务担保，超过其从现货市场低价采购所能节省的成本时，协议才有约束力。Bernstein指出，目前披露的担保总额约为330亿美元，而同期内存供应商的年收入预期约为1.3万亿美元。若以覆盖3至5年的收入计算，需要保护的金额高达约5.2万亿美元，当前担保仅占其中的0.6%。这一比例意味着，即便未来三星和SK海力士加入更多担保，也难以从根本上改变盈利波动性。

## 1. 担保结构随时间增强，但节奏变化保护仍有上限

报告区分了两种担保返还机制。SanDisk的担保在整个协议期内保持不变，这意味着随着剩余采购义务（RPO）逐年下降，担保占RPO的比例会上升，客户违约成本相对提高。美光的担保则按预定计划返还，且集中在协议后期。两种设计都使得后期保护力度增强，但前提是市场价格的下跌幅度没有超出担保的覆盖范围。

Bernstein的测算显示，即便在乐观情景下，LTA也只能将低谷期的营业利润率从历史最差的-10%至10%提升至0%至30%。这意味着，即使有LTA保护，低谷期的每股收益可能仅为当前峰值水平的十分之一。报告明确指出，LTA可以缓解节奏变化，但无法维持峰值盈利。

## 2. 渗透率存在天花板，消费与部分企业客户难以覆盖

并非所有客户都适合签署LTA。Bernstein认为，超大规模云服务商和HBM客户有强烈动机锁定长期供应，但消费电子公司、交易型买家以及部分客户更看重采购灵活性和最低成本。SanDisk的CFO在近期活动中也承认，消费业务“更具交易性”，LTA“并不真正适用”。

报告估算，约30%至50%的内存市场可能永远无法被LTA覆盖。这一判断基于两个观察：一是与美国云服务商的谈判已基本完成，但与部分其他地区云服务商的谈判仍在进行；二是部分企业更倾向于与本土供应商签署协议，而后者正在逐步扩大市场份额。这意味着，LTA的渗透率存在结构性上限。

## 3. 多空分歧集中在NAND需求与竞争格局

Bernstein内部对NAND的前景存在明显分歧。亚洲团队认为，AI需求对DRAM的拉动远大于NAND，且部分企业在NAND领域的长期竞争不确定性更高。美国团队则认为，随着AI工作负载的上下文窗口扩大，存储需求增长，NAND的消耗强度正在上升，在供给受限的背景下，供需格局可能趋于有利。

这一分歧直接影响了不同团队对供应商策略的判断。SanDisk和美光在推动有财务担保的LTA方面最为积极，而亚洲供应商则更为谨慎。报告认为，后续的LTA披露、内存平均售价走势以及SanDisk的分析师日，将是影响市场对LTA和内存板块估值认知的关键因素。

## 4. 美光研究Anthropic：供应商融资与不确定性放大

报告特别提及美光以股权研究方式参与Anthropic的案例，认为这是“供应商融资与不确定性放大”的典型表现。与传统的LTA不同，这种安排下供应商不仅承担了产能研究的不确定性，还通过股权方式间接暴露于AI初创公司的经营不确定性。Bernstein并未评价这一策略的优劣，但指出它反映了内存供应商在锁定需求时所面临的现实约束——当财务担保的规模不足以支撑协议时，供应商不得不寻求其他形式的承诺。
