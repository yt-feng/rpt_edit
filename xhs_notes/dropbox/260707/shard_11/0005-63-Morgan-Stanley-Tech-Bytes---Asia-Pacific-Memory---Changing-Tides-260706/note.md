记忆芯片的周期拐点，比想象中更近

📌 存储芯片进入关键观察期

最近研究报告中提到存储芯片的三重叠加信号，值得记录。

1/ 价格变化速率见顶
存储芯片虽然这轮有AI加持，但本质仍是周期行业。目前价格同比涨幅、库存水位、盈利修正广度都接近历史极值。市场通常会在这种时候开始横盘，甚至出现调整。

2/ 长期逻辑没变，但短期波动加剧
最大AI买家传出要出售算力，市场开始关注需求是否过剩。但从另一个角度看，这可能是企业在优化资本回报，并非真正的算力过剩。关键看2Q26财报季，云厂商是维持还是削减资本开支。

3/ LTA（长期协议）签完也未上涨？
存储股签了长协也未上涨，是因为市场较为理性——过去长协常被重新谈判或客户被动接收库存。本轮长协结构更扎实，但市场需要时间验证。

4/ 拥挤交易在松动
存储是机构重仓区，近期波动让一些资金在减仓。盈利修正广度已到历史高位，短期动量可能继续衰减。但生成式AI以来，已出现过三次类似调整，每次都是结构性趋势中的正常修正。

5/ 关注点转移
现阶段，云厂商财报比存储公司自身的表态更能影响市场表现。AI Agent带来的token优化（用更便宜的模型替代），可能改变存储需求结构。

长期看，2027年盈利增长仍有望超过35-40%，Agentic AI是下一个催化。短期财报前，市场表现可能持续波动。
