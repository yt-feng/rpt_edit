# 中国半导体设备：两大催化剂正在发酵

📌 存储扩产加速 + 华为3D IC突破

---

**1/ 存储厂扩产，比预期更猛**

最近某外资投行更新了中国WFE（半导体设备）市场预测：
- 2026年：中国WFE市场约480亿美元，同比+15%
- 2027年：约560亿美元，同比+18%

背后推手是两大存储厂——YMTC和CXMT的扩产节奏明显加快。

具体来看：
- YMTC：Fab 3已在建，预计2026年开始爬坡。2027年产能目标上调至85kwpm，2028年目标100kwpm
- CXMT：除了合肥、北京，还要在上海新建产能。2026-2028年产能预期分别上调至80k/90k/100kwpm

而且两家公司都在推进IPO——CXMT预计2026年6月在科创板上市，YMTC也已启动上市辅导。上市后融资能力增强，扩产底气更足。

**2/ 国产化率在快速提升**

研报数据显示，中国WFE设备的国产化率正在加速：

- 2024年整体国产化率约16%
- 2025年提升至22%
- 2026年预计达25%
- 2028年有望到30%

不同项目的国产化率差异很大：
- YMTC Fab 3：高达60%（3D NAND的刻蚀、沉积、混合键合设备大量采用国产）
- CXMT上海新厂：约35%
- SMIC京诚厂：约22%

这意味着，国内设备商正在从“替代”走向“主力”。

**3/ 华为的“Tau定律”可能改变游戏规则**

5月25日，华为发表了一篇论文，提出t-scaling理论和LogicFolding技术。

简单说：通过晶圆制造过程中的电路层垂直集成，缩短互连长度，实现类似3D IC的架构。这样5nm/7nm的芯片也能跑出更先进节点的性能。

论文反复提到两个关键技术：混合键合（hybrid bonding）和TSV（硅通孔）。

这对设备商意味着什么？
- 混合键合设备需求增加
- TSV铜电镀（ECP）设备需求增加
- 能提供这些工具的设备商将成为主要受益者

**4/ 设备商受益逻辑清晰**

研报上调了三家设备商的目标价：
- 北方华创：目标价818元
- 中微公司：目标价550元
- ACM Research：目标价90美元

核心逻辑：
- 存储厂扩产带来大量设备订单
- 国产化需求持续强劲
- 华为LogicFolding工艺将推动TSV金属化ECP设备需求增长，利好ACM的非清洗设备业务
