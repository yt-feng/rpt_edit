EN_B: Great question. The AI industry is shifting from GPU-heavy training to inference-heavy agentic applications. In agentic AI, the CPU becomes the central orchestrator. EN_A: And more CPUs mean more memory interface chips?
EN_B: Exactly. Every server CPU needs multiple DDR memory modules, and each module contains interface chips. The report identifies three compounding drivers. First, server CPU shipments are growing much faster than expected. Second, each CPU is using more DRAM with higher bandwidth. Third, the new MRDIMM memory modules have roughly 10 times the interface chip value of traditional modules.
EN_A: Ten times the value? That upgrade cycle sounds like the key. But is it going to be hard to adopt?
EN_B: The report says the adoption hurdle is manageable. The price premium for MRDIMM is only about 10% of a current 128GB module. And that gap narrows as DRAM prices rise. They forecast MRDIMM penetration to reach 25% by 2030. But one open question is whether that adoption could be much faster at the big cloud hyperscalers. The report does not fully answer that.
EN_A: Okay, good suspense. So who wins in this market? Who are the players?
EN_B: The competitive landscape is a textbook oligopoly. Three companies — Montage, Renesas, and Rambus — control over 90% of the global market. The barriers to entry are incredibly high. You need rigorous JEDEC qualification and deep co-development ties with CPU and DRAM makers. Customers almost never switch vendors once they qualify.
EN_A: So margins must be great?
EN_B: They are. The report points out that while the interface chip is critical for module performance, it only costs a low single-digit percentage of the total module price. So customers are happy to pay a high margin for guaranteed quality. On the traditional RDIMM roadmap, all three compete neck and neck. But on MRDIMM, Montage and Renesas have an early-mover advantage.
