# Azure增速加快，但微软面临三个观察点

📊 微软近期观察

最近有机构发布了微软的研究笔记，简单梳理一下逻辑👇

**1/ 核心看点：Azure增速持续提升**
- 4QFY预期Azure增速40-41%（此前指引39-40%）
- 1QFY预期继续40-41%，略低于市场预期的41%
- 关键：供应仍受限，但新产能（如威斯康星Fairwater数据中心）陆续上线

**2/ 三个值得关注的方面**
自4月财报后，微软报价有所调整，同期纳指表现不同，主要关注：
① 资本开支预期不断上调，Azure增速却只小幅上修
② 对特定供应商依赖度较高，相关成本变化值得留意
③ Copilot用户反馈分化，新同类产品（如Claude Cowork）可能影响Office 365

**3/ 资本开支仍在增加**
- 研报将FY28-30资本开支上调约10%，预计FY28达3190亿美元（含融资租赁）
- 微软约13%的CY26资本开支与组件涨价相关，其中超50%来自内存
- 内部芯片（Maia）进展慢于同业，短期内仍高度依赖外部供应商

**4/ Copilot数据在改善**
- 3QFY付费席位超2000万，AI业务ARR达37亿美元（+123%）
- 4QFY预计ARR达42-43亿美元（+115-120%）
- 但M365的持续加速仍需时间

**总结**：研报认为当前风险回报比正向，但公司表现要持续向好，需看到：Azure能持续超预期、内部芯片进展、Copilot用户粘性提升。
