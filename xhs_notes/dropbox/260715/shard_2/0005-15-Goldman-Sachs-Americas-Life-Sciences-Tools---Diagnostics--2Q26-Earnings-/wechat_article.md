# GS：美洲生命科学工具与诊断2Q26业绩观察

今年上半年，生命科学工具板块整体回报表现与市场基准存在一定差距。但GS在最新发布的2Q26业绩观察报告中传递了一个与市场定价不同的信号：其自建的GS Tools Tracker显示，二季度终端市场增长相较一季度出现了“轻微加速”。这已经是该指标连续第二个季度指向改善。

市场此前普遍关注工具公司的增长状态是否可能受到长期结构性因素影响。GS这份报告的核心判断是，目前的数据更支持“后疫情余波”而非结构性变化。报告同时更新了其中国设备更新刺激追踪器，后者显示二季度订单数量同比下降57%，但GS认为布鲁克等公司受冲击相对有限。

## 1. 工业端市场增速已接近历史高位，但仍有上行空间

GS的GS Tools Tracker覆盖17个季度数据集，分布在生物制药、工业、临床诊断和学术政府四个终端市场。二季度工业端增速达到高个位数，明显高于其长期平均的低个位数水平，环比加速约3个百分点。驱动因素主要是PMI和半导体资本支出的环比提升，但耐用品新订单有所走弱。

报告特别指出，按照历史模式，工业端增速尚未触及中双位数的高水位线，这意味着当前周期仍有继续上行的空间。安捷伦的CAM业务与工业追踪器历史相关性较高，可能成为这一趋势的主要受益者。

> **KC评论：** 工业端是当前工具板块中最具确定性的正面变量。半导体资本支出的回升和PMI的持续扩张，为相关仪器和耗材需求提供了支撑。但报告也提示，宏观不确定性是主要不确定性，尤其是中东地区的地缘政治因素可能带来约低个位数百分比的区域敞口影响。

## 2. 生物制药端增速仍处高位，但临床前资金传导需要时间

生物制药端在二季度保持低双位数增长，尽管相较一季度略有节奏变化。驱动因素包括生物技术研发支出、中国资本支出和生物技术资本支出的广泛改善。报告特别关注到，生物技术不确定性研究和IPO数据已连续三个季度保持高位，但历史规律显示，这些资金通常需要一年以上才能转化为实际的资本支出。

这意味着，2025年下半年临床阶段生物技术融资的改善，可能要到2026年下半年才能体现在工具公司的订单中。GS认为，赛默飞世尔在这一传导链条中处于有利位置，其CRO业务有望受益于临床阶段资金的滞后效应。

## 3. 学术政府端仍是最大影响，但中国刺激政策提供了对冲

学术政府端是四个终端市场中相对少见仍低于历史均值的领域。美国国家科学产品会的拨款支出已连续四个季度负增长，国立卫生研究院的支出虽略有加速，但仍处于低个位数增长区间。报告指出，研究人员面临多年期拨款动态、博士录取人数下降以及资本设备支出犹豫等问题，尽管资金开始到位，但实际采购意愿仍然谨慎。

不过，GS同时指出，其学术政府追踪器主要基于美国数据，中国设备更新刺激和欧洲的动态并未纳入。在中国方面，尽管二季度追踪到的仪器订单同比下降57%，但布鲁克的表现相对突出，其订单同比增长约55%，显示出在整体刺激退潮背景下的结构性优势。

## 4. 估值压缩后的工具板块，核心变量是增长能否持续加速

报告认为，当前工具板块的估值压缩已在一定程度上反映了市场对复苏斜率的不确定性。GS的GS Tools Tracker与工具公司平均有机增长率的相关系数达86%，且80%的季度能正确判断增长加速或减速的方向。连续两个季度指向加速，为下半年增长改善提供了数据支撑。

但报告也坦诚，每个公司都有其独特因素。赛默飞世尔面临的关键问题是其全年3-4%的有机增长指引是否过于保守，而美国商务部制药关税调整申请截止日期（6月12日）可能推动CDMO订单增长。整体而言，GS认为当前估值水平为高质量公司提供了有吸引力的入场点，但复苏的节奏仍存在不确定性。

> **KC评论：** 这份报告最有价值的部分不是对具体公司的预测，而是提供了一个可复用的观察框架——通过17个数据集交叉验证终端市场健康状况。对于关注工具板块的读者，与其纠结于单季度业绩波动，不如跟踪GS Tools Tracker的季度变化方向，它比任何单一公司的指引都更能反映行业真实需求曲线。
