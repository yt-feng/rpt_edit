数据中心项目管道爆了，295GW意味着什么

数据中心项目
增速惊人

某外资投行最新研报显示，北美数据中心项目管道在上月增长了5%，达到295GW，同比翻了3倍。这背后是AI算力需求的真实映射，还是市场过热的前兆？

1/ 谁在推动增长？
- 开发商贡献了86%的增量，是绝对主力
- 超大规模云服务商贡献37%，其中亚马逊占大头
- 新云服务商贡献13%
- 德州成为增长中心，单月新增6GW，占全部增量的46%

2/ 建设进度如何？
- 在建容量达59GW，环比增长12%
- 数据中心运营商、开发商和超大规模云服务商贡献了95%的新开工
- Meta和亚马逊是超大规模云服务商中的主要推动者
- 德州和威斯康星州贡献了40%以上的新开工

3/ 一个值得关注的趋势
- 受阻容量（因当地反对/审批问题）上升至32GW，占总管道的11%
- 这比去年夏天的7-9%有明显上升
- 开发商贡献了50%以上的受阻增量

4/ 自发电（Behind-the-Meter）加速
- 自发电管道达115GW，环比增长2%，年初至今增长30%
- 目前只有4%的已安装数据中心使用自发电
- 但在建容量中22%将使用，管道项目中39%计划使用
- 新云服务商最依赖自发电（管道中占66%）

5/ 对设备供应商的影响
- 自发电项目在配电设备上的支出比仅并网项目多30%
- 这为电气设备公司带来额外需求
- 研报估算了数据中心相关市场空间：Quanta Services约4万亿美元，Vertiv约9140亿美元，施耐德约7870亿美元

数据中心建设仍在加速，但受阻容量的上升值得持续关注。自发电趋势可能是未来几年最确定的增长主线之一。
