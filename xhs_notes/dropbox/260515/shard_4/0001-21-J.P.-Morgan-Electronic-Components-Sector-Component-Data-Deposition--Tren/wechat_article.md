# HDD 产业真正的拐点不是出货量，而是供给侧的定价权转移

2026年第一季度HDD出货数据已经公布。表面上看，33.0百万台的出货量与上季度持平，但真正值得关注的信息隐藏在数字背后：NL HDD出货量同比增长28%，HDD整体容量同比增长38%，平均单价同比上升29%。这些数字指向一个核心判断——HDD市场正在经历的不是需求复苏，而是结构性重定价。而在这场重定价中，供应链上游的龙头供应商正在获得过去十年未曾拥有的议价权。

某外资投行最新发布的电子元器件行业研报，通过TSR的1Q26数据，揭示了一个被市场低估的趋势：HDD产业的价值分配正在从下游整机向上游核心零部件转移。报告明确将TDK列为HDD相关个股的首选，理由是“自产厂商在增加HDD磁头产能方面保持克制，并将现有产能转向HAMR产品”。这是一个信号，意味着供给侧的约束正在成为定价权转移的催化剂。

本文基于该研报的核心数据与判断，提炼出五个层次的分析框架，帮助读者理解这一轮HDD产业变化的本质，以及哪些公司可能成为结构性受益者。

## 1. 容量增长而非数量增长，才是HDD需求真实强度的衡量标准

2026年第一季度HDD出货量同比仅增长15%，环比持平。如果只看这个数字，很容易得出“需求平淡”的结论。但研报数据中有一个指标更为关键：出货容量同比增长38%，达到477EB。这意味着单台HDD的平均容量从一年前的12.1TB提升到了14.5TB，增幅达20%。

为什么容量增长远快于数量增长？答案在于NL HDD的结构性增长。NL HDD出货量在1Q26达到18.7百万台，同比增长28%，占总出货量的56.7%。而NL HDD的平均容量远高于其他类型，单台平均价格达到325.20美元，是整体均价211.50美元的1.5倍以上。

So what：用“出货量”来衡量HDD行业景气度的传统框架已经失效。真正值得关注的指标是总容量出货量和平均单价。当云服务商和超大规模数据中心持续部署高容量存储设备时，HDD产业的价值池正在向高容量、高单价的产品集中。任何只盯着出货台数的分析，都会低估这个市场的真实规模。

## 2. NAND Flash与HDD的成本差距急剧扩大，重新确立了HDD在大容量存储中的经济性护城河

研报中有一组数据值得反复推敲：1Q26 NAND Flash与NL HDD的GB成本差异扩大到了12.7倍，而1Q25这一数字仅为5.2倍，4Q25为6.6倍。这是2020年以来的最高水平。

这意味着什么？在过去一年中，NAND Flash的价格下降速度远慢于HDD的单位成本优化速度。当存储采购决策者面对两种技术方案时，HDD在大容量冷存储和温存储场景中的经济性优势正在急剧扩大。12.7倍的成本差异，几乎让SSD在每GB成本上无法与HDD竞争——除非应用场景对性能有刚性需求。

So what：这一差距的扩大并非短期波动。它反映了两种技术路径的根本差异：NAND Flash的制程微缩正在接近物理极限，而HDD通过HAMR等新技术仍在持续提升面密度。报告提到自产厂商正在将产能转向HAMR产品，这进一步确认了HDD技术路线的演进方向。对于投资决策而言，当成本差异达到两位数倍数时，云服务商的采购行为将出现系统性倾斜——更多的容量需求将流向HDD，而不是SSD。

## 3. 磁头供应链正在经历从量增到价增的转换，TDK是这场转换的核心受益者

1Q26 HDD磁头（HGA）出货量达到4.02亿个，同比增长22%，环比增长1%。但更关键的数字是每台HDD的磁头数量：整体从1Q25的11.5个增加到12.2个，NL HDD的磁头数量维持在19.4个的高位。

磁头数量的增长背后有两个驱动力：一是NL HDD出货量增长，直接拉动了总磁头需求；二是随着HDD容量提升，单台设备需要更多的磁头来实现更高的读写效率。研报数据显示，TDK的HGA出货量为5280万个，同比增长10%，市场份额从1Q25的14.5%降至13.1%。表面上看份额在下降，但报告特别指出：“TSR数据显示，对两家自产厂商的供应在1Q26已经开始，尽管量还很小。”

这正是研报的核心洞察所在。自产厂商（即HDD制造商内部的磁头产能）正在将现有产能转向HAMR产品，这意味着它们在传统PMR磁头上的产能投放将受到约束。而TDK作为独立供应商，正在填补这一缺口。报告判断TDK“能够继续增加在自产厂商中的市场份额”。

So what：磁头供应链正在经历从“量增”到“价增”的转换。随着HAMR技术渗透率提升，磁头的技术门槛和单位价值量都将上升。TDK作为少数具备HAMR磁头量产能力的独立供应商，其议价能力和市场份额有望同步提升。研报给出的FY25E P/E为28.16倍，在电子元器件板块中并不算极端，但考虑到结构性份额增长的预期，这一估值仍有上行空间。

## 4. 主轴马达市场格局稳定，但竞争焦点已从份额转向技术升级

1Q26 HDD主轴马达出货量为3400万个，同比增长11%，环比微降1%。市场份额方面，Nidec占60%，MinebeaMitsumi占40%，格局基本稳定。主轴马达的SPM比率（每台HDD对应的马达数量）从1Q25的1.07降至1.02，说明多马达设计的渗透率正在下降。

与磁头供应链不同，主轴马达市场已经进入成熟期。竞争焦点不再是份额争夺，而是如何在高容量、高转速需求下提升产品可靠性。Nidec和MinebeaMitsumi两家公司的股价表现差异明显：截至研报统计日，Nidec过去12个月下跌3.9%，而MinebeaMitsumi上涨86.9%。这种分化可能反映了市场对两家公司在HDD之外业务（如汽车、机器人）的不同预期。

So what：主轴马达作为HDD中的成熟组件，其投资逻辑已与HDD产业本身脱钩。投资者需要关注的是这些公司在非HDD领域的成长性，而非HDD出货量的边际变化。研报对Nidec给予UW评级，目标价1800日元，明显低于当前股价2435日元，也印证了这一判断。

## 5. 报告尚未完全回答的关键问题：HAMR技术的渗透速度与产能约束之间的博弈

研报的核心逻辑建立在两个假设之上：一是自产厂商主动约束产能扩张，二是HAMR技术将推动磁头单位价值量提升。但报告并未充分展开一个关键问题——HAMR技术的渗透速度到底有多快？

目前，HAMR磁头的量产仍处于早期阶段。研报提到“对两家自产厂商的供应在1Q26已经开始，尽管量还很小”。这意味着HAMR的渗透率仍然极低。如果HAMR的规模量产进度慢于预期，那么自产厂商可能不会像报告假设的那样快速转移产能，TDK的份额增长逻辑就会受到挑战。

另一方面，如果HAMR渗透速度超预期，磁头的单位价值量确实会上升，但这也意味着技术路线的切换风险——现有PMR磁头的产能可能面临加速折旧。对于TDK而言，这是一个“甜蜜的烦恼”：短期看，HAMR是提价和增量的催化剂；长期看，技术路线的切换也意味着研发投入的持续加大。

这里仍需验证：自产厂商的产能约束是否真的如报告所判断的那样具有持续性？在HDD需求持续增长的背景下，自产厂商是否有动机重新扩张产能？这些问题在研报中没有完全展开，但对判断TDK的长期投资价值至关重要。

## 从数据到框架：如何用这组数字重新审视HDD产业链

对于产业决策者和投资者而言，1Q26的HDD数据提供了一个重新审视产业链价值分配的框架。可以从三个维度来观察：

第一，需求端的真实强度应该用“容量”而非“数量”来衡量。477EB的季度出货量、38%的同比增长，说明云服务商的存储需求仍在高速扩张。任何关于“HDD需求见顶”的判断，都需要重新审视。

第二，成本端的变化正在重新划定HDD与SSD的竞争边界。12.7倍的GB成本差异意味着，在可预见的未来，HDD在大容量存储场景中的经济性优势不会受到SSD的威胁。这为HDD产业的长期需求提供了坚实的底部支撑。

第三，供给端的变化是当前最大的变量。自产厂商的产能约束、HAMR技术的渗透、独立供应商的份额提升——这三个因素叠加在一起，正在重塑供应链的价值分配。TDK作为研报的首选标的，其核心逻辑在于：当供给端出现结构性约束时，拥有技术壁垒的独立供应商将获得定价权。
