# 全球半导体与半导体设备观察

## 全球半导体设备——存储市场波动时，设备领域能否保持独立走势？

在当前市场环境下，许多参与者认同我们对半导体设备领域的长期观察，但担心其与存储类公司的报价走势高度关联。本文回顾了历史报价走势，并对此观点进行探讨。

### 历史关联度分析

存储与半导体设备公司的报价历史关联度并不高。我们以存储领域前三大公司和前五大晶圆厂设备公司为基准进行分析。2012-2018年间，存储与设备公司的关联度仅为0.4。2019年以来关联度有所上升，但也仅达到0.6。相比之下，设备公司与整体半导体板块的关联度一直保持在0.8-0.9的较高水平。

### 走势分化实例

存储与设备公司的报价曾多次出现不同方向的变化。值得关注的时期包括：2015年1月至2016年12月，设备板块上涨21.9%，而存储板块下跌16.2%，两年间相对表现差距达38.2%；2021年1月至2022年12月，设备板块上涨15.3%，而存储板块下跌34%，两年间相对表现差距达49%。虽然我们对设备与存储两个方向均持积极看法，但参与者仍可通过分散配置来获取收益，而非担忧两者必须同涨同跌。考虑到设备投入是扩充存储产能的必要条件，而产能扩张正是存储报价波动的原因，这一点尤为重要。

### 均值回归现象

长期来看，存储与设备的表现可能趋于一致——正如2011-2019年间的情况。虽然自2025年6月以来存储板块相对设备板块的表现差距高达661%，但这只是对2019年至2025年6月期间长期相对落后的修正，直到2026年2月两者在15年间均上涨36倍时才重新持平。如今存储板块已显著领先设备板块，若发生均值回归，未来可能有利于设备板块。

### 基本面观察

从基本面看，我们对设备领域持积极态度。存储资本支出明显加速；SK海力士近期宣布对其清州新工厂追加100万亿韩元（约670亿美元）投资，韩国政府似乎也在考虑支持三星和SK海力士在韩国西南部建设工厂的措施。我们认为市场对设备市场及公司每股盈利的共识预期在2028年前存在上调空间，并预计未来仍有增长。

对于存储领域，虽然我们认为长期协议帮助有限，但供应短缺及即将到来的HBM报价调整仍将带来显著的盈利上调空间。我们仍关注三星、SK海力士及美光，尤其是在近期回调之后。我们对KIOXIA的评级为低于市场表现，主要基于估值及来自中国的长期竞争因素。
