# 服务器CPU出货量预计增长，AI推理正在重塑芯片供应链

过去半年，市场对AI算力的讨论几乎全部集中在GPU和加速器上。很少有人认真问一个问题：当AI从训练转向推理，当“智能体”开始自主执行任务，CPU的角色会发生什么变化？

这个问题的答案，可能比大多数人想象的要重要得多。

最近读到一份研究机构的报告，提出了一个非常有意思的分析框架。他们把服务器CPU需求拆成三个桶：AI头节点CPU、智能体AI服务器CPU、以及通用服务器CPU。这个分类本身就是一个洞察——它暗示我们，CPU市场正在经历一次结构性的重塑，而不仅仅是量的增长。

报告的核心判断是：服务器CPU出货量将从2025年的2600万颗增长到2028年的6800万颗，年复合增长率达到38%。更值得注意的是，到2028年，这个市场的总收入规模可能接近1000亿美元。

这个数字意味着什么？对比一下，2024年全球服务器CPU市场大约在300-400亿美元左右。三年翻两倍多，这不是周期性的波动，而是结构性的变化。

**为什么CPU突然变得这么重要？**

答案藏在AI推理的演进路径里。

当模型从训练转向推理，尤其是进入“智能体”时代——即AI能够自主规划、调用工具、执行多步骤任务——CPU的角色就从“配角”变成了“调度中枢”。报告里有一个很形象的描述：智能体=大模型+工具框架，而CPU在这个框架中承担着编排、存储、安全等关键职能。

具体到数字上，报告预测智能体AI服务器CPU的需求将在2025-2028年间实现155%的年复合增长率。这个增速远超AI加速器本身（50% CAGR），也远超通用服务器CPU（5% CAGR）。

换句话说，AI推理的爆发，正在创造一个新的CPU需求增量市场，而这个市场的大多数人还没有充分意识到。

**一个被低估的“配比”变化**

支撑这个判断的核心逻辑，是加速器与CPU的配比关系正在发生根本性变化。

在传统的HGX服务器中，加速器与CPU的比例大约是4:1。但在NVL72计算托盘上，这个比例已经压缩到2:1。而在下一代TPU设计中，这个比例可能进一步降到1:1。

为什么会这样？因为AI服务器架构越来越复杂，需要更多的CPU来协调数据流、管理缓存、处理KV cache等任务。加速器越强大，反而越需要CPU来“配合”它。

这个配比变化的影响是巨大的。报告估算，AI头节点CPU的需求将从2024年的180万颗增长到2028年的1680万颗，年复合增长率74%。而同期AI加速器的出货量从760万增长到3250万，增速是50%——CPU增速反而更快。

这就是结构性变化的力量：不仅是量在增长，单位加速器需要的CPU也在增加。

**ARM的逆袭：从边缘到主流**

另一个值得关注的趋势是ARM架构在服务器CPU市场的崛起。

报告预测，到2028年，ARM架构可能占据AI头节点CPU需求的约90%。在整个服务器CPU市场中，ARM的份额将从2025年的22%增长到2028年的43%。

推动这一趋势的，是英伟达的Vera和谷歌的Axion等ARM-based CPU的广泛应用。在NVL72这样的新架构中，ARM已经成为默认选择。

有意思的是，报告认为x86市场并不会萎缩，反而会加速增长——预计年复合增长率达到25%，远高于上一个周期的持平或低个位数增长。只是ARM的增速更快。

这意味着，未来三年的服务器CPU市场，不是一个“此消彼长”的零和游戏，而是一个“水涨船高”的增量市场。x86和ARM都会增长，只是ARM在吃掉更大的份额。

**谁在受益？**

报告列出了几个关键受益环节：

首先是供应链上游。CPU出货量增加直接带动基板、BMC芯片、插座等配套需求。报告特别提到了ASPEED（BMC芯片）、Lotes（插座）和Unimicron（基板）这三家公司，认为它们会是“超级服务器CPU周期”的主要受益者。

其次是代工和封测。AMD在x86服务器CPU领域的份额提升，对台积电和ASE（日月光）是利好。因为AMD是台积电的先进制程大客户，也是ASE的重要客户。

第三是存储。随着DIMM和SOCAMM需求的增加，DRAM厂商如SK海力士和三星电子也会受益。

最后是下游的PCB厂商和服务器ODM。服务器出货量的强劲增长，对Tripod（PCB）、Wiwynn和Inventec（服务器ODM）都是正面因素。

**一个值得追问的问题**

读完这份报告，我最大的感受是：市场对AI的讨论，可能过度集中在GPU和加速器上，而忽略了支撑整个生态的基础设施——CPU。

当AI从“展示能力”进入“实际部署”阶段，推理侧的硬件需求会呈现出与训练侧完全不同的特征。CPU的角色会从“配角”变成“枢纽”，这个转变带来的市场机会，可能比很多人想象的要大。

当然，报告里的预测是基于一系列假设的。比如，智能体AI的采用速度、加速器与CPU的配比变化、ARM的渗透率等等。任何一个假设的偏差，都会影响最终的数字。

但即使只看方向，这个判断也是清晰的：服务器CPU市场正在经历一轮由AI推理驱动的结构性增长，而这个增长才刚刚开始。

完整报告里还有不少细节，比如对各家云厂商自研芯片的拆解、对配比变化的具体假设、以及对供应链各环节的量化分析，适合在后续交流中继续探讨。
