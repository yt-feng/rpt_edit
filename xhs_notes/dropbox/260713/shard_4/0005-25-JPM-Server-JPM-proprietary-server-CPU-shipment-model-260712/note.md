AI推理需求增长，服务器CPU进入新的发展阶段

服务器CPU，正在被AI重新定义

某机构最新研究分析了一个关键趋势：AI从训练转向推理，正在改变服务器CPU的需求结构。

过去大家关注GPU，现在CPU的关注度也在提升。

📌 三个需求方向，一个增长阶段

1️⃣ AI前端CPU：加速器越复杂，需要的CPU越多
- 加速器与CPU比例从4:1降到2:1甚至1:1
- NVL72机柜就是2:1设计，未来TPU可能做到1:1
- 预计2025-2028年AI前端CPU出货量年均复合增长74%

2️⃣ 智能体AI CPU：新的增长点
- AI推理需要大量CPU做编排、存储、安全
- 每2个加速器就要配1个CPU，这个比例还在上升
- 预计2025-2028年年均复合增长155%，是主要增量

3️⃣ 传统服务器CPU：稳定但增长较慢
- 年复合增长约5%，虽然不是主要增长点，但仍是基础

📊 数据参考：服务器CPU出货量从2025年2600万颗→2028年6800万颗，年均复合增长38%

💡 架构变化：ARM正在扩大市场份额
- 2025年ARM约占22%，2028年预计升至43%
- 驱动来自NVIDIA Vera和Google Axion
- x86也有增长，年均复合增长仍有25%——比上一轮周期更快

🔍 哪些环节值得关注？
- 芯片设计：ASPEED（BMC）、Lotes（插座）
- 制造与封装：台积电、ASE
- 基板：Unimicron
- 存储：SK海力士、三星
- 下游：服务器PCB厂（Tripod）、ODM（Wiwynn、Inventec）

一个值得注意的细节：CPU单价也在变化，预计每年提价10%。量价齐升，整个服务器CPU市场2028年有望达到1000亿美元。
