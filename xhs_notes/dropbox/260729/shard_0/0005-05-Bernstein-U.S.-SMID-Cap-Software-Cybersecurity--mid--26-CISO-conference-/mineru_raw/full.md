# 网络安全：2026年中CISO电话会议纪要——预算趋势、优先级与AI影响

我们近期举办了一场电话会议，邀请了三位首席信息安全官（CISO）讨论最新的预算趋势、AI影响及优先级事项。以下是完整的编辑版会议纪要。

网络安全支出持续超越整体IT支出，主要驱动力来自AI。安全负责人一致将AI描述为新投入的最大催化剂，原因在于组织既要防御AI驱动的攻击，也需要安全地支持内部AI应用。

身份已成为新的安全边界，非人类身份现已成为首要关注点。焦点正转向保护AI代理（人机协同+独立代理）——如何为数据/系统/应用访问分配身份，并应用特权访问和治理框架，确保对人类和非人类行为者均实施最小权限、有时限的访问。

组织正在努力平衡AI应用与控制及可见性。安全负责人报告称，员工在多个大语言模型上的实验急剧增加，引发了对以下问题的担忧：哪些数据被输入模型、代理可以访问哪些系统、它们可以执行哪些操作，以及这些操作如何被监控和审计。因此，组织正在通过集中式AI路由器或端点、网络和数据层控制来投资AI治理，以提供对提示词、代理行为、数据访问及潜在数据外泄风险的可见性。

除了预算增加，供应商整合是新安全优先级的主要资金来源。CISO们正在淘汰遗留平台，重新评估现有安全堆栈，并寻求从现有供应商处增加功能，因为这通常比添加同类最佳独立产品便宜得多。……但供应商整合是在关键网络安全支柱层面，而非端到端。与会者普遍倾向于在“核心支柱”（如身份、端点、网络、Web安全、云安全和电子邮件）内保持独立领先供应商。CrowdStrike、Wiz、Palo Alto和Okta因创新而频繁受到称赞。

安全运营正朝着自动化方向发展，因为人类速度的响应已不再足够。与会者一致认为，AI驱动的攻击者正在加速威胁节奏，迫使组织积极评估代理型SOC平台和自主响应能力，以减少调查时间、提高韧性，并更接近机器速度运行。能够跨网络安全支柱进行整合的“瑞士”式风投支持初创公司（如Torq、Tines）似乎更受青睐。讨论还表明，传统SIEM相对于代理型ITDR/SOC模式正变得不那么具有战略意义。

讨论传递的核心信息是，AI正在迫使网络安全战略重新设计。预算编制、身份管理、安全运营、供应商选择、治理和风险管理都在通过AI视角重新评估。安全负责人不再将AI视为新兴趋势；他们正在围绕“AI将定义未来威胁格局和未来技术环境”这一假设来重构安全计划。

**网络安全支出持续超越整体IT支出，主要驱动力来自AI。** 在各行业中，安全预算要么增长速度超过整体IT预算，要么在其他IT职能面临削减时得到保护。安全负责人一致将AI描述为新投入的最大催化剂，原因在于组织既要防御AI驱动的攻击，也需要安全地支持内部AI应用。

**身份已成为新的安全边界，非人类身份现已成为首要关注点。** CISO们强调，远程工作、AI代理和自主工作流已从根本上改变了访问管理需求。焦点正从员工/客户账户转向独立AI代理的身份——如何为数据/系统/应用访问分配身份，并应用特权访问和治理框架，确保对人类和非人类行为者均实施最小权限、有时限的访问。

**组织正在努力平衡AI应用与控制及可见性。** AI在工程和业务团队中的使用正在快速增长，速度往往超出预期。安全负责人报告称，令牌消耗、员工在多个大语言模型上的实验急剧增加，对以下问题的担忧日益加剧：哪些数据被输入模型、代理可以访问哪些系统、它们可以执行哪些操作，以及这些操作如何被监控和审计。因此，组织正在通过集中式AI路由器或端点、网络和数据层控制来投资AI治理，以提供对提示词、代理行为、数据访问及潜在数据外泄风险的可见性。讨论的重点不在于限制AI使用，而在于围绕数据保护、访问权限和代理自主权建立防护栏。

**特别是在预算受限的环境中，CISO们正在淘汰遗留平台，重新评估现有安全堆栈，并寻求从现有供应商处增加功能，因为这通常比添加同类最佳独立产品便宜得多。** 许多组织不是购买独立的点解决方案，而是在可能的情况下从现有战略供应商处增加功能，因为附加模块通常比引入新产品便宜得多。目标是释放资源用于更高优先级的计划。

**供应商整合是在关键网络安全支柱层面，而非端到端。** 尽管微软和Palo Alto等公司继续扩展其安全产品组合，但与会者普遍倾向于在“核心支柱”（如身份、端点、网络、Web安全、云安全和电子邮件）内保持独立领先供应商。CrowdStrike、Wiz、Palo Alto和Okta因创新而受到称赞，而对那些在AI和现代身份需求方面进展较慢的供应商则表达了担忧。

**与会者一致认为，AI驱动的攻击者正在加速威胁节奏，使得传统SOC模式越来越难以维持。** 组织正在积极评估代理型SOC平台和自主响应能力，以减少调查时间、提高韧性，并更接近机器速度运行——能够跨网络安全支柱进行整合的“瑞士”式初创公司似乎更受青睐。讨论还表明，传统SIEM相对于能够将信号转化为行动的集成威胁检测、威胁情报、编排和响应能力，正变得不那么具有战略意义。最终状态越来越趋向于代理型ITDR/SOC模式，该模式将检测、丰富、调查、优先级排序和响应整合为高度自动化的工作流程。

**讨论传递的核心信息是，AI正在迫使网络安全战略重新设计。** 预算编制、身份管理、安全运营、供应商选择、治理和风险管理都在通过AI视角重新评估。安全负责人不再将AI视为新兴趋势；他们正在围绕“AI将定义未来威胁格局和未来技术环境”这一假设来重构安全计划。
