# DDR4 涨价超预期，存储芯片的“老树开花”

📌 老存储，新观察

近期存储芯片板块关注度有所调整，主流DDR5涨价节奏放缓，加上市场对CSP资本开支的讨论，老一代存储（DDR4、SLC/MLC NAND、NOR Flash）的相关公司受到一定影响。但某外资研究机构最新报告指出，这些“老产品”在3季度迎来了超预期的涨价窗口。

1️⃣ DDR4：CSP积极签署长约
- 报告认为，3季度DDR4月度涨价幅度可能超过20%，季度环比涨幅至少30%。
- 关键信号：CSP（云服务商）不仅愿意接受更高报价，甚至希望签署1-2年的长期供货协议（仅锁定数量，不锁价）。这在过去较少见，说明供给端确实偏紧。

2️⃣ 利基型NAND & NOR：涨价幅度更明显
- SLC/MLC NAND：3季度预计季度环比涨50-60%。
- NOR Flash：3季度预计季度环比涨30-40%。
- 这些品类虽然市场规模较小，但下游工业、汽车、IoT需求稳定，供给端新增产能有限，结构性缺口持续存在。

3️⃣ 关于某公司的“降价提示”
- 某公司公告称，其利基型存储产品未来可能大幅降价。报告认为，这更多是**长期趋势的提示**，而非短期风险。因为当前DDR4、SLC/MLC NAND、NOR Flash依然存在结构性供给缺口，短期涨价逻辑未变。

4️⃣ 估值支撑参考
- 大中华区存储IDM公司（如旺宏、南亚科、华邦电）当前估值在1.2-1.5倍2028年预测每股净资产（BVPS），历史上1.0倍BVPS是较强支撑位。
- 某公司报价已从高点回调45%+，估值压力有所释放。

🧠 个人观察
市场总喜欢关注新产品（DDR5、HBM），但有时候“老产品”因为供给出清、需求刚性，反而存在预期差。这次DDR4的涨价节奏，可能比很多人想的要强。
