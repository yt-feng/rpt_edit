# 大中华区半导体行业观察 | 亚太市场

# 传统存储：近期趋势分化

近期关于存储周期的讨论、相关企业的现金流关注，以及部分市场参与者的仓位调整，导致传统存储类公司估值有所变化。但我们观察到，DDR4报价上涨动能增强，且传统闪存产品在第三季度展现出较强的定价能力。我们认为，以2028年预期每股账面价值的1.0倍作为参考，当前价位具备一定的支撑基础。

**主流存储市场趋势变化**：根据Trendforce（图表1），2026年第三季度传统DRAM混合报价预计环比上涨13-18%。具体来看，PC用DDR5报价预计环比上涨15-20%，服务器用DDR5报价环比上涨13-18%，移动端LPDDR5(X)报价环比上涨8-13%，NAND报价环比上涨10-15%。此外，Trendforce预计第四季度传统DRAM报价环比涨幅为3-8%，NAND为0-5%。这些预估增速低于部分市场参与者此前的预期。

然而，近期我们看到传统存储产品报价表现更为强劲：与我们之前的报告（链接）观点相似，我们认为DDR4在第三季度有望持续月度提价。相比一个月前的预期，我们观察到部分云服务提供商愿意为DDR4接受更高的报价，甚至可能尝试与供应商签署1-2年的长期协议（仅锁定数量）。因此，我们认为月度报价在第三季度可能上涨20%以上，意味着季度环比涨幅至少为30%。我们同时维持对第三季度SLC/MLC NAND报价环比上涨50-60%，以及NOR Flash报价环比上涨30-40%的预期。

**A股相关公司的仓位调整有望趋于稳定**：北京兆易创新发布公告（链接），提示公司利基型存储产品未来可能面临价格明显下降。我们认为这一提示更多反映的是长期趋势，而非短期可能性，因为当前DDR4、SLC/MLC NAND及NOR Flash领域仍存在结构性供给缺口，支撑着报价的持续上行。

**支撑位如何理解？** 兆易创新（603986.SS）：作为设计公司，市盈率底部较难精确衡量，但该报价自6月29日高点已回落45.6%，提供了一定的估值支撑。旺宏/南亚科/华邦电分别交易于2028年预期每股账面价值的1.5倍/1.2倍/1.2倍；从历史数据看，1.0倍对于大中华区IDM公司而言是一个较强的支撑参考水平。
