# 4月外汇数据揭示的真正信号：资本回流并非趋势反转，而是结构性分化的开端

4月的外汇数据，像一针强心剂。370亿美元的净流入，与3月70亿美元的净流出形成鲜明对比。市场上很快会出现两种声音：一种认为资本外流压力已过，另一种则将其归结为短期扰动。

但这份某外资投行最新发布的研报，给出的判断远比“好或坏”更值得深究。它指向一个更核心的问题：当前的外汇流入，其结构正在发生根本性变化。真正重要的不是流入的总量，而是流入的钱是谁的、通过什么渠道、以及这些渠道背后的驱动力还能持续多久。

如果你只看月度数据的波动，很容易被短期情绪左右。但如果拆解这份报告中的分项数据，你会发现一个清晰的信号：中国的外部收支平衡正在经历从“贸易顺差驱动”到“金融账户驱动”的切换，而这个切换过程，恰恰是市场定价尚未充分反映的变量。

以下是我们从这份研报中提炼出的四个核心洞察，以及一个尚未被完全回答的关键问题。

## 1. 4月净流入的主要驱动力并非来自贸易，而是来自企业和银行的资产负债表行为

研报显示，4月经常账户净流入为340亿美元，低于3月的470亿美元。其中，货物贸易相关的净流入从3月的600亿美元降至480亿美元。这意味着，4月外汇净流入的“增量”主要来自金融账户，而非贸易顺差。

具体来看，4月证券投资渠道录得120亿美元净流入，而3月为70亿美元净流出。更值得关注的是，商业银行的净外部资产在4月增加了190亿美元，而3月为减少100亿美元。这说明，企业和银行正在主动调整其海外资产和负债的配置——它们可能在减少海外存款、增加结汇，或者通过衍生品交易对冲汇率风险。

这意味着什么？贸易顺差依然庞大，但企业结汇意愿在下降（4月结汇比率从3月的117%降至56%）。与此同时，金融渠道的资金流动正在成为边际定价力量。市场的关注点应从“出口赚了多少钱”转向“这些钱是否愿意留在境内”。

## 2. 债券市场的外资流出仍在持续，但速度和结构都在变化

一个容易被忽略的细节是，4月北向债券通净流出100亿美元，低于3月的190亿美元。流出规模在收窄，但方向并未逆转。

研报中一张图表揭示了更精细的结构：外资卖出中国国债和政策性银行债的规模在减少，但卖出同业存单的规模依然较大。这说明，外资对中国主权信用的信心有所修复，但对流动性管理工具（如同业存单）仍持谨慎态度。这种“分化式流出”暗示，外资并非一刀切地看空人民币资产，而是在进行风险定价的精细化调整。

对于市场参与者而言，这意味着人民币债券的定价逻辑正在从“被动配置”转向“主动交易”。未来，外资流入的恢复可能不是V型反弹，而是基于利差、汇率预期和信用风险的逐项修复。

## 3. 官方外汇储备的变动，正在被估值效应和商业银行行为共同“扭曲”

4月官方外汇储备增加了460亿美元（扣除估值效应后），而3月为减少约100亿美元。但研报特别指出，商业银行的净外部资产在4月增加了190亿美元。这两个数字加总，才更接近真实的资本流动全貌。

这是因为，官方储备的变动受汇率和资产价格波动影响很大（4月估值效应估计为230亿美元）。而商业银行的海外资产变动，则反映了境内实体（包括企业和个人）的跨境资金调度。当商业银行增加海外资产时，意味着资金在流出；反之，则是流入。4月商业银行净外部资产大幅增加，与官方储备增加形成了有趣的对照——一部分资金可能从官方储备渠道“转移”到了商业银行体系，或者两者共同反映了资本流入的不同形式。

这个现象提醒我们，单纯看官方储备变动来判断资本流动，可能产生误判。真正的资金流，需要结合商业银行资产负债表和跨境人民币流动数据来交叉验证。

## 4. 一个尚未被完全回答的关键问题：结汇比率骤降是否意味着企业仍在“囤汇”？

报告中最引人注目的数据之一，是4月货物贸易结汇比率从3月的117%骤降至56%。3月结汇比率超过100%的原因可能是前期积压的结汇集中释放，而4月的骤降则表明，企业并没有因为人民币汇率波动而大规模结汇。

这背后有两种可能的解释：一是企业预期人民币仍有贬值压力，选择持有外汇；二是企业正在利用外汇进行海外投资或支付，而非结汇。报告没有给出明确结论，但这恰恰是当前市场最需要关注的风险点。

如果结汇比率持续低迷，即使贸易顺差维持高位，外汇市场仍可能面临“顺差不顺收”的困境——即赚来的外汇没有进入银行间市场，导致人民币汇率缺乏支撑。这个问题，需要后续月份的数据来验证，也是我们在微信群中持续跟踪的核心变量之一。
