芯片长协：这次与以往有何不同

**旧协议 vs 新协议**

**半导体长期协议的历史回顾与结构变化**

---

近期阅读了一份关于半导体长期协议（LTA）演变的研究报告。报告指出，当前阶段的协议结构与过去几次周期相比，确实存在显著差异。

过去，半导体LTA在本质上更偏向于买方的工具，供应商的实际保障较为有限。主要存在两种结构：

**1. 取或付（Take-or-Pay）**：买家承诺最低采购量，否则需支付罚款。但罚款缺乏预付资金支持，只能通过诉讼追讨，过程漫长且成本高昂。

**2. 不可取消订单**：买家承诺不取消订单，但历史经验表明，在市场周期转向时，取消订单的情况仍会发生。

两个具有代表性的案例：

**案例1：Microchip / 模拟芯片**

2020-2022年芯片供应紧张期间，汽车和工业客户大量抢购并重复下单。Microchip推出了“优先供应计划”（PSP），要求客户提交12个月不可取消、不可调整的订单。

然而，模拟芯片的需求与终端产量紧密相关，不会呈现指数级增长。一旦供应缓解，客户库存积压，无法容纳更多芯片。最终，Microchip被迫允许客户暂停订单，营收出现明显回落。

**启示**：合同约束力不足，客户违约成本几乎为零。

**案例2：Hemlock / 多晶硅**

2000年代中期，多晶硅供应紧张，价格一度升至每公斤400美元。Hemlock与太阳能厂商签订了10至14年的长期协议，锁定价格为每公斤40至60美元。

随后，全球产能大幅扩张，价格跌至每公斤15美元以下。若买家按合同价采购，每生产一块太阳能板将面临亏损。加之相关贸易政策变化，买家进口受阻。

结果：SolarWorld破产，Kyocera支付4.5亿美元解约，Hemlock虽在诉讼中胜诉，但大部分款项未能收回。

**启示**：合同虽有法律效力，但依赖诉讼追偿，等到判决时，客户可能已无力支付。

**当前内存LTA的三个关键变化：**

1️⃣ **预付资金安排**：客户需支付现金押金、提供信用证或第三方担保，且保函覆盖比例随时间递增，后期可达剩余采购额的75%至100%。违约成本变得切实可见。

2️⃣ **对手方质量**：客户多为资产负债表稳健的大型云服务商，而非小型太阳能公司或汽车分销商。

3️⃣ **结构性需求**：由人工智能驱动的持续建设，而非临时抢购或重复下单。高端内存产能已排期至2026至2027年。

研究报告认为，新的LTA提供了实质性的下行保护，但并非无限保障。与过去相比，当前客户违约的动机已大幅降低。
