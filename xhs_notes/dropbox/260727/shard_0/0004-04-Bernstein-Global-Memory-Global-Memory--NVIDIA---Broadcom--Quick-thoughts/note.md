# AI存储领域合作动态观察

近期，三星与SK海力士在AI存储方面签署了重要合作意向。

某外资机构研究解读韩国AI峰会上的存储合作信息：

1️⃣ SK海力士与NVIDIA达成5000亿美元合作意向，涉及HBM4等下一代AI存储供应。同时规划了2027年为SK电讯建设2GW Vera Rubin AI数据中心。

2️⃣ 三星与博通签署2000亿美元MOU（至2030年），涵盖HBM存储和2nm以下先进制程代工，以及2.3D/2.5D先进封装技术。

3️⃣ 研究认为这些合作凸显存储技术在AI领域的关键地位。行业共识预测2027/2028年存储年营收约1.3万亿美元。

4️⃣ 对台积电影响有限，因需求排队较长，三星订单不会影响台积电近期表现。

5️⃣ 研究关注存储板块，认为近期调整值得观察。同时提示中国在NAND领域的长期发展，DRAM因EUV壁垒相对稳定。

6️⃣ 按NVIDIA约1万亿美元（CY25-27）和博通1000亿美元+的AI营收指引，这些存储协议有助于缓解供应紧张。
