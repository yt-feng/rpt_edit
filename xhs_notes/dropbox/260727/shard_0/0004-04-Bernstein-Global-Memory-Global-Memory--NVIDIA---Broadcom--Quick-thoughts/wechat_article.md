# Bernstein：全球存储-英伟达与博通战略合作

在韩国于旧金山举办的AI峰会上，三星、SK海力士、英伟达与博通宣布了多项战略合作。Bernstein在最新发布的全球存储研究报告中指出，这些合作的核心信号是：存储器件在AI基础设施中的战略地位正在被重新定义，其重要性甚至超过逻辑半导体。

SK海力士与英伟达签署的意向书明确了此前7月宣布的合作细节，包括超过5000亿美元的存储合作规模，以及计划于2027年为SK电讯上线的一座2GW Vera Rubin DSX AI工厂。Bernstein同时注意到，SK集团据报还将在未来5年内与其他全球科技公司就存储供应展开价值2500亿美元的额外合作。三星与博通则签署了一份谅解备忘录，涉及未来5年（至2030年）价值2000亿美元的存储（含HBM）与代工服务。代工部分将聚焦2纳米及以下制程，用于无线宽带通信解决方案，以及面向AI与网络芯片的2.3D和2.5D先进封装技术。

> **KC评论：** 这些数字——5000亿、2000亿、2500亿——并非精确的订单承诺，更多是合作框架的上限指引。但它们的体量本身已经说明，英伟达和博通正在用长期协议锁定未来数年的存储供应，尤其是HBM4及后续世代的高带宽内存。

## 1. 存储年收入预期在2027至2028年达到约1.3万亿美元

Bernstein引用的市场共识数据显示，全球存储行业年收入在2027年和2028年都将维持在约1.3万亿美元的水平。将上述合作金额置于这一背景下，可以看出英伟达与博通所寻求锁定的供应规模，在整体市场中占据了相当可观的份额。报告认为，这些交易有助于缓解市场对英伟达和博通供应能力的担忧——两家公司均给出了强劲的AI增长指引，英伟达2025至2027财年累计AI收入约1万亿美元，博通下一年度AI收入则超过1000亿美元。

## 2. 对台积电的潜在影响可以忽略不计

Bernstein分析认为，这些合作对台积电的影响微乎其微。原因在于，博通是否会将AI ASIC交由三星进行晶圆制造或先进封装，目前仍不明确。更重要的是，台积电的产能面前排着长长的需求队列，即便三星或英特尔确实抢走一部分份额，也不会对台积电可预见的盈利产生实质性影响。这一判断暗示，当前AI芯片的产能瓶颈依然集中在台积电，三星的先进封装技术（如2.3D Cube-E和Cube-R，分别对标台积电CoWoS-L和CoWoS-R）短期内难以撼动其地位。

## 3. 存储在AI中的角色比逻辑半导体更关键

Bernstein在报告中明确提出，存储器件对AI的重要性高于逻辑半导体。这一判断基于一个核心事实：AI工作负载对内存带宽和容量的需求正在指数级增长，而HBM等先进存储产品的供应能力直接决定了AI芯片的实际产出效率。报告对存储板块整体持建设性看法。但在细分领域，Bernstein对NAND闪存表达了长期关注，认为相关厂商在该领域的竞争态势值得观察；而在DRAM领域，由于技术门槛较高，相关厂商的竞争难度显著更高。基于这一框架，报告对三星、SK海力士和美光均给予正面评级，对铠侠则给予谨慎评级。

> **KC评论：** Bernstein对存储与逻辑半导体的重要性排序，提供了一个观察AI产业链的新框架。过去市场更关注GPU算力的迭代速度，但这份报告提醒我们，存储供应的稳定性和技术演进节奏，可能成为制约AI规模扩张的更紧约束。三星和SK海力士此次获得的长期协议，本质上是在将这种约束转化为自己的护城河。
