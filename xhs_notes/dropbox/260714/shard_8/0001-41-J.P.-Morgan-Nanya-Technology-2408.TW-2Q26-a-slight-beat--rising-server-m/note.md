# 南亚科2Q26观察：服务器业务占比提升，长期协议结构趋于多元

**封面：服务器相关收入占比超过20%**
**副标题：长期协议结构多元化，盈利波动性或有所减弱**

**正文：**

1. 南亚科2Q26实现营收825亿新台币，营业利润608亿新台币，略高于市场预期。平均售价环比增长超过60%，出货量保持平稳，成本结构稳定，盈利改善主要受价格因素驱动。

2. 服务器相关收入占比超过20%，此前历史区间约为10-15%。若计入eSSD间接敞口，实际占比更高。LPDDR5X堆叠方案切入服务器ARM CPU供应链，被视为下一个增长方向。

3. 长期协议结构呈现多样化特征：部分协议锁定价格与数量，部分仅锁定数量而价格按季度市价调整。管理层表示，供应偏紧状态已持续多个季度，客户更倾向于签署多年期长期协议，这有助于平滑盈利波动。

4. 2026年资本支出计划为520亿新台币，上半年仅支出69亿新台币，下半年将有所加速。新厂一期规划月产能30K，峰值可达45K，总资本支出约4800亿新台币。研究观点认为，这可能是供应瓶颈逐步释放的信号，结合长期协议推进，中期稳定性有望增强。

5. 短期来看，公司报价可能呈现区间波动，直至云服务商资本支出指引得到进一步确认。中期风险回报仍具一定吸引力，驱动因素包括：服务器硬件支出进展、亚洲同业展望、DDR4/DDR5月度定价变化、以及中国竞争对手IPO后的计划安排。

6. 产品组合方面：DDR4与LPDDR4合计占比60-70%，DDR3和DDR5各约占10%。DDR4价格上涨动能强于DDR5，短期趋势可能延续。非AI应用需求保持平稳，高端产品表现优于低端产品。

7. 股东回报方面：分红率约为40%，需平衡资本支出需求。员工奖金已计入上半年费用。

8. 客户需求结构：消费电子相关占比60%，云/PC/手机相关占比40%。公司正在争取更统一的支持。
