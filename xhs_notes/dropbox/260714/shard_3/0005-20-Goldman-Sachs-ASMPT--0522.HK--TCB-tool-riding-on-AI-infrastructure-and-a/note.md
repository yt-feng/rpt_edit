# AI基建带火先进封装，这家设备商怎么看

先进封装，AI基建的“隐形推手”

某机构最新研究上调了ASMPT的目标价至206港元，核心逻辑是AI基建周期正在拉动先进封装设备需求。简单拆解一下：

1️⃣ **AI服务器需求上修**
- 研究上调2026-28年AI芯片出货量14%/22%/14%
- 美国云厂商资本开支上调8%/27%/25%
- 中国云厂商资本开支上调37%/44%/55%
- AI基建的持续投入直接拉动封装设备订单

2️⃣ **TCB设备是核心关注点**
- 热压键合（TCB）设备是先进封装的关键环节
- 已获得全球某IDM大厂8台芯片对晶圆TCB设备的重复订单
- 台积电CoWoS扩产也是重要推动力
- 研究预计2026-28年净利润复合增速达36%

3️⃣ **估值逻辑的变化**
- 改用2030年折现PE估值，更看重长期增长
- 目标价从旧模型上调至206港元
- 但维持中性评级，当前33倍2027年PE已反映不少预期

**一点思考**：设备股往往是产业链的“卖水人”，AI基建的确定性增长确实利好上游。但估值不便宜时，市场需要看到更多订单落地才能消化预期。你对先进封装赛道怎么看？
