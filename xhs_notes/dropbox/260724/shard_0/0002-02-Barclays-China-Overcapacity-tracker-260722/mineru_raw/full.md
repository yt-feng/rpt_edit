# 数据分析：出口表现与国内结构性变化

Roanna Chau

增长点更趋集中。中国6月生产与出口数据显示，新经济领域与传统领域之间存在结构性分化，增长点更集中于特定的上游及赋能技术领域。集成电路产量同比增长18.8%，较5月的22.9%有所放缓，但出口价值增速进一步加快至121.9%，尽管出口量小幅下降0.3%。这表明半导体出口的驱动力正越来越多来自单价提升和/或向高价值产品转移，而不仅仅是出货量的增长。锂电池领域同样保持韧性，出口量与出口值分别增长23.5%和31.7%。

相比之下，新能源汽车领域呈现出国内生产与外部需求之间日益扩大的差异。6月混合动力乘用车产量下降34.2%，插电式混合动力下降32.4%，而纯电动汽车产量基本持平于-0.6%。但出口量依然强劲，分别增长105.3%、183.3%和81.3%。

家用电器呈现出更为均衡的局面。冰箱产量、出口量及出口值同比分别增长14.7%、18.9%和19.5%；洗衣机出口保持正向，量值分别增长11.9%和9.8%。空调6月也出现出口回升，出口量与出口值在5月收缩后分别恢复至11.3%和10.1%的增长，尽管国内产量仍较为温和，为-9.6%。这一时间点与西欧创纪录高温及制冷设备需求上升相吻合。与传统产能出清型出口不同，空调出口量与出口值增长幅度大致匹配，表明改善主要来自需求驱动而非价格折让。

总体来看，复苏呈现结构性特征，半导体和电池领域表现最为突出，而汽车和空调领域明显的出口-生产分化则表明，外部需求在吸收国内产能方面的作用日益重要。

出口产能流动仍是主要特征，但构成正在变化。2025年底，我们曾分析认为2026年中国货物流动将加速并跨领域扩大——这是反内卷政策以及国内需求环境持续作用下的结果。6月数据与此判断相符，但不同领域之间的分化日益显著：一部分属于产能出清型出口，另一部分则受益于更强的定价能力或更优的产品组合。集成电路是一个最清晰的例子：出口价值增速从3月的84.9%加速至4月的99.6%、5月的110.9%和6月的121.9%，然而出口量增速却从3月的12.9%放缓至4月的3.6%、5月的2.0%和6月的-0.3%。价值与数量差距的扩大表明出口单价和/或产品组合有所改善，使其更少表现为数量驱动的产能出清，更多体现为中国在技术价值链上的提升。

铝材也展示了行业内部的差异化。铝制品出口值同比增长77.0%，而出口量增长44.9%，指向更高的单价或更优的产品组合。相比之下，氧化铝出口值增长35.1%，落后于58.8%的出口量增长，表明其面临更大的定价压力。这种对比说明中国的出口强势并非仅限于上游大宗商品的出货量增长，部分高价值制造品得益于更有利的定价或产品组合。

电气化领域保持强劲，而太阳能及传统领域则呈现更明显的产能压力信号。锂电池出口在6月重新提速，出口量同比增长23.5%，高于5月的12.3%，出口值增长31.7%。尽管价值增速较2-3月的63-69%有所放缓，但仍高于数量增速，与全球对电动车、储能及可再生能源整合的稳定需求相符。太阳能电池方面则呈现更为复杂的局面，6月出口量收缩16.5%，继5月的11.2%下降之后进一步下滑，与3月79.6%和4月60.4%的增长形成鲜明对比。不过出口值在6月恢复至13.2%的增长，表明尽管出货量减弱，但定价有所企稳或产品组合有所改善。

传统重产能领域内需表现相对稳定。水泥产量下降5.6%，但出口量仍增长109.2%，出口值增长88.4%，保持着最为典型的数量驱动型产能出清特征。钢材产品产量基本持平为-0.4%，但出口温和改善，出口量与出口值分别增长6.6%和10.3%。

# 经济分析：分化中的再平衡

Ying Zhang

## 价格回升尚未充分预示广泛再平衡

中国价格指标近几个月来有所改善，PPI和出口价格均出现上行。PPI在3月转正，结束了长达41个月的负值区间，并在6月升至近四年高点。出口价格也在4月重回正值区间，5月同比增长8.9%，为2023年1月以来最大涨幅。然而，近期价格的改善可能尚未充分预示定价能力的广泛增强。价格上涨似乎主要受全球大宗商品和能源价格变动带来的投入成本上升，以及全球AI投资热潮中部分AI相关和科技领域较强定价的推动。对大部分工业领域而言，供需格局可能仍处于调整之中。

出口价格的行业细分进一步印证了这种不均衡的价格上涨特征。半导体和电子等高科技领域定价态势较为稳固，而食品饮料（-10%）、木材（-7%）、纸张（-7%）、纺织品（-5.4%）、鞋类（-8.6%）、家具（-11.8%）、玩具（-11.7%）和车辆（-2.5%）等广泛制造业领域价格仍承压。这种分化与宏观经济中更广泛的二元结构相呼应。在最近的季度货币政策委员会会议上，央行新增了对经济中“结构性分化”挑战的表述，相较上次季度会议声明及5月发布的一季度货币政策报告均有补充。

## 出口作为渠道，侧重高科技领域

外部需求对中国工业领域的重要性日益提升，既为受益于强劲全球需求的特定领域提供了增长来源，也为面临内需调整的领域提供了出口渠道。上半年六个月中有五个月的出口超出市场预期，6月最新数据显示出货量同比增长27%。一个重要的积极变化是出口结构的持续升级。如今，出口增长中越来越大的份额来自与人工智能、先进制造和能源转型相关的行业，而非主要依靠规模和数量竞争的传统制造业。

据估算，半导体（特别是内存芯片）和自动数据处理设备共同贡献了约8个百分点的主要出口增长，占上半年出口同比增长17.6%的40%以上。相比之下，低技术和劳动密集型领域（约占出口总额的15%）仍较为滞后，鞋类和玩具出口持续收缩。这种出口表现的分化可能进一步强化了前述的定价和盈利能力不均衡趋势——高科技领域的需求相对强劲，而传统制造业的定价压力则持续存在。

## 贸易环境与供需再平衡的努力

更广泛来看，中国强劲的出口表现日益受到主要贸易伙伴的关注。随着中国出口在多个领域持续扩大市场份额，主要经济体已加强贸易防御措施，特别是在电动汽车和清洁技术供应链、化工及金属密集型工业产品相关领域。欧盟与中国也就多个领域的贸易关系展开对话，这反映了各方对中国制造业布局和出口竞争力扩展的关注。

在此背景下，近期政策信号日益强调加强内需、改善供需平衡。4月，《求是》罕见发出关于“避免盲目追求更大出口和贸易顺差”的提示，指出过大的贸易顺差可能给经济发展带来风险，并呼吁“适度缩减”贸易顺差。

与此同时，政策层面持续聚焦于应对国内供需平衡问题。供给方面，“反内卷”行动持续推进，2026年政府工作报告将去年“全面整治”的表述升级为“深入整治”过度和无序竞争。决策层多次强调有序淘汰落后产能、加强产业自律。在此背景下，锂电池和太阳能电池消费税的重新引入，反映出更广泛地引导产能扩张与行业发展的努力。

需求方面，有关部门持续强调扩大内需。7月，中国发布了首个专门针对扩大消费的五年规划，目标至2030年社会消费品零售总额达约60万亿元，并更加侧重服务消费。同时，提出的“六网”基础设施建设项目，旨在支持传统与新兴基础设施领域的投入。
