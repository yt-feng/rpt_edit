# 国产半导体设备，当前表现如何？

**短期观察，长期关注**

某外资机构最新研究分析，关于一家国产半导体设备厂商的现状与展望。

**1. 近期业绩有波动，但毛利率表现值得关注**
1Q26营收低于预期，原因是新产品爬坡周期比预期更长。但毛利率连续三个季度超过40%，说明成本控制或产品结构在持续优化。

**2. 核心逻辑：本土供应链与AI趋势**
研究看好中国半导体供应链，主要驱动力是本土先进制程扩产和AI发展。特别是长鑫存储与腾讯的服务器DRAM长期供应协议，表明本土客户需求稳定，且向高端应用迁移。这家设备商有望从中持续受益。

**3. 盈利预期：先调整后改善**
基于1Q26的业绩，研究下调了2026年净利润预期（-5%），主要是下调了收入预期。但上调了2027-28年的收入和毛利率预期，因为公司正将供应链转向国内供应商，且受益于本土存储和先进制程的扩产。

**4. 市场定价如何看？**
目标价上调至32.9元，基于2027年预期盈利的49.9倍市盈率（高于之前的45.9倍）。这个倍数参考了可比公司的PEG（市盈率相对盈利增长比率）在0.9-1.8倍之间，该公司为1.3倍，处于合理区间。

**但需留意**
当前报价（37.57元）已高于目标价，隐含约12%的调整空间。研究维持“中性”评级，认为积极因素已基本被市场消化。风险包括：国内半导体资本开支不及预期、竞争加剧、新产品（RTP和干法刻蚀机）出货放量慢于预期。

**一点思考**
短期业绩和市场定价存在波动，但中长期本土供应链的叙事逻辑依然清晰。这家公司正处于从“依赖行业趋势”到“依靠自身产品力”切换的关键期，新产品爬坡速度是重要观察点。
