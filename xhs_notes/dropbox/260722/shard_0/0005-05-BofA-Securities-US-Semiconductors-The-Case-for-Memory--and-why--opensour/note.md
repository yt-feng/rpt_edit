# 中国开源大模型，反而利好存储芯片

存储芯片需求不降反升

最近国产大模型API定价有所调整，很多人关注存储芯片需求的变化。但相关研究给出了一个反直觉的结论：开源模型不仅没有减少存储需求，反而在扩大它。

1/ 开源模型≠低成本运行  
Kimi K3定价约为Claude Opus 4.8的1/5，但跑一次推理依然需要1.4TB的HBM。API价格是商业策略，不是硬件成本的真实映射。更关键的是，每次下载开源模型权重，都会产生一个独立的客户侧存储需求——这在闭源API模式下根本不存在。

2/ 模型越做越大，存储需求只增不减  
从DeepSeek-V3的671B参数到Kimi K3的2.8T参数，模型规模在18个月内翻了4倍。即使量化技术从FP8降到MXFP4（节省50%），但参数增长远超压缩效率。MoE架构虽然能降低算力消耗，但所有专家权重都必须驻留在HBM中，存储容量与总参数成正比。

3/ 开源模型=存储需求倍增器  
闭源模型（如GPT-5.6）的权重只部署在少数数据中心，所有用户共享同一份HBM。但开源模型每被下载一次，就多一套独立的HBM/DRAM/NAND需求。一个企业自托管Kimi K3需要64+加速器，10,000个企业就是10,000倍的存储需求。

4/ 效率提升vs需求增长，后者更显著  
即使MoE、量化、KV缓存压缩等技术让单次推理更高效，但多智能体工作负载的token消耗量已比传统聊天模型高出20万倍。这是效率提升与需求增长之间的一种常见现象。

存储芯片的需求逻辑，正在从“算力驱动”转向“模型规模×部署节点”的双重驱动。开源化带来的不是需求缩减，而是需求增长。
