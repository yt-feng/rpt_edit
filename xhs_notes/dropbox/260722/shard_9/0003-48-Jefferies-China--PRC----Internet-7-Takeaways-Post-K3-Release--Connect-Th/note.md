K3 之后，中国模型正在缩小差距

缩小差距的关键一步

某外资机构最新研究拆解了 K3 发布后的行业格局，信息量很大，帮你划重点。

1️⃣ K3 不是终点，是加速点
- Moonshot AI 表示 Scaling Law 依然有效，K3 远未触及智能上限
- 发布后第二天，ARR 增速创下最快纪录
- 这是中国模型首次在 Frontend Code Arena 领先美国模型（vs 年初 DeepSeek-R1 仅接近）

2️⃣ 更多万亿参数模型在路上
- Qwen 3.8：总参数 2.4T，即将发布
- MiniMax M3 Pro、Zhipu GLM 新版本、Tencent Hy4 都在排队
- 模型迭代周期已压缩到 3 个月以内

3️⃣ 算力是最近融资的核心
- DeepSeek（70亿美金）、Zhipu（40亿美金）、MiniMax（20亿美金）最新融资均指向算力
- 智谱披露 ZCube 架构比 Clos 降低 33% 成本、提升 15% 吞吐量

4️⃣ Token 支出指数持续走低
- 7月12日当周指数 1.56-1.61（vs 5月31日的 2.04）
- 中国模型 API 价格仅为美国模型的零头（MoE 架构+线性注意力）
- 编码和 Agent 场景下，性价比模型越来越关键

5️⃣ 应用端也有新信号
- 腾讯 WorkBuddy 桌面月活达 885 万，领先字节 Trae
- 阿里发布 Meoo 企业 AI 应用
- 2026 年/2027 年初，多家公司有望 ARR 超 10 亿美金

6️⃣ 视频生成格局暂无明显变化
- Kimi 联合创始人表示当前重点是模型智能
- 火山引擎 Seedance 2.5 已发布，视频生成占 MaaS 收入过半
