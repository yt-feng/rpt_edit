闲鱼标题：投行研报：全球半导体CPU复兴与AI数据中心TAM分析

商品描述：
这是一份来自国际投行的深度行业研报，主题聚焦于全球半导体行业，特别是CPU在AI数据中心领域的复兴趋势。报告详细分析了从生成式AI 1.0（聊天机器人）向2.0（智能体）转型如何推动服务器CPU需求激增，并给出了对2030年服务器CPU市场总规模（TAM）的预测。

这份资料适合以下人群：券商、基金、PE/VC机构的研究员或分析师；正在准备投研、券商、咨询行业面试的求职者；对AI基础设施、半导体产业链有研究兴趣的学生或从业者；以及需要撰写行业报告、进行市场分析的专业人士。

核心内容亮点：
- 预测2030年服务器CPU TAM达2230亿美元
- 分析AI智能体如何改变CPU与GPU的配对比例
- 覆盖Arm、AMD、Intel、Hygon等核心标的估值模型
- 包含三种情景（牛市/基准/熊市）下的TAM测算
- 探讨AI数据中心资本开支对CPU需求的驱动逻辑
