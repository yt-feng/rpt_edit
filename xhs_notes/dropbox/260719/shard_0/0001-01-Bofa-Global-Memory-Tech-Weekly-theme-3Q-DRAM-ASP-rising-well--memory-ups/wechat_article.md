# 研究笔记：全球存储行业三季度观察

近期市场对存储芯片三季度表现存在不同看法。根据相关机构调研，三季度DRAM合约价格呈现一定变化——服务器DRAM环比上涨20-30%，由高速LPDDR5领涨。现货市场同样给出信号，DDR5和DDR4价格在7月继续环比上升。

报告的核心判断是：三季度DRAM平均售价环比增长21%，高于部分常规假设。调研覆盖了从长期协议定价到急单价格的多个维度，发现非长期协议部分的DRAM销售占比高达60-70%，这部分价格弹性高于市场预期。

## 1. 现货价格连续八周上涨，OEM从观望转向备货

DRAM现货价格已连续八周走高，这与两三个月前的市场情绪形成对比。当时许多OEM因采购成本上升而调整了PC、平板和智能手机的生产计划，但现在它们正在为9月和四季度旺季备货而加大采购力度。

一个值得注意的细节是，现货市场交易量仅占全球供应的低个位数百分比，因此部分OEM转而通过急单方式采购常规DRAM。当前DDR5和DDR4的现货价格均指向约20%的季度环比涨幅。NAND现货价格也在本周出现回暖，1Tb wafer环比上涨4%。

## 2. 台积电和ASML的指引为存储需求提供额外支撑

台积电二季度营收400亿美元、同比增长34%，营业利润率60%，同时将2026年资本支出指引上调至600-640亿美元，并宣布在美国额外研究1000亿美元建厂。这些数字本身已经足够强劲，但对存储行业而言，更重要的信号在于：台积电的客户需要更先进的HBM、SOCAMM和企业级SSD。

ASML的二季度业绩同样对存储有利。其当季系统销售额中，韩国占比43%、台湾30%、中国14%。管理层对AI芯片和高数值孔径EUV的展望，意味着存储客户对先进逻辑芯片的需求将继续拉动HBM和高端DRAM的订单。

> **观察：** 台积电和ASML的业绩通常被视为逻辑芯片的风向标，但相关框架提示了一个反向传导逻辑——AI芯片的产能扩张会直接拉动HBM和eSSD的需求，存储不再是独立的周期性变量，而是AI资本开支的受益方。

## 3. 中国IC进口创纪录，存储占比过半

6月中国集成电路进口额达到596亿美元，同比增长72%，创历史新高。其中存储芯片进口在5月达到308亿美元，占全部IC进口的54%，同比增长249%。这一数据从需求侧印证了全球存储市场的表现。

智能手机方面，5月中国出货量同比增长19%，尽管DRAM供应仍在调整中。华为在二季度的市场份额从18%提升至23%，苹果和华为分别实现19-24%的同比增长，而其他主要品牌则出现10-22%的变化。市场集中度提升的趋势在存储消耗量上也有体现——高端机型对LPDDR5和更大容量NAND的需求明显高于中低端机型。

## 4. 一个可复用的观察框架：关注长期协议覆盖率和急单价格
