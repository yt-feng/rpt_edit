DRAM 价格变化超预期，存储行业趋势如何观察？

存储产品价格变化，比预期更为明显

近期有研究机构对DRAM三季度合约价进行了详细分析，得出的结论比市场此前预期更为积极。几个值得关注的点：

1️⃣ 服务器DRAM价格变化最为突出，环比上涨20%-30%，主要受高速LPDDR5需求推动。此前市场预期涨幅约20%，实际表现更高。即便是DDR4这类成熟产品，现货价格也在7月环比继续上行。

2️⃣ 长期协议之外的DRAM销售占比达60%-70%，这部分价格环比变化较为扎实，普遍在5%-10%。部分OEM厂商开始追加急单，不仅涉及DRAM，NAND产品也同步跟进。

3️⃣ 现货市场已连续上涨8周，DDR5和DDR4现货价格指向约20%的环比涨幅。虽然现货市场规模有限，但其信号意义值得留意——此前OEM厂商对高价持观望态度，如今为备战9月及四季度传统旺季，开始主动补充库存。

4️⃣ 台积电和ASML的财报也释放了积极信号。台积电二季度营收400亿美元，毛利率68%，全年资本支出上调至600-640亿美元。ASML二季度营收93亿欧元，三季度指引更高。这两家公司的客户需要更先进的HBM、SOCAMM和eSSD，对存储行业构成直接利好。

5️⃣ 中国6月芯片进口创历史新高，达596亿美元，同比增72%。其中存储芯片进口在5月已达308亿美元，占总进口的54%，同比增249%。需求端支撑较为坚实。

整体来看，三季度DRAM均价环比上涨21%的判断，比TrendForce的13%-18%更为乐观。NAND方面，7月现货价格也在回暖，1Tb wafer环比涨4%，三季度NAND ASP有望上涨10%以上。

存储产品价格变化周期仍在持续，但节奏和幅度需要持续观察。
