ZH_A: 最近英伟达发布了一款新的ARM架构服务器CPU，叫Vera，里面用了一种新的内存封装格式，叫SOCAMM2。这个变化到底意味着什么？

ZH_B: 简单说，市场担心这会冲击澜起科技和瑞萨电子这些内存接口芯片公司的市场空间。但我们认为，SOCAMM2大概率只会停留在英伟达自己的生态里，不会成为主流标准。

ZH_A: 所以这份报告真正要回答的问题就是——SOCAMM2到底会不会取代现有的DDR5 MRDIMM？

ZH_B: 对。核心判断是：不会。英伟达采用SOCAMM2，更多是出于自身系统级的能效优化，而不是内存技术的一次范式转变。

ZH_A: 那我先问一个最直接的问题——SOCAMM2和MRDIMM比，到底差在哪？

ZH_B: 简单说，SOCAMM2的带宽和容量都落后。比如MRDIMM能做到每颗CPU最高1.6TB/s的带宽和16TB的容量，而SOCAMM2只有1.2TB/s和1.5TB。差距很明显。

ZH_A: 那英伟达为什么还要用？

ZH_B: 因为英伟达更看重每瓦性能。SOCAMM2功耗比RDIMM低大约30%，在AI服务器里，CPU内存的功耗会挤占GPU的供电预算。所以对英伟达来说，省电比绝对性能更重要。

ZH_A: 那其他服务器CPU厂商会不会跟进？

ZH_B: 我们认为不会。x86和ARM阵营的CPU已经深度绑定了DDR生态，包括内存控制器、平台设计、软件认证，全都要重新做。切换成本太高，而且会失去向后兼容性。

ZH_A: 所以SOCAMM2对澜起和瑞萨的实际影响其实很小？

ZH_B: 对。SOCAMM2每个模块的接口芯片价值只有几美元，而MRDIMM是50到70美元。如果SOCAMM2成为主流，整个内存接口芯片市场会大幅缩水。但我们判断它只会局限在英伟达的CPU份额里，影响很小。

ZH_A: 那报告里有没有提到什么还没完全展开的问题？

ZH_B: 有几个。比如SOCAMM2在英伟达内部从LPDDR5升级过来，其实反而会带来一些增量接口芯片需求，这个影响还需要进一步量化。另外，Rambus目前在SOCAMM2接口芯片上领先，但技术壁垒不高，澜起和瑞萨能不能快速追上来，也需要后续观察。

ZH_A: 那最后简单总结一下，这份报告的核心投资结论是什么？

ZH_B: 维持对澜起科技和瑞萨电子的“增持”评级。SOCAMM2不会改变DDR在服务器市场的结构性主导地位。市场对替代风险的担忧被夸大了。

EN_A: Nvidia just announced their new ARM-based server CPU, Vera, and it uses a new memory package called SOCAMM2. So what’s the big deal here?

EN_B: Some investors worry this could shrink the total addressable market for memory interface chip suppliers like Montage and Renesas. But our view is that SOCAMM2 will likely stay niche to Nvidia. It’s not going to become the new standard.

EN_A: So the real question this report is trying to answer is whether SOCAMM2 will replace the existing DDR5 MRDIMM.

EN_B: Exactly. And our answer is no. Nvidia’s move is more about system-level power optimization than a memory technology inflection point.

EN_A: Let’s start with the obvious comparison. How does SOCAMM2 stack up against MRDIMM?

EN_B: In terms of pure bandwidth and capacity, MRDIMM wins. It can deliver up to 1.6 terabytes per second per CPU and up to 16 terabytes of capacity. SOCAMM2 gives you 1.2 terabytes per second and only 1.5 terabytes. The gap is significant.

EN_A: Then why would Nvidia choose it?

EN_B: Because Nvidia cares more about performance per watt. SOCAMM2 consumes about 30% less power than RDIMM. In an AI server, every watt you save on CPU memory can be redirected to GPU compute. So for Nvidia, the tradeoff makes sense.

EN_A: Will other server CPU makers follow suit?

EN_B: We don’t think so. x86 and other ARM CPU vendors are deeply integrated with the DDR ecosystem. Switching would require redesigning memory controllers, platform layouts, and requalifying the entire software stack. The switching costs are prohibitive, and they’d lose backward compatibility.

EN_A: So the impact on Montage and Renesas is actually quite limited?

EN_B: Yes. SOCAMM2 carries only a few dollars of interface chip content per module. MRDIMM carries 50 to 70 dollars. If SOCAMM2 became mainstream, the TAM would shrink. But we believe it will stay confined to Nvidia’s CPU volume, which is a very small slice of the overall market.

EN_A: Are there any open questions the report doesn’t fully answer?

EN_B: A few. For example, within Nvidia, the shift from soldered LPDDR to SOCAMM2 actually adds some incremental interface chip demand. That needs more quantification. Also, Rambus has a first-mover advantage in SOCAMM2 interface chips, but the technical barriers are low. It’s not yet clear how quickly Renesas and Montage can catch up.

EN_A: So what’s the bottom line for investors?

EN_B: We maintain our Outperform ratings on Montage and Renesas. SOCAMM2 does not change the structural dominance of DDR in the server market. The market’s fear of displacement is overstated.
