# Equinix：数据中心龙头的AI机遇

数据中心领域的领先企业，正在加速发展

某外资机构最新研究解读EQIX 2Q26

1/ 数据中心龙头Equinix近期发布了超出预期的业绩报告，核心亮点是显著上调了长期指引。年度AFFO每股增速从5-9%提升至9-12%，这一调整幅度在数据中心行业中较为少见。

2/ 资本开支同步有所提升，从每年30-40亿增加到50-70亿。初步来看幅度较大，但研究认为整体可控。约80%的资本投向已有设施的25个核心市场，开发回报表现达到中20%水平，优于行业平均水平。且公司无需通过股权融资，债务增量也较为有限。

3/ 本季度表现较为突出：连续第三个季度实现双位数MRR增长，新增9700个互联连接创下历史新高，互联收入同比增长约9%。调整后EBITDA利润率达到创纪录的53%。

4/ 值得关注的是，AI驱动的需求正在加速落地。前十大AI模型提供商中有8家、前十大云服务商中有8家都在使用EQIX的网络。研究梳理了四个AI应用场景：私有模型部署、数据主权合规、AI工厂训练、低延迟智能体工作负载。

5/ 公司正在执行“更大胆建设”战略，目前52个重大项目分布在33个市场，7月起已将7000多个机柜提前到今年交付。约30%的零售容量已提前售出，194个成熟资产整体利用率达82%，现金回报率27%。

6/ 研究给出的目标价1270美元，基于约25倍前瞻AFFO。核心逻辑是：即便AI需求存在不确定性，企业级托管需求本身具有较高的粘性和韧性，长期风险回报比相对均衡。
