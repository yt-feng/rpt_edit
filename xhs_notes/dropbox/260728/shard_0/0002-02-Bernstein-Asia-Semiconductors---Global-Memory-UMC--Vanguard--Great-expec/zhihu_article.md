# 台积电的一句话，让联电和世界先进的报价涨了150%，但这份研究说市场搞错了

过去半年，半导体成熟制程领域发生了一件很有意思的事。联电（UMC）和世界先进（Vanguard）的报价分别上涨了约150%和65%，市场给出的理由很清晰：一是涨价预期，二是台积电（TSMC）正在退出成熟制程，订单会“溢出”到它们身上。

这个逻辑听起来很顺畅，但一家研究机构却提出了一个尖锐的反问：**市场是不是在用一个错误的假设，去支撑一个过高的期待？**

这份报告的标题就很直白——“Great expectations but on false assumptions?”（伟大的预期，但基于错误的假设？）。它没有全盘否定这两家公司，而是逐一拆解了市场最看好的几个核心逻辑，结论是：联电和世界先进目前的报价，可能已经透支了未来好几年的利好。

我们来看看报告是怎么推演的。

## 台积电的“溢出效应”，可能只是个数字游戏

市场最核心的叙事是：台积电正在淘汰两座老旧晶圆厂（Fab 2 和 Fab 5），这些产能的客户会自然流向联电和世界先进。听起来像是“肉从台积电碗里掉出来，直接落进联电和世界先进的碗里”。

但报告计算了一个关键数据：台积电这两座厂的总产能，即使全部转移给联电和世界先进，也只占到它们两家合计6英寸和8英寸产能的8%-13%，占它们总产能的比例更是只有4%-6%。

**4%-6%是什么概念？** 这意味着，即使这个逻辑完全成立，对两家公司的营收和利润的边际贡献也相当有限。更关键的是，台积电在最近的财报电话会上明确表示，它正在日本和欧洲扩建成熟制程产能。换句话说，台积电不是在“退出”成熟制程，而是在“重新布局”。所谓的“溢出效应”，即便有，也远远不足以支撑报价弹性较高。

这里可以反问一句：如果台积电自己都在扩成熟制程，为什么市场会认为台积电的客户会大量流失到联电和世界先进那里？这个逻辑链条本身就有裂缝。

## 涨价故事：中国同行能涨，不代表联电能涨

2026年下半年，联电和世界先进确实成功上调了部分成熟制程的价格，涨幅约为高个位数百分比。市场因此预期后续还会有更多涨价。

但报告指出，这个涨价逻辑存在一个结构性问题：**中国晶圆代工厂的涨价，和联电、世界先进的涨价，是两回事。**

中国代工厂受益于本土化替代需求，且产能早已满载，涨价有坚实的供需支撑。而联电和世界先进面临的竞争环境不同——它们不仅要面对中国同行的价格压力，还要面对一个更宏观的隐忧：**高企的内存成本正在挤压下游客户的采购预算。**

台积电在财报会上说过一句话：“成熟制程的需求……并不强劲。”如果终端需求本身疲软，涨价就变成了“有价无市”。报告进一步担心，随着内存成本持续高企，下游客户可能会削减成熟制程的订单量，最终反噬联电和世界先进的产能利用率。

## 世界先进相对好一些，但也不是“捡钱”的机会

在联电和世界先进之间，报告认为世界先进相对更有韧性。原因在于它的产品结构：**超过75%的收入来自电源管理IC（PMIC）和CMOS图像传感器（CIS）。** 台积电明确表示，成熟制程中只有这两个细分领域需求还算强劲。世界先进恰好踩中了这个点。

此外，台积电因为CoWoS先进封装需求明显走强，需要将部分中介层（interposer）订单外包给世界先进。这对于世界先进在新加坡的12英寸新厂（VSMC）来说，是一个重要的需求支撑。VSMC的第一阶段产能（4.4万片/月）已经被长期协议锁定，首片40纳米晶圆已于2025年6月成功产出，预计2027年一季度进入量产。

但报告也同时指出，世界先进目前的报价已经隐含了这些利好。即使上调了目标价和估值倍数，其当前报价仍高于目标价约7%，加上约3%的股息率，整体回报空间并不诱人。

## 硅光子和3纳米：故事很性感，但落地还很远

联电最近宣布与SILITH合作生产光子集成电路（PIC），并获得了imec的技术授权。市场对此寄予厚望，认为这是联电切入高速数据传输市场的关键一步。

但报告的态度很冷静：**硅光子确实是一个有潜力的市场，但联电才刚刚起步，距离产生实质性收入可能还需要数年时间。** 作为对比，Tower Semiconductor的硅光子收入在2026年一季度同比增长了3倍，并已锁定了2027年13亿美元的收入合同，为此投入了9.2亿美元的资本开支。而联电目前尚未公布任何针对硅光子的专项资本支出计划。

另一个更宏大的叙事是联电与英特尔在3纳米制程上的合作。报告认为，这个合作“讨论有可能，但落地很难”。原因在于：联电在7纳米和5纳米上没有任何经验和客户基础，它能为3纳米合作带来的技术或客户资源非常有限。英特尔的3纳米产能目前几乎全部用于内部产品，要将其改造成“代工友好型”模式，需要巨大的工程投入和资本开支。对联电而言，这个负担可能太重了。

## 估值：即使修正后，联电仍高于疫情峰值

报告最核心的结论之一，是联电目前的估值仍然偏高。即使经历了近期的报价回调，联电的市净率（P/B）仍达到3.8倍，高于2022年新冠疫情导致全球芯片短缺时的峰值。

报告上调了联电的目标价，从47新台币提高到88新台币，但理由并非基本面大幅改善，而是因为其净资产回报表现（ROE）预期从疫情前的个位数提升到了15%-20%区间，因此给予了更高的估值倍数（从1.5倍P/B提高到2.5倍）。但即使如此，88新台币的目标价仍意味着较当前报价有约31%的下行空间。

**这里有一个值得思考的问题：** 当一家公司的报价在半年内翻了一倍多，而支撑其上涨的三大逻辑（台积电溢出、持续涨价、新业务突破）都被报告逐一质疑时，市场是在提前定价未来的增长，还是在为错误的假设买单？

## 写在最后

这份报告的价值不在于给出一个“买或卖”的结论，而在于它提供了一个**反常识的推演框架**。当市场情绪一致看好时，最需要问的问题往往是：“如果这些假设都不成立，会发生什么？”

完整报告里还有不少细节，比如对折旧费用、竞争格局、中国代工厂产能扩张的长期压力分析，这些内容更适合在社群里继续拆解。毕竟，研究的意义不在于知道结论，而在于理解推导过程。
