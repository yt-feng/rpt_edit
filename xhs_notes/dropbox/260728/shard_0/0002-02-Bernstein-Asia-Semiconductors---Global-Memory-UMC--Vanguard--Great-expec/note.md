半导体行业观察：联电与世界先进近期动态

📌 两大晶圆代工厂，市场预期或需重新审视

某机构最新研究指出，联电(UMC)和世界先进(Vanguard)今年以来市场表现分别达到150%和65%的涨幅，但支撑这一趋势的逻辑可能需要进一步验证。以下为几个关键观察点：

1️⃣ 台积电溢出订单≠直接利好
市场普遍认为台积电淘汰旧产线会带来订单转移，但研究测算：即便全部转移，也仅占联电和世界先进6英寸/8英寸产能的8-13%，占总产能的4-6%。同时，台积电在日本、欧洲持续扩产成熟制程，溢出效应相对有限。

2️⃣ 涨价逻辑的持续性待观察
2027年内存成本处于较高水平，成熟制程需求并不强劲。中国代工厂受益于本土化趋势，但联电和世界先进并不完全适用这些因素。研究认为，涨价预期已在当前报价中有所体现，后续空间需谨慎看待。

3️⃣ 世界先进相对稳健
75%以上收入来自电源管理IC和CMOS图像传感器，这两块是台积电提及需求尚可的领域。此外，承接台积电CoWoS中介层订单，新加坡12英寸厂投产确定性较高。

4️⃣ 联电的硅光子和3nm布局尚需时间
硅光子即便成功，也需要数年才能贡献业绩。至于与Intel合作3nm？联电缺乏7nm/5nm经验，合作落地概率较低。

研究给出：联电目标价88新台币（潜在调整幅度约31%），世界先进目标价146新台币（潜在调整幅度约7%）。
