存储芯片超级周期，能持续到2027？

📈 存储芯片景气周期远超预期

**存储芯片的超级周期，可能比想象中更长。**

某外资投行最新研报指出，存储芯片供需紧张格局有望延续到2027年甚至2030年。核心逻辑有五点：

1️⃣ **长协锁定利润**：大科技公司和OEM厂正大量签署长期供货协议（LTA）。未来存储芯片价格波动会变小，行业利润更稳定，类似台积电的商业模式。

2️⃣ **新厂建设困难**：建一座新晶圆厂成本极高，还面临地方政策、水电供应等限制。即便到2028年，产能扩张也有限。

3️⃣ **技术升级拉长周期**：从HBM到更先进制程，生产周期变长、良率降低，前道和后道设备尺寸更大。这导致有效产能释放速度变慢。

4️⃣ **资本开支翻倍**：尽管资本开支比正常周期翻了一倍多，但自由现金流仍在显著增长。说明需求太强，赚的钱远多于投入。

5️⃣ **HBM4已开始贡献收入**：美光HBM4已有10亿美元销售额，同时在全球多地（美国、台湾、新加坡、日本）启动新厂建设，并下了大量EUV光刻机订单。

💡 **价格竞争不会加剧**

一个容易被忽视的点：存储芯片大厂越来越多用长协锁定价格，产品也转向高端（HBM、SOCAMM、LPDDR5）。这意味着它们不再需要靠打价格战抢市场。像南亚科这种还在靠月度/季度议价的老牌厂商，处境会越来越被动。

📊 **数据验证景气度**

韩国6月前20天半导体出口同比增长188%，已连续5个月三位数增长。DRAM现货价连续5周上涨（累计+20%），NAND则小幅回落（-5%）。

研报小幅上调2026-2028年全球DRAM/NAND销售预测2-4%，主要反映2Q26均价超预期。2026年全球存储市场规模预计达8768亿美元，2027年将突破1.2万亿。
