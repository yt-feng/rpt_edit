# AI 存储需求从GPU蔓延到CPU，市场格局在变

**存储需求升级，不止GPU**

## 一份研报拆解存储行业新逻辑

最近在看某外资投行关于全球存储市场的深度研报，信息量很大，分享一下核心逻辑👇

**1/ AI计算从GPU延伸到CPU，存储需求更广了**

之前大家关注AI，目光都集中在GPU上。但现在CPU也开始承担AI任务——任务协调、状态管理、API执行这些工作负载在加速。

数据很直观：CPU与GPU的配比从23年的5.4:1，到25年变成3.2:1，预计28年进一步到2.4:1。这意味着服务器级DDR/LPDDR5的需求被大幅上修，27-28年增幅达20-22%。

研报测算，AI CPU的DRAM需求在27-28年将达到1100万/1700万GB，占整体市场需求的19%/24%。

**2/ 存储市场总规模在膨胀，供需缺口可能加大**

相比之前的模型，26-28年的存储TAM被上修了37-53%。供需缺口可能进一步恶化，理论上对DRAM/NAND价格形成支撑。

但研报认为价格趋势会相对稳定——因为长期协议合同销售占比在提升。预计存储TAM到27年将扩大至1.3万亿美元。

**3/ HBM的产能分配持续攀升，挤压传统DRAM**

HBM的需求增长太快了。研报上调了HBM的TAM预期，26-28年上调17-21%。关键变化：

- ASIC需求加速，位元占比从26年的33%升至27年的39%
- HBM与非HBM之间的每bit成本出现交叉，厂商有动力提高HBM报价

HBM需求三年复合增长率达85%，远超市场其他部分。DRAM晶圆产能分配给HBM的比例将从26年的24%升至28年的31%，对传统DRAM供给形成更大压力。

**4/ 存储正在变成战略资产**

存储占CSP硬件资本开支的比例，从AI初期的15%左右，预计今年将超过50%。

但很多投资者对存储价值占比继续提升表示担忧——这也是存储股相对于盈利仍存在折价的主要原因。不过，更高的CSP硬件支出和更长的投资周期，应该能缓解这些担忧。

**5/ 企业级SSD引领NAND扩张**

企业级SSD市场在26年将超过500EB（占NAND总需求的43%），未来两年以52%复合增速增长，预计达到1100EB以上。

考虑到ASP溢价，eSSD价值TAM可能超过3000亿美元（比HBM还大）。

**6/ 资本开支加速但仍有瓶颈**

存储厂商计划未来三年投入4500亿美元资本开支（比之前的预测增加50%）。DRAM端，EUV光刻机采购和基础设施是主要瓶颈；NAND端，大部分投入用于技术迁移，新产能要到28年下半年才见效。

**7/ 中国存储厂商份额在提升**

DRAM份额从25年的6%升至26-28年的8-11%，NAND从12%升至12-16%。但由于产品组合偏弱，价值份额增长有限（DRAM/NAND价值份额到28年预计为10%/12%）。

---

整体看，存储行业正从周期性转向结构性增长。AI带来的需求谱系在拓宽，传统的估值框架可能需要更新。
