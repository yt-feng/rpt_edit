# 市场对地平线的观察，研报认为“变化才刚开始”

市场反应或已过度

近期地平线报价出现明显调整，市场关注大客户转向自研、份额可能被压缩。但某外资机构最新研究观点不同：市场看到的是挑战，他们看到的是机遇。

1/ 比亚迪并非退出，而是升级
市场担心BYD自研芯片会替代地平线，但研报认为“天神之眼5.0”升级反而为地平线提供了平台更新的机会。通过J6系列+HSD组合，地平线有望在C/B两个版本上扩大份额。

2/ 护城河：全栈产品矩阵
从BPU、NPU工具链到SoC再到HSD，地平线为车企提供了较高的灵活度。即便是高度自研的车企，也可以借助地平线的架构进行底层支撑。J6M覆盖大众市场，J6B面向海外，J6H/P+HSD定位高端，全线布局。

3/ 真正的趋势是本土化
国产平台凭借成本、效率和政策支持，正加速替代海外方案。研报判断到2026-27年，本土参与者（包括自研和第三方）将持续获取海外对手的市场份额。行业格局偏向均衡，并非赢家通吃。

4/ 自研≠放弃
芯片迭代速度较快，主流车企较难实现全栈自研。参考智能手机发展历程，即使客户最终选择自研，地平线仍可收取授权费——类似ARM模式。在报价已调整较多后，风险回报比已向有利方向倾斜。

目前估值基本与Mobileye持平，但市场仅对ADAS业务进行了定价，AD的期权价值尚未充分体现。HSD 2.0刚于6月底开始推送，可能促使客户重新评估自研方案。后续若确认新定点，或成为潜在催化剂。
