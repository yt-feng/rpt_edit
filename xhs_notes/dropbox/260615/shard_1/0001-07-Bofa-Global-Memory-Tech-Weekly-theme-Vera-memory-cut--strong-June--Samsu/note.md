NVIDIA新CPU的存储容量没缩水

Vera存储不减量

市场传闻可能是误读

最近有个传闻挺有意思，说NVIDIA新款CPU Vera的存储容量要砍半，从1500GB降到750GB。我仔细翻了下研报，发现这个说法大概率不成立。

1/ **Vera Rubin依然是1500GB为主流**
- 带HBM4的Vera Rubin超算芯片，标配是192GB×8的SOCAMM，也就是1500GB
- 不带HBM的Vera CPU机架，可以用750GB（96GB×8），但初始出货也是1500GB
- 客户（Google、Amazon、微软、Meta）可以自己选配，但低配会影响性能

2/ **存储需求不仅没减，还多了增量**
- 初始SOCAMM订单都是给Vera Rubin的
- Vera CPU机架是新增需求，反而扩大了整体市场空间（TAM）
- 所以这波不是砍单，是扩容

3/ **行业数据也在印证景气度**
- 韩国6月上旬半导体出口创历史新高：110亿美元，同比+206%
- DDR4/DDR5现货价格周涨3-4%
- 台湾存储厂商5月营收同比暴涨：南亚科+730%，群联+301%
- 中国5月IC进口额567亿美元，同比+68%（虽然量跌1%，但价涨近70%）

4/ **三星可能成为高股息标的**
- 研报测算2026年自由现金流约200万亿韩元
- 50%派息率的话，股息可达50-70万亿
- 部分股息可能提前4-5个月发放
- 优先股对追求高股息的投资者更有吸引力

5/ **韩国投研会议即将召开**
- 6月15-19日，约200位投资者、120家企业参与
- 预计存储芯片短缺可能延续到2027-2028年
- 企业将展示在AI、机器人、军工等领域布局

存储芯片这轮周期看起来还在加速，不是减速。
