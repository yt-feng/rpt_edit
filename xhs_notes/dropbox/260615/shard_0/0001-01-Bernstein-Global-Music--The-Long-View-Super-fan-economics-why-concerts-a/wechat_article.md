# Bernstein：K-pop 的盈利重心已从卖专辑转向卖时间，演唱会才是真正的利润引擎

全球音乐产业的叙事正在经历一次静默但彻底的切换。过去二十年，K-pop 的增长故事几乎等于专辑销量的增长故事——实体销量、数字下载、流媒体播放量，构成了行业估值的核心锚点。但Bernstein最新发布的深度报告《Global Music: The Long View》提出了一个值得所有产业决策者认真审视的判断：这个模型已经过时了。

报告的核心主张非常清晰——K-pop 已经从以“单位”驱动的业务，转向了以“时刻”驱动的经济。粉丝不再为拥有产品付费，而是为与偶像共度的时间付费。演唱会，正在取代专辑，成为整个行业利润池的自然重心。这不仅仅是疫情后线下消费的报复性反弹，而是一个结构性的、不可逆的商业模式迁移。

这份Bernstein研报的洞察力不在于它发现了“演唱会赚钱”，而在于它揭示了这一转变背后的经济学逻辑：当资产价格膨胀，真正的稀缺资源不再是资本，而是时间。时间的价值在持续攀升，而实物商品的价值在相对下降。在这样的框架下，艺术家管理的本质，变成了如何最优地分配艺术家的时间，并最大化每一次互动的货币化效率。

以下是我们从这份报告中提炼出的五个核心洞察，以及一个报告尚未完全回答的关键问题。

## 1. 粉丝经济学正在从“拥有”转向“体验”，演唱会成为情感回报率最高的消费场景

报告提出了一个在咨询行业常被称为“情感回报率”的概念。粉丝愿意为一场两到三小时的演唱会支付远高于一张专辑的价格，不是因为演唱会本身作为“产品”的价值更高，而是因为它带来的情感回报密度更大。

在 K-pop 的语境中，一场演唱会结束后，价值并不会停止产生。它会通过社交媒体分享、粉丝二次创作、社群持续互动等方式，持续发酵数月。这意味着，一场演唱会实际上是一个“高杠杆”的情感资产——它撬动的后续价值远超其本身。报告指出，这种动态支撑了演唱会门票和捆绑体验的溢价定价，而这种定价在传统的产品逻辑下是难以成立的。

对于产业决策者而言，这意味着一个根本性的战略转向：不再是最大化艺术家的产出量，而是最大化艺术家与粉丝之间每一个触点的货币化深度。演唱会不再是一个孤立的活动，而是整个价值网络的枢纽。谁掌握了这个枢纽，谁就掌握了利润分配的主动权。




![研报原图 2](assets/source_image_02.jpg)

## 2. Hybe 将演唱会从“低利润活动”改造为“高利润节点”，规模优势是关键

传统意义上，演唱会是一门低利润率的生意。一旦计入高昂的舞台搭建成本、场地租金、以及主办方的分成，净利润率往往并不诱人。但Bernstein的报告指出，拥有大规模粉丝群体的顶级 IP 可以彻底改写这个公式。

Hybe 的案例就是最好的证明。报告数据显示，Hybe 在 2024 年一年内，在全球 53 个城市举办了 279 场演唱会，其中仅 BTS 就完成了超过 80 场全球售罄演出。这种规模不仅仅是数字上的震撼，它带来了一个关键的结构性优势：议价权。

当一个公司能够稳定地填满 5 万人容量的场馆，并且能够执行高密度的巡演计划时，它在与本地主办方谈判时的地位就完全不同了。Hybe 的全球规模使其减少了对本地主办方的依赖，从而能够保留更大比例的巡演经济收益。每一场演唱会，在 Hybe 的运营体系中，不再是一个独立的成本中心，而是一个“货币化节点”——门票、VIP 和声卡套餐、巡演限定周边、粉丝俱乐部会员、以及叠加的数字化内容，构成了一个完整的收入栈。

报告给出的判断是清晰的：Hybe 的演唱会利润率在结构上高于行业均值，而这正是其作为行业领导者的护城河之一。




![研报原图 3](assets/source_image_03.jpg)

## 3. 超级粉丝的生命周期价值正在被重新定义，流媒体与现场演出的闭环已经形成

报告揭示了一个值得关注的产业趋势：K-pop 超级粉丝的货币化正在成为一个强大的“飞轮”，连接了 Spotify 和 Live Nation 这两家看似不同赛道的公司。

这些超级粉丝已经在数字平台上表现出极高的 ARPU，他们是 Spotify 高级订阅的理想转化对象。而通过 Live Nation 的工具，这些数字端的消费行为可以直接转化为线下演唱会门票的购买。报告描述了一个清晰的闭环：Spotify 在线上的粉丝货币化，Live Nation 在线下的粉丝货币化，两者共同最大化粉丝的生命周期价值。

这个洞察对于理解整个音乐产业的竞争格局至关重要。过去，唱片公司、流媒体平台和现场演出公司是相对独立的价值链环节。但现在，随着超级粉丝的消费行为在线上和线下之间无缝切换，这些环节正在被整合成一个更紧密的生态系统。谁能够在这个生态系统中占据核心位置，谁就能分到最大的利润蛋糕。

Bernstein对 Spotify 和 Live Nation 均给出了“跑赢大盘”的评级，这本身就是一个信号：市场可能尚未充分定价这种线上线下协同效应带来的结构性增长。

## 4. K-pop 在全球巡演市场的份额正在逼近 10%，这不再是利基市场

报告中的一个数据点值得特别关注：K-pop 在全球 Top 100 巡演中的份额已经接近 10%。对于习惯了将 K-pop 视为“亚洲区域市场”或“粉丝亚文化”的投资者而言，这个数字应该是一个警醒。

10% 的份额意味着 K-pop 已经不再是全球现场娱乐生态中的小众品类。它正在以可量化的方式，从区域内容出口演变为全球性的现场体验消费品类。报告指出，Hybe 占据了 K-pop 演唱会收入的约 70%，这意味着它实际上已经将自己置于一个结构性的全球扩张市场之中，而非局限于国内偶像产业的竞争。

对于全球的现场娱乐公司、场馆运营方、以及品牌赞助商而言，K-pop 的崛起意味着一个新的、高消费力的受众群体正在形成。这个群体的消费行为模式与传统的摇滚或流行音乐粉丝不同——他们更倾向于为“体验”付费，更愿意为“稀缺”买单，并且具有极强的社交传播意愿。这不仅仅是市场份额的变化，更是消费逻辑的重塑。

## 5. BTS 的回归将验证“全平台变现”模型，尚未被充分定价的是 IP 所有者的议价权

报告将 BTS 的最新回归视为一个“全平台变现”模型的教科书式案例。一张新专辑、一个回归舞台、以及随即在全球平台上的霸榜——从 Spotify 到 Netflix，同一个 IP 在多个渠道同时产生收入。

报告指出，这种多平台同步变现的能力，正在将议价权从渠道方转移到 IP 所有者手中。当你的 IP 能够同时驱动 Spotify 的播放量、Netflix 的观看量、以及线下场馆的满座率时，你在与每一个平台谈判时的筹码都会增加。

但这里有一个报告尚未完全展开、但值得深入思考的问题：这种议价权的提升，究竟能带来多少实际的利润增量？Hybe 的估值倍数是 22.7 倍 2026 年预期市盈率，而 Universal Music 是 16.4 倍。市场似乎已经部分定价了 Hybe 作为 IP 所有者的溢价，但 BTS 回归后，这个溢价是否应该进一步扩大？报告没有给出明确的答案，但这恰恰是投资者需要持续跟踪的关键变量。

## 报告尚未完全回答的关键问题：Hybe 的“非 BTS” IP 能否复制同样的货币化效率？

报告的核心案例几乎全部围绕 BTS 展开。这本身不是问题——BTS 是 Hybe 最重要的资产，也是全球 K-pop 产业最成功的 IP。但一个理性的投资者必须追问：当 BTS 的活跃度进入自然周期，或者当新一代 IP 需要接棒时，Hybe 的“时刻经济”模型能否被同样高效地复制？

报告提到，Hybe 的新生代 IP 已经能够获得与全球顶级艺人相当的演唱会定价，这无疑是一个积极的信号。但定价能力并不等于利润结构。新生代 IP 的场馆规模、巡演密度、以及周边产品的渗透率，是否能够支撑与 BTS 类似的利润率？报告没有提供足够的数据来验证这一点。

这是一个需要持续观察的假设。如果 Hybe 能够证明其 IP 孵化体系可以系统性地产出具有全球定价权的艺人，那么其估值逻辑将从“拥有 BTS 的公司”升级为“拥有全球顶级 IP 孵化能力的平台”。反之，如果 BTS 的不可替代性过高，那么当前的估值溢价就可能面临修正。

## 给读者的观察框架：如何判断“时刻经济”是否真正落地

对于关注这一赛道的产业决策者和投资者而言，我们认为可以建立一个简单的观察框架，来验证Bernstein报告中的核心判断是否在实际经营中落地：

第一，关注演唱会收入占总收入的比重是否持续提升，以及更重要的，演唱会业务的利润率是否在改善。如果只是收入增长而利润率承压，那么“时刻经济”的叙事就需要打折扣。

第二，关注超级粉丝的 ARPU 变化。报告的逻辑链条中，一个关键假设是“更投入的超级粉丝群体支撑了更高的人均消费”。这个假设需要被实际数据验证。如果人均消费增速放缓，那么整个模型的增长上限就会受限。

第三，关注非 BTS IP 的全球巡演规模和定价能力。这是检验 Hybe 平台价值的最直接指标。如果新生代 IP 能够持续在全球范围内执行高密度、高定价的巡演，那么 Hybe 的护城河就远比市场想象的更深。

Bernstein的这份报告提供了一个有力的分析框架，但它提出的问题远比它回答的问题更有价值。K-pop 产业的“时刻经济”转型才刚刚开始，真正的胜负手，在于谁能将这种一次性的现场体验，转化为可持续的、可复制的商业模式。
