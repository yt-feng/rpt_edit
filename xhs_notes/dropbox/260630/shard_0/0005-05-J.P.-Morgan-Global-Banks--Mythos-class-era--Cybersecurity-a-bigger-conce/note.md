AI让银行更危险了，不是贷款那种

银行最大的隐形炸弹

前沿AI模型（比如Mythos、GPT-5.5）已经把发现系统漏洞的时间从几个月压缩到几小时。银行面临的核心问题，正在从“信用风险”转向“网络安全引发的流动性风险”。

1/ 谁最脆弱？
- 还在用几十年前COBOL代码的老系统银行
- 依赖外部供应商但对方修复速度慢的银行
- 多次并购后遗留多个旧平台的银行
- 拿不到最新AI防护技术的银行

2/ 为什么流动性比信用更危险？
社交媒体的传播速度，叠加AI攻击能力，银行挤兑可能会比CS事件更剧烈。某外资投行认为，应该用“存款流失压力测试”来评估银行韧性，而不是只看资本充足率。

3/ 怎么判断银行安全？
外部很难直接评估IT基础设施，所以研究者把“IT支出占运营成本比例”作为参考指标。2025年全球银行平均约17%，但美国大行绝对支出更高、技术更新更快，欧洲银行相对落后。

4/ 一些有意思的趋势
- 物理安全键（硬令牌）可能回归，因为AI让远程钓鱼太容易
- 新加坡银行已开始对数字交易设置冷静期
- 量子计算威胁下，以太坊已启动“后量子防护”路线图，目标2029年

5/ 保险越来越重要
2025年全球网络保险保费约150亿美元，预计2030年达280亿美元。金融行业是最大付费群体，未来监管可能强制银行买够网络保险。

6/ 一个值得关注的问题
AI既能帮银行更快发现漏洞，也能帮攻击者更低成本发起攻击。两条曲线的交点在哪里，决定了未来银行的安全边界。
