# 二季度数据观察：需求与供给的节奏差异

需求与供给的节奏差异

📌 6月数据延续结构性分化

1️⃣ 需求 vs 供给：差距明显
- 基建投资同比回落，房地产相关指标调整
- 零售销售小幅增长
- 工业产出受出口带动，创三个月新高

2️⃣ 传统与新兴行业
- 新能源、半导体、工业机器人、AI持续增长
- 钢铁、煤炭、水泥等传统行业继续调整

3️⃣ 内需与外需
- 出口仍是增长主要支撑
- 内需修复节奏相对偏慢

📌 关键数据一览
- 二季度GDP增速从5%调整至4.3%
- 零售销售6月仅增1%，低于一季度均值2.4%
- 固定资产投资连续两月同比下滑
- 房地产投资调整24.4%，新开工面积调整26%
- 工业产出逆势加速至5.3%，高技术制造业增长14%

📌 下半年展望
- 三季度动能预计延续当前节奏
- 四季度有望在政策支持下回升
- 8000亿新融资工具尚未落地，预计下半年启动
- 关注7月下旬和10月重要会议

研究认为，GDP增长与需求指标之间的差异，反映的是生产端统计与需求端感受的背离。出口韧性是当前宏观环境的重要支撑，但内需修复仍需政策持续发力。
