# 香港地产市场观察

📈 盈利变化趋势

某外资机构最新研究显示，香港地产公司经历2-3年盈利调整后，或将迎来多年度盈利回升📊

1️⃣ 盈利预测一览
- 长实集团：剔除一次性收益后核心利润+11%
- 恒基地产：受益于高利润项目入账，利润+42%
- 太古地产：香港住宅项目入账推动+13%
- 新鸿基地产：预计+5%，还有上行空间
- 新世界发展：可能继续调整但幅度收窄

2️⃣ 派息确定性
大部分公司至少维持派息不变：
- 新地、香港置地、长实：约5%增长
- 怡和、太古、九龙仓：2-3%增长
- 领展：基本持平
- 新世界：不派息

3️⃣ 子板块排序（2H26）
中央写字楼>住宅=内地零售=香港可选消费>香港必需消费>非核心写字楼>内地写字楼

4️⃣ 关注重点
- 开发商：楼价走势、新房去化率、销售数据
- 收租股：月度零售数据、写字楼租金
- 资本循环：香港置地、太古、领展、怡和、长实最积极

香港楼价年初至今已涨11%，后续走势值得观察。中央写字楼租金从低位回升9%，是亮点👀
