# 华润置地半年报前瞻：资产运营与价值释放的平衡

封面：资产运营承压，REITs探索新路径

上半年利润预计持平，关注三个关键点

某机构近期发布了华润置地2026年上半年业绩前瞻，核心逻辑清晰：上半年利润大概率同比持平，但结构分化明显。

1/ 利润的“加减法”
- 减：开发业务收入收缩（行业共性），毛利率可能低于2024年上半年的12.4%。部分城市房价持续调整，老旧低毛利项目减值计提可能超过15.5亿。
- 加：投资物业（租金）稳定增长（同比+13%），加上成都万象城REIT上市带来数十亿处置收益，基本对冲了开发端的压力。

2/ 上半年运营数据表现
- 合同销售增长6%至1170亿，表现优于国企同行平均水平（持平）
- 拿地强度26%，项目层面毛利率约24%，且通过收并购获取了部分低价土地
- 租金收入增速13%，明显高于同行（低个位数）

3/ 后续关注四个方向
- 管理层对存货减值规模和毛利率的指引
- 新C-REITs项目进展（成都万象城只是第一单）
- 万象城租户成本率（2025年为11.5%）和消费趋势
- 政策端：就业、消费信心、供给侧支持

估值面：当前公司报价对应2026年末净资产价值折让17%，市净率1.1倍，股息率4.5%，相比国企同行均值（38%折让、0.4倍市净率、2%股息率）仍有溢价。研究报告目标价36.6港元，较现价有约9%上行空间。
