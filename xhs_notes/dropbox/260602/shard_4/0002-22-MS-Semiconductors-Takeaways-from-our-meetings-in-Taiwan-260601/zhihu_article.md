### NVIDIA 的 CPU 业务竟然能做到 200 亿美元？解析 AI 芯片供应链的三大关键信号

最近关于 AI 芯片的讨论，似乎总在几个极端之间摇摆：一边是“算力需求见顶”的悲观论调，另一边是“芯片供不应求”的持续焦虑。市场对 NVIDIA 下一代 Rubin 架构的进展、AMD 在服务器 CPU 市场的份额变化，以及 ASIC 芯片是否会冲击 Broadcom 的统治地位，都存在不小的分歧。

一份来自投行的台湾调研纪要，恰好提供了观察这些分歧的一手视角。这份报告并非简单的“看好”或“看空”，而是通过实地走访供应链，给出了几个值得深思的结论。今天，我们就来拆解其中三个最反直觉、也最关键的信号。

### 核心判断：NVIDIA 的 Rubin 没有“跳票”，但市场可能低估了它的 CPU 野心

关于 NVIDIA 下一代架构 Rubin 的流言，最近确实不少。有说芯片需要重新流片（respin）的，有说量产进度大幅延后的，甚至有说会推出一个使用 HBM3e 内存的“缩水版”Rubin。但根据这份报告在台湾供应链多个环节的交叉验证，这些说法目前都缺乏证据。

报告明确指出，Rubin 的量产爬坡 **按计划进行**。虽然早期确实存在几周的“实施延迟”，但这与之前 Grace Blackwell 架构在机架层面遇到的严重挑战完全不同，对芯片本身的影响微乎其微。第一代芯片在性能上通常有优化空间，这是常态，但没有任何迹象表明 Rubin 会遇到 Blackwell 那样的系统级问题。Vera Rubin（后续增强版）的目标依然是成为“每 Token 成本最低的性能领导者”。

这其实引出了一个更值得关注的话题：市场对 NVIDIA 的 CPU 业务，似乎存在严重的认知偏差。

### 信号一：NVIDIA 的 200 亿美元 CPU 目标，可能比想象中更靠谱

NVIDIA 在最近的财报电话会议上抛出了一个令市场震惊的数字：今年 CPU 业务营收将达到 200 亿美元。这个数字让 NVIDIA 一跃成为服务器 CPU 市场的领导者之一。但市场普遍对此表示怀疑，很多人认为这 200 亿里包含了内存等其他产品的收入。

报告通过供应链调研，给出了一个相对清晰的拆解：这 200 亿美元中，大约 100-120 亿来自“头节点”（Head Node）CPU。这部分 CPU 通常与两颗 GPU、一颗 NVSwitch 和内存打包销售，价格本身就有一定的“任意性”。但关键在于，剩下的 70-100 亿美元，是来自独立的 Grace 或 Vera CPU 的销售。

这个数字之所以令人惊讶，是因为它意味着 NVIDIA 的 ARM 架构 CPU 正在被大量客户单独采购。报告提到，其 6 家已公布的客户，每家都可能带来数十亿美元的独立 CPU 订单。在目前 ARM 服务器 CPU 供应相对稀缺的环境下，NVIDIA 的 Grace/Vera 凭借已被验证的性能和充足的供应，成了一个非常有吸引力的选择。

这背后的逻辑是什么？可能指向一个更深层的问题：**服务器 CPU 市场可能正在经历一场“短缺”**。报告提到，目前 DRAM 的短缺是 AI 服务器建设的最大瓶颈，但 CPU 的短缺同样不容忽视。当 x86 阵营（Intel 和 AMD）的供应紧张、价格上升时，一部分需求自然会流向 ARM 架构的 NVIDIA。这对于长期被 x86 统治的服务器 CPU 市场来说，可能是一个结构性的变化信号。

### 信号二：Intel 的 18A 工艺取得进展，但代工业务的长期前景依然模糊

Intel 的“自救”故事中，18A 工艺和代工业务是关键一环。报告给出了一个谨慎乐观的判断：18A 工艺的进展确实在“更坚实的轨道上”。用于笔记本的 Panther Lake 芯片已经在该节点上流片，良率虽然在持续改善，但尚未达到经济目标，不过已经达到了“可靠”的水平。

然而，更关键的服务器芯片路线图，情况就没那么乐观了。报告认为，Intel 一些最核心的部件，未来仍然可能转向台积电。例如，明年发布的 Coral Rapids 服务器芯片将使用 18AP（18A 的增强版），但更长远看，台积电可能依然能提供更好的性能。在封装技术（EMIB）方面，也面临来自台积电的竞争，一些 EMIB 客户已经开始将台积电作为备选方案。

结论很清晰：**Intel 故事的核心，依然是其服务器 CPU 路线图的竞争力，而不是代工业务的“期权价值”**。短期内，由于服务器 CPU 的普遍短缺，Intel 或许能通过“超预期”来维持市场信心，但代工业务能否真正成为其第二增长曲线，目前还看不到清晰的路径。

### 信号三：关于 Broadcom 的 ASIC 份额之争，80/20 的分割可能是当前最现实的判断

AI 芯片的另一个热点，是定制 ASIC 芯片。Broadcom 为 Google 设计的 TPU 是其核心业务之一。但市场一直担心，Google 正在通过“客户自有工具”（Customer Owned Tooling）与联发科合作，开发更低成本的 ASIC，从而削弱 Broadcom 的份额。

这份报告给出了一个非常有意思的“内部辩论”视角。报告作者的观点是，Broadcom 长期仍能保持其 ASIC 客户 80% 以上的份额。这个判断与联发科自身宣称的“长期目标 15-20% 份额”是一致的。联发科虽然取得进展，但报告认为其存在潜在的“启动问题”。一个关键细节是，联发科试图通过绕过 Broadcom 来节省高带宽内存（HBM）的采购成本，但现实是，公开市场的 HBM 价格远高于 Broadcom 此前签订的合同价格。这意味着，所谓的“成本节约”可能并不成立。

当然，报告也诚实地指出，负责联发科的分析师团队持不同观点，他们认为联发科到 2028 年可能获得多数份额。这个分歧本身，就说明 ASIC 市场的竞争格局远未到尘埃落定的时候。在芯片真正量产之前，任何判断都带有预测性质。但从供应链的准备程度来看，**未来 2-3 年内，80/20 的份额分割，可能是更贴近现实的假设**。

### 总结：短缺、分歧与结构性变化

这份调研纪要揭示的，并非一个单一的“利好”或“利空”故事，而是一个充满结构性变化和分歧的市场。

1.  **NVIDIA 的统治力在深化**：不仅在 GPU 上，其 CPU 业务正在成为一个被低估的增长极。Rubin 的顺利推进，也意味着其产品迭代节奏并未被打乱。
2.  **CPU 市场正在经历“洗牌”**：x86 的短缺和价格上涨，正在为 ARM 架构（主要是 NVIDIA）创造窗口。Intel 的 18A 工艺虽进步，但远未能解决其长期竞争力问题。
3.  **ASIC 市场的“分蛋糕”游戏**：Broadcom 和联发科的竞争，最终取决于谁能提供更优的性价比，而不仅仅是技术本身。供应链成本和执行能力，将是决定胜负的关键。
4.  **内存瓶颈是真正的“灰犀牛”**：报告反复强调，DRAM 短缺是 AI 建设最大的瓶颈，且短期内看不到缓解迹象。这可能是整个 AI 芯片供应链中最需要关注的系统性风险。

这份报告的价值，不在于给出一个简单的“买什么”，而在于它通过一线调研，为我们提供了理解当前 AI 芯片产业复杂性的框架。关于 Intel 代工业务的长期前景、NVIDIA CPU 业务的具体客户结构、以及 ASIC 市场更详细的竞争分析，完整报告里还有不少细节，适合放在社群里继续拆解。
