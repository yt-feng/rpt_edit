# AI服务器带动高端CCL需求增长

高端CCL，供需格局持续变化

近期行业研究指出，高端CCL（铜箔基板）正进入新一轮价格调整与盈利改善周期。核心逻辑：AI服务器需求增长较快，高端产能供应相对紧张。

1/ 供需情况如何？
- 高端CCL需求2025-2028年复合增长率约96%
- 同期高端产能增长约22%
- 预计2026-2028年供需关系持续偏紧
- 整体CCL市场2028年规模约570亿美元，复合增长53%

2/ 价格变化的原因？
- 高端CCL价格调整主要受需求拉动
- AI客户对高质量CCL需求迫切，对价格调整接受度较高
- PCB厂商能将成本变化传导至终端客户
- 预计M7+等级CCL下半年价格有调整空间

3/ 哪些项目在推动？
- Nvidia Vera Rubin 8月启动量产
- AWS Trainium 3出货环比增长50%+
- Google TPU 9月开始出货
- 下一代服务器CPU从M6升级到M7，单机价值提升80%+

4/ 盈利改善情况如何？
- 两家主要厂商EMC和TUC：
  - 2Q26毛利率环比提升4.7/4.8个百分点
  - 3Q26再提升2.4个百分点
  - 预计到4Q26毛利率分别达37.4%/33.8%
  - 3Q26 EPS比市场预期高34%/21%

5/ 低端CCL方面？
- 消费电子需求相对平稳，手机/PC出货量变化不大
- 价格调整主要受材料成本影响
- 4Q26起价格调整速度可能放缓

两家高端CCL厂商合计占AI CCL市场50%+份额，且M7+产品占比持续提升。在供需偏紧格局下，盈利改善周期值得关注。
