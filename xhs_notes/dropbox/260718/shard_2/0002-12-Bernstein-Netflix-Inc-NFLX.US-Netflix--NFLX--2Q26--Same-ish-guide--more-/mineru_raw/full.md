# Netflix (NFLX) 2Q26: 指引维持，市场关注点增多

Netflix盘后交易报价下跌约9%，对应估值低于18x '27E 每股预期收益。虽然这一反应体现了近期市场参与者的观望情绪，但我们认为当前估值尚未充分反映Netflix的中长期潜力。用户增长、定价与利润率等基本面因素依然稳健，我们预计收入、利润率及盈利增长将符合公司管理层的目标。不过，Netflix短期内面临不少待解答的问题，且近期缺乏明显的积极催化因素。以下是我们关注的5个要点：

**数据层面。** 第二季度收入、营业利润及每股收益基本符合预期，但UCAN区域收入略低于预期。内容摊销费用低于预期，对盈利的小幅超预期有所贡献。

**收入指引维持区间，但市场期待更多。** Netflix维持全年收入增长14%的展望（取整后），但按固定汇率计算的收入增长预期从此前的11-13%区间收窄至12%。如先前讨论，这可能反映了上半年用户增长的挑战，并引发市场对增长是否比预期更快放缓的讨论。

**利润率仍为31.5%。** 上半年数据已出，Netflix对下半年的内容支出计划及广告收入与利润率的趋势应有较好的把握，这些因素本可支持对31.5%利润率目标的上调。管理层重申指引，让市场参与者讨论这是保守态度还是看到了需要谨慎的理由。目前来看，市场参与者似乎更倾向于后者，尤其是在下一次财报发布前缺乏明显短期催化因素的背景下。摘要续下页……

## 研究观点

我们维持对Netflix的“跑赢大盘”评级，目标价修订为\$95（下调\$5）。FY27每股收益预期上调主要源于第二季度股份回购加速，预计FY26总回购规模约为\$90亿（此前约为\$55亿）。FY26每股收益预期保持不变，因加速回购被第二季度高于预期的技术支出所抵消，导致FY26营业利润率略有下调（31.65% vs 此前约31.8%）。我们也将估值倍数下调1倍（从26倍至25倍），以反映近期缺乏正面催化因素的市场情绪。

## 详细分析

摘要续……

**最后，关于用户参与度。** Netflix指出，仅凭观看时长来衡量表现是不够的。例如，直播节目约占内容支出的5%，但仅占观看量的约1%，却在用户获取方面发挥了不成比例的作用——内容质量至关重要。不过，这些新用户最终也应会与更广泛的内容库互动，从而支持用户参与度的整体增长。虽然减少用户参与度披露的决定可能出于善意，但时机并未有助于改善市场情绪。在缺乏用户数据或其他运营健康领先指标的情况下，市场参与者可能更依赖第三方数据，由此产生的“噪音”短期内难以消退。

**预计Netflix将采取更多行动。** Netflix似乎正在积极应对用户参与度的挑战。其核心是增长问题，公司正在拓展新的内容形式和类别，包括中短视频、线性节目和竖屏内容，以深化用户参与度并维持长期增长。

NFLX在收盘后公布了2Q26业绩。

- 第二季度收入同比增长13%（按报告口径，按固定汇率计算增长12%），达到1260亿美元，略低于公司此前指引和市场一致预期。
- 按固定汇率计算，亚太地区收入增长领先，同比增长18%（含汇率影响为16%）。其次是拉丁美洲，按固定汇率计算同比增长16%（含汇率影响为21%）。EMEA地区按固定汇率计算同比增长11%（含汇率影响为14%），UCAN地区按固定汇率计算同比增长10%。
- 公司对3Q26的收入指引为1286亿美元，相当于同比增长11.7%，略低于市场一致预期。
- Netflix管理层提到，他们有三个重点领域以实现目标：1）为会员提供更多娱乐价值，2）利用技术改善服务，3）提升变现能力。
- Netflix表示将减少“What We Watched”报告的发布频率，从半年一次改为每年一次，该报告披露平台上的观看时长数据。
- 管理层解释称，观看时长与收入之间并非线性关系，他们衡量用户参与度的标准不仅包括观看时长，还包括内容的质量和多样性。例如，直播活动和动画各占内容预算的约5%，但分别占观看时长的1%和8%。公司估计，两者对业务的贡献价值相似，尽管动画的观看时长是直播活动的8倍，因为过去5年中，前10大新会员注册日中有6天来自直播活动。
- Netflix表示对早期视频播客的表现感到鼓舞。约一半的Netflix观看发生在晚间，但最近推出的视频播客在白天和移动设备上的观看比例更高，这表明用户参与度是增量性的。
- Netflix表示近期的价格调整进展顺利。此外，他们提到一直在测试吸引新会员的最佳方式，包括在多个国家为非重新加入的新会员测试免费试用，如果广告变现改善且不会对付费层级产生替代效应，未来甚至可能在某些情况下推出免费的广告支持层级。
- 利润率超出预期，达到33.4%。然而，3Q26的营业利润率指引仅为33.2%，低于市场一致预期的33.5%。管理层重申2026年摊销费用同比增长10%的指引（高于过去五年平均的8%）。2Q26摊销费用增长12.5%，但管理层仍预计下半年内容摊销增长将放缓。
- 2Q26自由现金流达到15亿美元（2Q25为22亿美元）。下降部分源于与WBD终止费相关的现金税支出增加。公司重申2026年全年自由现金流指引为125亿美元（此前因WBD终止费从上季度的110亿美元上调），并继续假设现金内容支出与内容摊销的比率约为1.1倍。
- 2Q26股份回购总额为47亿美元，为单季最高回购规模。自董事会4月批准额外250亿美元回购授权以来，公司目前剩余回购授权为271亿美元。

## 股票评级定义

## Bernstein品牌

Bernstein品牌根据未来12个月相对于特定市场指数的相对表现预测对股票进行评级：美国和加拿大交易所上市股票对标S&P 500，欧洲交易所及亚太地区以外新兴市场交易所上市股票对标Bloomberg Europe Developed Markets Large and Mid Cap Price Return Index EUR (EDME)，日本交易所上市股票对标Bloomberg Japan Large and Mid Cap Price Return Index USD (JPL)，亚洲（除日本）交易所上市股票对标Bloomberg Asia ex-Japan Large and Mid Cap Price Return Index (ASIAX)——除非另有说明。

Bernstein品牌有三个评级类别：

- **跑赢大盘**：股票将跑赢市场指数超过15个百分点
- **与大盘持平**：股票表现将与市场指数持平，偏差在+/-15个百分点以内
- **跑输大盘**：股票将落后市场指数超过15个百分点

**暂停覆盖**：Bernstein品牌下对某公司的覆盖已暂停。评级和目标价暂时失效，不再当前有效，因此不应依赖。

**未评级**：当目前无法准确估值股票或准确预测公司表现时分配的评级。覆盖分析师可能继续发布关于该公司的研究报告，以向读者更新事件和发展。

**未覆盖（NC）** 表示未在覆盖范围内的公司。

Bernstein品牌股票评级基于12个月时间跨度。

## Autonomous品牌——普通股

Autonomous品牌按如下方式对普通股进行评级。我们使用的基准为：欧洲银行和支付领域对标Bloomberg Europe 600 Financials Price Return Index (E600BK)和Bloomberg Europe Dev Mkt Financials Large and Mid Cap Price Ret Index EUR (EDMFI)，欧洲保险公司对标Bloomberg Europe 600 Insurance Price Return Index (E600IN)，美国银行和支付领域对标S&P 500和S&P Financials，美国保险领域对标S5LIFE，美国非寿险公司对标S&P Insurance Select Industry (SPSIINS)，新兴市场银行、保险公司和支付领域对标Bloomberg Emerging Markets Financials Large, Mid and Small Cap Price Return Index (EMLSF)。评级相对于行业（而非市场）表述。
