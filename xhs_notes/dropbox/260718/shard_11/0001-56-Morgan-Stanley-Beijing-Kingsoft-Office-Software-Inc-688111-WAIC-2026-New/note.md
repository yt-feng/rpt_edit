# WPS 365 正在进化成企业操作系统

**WPS 的 AI 进化**

某研究机构刚刚发了一篇关于金山办公在WAIC 2026上的观察，核心逻辑很清楚：AI正在模糊工具、助手和企业管理软件的边界。

1️⃣ **Lingxi Pro 个人办公助手**
对标腾讯元宝这类通用助手，但更聚焦办公场景。支持项目式上下文管理，能高质量执行任务，关键是可以直接在WPS和微软Office里用插件运行。本质上是一个专业办公版的AI Agent。

2️⃣ **WPS 365 升级为 WPS Comate**
这是最值得关注的变化。WPS 365从AI办公协作工具，转型为一站式办公工作平台，直接切入企业管理领域。新架构包含5个模块：
- WPS AI Hub（Token审计）
- WPS AI Docs（文档管理）
- WPS Data Hub（数据管理）
- WPS API Hub（软件系统集成）
- WPS Trust（安全）

3️⃣ **竞争壁垒在哪？**
研究认为金山办公的核心优势在于：完整的办公+协作套件、已有的云文档基础、以及对办公场景的垂直深耕。这三者结合，让它在AI时代有独特的切入点。

目前看，WPS正在把办公软件从“工具”变成“平台”，这个方向值得持续观察。你觉得传统办公软件的边界在哪里？
