# Kimi K3 模型观察：国产模型表现超预期

封面：K3 模型解析

国产模型性价比突出

某外资研究机构最新报告指出，Moonshot AI 发布的 K3 模型表现超出预期，在多个基准测试中与全球顶尖模型正面竞争。

1/ K3 核心亮点
- 首个开源 2.8T 参数模型，具备 1M 上下文窗口
- 在 Artificial Analysis 智能指数中排名第三，仅次于 Fable5 和 GPT-5.6 Sol
- Frontend Code Arena 排名第一，编码能力突出
- 在通用 Agent 和视觉 Agent 领域表现领先

2/ 架构创新带来成本优势
- Delta Attention 实现百万 token 上下文 6.3 倍解码加速
- Attention Residuals 以不到 2% 的额外成本提升 25% 训练效率
- Stable LatentMoE 框架下激活 896 专家中的 16 个
- 整体缩放效率相比 K2 提升 2.5 倍

3/ 性价比表现突出
K3 输入价格 3 美元/输出 15 美元，远低于 Claude Opus 4.8（5/25 美元）。国产模型在 MoE、线性注意力、MFU 等架构优化下，API 成本仅为美国模型的零头。

4/ 市场趋势：从聊天到工作
OpenRouter 数据显示，中国模型 token 消耗已超越美国模型。编码和 Agent 场景驱动需求增长，模型正从“聊天工具”转向“工作助手”。
